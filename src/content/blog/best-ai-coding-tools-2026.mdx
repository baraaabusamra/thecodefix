سوق أدوات الذكاء الاصطناعي للمبرمجين شهد نموًا ملحوظًا خلال السنوات الأخيرة. هاد دليل عربي مرتّب لأهم الفئات والأدوات المتاحة حاليًا، حتى تعرف وين تبلش بدون ما تضيع بين عشرات الخيارات.

## الفئة 1: الإكمال التلقائي داخل المحرر

أدوات تعمل كإضافة داخل محرر الكود يلي already تستخدمه، وتقترح كود أثناء كتابتك مباشرة:

- **GitHub Copilot** — الرائد الأصلي، مدمج بعمق مع GitHub
- **Tabnine** — يركّز على الخصوصية وتشغيل نماذج محلية

**الأفضل لـ:** مطورين يريدون تسريع الكتابة اليومية بدون تغيير أدواتهم.

## الفئة 2: محرّرات كاملة مبنية حول الذكاء الاصطناعي

محرّرات كود مستقلة (غالبًا مبنية على أساس VS Code) صُممت من الصفر حول فكرة الذكاء الاصطناعي كجزء أساسي، مو إضافة:

- **Cursor** — الأشهر بهذي الفئة، وضع Agent يخطط وينفّذ عبر عدة ملفات
- **Windsurf** — منافس مباشر بنفس الفكرة

**الأفضل لـ:** من يريد تجربة متكاملة، الذكاء الاصطناعي جزء من كل خطوة بالتطوير.

## الفئة 3: الوكلاء المستقلون (Agentic Tools)

أدوات تعمل من سطر الأوامر أو خلفية العمل، وتقدر تنفّذ مهام **كاملة** بشكل شبه مستقل (تخطيط، كتابة، اختبار، حتى فتح Pull Request):

- **Claude Code** — وكيل سطر أوامر، يدعم subagents متوازية لمهام مختلفة
- **OpenAI Codex** (بنسخته الوكيلية الحديثة)
- **GitHub Copilot Workspace** — وضع الوكيل من Copilot نفسه

**الأفضل لـ:** مهام طويلة ومعقّدة (ميزة كاملة، إصلاح باق كبير، refactor واسع).

## مصطلح جديد يستحق المعرفة: Vibe Coding

**Vibe Coding** مصطلح انتشر مؤخرًا، ويوصف أسلوب برمجة تعتمد فيه بشكل كبير على **وصف** ما تريده للذكاء الاصطناعي (بالحوار الطبيعي) بدل كتابة كل سطر يدويًا — يشتغل ممتاز للنماذج الأولية السريعة وتجربة الأفكار، لكن يحتاج مراجعة دقيقة وفهم حقيقي قبل أي استخدام بمشروع إنتاجي حقيقي.

## جدول اختيار سريع

| حجم المهمة | الأداة المناسبة |
|-------------|-------------------|
| إكمال سطر أو دالة أثناء الكتابة | Copilot / Tabnine |
| بناء ميزة متوسطة بواجهة مرئية | Cursor / Windsurf |
| مهمة كبيرة مستقلة (ميزة كاملة، باق معقّد) | Claude Code / أدوات الوكلاء |
| نموذج أولي سريع لفكرة | أي أداة بأسلوب Vibe Coding |

## نصيحة أخيرة

**الأداة لا تغني عن فهم البرمجة.** كل هاي الأدوات تحتاج شخصًا يفهم أساسيات البرمجة ليوجّهها بشكل صحيح، ويراجع نتيجتها، ويتأكد إنها آمنة وصحيحة. ابدأ دائمًا بتعلّم الأساسيات (راجع مسارات The Code Fix)، وبعدها استخدم هاي الأدوات لتسريع عملك، مو كبديل عن الفهم.
