عند بناء الواجهة الخلفية، يبرز إطاران شهيران: **Django** بلغة Python و
**Laravel** بلغة PHP. لنقارن.

## Django — قوّة Python 🎸

[Django](/learn/django) إطار [Python](/learn/python) يتبنّى مبدأ **"كل شيء
متضمّن"** (Batteries included)، فيوفّر لك أدوات جاهزة لكل شيء.

- ✅ لوحة تحكّم إدارية جاهزة
- ✅ أمان قويّ افتراضيًّا
- ✅ مثالي عند الحاجة لدمج الذكاء الاصطناعي

## Laravel — أناقة PHP 🔺

[Laravel](/learn/laravel) أشهر إطار [PHP](/learn/php)، يشتهر بصياغته الأنيقة
وسهولته.

- ✅ صياغة أنيقة وممتعة
- ✅ نظام بيئي غنيّ (Eloquent، Blade)
- ✅ انتشار ضخم في الويب

## جدول المقارنة

| الجانب | Django | Laravel |
|--------|--------|---------|
| اللغة | Python | PHP |
| الفلسفة | كل شيء متضمّن | أناقة ومرونة |
| لوحة الإدارة | جاهزة | عبر حزم |
| الذكاء الاصطناعي | سهل الدمج | محدود |

## كيف تختار؟

- تعرف/تفضّل **[Python](/learn/python)** أو تحتاج الذكاء الاصطناعي؟ → [Django](/learn/django).
- تعرف/تفضّل **[PHP](/learn/php)** وتريد إطارًا أنيقًا؟ → [Laravel](/learn/laravel).

## الخلاصة

الاختيار بين Django و Laravel غالبًا اختيار بين Python و PHP. كلاهما ممتاز
وموثوق، فاختر حسب لغتك المفضّلة وهدف مشروعك.

[ابدأ بمسار Django](/learn/django) أو [بمسار Laravel](/learn/laravel).
