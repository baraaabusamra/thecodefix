عند بناء الواجهة الخلفية، يبرز إطاران شهيران: **Django** بلغة Python و
**Laravel** بلغة PHP. لنقارن.

## Django — قوّة Python 🎸

[Django](/learn/django) إطار [Python](/learn/python) يتبنّى مبدأ **"كل شيء
متضمّن"** (Batteries included)، فيوفّر لك أدوات جاهزة لكل شيء.

- ✅ لوحة تحكّم إدارية جاهزة
- ✅ أمان قويّ افتراضيًّا
- ✅ مثالي عند الحاجة لدمج الذكاء الاصطناعي

## Laravel — أناقة PHP 🔺

[Laravel](/learn/laravel) أشهر إطار [PHP](/learn/php)، يشتهر بصياغته الأنيقة
وسهولته.

- ✅ صياغة أنيقة وممتعة
- ✅ نظام بيئي غنيّ (Eloquent، Blade)
- ✅ انتشار ضخم في الويب

## مثال عملي: جلب سجلّات من قاعدة البيانات

**Django ORM**:

```python
# جلب كل المستخدمين النشطين، مرتّبين بتاريخ الانضمام
active_users = User.objects.filter(is_active=True).order_by("-date_joined")
```

**Laravel — Eloquent**:

```php
// نفس الاستعلام بالضبط بصياغة Laravel
$activeUsers = User::where('is_active', true)->orderBy('created_at', 'desc')->get();
```

الاثنان يقدّمان ORM قويًّا بصياغة "طبيعية" قريبة من الإنجليزية بدل SQL خام،
والفرق الحقيقي بينهما فلسفي أكثر منه تقني: Django يفرض عليك بنية مشروع
موحّدة (apps، models، views) فتجد كل مشاريع Django متشابهة البنية، بينما
Laravel أكثر مرونة في التنظيم — حرّية أكبر، لكن اتساق أقلّ بين المشاريع
المختلفة.

## جدول المقارنة

| الجانب | Django | Laravel |
|--------|--------|---------|
| اللغة | Python | PHP |
| الفلسفة | كل شيء متضمّن | أناقة ومرونة |
| لوحة الإدارة | جاهزة (Django Admin) | عبر حزم خارجية (Filament، Nova) |
| الذكاء الاصطناعي | سهل الدمج | محدود |
| نظام القوالب | Django Templates | Blade |
| بنية المشروع | موحّدة ومفروضة | مرنة، حسب اختيار المطوّر |

## خطأ شائع عند الاختيار

اختيار الإطار بناءً على "أيّهما أحدث موضة" بدل اللغة التي يعرفها فريقك فعليًّا
قرار مكلف. كلا الإطارين ناضج ومستقرّ وموثّق جيّدًا؛ الفارق العملي الحقيقي
في 90% من المشاريع هو ببساطة: هل فريقك يعرف Python أم PHP؟ ابدأ من هناك.

## كيف تختار؟

- تعرف/تفضّل **[Python](/learn/python)** أو تحتاج الذكاء الاصطناعي؟ → [Django](/learn/django).
- تعرف/تفضّل **[PHP](/learn/php)** وتريد إطارًا أنيقًا؟ → [Laravel](/learn/laravel).

## الخلاصة

الاختيار بين Django و Laravel غالبًا اختيار بين Python و PHP. كلاهما ممتاز
وموثوق، فاختر حسب لغتك المفضّلة وهدف مشروعك.

[ابدأ بمسار Django](/learn/django) أو [بمسار Laravel](/learn/laravel).
