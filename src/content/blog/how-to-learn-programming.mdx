تعلّم البرمجة من الصفر ليس صعبًا كما يبدو — يحتاج فقط **خطة واضحة والتزامًا**.
في هذا الدليل نضع لك مسارًا عمليًا بالعربي يأخذك من الصفر إلى بناء مشاريع حقيقية.

## 1. حدّد هدفك أولًا

قبل اختيار اللغة، اسأل نفسك: ماذا تريد أن تبني؟

- **مواقع ويب؟** ابدأ بـ [HTML](/learn/html) و [CSS](/learn/css) ثم [JavaScript](/learn/javascript).
- **تطبيقات موبايل؟** تعلّم [Flutter](/learn/flutter).
- **ذكاء اصطناعي وتحليل بيانات؟** ابدأ بـ [Python](/learn/python).

## 2. أتقن الأساسيات قبل أي شيء

لا تقفز بين اللغات. ركّز على مفهوم واحد حتى تتقنه:

1. المتغيّرات وأنواع البيانات
2. الشروط والحلقات
3. الدوال
4. المصفوفات والكائنات

## 3. تعلّم بالممارسة لا بالمشاهدة فقط

> القاعدة الذهبية: لكل ساعة مشاهدة، اقضِ ثلاث ساعات في كتابة الكود بنفسك.

استخدم [محرّر الأكواد التفاعلي](/playground) وجرّب كل ما تتعلّمه فورًا.

## 4. ابنِ مشاريع صغيرة

بعد كل مفهوم، ابنِ شيئًا: آلة حاسبة، قائمة مهام، صفحة شخصية. المشاريع هي ما
يثبّت المعلومة ويبني معرضك (Portfolio).

## 5. خطة 6 أشهر مقترحة

| الشهر | التركيز |
|-------|---------|
| 1–2 | HTML + CSS + بناء صفحات |
| 3–4 | JavaScript + مشاريع تفاعلية |
| 5 | إطار عمل ([React](/learn/react)) |
| 6 | مشروع متكامل + [Git](/learn/git) |
