في عالم تطوير أندرويد، **Kotlin** و **Java** هما الخياران الرئيسيان. لنفهم الفرق
ولماذا تتصدّر Kotlin اليوم.

## Java — الأساس الكلاسيكي ☕

[Java](/learn/java) كانت اللغة الأصلية لأندرويد لسنوات طويلة، وما زالت تشغّل
ملايين التطبيقات.

- ✅ ناضجة ومستقرّة ومنتشرة
- ✅ مكتبات ضخمة وكود وفير
- ❌ أكثر إطالةً (verbose) وعرضةً لأخطاء null

## Kotlin — الحداثة والإيجاز 🟣

[Kotlin](/learn/kotlin) هي اللغة الرسمية الموصى بها من جوجل لأندرويد.

- ✅ كود أقصر وأوضح
- ✅ أمان من أخطاء null المدمج
- ✅ تتوافق 100% مع Java

## جدول المقارنة

| الجانب | Java | Kotlin |
|--------|------|--------|
| الإيجاز | أطول | أقصر بكثير |
| أمان null | يدوي | مدمج |
| توصية جوجل | قديمة | الرسمية الحالية |
| التوافق | — | متوافقة مع Java |

## كيف تختار؟

- تبدأ **مشروع أندرويد جديدًا**؟ → [Kotlin](/learn/kotlin) هي الخيار الموصى به.
- تعمل على **كود قديم أو تريد فهم الأساس**؟ → [Java](/learn/java) مفيدة.

## الخلاصة

Kotlin هي حاضر ومستقبل أندرويد بإيجازها وأمانها، لكن Java ما زالت أساسًا مهمًّا.
تعلّم Kotlin للمشاريع الجديدة.

[ابدأ بمسار Kotlin](/learn/kotlin) أو [بمسار Java](/learn/java).
