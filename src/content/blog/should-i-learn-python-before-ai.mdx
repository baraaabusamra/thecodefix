سؤال شائع جدًا: **"هل لازم أتعلم Python قبل ما أبدأ ذكاء اصطناعي؟"** الجواب المختصر: **نعم، لكن أساسيات Python فقط**، وليس Python كاملاً.

## متى يجب أن تتعلم Python أولًا

إذا كنت **مبتدئًا تمامًا في البرمجة**، تعلّم أساسيات Python أوّلًا ثم ابدأ الذكاء الاصطناعي. الأسباب:

- **Python هي لغة الذكاء الاصطناعي الأولى**. NumPy، Pandas، scikit-learn، PyTorch — كلها مكتبات Python.
- **المفاهيم تتداخل**: حين تبدأ AI بدون أساس Python، ستقضي وقتك في البحث عن أخطاء syntax بدل فهم النموذج.
- **التركيز الذهني**: تعلّم موضوع واحد في كل مرة أنجع من تعلّم موضوعين معًا.

## ما الحد الأدنى من Python الذي تحتاجه؟

يكفي إتقان هذه الأساسيات فقط:

- **المتغيرات وأنواع البيانات** (int, float, str, bool).
- **الشروط** (`if / elif / else`).
- **الحلقات** (`for` و `while`).
- **الدوال** (`def`).
- **القوائم والقواميس**.
- **الاستيراد** (`import`).

هذا ما يغطّيه تقريبًا أول 15 درسًا من [مسار Python الكامل على The Code Fix](/learn/python/00-intro).

## ما الذي لا تحتاج تعلّمه في البداية

اترك هذه حتى تحتاجها:

- **OOP المتقدّم** (classes, inheritance) — ستتعلمها عند بناء نماذج PyTorch.
- **Decorators و Generators** — مفيدة لكن متقدمة.
- **Async/Await** — غير ضروري لمعظم مشاريع AI.
- **Type hints** المتقدّمة — تأتي لاحقًا مع فهم أعمق.

لا تحاول إتقان Python "كاملة" قبل البدء — هذا فخ. تعلّم حسب الحاجة.

## إذا كنت تعرف لغة برمجة أخرى

ربما لا تحتاج Python "من الصفر". تعلّم سريع ثم ابدأ:

- **تركيب Python** (indentation, no semicolons, no curly braces).
- **القوائم والقواميس** (قريبة من JSON).
- **Pip و venv** (إدارة الحزم والبيئات).
- **NumPy و Pandas** مباشرة.

ثم ابدأ المسار العملي للذكاء الاصطناعي.

## خطّة عملية

### 1. الأساسيات (2–3 أسابيع)

إذا كنت مبتدئًا:

### 2. أدوات Python الإضافية (أسبوع واحد)

- [الوحدات و PIP والبيئات](/learn/python/16-modules-pip) — لفهم `import` و venv.

### 3. بيئة AI (يوم واحد)

- [بيئة Python للذكاء الاصطناعي](/learn/ai-ml/10-python-ai-env) — إعداد venv خاص بمشروع AI.

### 4. مسار AI (4+ أسابيع)

- [ما هو تعلّم الآلة؟](/learn/ai-ml/00-intro) → الدروس التالية في المسار.

## لماذا Python بالذات؟

- **مكتبات ناضجة**: NumPy، Pandas، scikit-learn، PyTorch — كل واحدة منها تختصر أشهر عمل.
- **مجتمع ضخم**: أي مشكلة ستواجهها، هناك Stack Overflow أو GitHub يحلّها.
- **تركيب واضح**: `import pandas as pd; df.head()` — شبه طبيعي.
- **دعم أدوات AI نفسها**: مكتبات النماذج اللغوية الكبيرة (Hugging Face، OpenAI SDK) كلها Python-first.

لغات أخرى (R، Julia، C++) لها وجود في AI، لكن **Python هي الخيار العملي الأول**.

## أسطورة شائعة: "لازم أتعلم Python كاملة قبل AI"

**لا**. سترى مهندسين ومهندسات AI يستخدمون Python بشكل سطحي لكن فعّال. لا أحد يحفظ توثيق Python كاملاً. الجميع يستخدم Stack Overflow والـ AI assistants (نعم، يستخدمون AI لتعلّم AI) لملء الفجوات.

## الخلاصة

- **تعلّم أساسيات Python أولًا** (2–3 أسابيع لمبتدئ).
- **ثم ابدأ مسار AI** — حيث ستتعلم Python أعمق تدريجيًا حسب حاجتك.
- **لا تحاول إتقان Python كاملة** قبل البدء — هذا يطيل الطريق بدون داعٍ.
