## الإدراج

```swift
let name = "براء"
let age = 25
print("اسمي \(name) وعمري \(age)")
```

## دوال شائعة

```swift
let s = "Hello Swift"
print(s.count)                // 11
print(s.uppercased())         // HELLO SWIFT
print(s.lowercased())
print(s.contains("Swift"))    // true
print(s.hasPrefix("Hello"))   // true
print(s.replacingOccurrences(of: "Hello", with: "Hi"))
```

## الدمج

```swift
let a = "مرحبًا"
let b = "بالعالم"
let c = a + " " + b
var greeting = "أهلًا"
greeting += " بك"
```
