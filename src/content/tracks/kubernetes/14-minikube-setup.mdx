قبل نشر أي تطبيق على Kubernetes، تحتاج عنقودًا للتجربة. **Minikube** يمنحك عنقودًا كاملًا على جهازك مجّانًا. درس عملي يبني على [ما هو Kubernetes؟](/learn/kubernetes/00-intro).

> ⚠️ الأوامر تمثيلية وتحتاج تشغيلًا على جهازك للتأكّد. Minikube يتطلّب أداة حاويات أو مُحاكيًا (مثل [Docker](/learn/docker/00-intro)) مثبّتًا مسبقًا.

## المتطلّبات المسبقة

- أداة `kubectl` (عميل Kubernetes) و`minikube` مثبّتان.
- بيئة تشغيل حاويات (Docker مثلًا).

## الخطوة 1: ابدأ العنقود

```bash
minikube start
```

يُنشئ Minikube عنقودًا من عقدة واحدة على جهازك، ويُهيّئ `kubectl` للتخاطب معه تلقائيًا.

## الخطوة 2: تحقّق أنّ العنقود يعمل

```bash
kubectl get nodes
```

يجب أن ترى عقدةً واحدة بحالة `Ready`. هذا يؤكّد أنّ العنقود جاهز وأنّ `kubectl` متّصل به.

## الخطوة 3: استكشف العنقود

```bash
kubectl cluster-info          # معلومات مستوى التحكّم
kubectl get pods -A           # كل الـ pods (بما فيها مكوّنات النظام)
minikube dashboard            # لوحة تحكّم رسومية في المتصفّح
```

لوحة التحكّم مفيدة للمبتدئين لرؤية الموارد بصريًّا.

## الخطوة 4: الإيقاف والحذف

```bash
minikube stop      # إيقاف العنقود مع الاحتفاظ به
minikube delete    # حذف العنقود كليًّا لتحرير الموارد
```

## أخطاء شائعة

- **فشل البدء**: تأكّد أنّ بيئة الحاويات (Docker) تعمل قبل `minikube start`.
- **`kubectl` لا يتّصل**: تأكّد أنّ العنقود يعمل، وأنّ السياق (context) مضبوط على minikube.
