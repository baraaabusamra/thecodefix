## أين أنا؟

```bash
pwd          # يطبع المجلّد الحالي
```

## عرض المحتويات

```bash
ls           # قائمة بالملفّات
ls -l        # تفاصيل (صلاحيات، حجم، تاريخ)
ls -a        # يشمل المخفيّة (تبدأ بنقطة)
ls -lh       # أحجام مقروءة (KB/MB)
```

## التنقّل

```bash
cd /home/user    # مسار مطلق (يبدأ بـ /)
cd Documents     # مسار نسبي
cd ..            # المجلّد الأعلى
cd ~             # المجلّد الرئيسي (home)
cd -             # المجلّد السابق
```

## بنية الأدلّة المهمّة

| المسار | المحتوى |
|------|------|
| `/` | الجذر |
| `/home` | مجلّدات المستخدمين |
| `/etc` | ملفّات الإعداد |
| `/var` | السجلّات والبيانات المتغيّرة |
| `/usr` | البرامج |
