## شجرة واحدة تبدأ من /

في Windows لكل قرص حرف (`C:` و`D:`). في Linux **كل شيء** شجرة واحدة جذرها `/`، والأقراص الإضافية والذاكرات تُربط (mount) كمجلّدات داخلها. وفي Linux "كل شيء ملف" تقريبًا: حتى الأجهزة لها ملفات في `/dev`.

## أين أنا؟

```bash
pwd          # print working directory: المجلّد الحالي
# /home/baraa
```

كل أمر تشغّله يعمل نسبة إلى **مجلّد العمل الحالي**. معظم أخطاء "No such file or directory" سببها أنك لست حيث تظنّ.

## عرض المحتويات

```bash
ls              # الأسماء فقط
ls -l           # تفاصيل: صلاحيات، مالك، حجم، تاريخ
ls -a           # يشمل المخفيّة (أسماؤها تبدأ بنقطة مثل .bashrc)
ls -lh          # أحجام مقروءة: 4.0K و 12M بدل البايتات
ls -lt          # الأحدث تعديلًا أولًا
ls /etc         # محتويات مجلّد آخر دون الانتقال إليه
```

الملفات المخفيّة ليست سرّية؛ هي فقط لا تظهر افتراضيًا حتى لا تزحم العرض. ملفات الإعداد (`.bashrc` و`.gitignore` و`.env`) كلها مخفيّة بهذا الأسلوب.

## التنقّل بـ cd

```bash
cd /var/log      # مسار مطلق: يبدأ بـ / من الجذر
cd nginx         # مسار نسبي: من حيث أنت الآن
cd ..            # المجلّد الأعلى (الأب)
cd ../..         # مستويان للأعلى
cd ~             # مجلّدك الرئيسي (أو cd وحدها)
cd -             # المجلّد السابق: مفيد للتنقّل بين مكانين
```

### مطلق أم نسبي؟

- **المسار المطلق** (`/home/baraa/app/config.yml`) يعمل من أي مكان، لأنه يبدأ من الجذر. استخدمه في السكربتات ومهام cron، لأنها قد تعمل من مجلّد غير متوقّع.
- **المسار النسبي** (`app/config.yml`) أقصر، لكنه يعتمد على مكانك الحالي.

ورموز خاصة: `.` المجلّد الحالي، و`..` الأب، و`~` مجلّدك الرئيسي. لذلك `./script.sh` تعني "شغّل script.sh الموجود **هنا**".

## المجلّدات المهمّة

| المسار | ماذا فيه |
| --- | --- |
| `/` | الجذر: بداية كل شيء |
| `/home` | مجلّدات المستخدمين (`/home/baraa`) |
| `/root` | مجلّد المستخدم root (ليس داخل `/home`) |
| `/etc` | ملفات الإعداد: nginx وssh وقوائم المستخدمين |
| `/var` | بيانات متغيّرة: السجلّات (`/var/log`)، ومواقع الويب أحيانًا (`/var/www`) |
| `/usr` | البرامج المثبّتة ومكتباتها (`/usr/bin`) |
| `/tmp` | ملفات مؤقتة، تُحذف غالبًا عند إعادة التشغيل |
| `/dev` | ملفات الأجهزة (الأقراص `/dev/sda`) |
| `/proc` | معلومات حيّة عن العمليات والنظام (ملفات وهمية تولّدها النواة) |

حين تبحث عن إعداد خدمة فابدأ بـ `/etc`، وحين تبحث عن سبب خطأ فابدأ بـ `/var/log`.

## مثال: جولة على خادم

```bash
cd /etc/nginx           # إعدادات nginx
ls sites-enabled/       # المواقع المفعّلة
cd /var/log/nginx       # سجلّاتها
ls -lt | head -3        # أحدث 3 ملفات سجلّ
cd -                    # ارجع إلى /etc/nginx
```

## أخطاء شائعة

- **مسار نسبي في سكربت أو cron:** يعمل حين تشغّله من مجلّد المشروع ويفشل من غيره. استخدم مسارات مطلقة.
- **`cd` إلى مجلّد باسم فيه مسافة بلا تنصيص:** `cd "My Documents"`.
- **الخلط بين `/home` و`~`:** `~` هي `/home/اسمك` تحديدًا، و`/home` المجلّد الذي يحتوي كل المستخدمين.
- **نسيان `./` قبل سكربت في المجلّد الحالي:** `script.sh` وحدها تبحث في `PATH` فقط، فتعطي `command not found`.
- **البحث عن ملف مخفيّ بـ `ls` العادية:** أضف `-a`.
