## ما هو Linux؟

**Linux** نظام تشغيل مفتوح المصدر، مجاني وقوي، يشغّل معظم **الخوادم** في
العالم، والهواتف (أندرويد مبني عليه)، والأنظمة المدمجة.

## لماذا يتعلّمه المطوّر؟

- معظم الخوادم تعمل بـ Linux — ستتعامل معه عند النشر.
- سطر الأوامر أسرع وأقوى من الواجهة الرسومية.
- أساسي لـ DevOps و Docker والسحابة.

## ما هو سطر الأوامر (Terminal)؟

واجهة نصّية تكتب فيها **أوامر** للتحكّم بالنظام، بدل النقر بالفأرة. أسرع
وأكثر دقّة للمطوّرين.

## أول الأوامر

```bash
pwd        # أين أنا؟ (المجلد الحالي)
whoami     # من أنا؟ (اسم المستخدم)
date       # التاريخ والوقت
clear      # تنظيف الشاشة
```

## بنية الأمر

```bash
command -options arguments
```

مثال:

```bash
ls -l /home    # ls = الأمر، -l = خيار، /home = وسيط
```

## الحصول على مساعدة

```bash
man ls       # دليل الأمر الكامل
ls --help    # ملخّص سريع
```
