## if: يفحص رمز الخروج

في Bash، `if` لا تفحص قيمة صحيحة أو خاطئة كما في اللغات الأخرى، بل **رمز خروج أمر**: `0` يعني نجاح، فيُنفَّذ الفرع:

```bash
if grep -q "root" /etc/passwd; then
    echo "المستخدم root موجود"
fi
```

أما `[[ ... ]]` فهو أمر مدمج يفحص شرطًا ويُرجع 0 أو 1:

```bash
age=20
if [[ "$age" -ge 18 ]]; then
    echo "بالغ"
elif [[ "$age" -ge 13 ]]; then
    echo "مراهق"
else
    echo "طفل"
fi
```

### `[[ ]]` أم `[ ]`؟

`[ ]` (أو `test`) هي الصيغة القديمة المتوافقة مع كل الـ Shells، و`[[ ]]` نسخة Bash الأأمن. في سكربتات Bash فضّل `[[ ]]`:

```bash
name=""
# [ $name = "admin" ]      # ❌ تصبح [ = "admin" ] : unary operator expected
[[ $name = "admin" ]] || echo "ليس مديرًا"   # ✅ تعمل حتى مع متغيّر فارغ
```

`[[ ]]` لا تقسم المتغيّرات عند المسافات، وتدعم `&&` و`||` داخلها، ومطابقة الأنماط. لكن عادة التنصيص (`"$name"`) جيدة على أي حال.

### عوامل المقارنة

| للأرقام | للنصوص | المعنى |
| --- | --- | --- |
| `-eq` | `==` | يساوي |
| `-ne` | `!=` | لا يساوي |
| `-gt` و`-lt` | | أكبر، أصغر |
| `-ge` و`-le` | | أكبر أو يساوي، أصغر أو يساوي |
| | `-z "$s"` | النص فارغ |
| | `-n "$s"` | النص غير فارغ |

لا تستخدم `>` و`<` للأرقام داخل `[ ]`: هناك تعني إعادة توجيه، فتنشئ ملفًا اسمه بالرقم! للأرقام استخدم `-gt` أو `(( a > b ))`.

## فحص الملفات

```bash
config="/etc/hostname"
if [[ -f "$config" ]]; then echo "ملف موجود"; fi
if [[ -d /tmp ]]; then echo "مجلّد موجود"; fi
if [[ ! -e "/no/such/path" ]]; then echo "غير موجود"; fi
if [[ -r "$config" && -s "$config" ]]; then echo "قابل للقراءة وغير فارغ"; fi
```

`-f` ملف عادي، و`-d` مجلّد، و`-e` موجود بأي نوع، و`-r` و`-w` و`-x` الصلاحيات، و`-s` حجمه أكبر من صفر، و`!` النفي.

## for

```bash
for name in سارة علي براء; do
    echo "أهلًا $name"
done

for i in {1..3}; do
    echo "المحاولة $i"
done

for file in *.log; do
    [[ -e "$file" ]] || continue   # لا ملفات؟ النمط يبقى حرفيًا "*.log"
    echo "معالجة $file"
done
```

السطر `[[ -e "$file" ]] || continue` يحمي من حالة لا توجد فيها ملفات مطابقة: حينها يمرّر Bash النص `*.log` نفسه كقيمة.

## while

```bash
count=1
while [[ $count -le 3 ]]; do
    echo "$count"
    ((count++))
done

# قراءة ملف سطرًا سطرًا (الطريقة الصحيحة)
printf 'أ\nب\n' > lines.txt
while IFS= read -r line; do
    echo "سطر: $line"
done < lines.txt
```

`IFS= read -r` تقرأ السطر كما هو تمامًا، بمسافاته وشرطاته العكسية.

## case: بدل if متكرّرة

```bash
action="start"
case "$action" in
    start)   echo "تشغيل" ;;
    stop)    echo "إيقاف" ;;
    restart) echo "إعادة تشغيل" ;;
    *)       echo "الاستخدام: $0 start|stop|restart"; exit 1 ;;
esac
```

مثالية لسكربتات الأوامر الفرعية (`./app.sh start`). و`*)` تلتقط أي قيمة أخرى.

## الدوال

```bash
log() {
    local level="$1"           # local: داخل الدالة فقط
    shift                      # أزح الوسيط الأول، والباقي هو الرسالة
    echo "[$(date +%T)] [$level] $*"
}

backup_exists() {
    [[ -f "$1" ]]              # رمز الخروج = نتيجة الدالة
}

log INFO "بدء النسخ"
if backup_exists /etc/hostname; then
    log OK "الملف موجود"
fi
```

الدوال تأخذ وسائطها بـ `$1` و`$2` مثل السكربت تمامًا، و"تُرجع" النجاح أو الفشل برمز الخروج، والقيم بطباعتها (`result=$(myfunc)`). واجعل متغيّراتها `local` دائمًا، وإلا عدّلت متغيّرات السكربت العامة بصمت.

## أخطاء شائعة

- **المسافات داخل الأقواس:** `[[$a -eq 1]]` خطأ؛ اكتب `[[ $a -eq 1 ]]`.
- **`>` لمقارنة الأرقام داخل `[ ]`:** تنشئ ملفًا. استخدم `-gt`.
- **`==` للأرقام أو `-eq` للنصوص:** `-eq` مع نص غير رقمي خطأ.
- **`for f in $(ls)`:** ينكسر مع المسافات في الأسماء. استخدم `for f in *`.
- **متغيّرات الدوال بلا `local`:** تتسرّب للسكربت كله.
