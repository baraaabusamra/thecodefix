## لماذا هذه الأدوات مهمّة؟

السجلّات، وملفات الإعداد، وCSV، ومخرجات الأوامر: كلها **نصوص بأسطر**. أدوات Linux الصغيرة تعالج النص سطرًا سطرًا، وكل واحدة تفعل شيئًا واحدًا جيدًا. وحين تربطها بالأنابيب `|` تجيب في سطر واحد عن أسئلة تحتاج سكربتًا كاملًا في لغة أخرى.

سنستخدم هذا الملف في الأمثلة:

```bash
cat > access.log <<'EOF'
10.0.0.1 GET /home 200
10.0.0.2 GET /login 200
10.0.0.1 POST /login 401
10.0.0.3 GET /home 200
10.0.0.1 GET /admin 403
10.0.0.2 GET /home 500
EOF
```

## grep: ابحث عن أسطر

```bash
grep "login" access.log           # الأسطر التي تحتوي login
grep -i "GET" access.log          # تجاهل حالة الأحرف
grep -v " 200$" access.log        # العكس: كل ما ليس 200 (الأخطاء)
grep -c "/home" access.log        # عدد الأسطر المطابقة: 3
grep -n "admin" access.log        # مع رقم السطر
grep -r "TODO" src/               # بحث في كل ملفات مجلّد
grep -E " (401|403)$" access.log  # تعبير نمطي موسّع: 401 أو 403 في آخر السطر
```

`grep` هو أول ما تفتحه عند كل مشكلة: "أين في السجلّ ظهر هذا الخطأ؟" و`-v` (العكس) مفيدة جدًّا لاستبعاد الضجيج.

## sed: عدّل النص

```bash
sed 's/GET/get/' access.log        # استبدل أول ظهور في كل سطر
sed 's/10\.0\.0\./IP-/g' access.log # g: كل الظهورات. لاحظ \. للنقطة الحرفية
sed -n '2,4p' access.log           # اطبع الأسطر 2 إلى 4 فقط
sed '/admin/d' access.log          # احذف الأسطر التي فيها admin
```

`sed` **لا يعدّل الملف** افتراضيًا؛ يطبع النتيجة فقط. للتعديل في المكان:

```bash
sed -i.bak 's/localhost/127.0.0.1/g' config.ini   # يعدّل ويحفظ نسخة config.ini.bak
```

`-i` بلا لاحقة نسخة احتياطية تعدّل مباشرة بلا رجعة. جرّب الأمر بدون `-i` أولًا وانظر للنتيجة، ثم أضفها.

## awk: اعمل بالأعمدة

`awk` يقسم كل سطر إلى **حقول** (بالمسافات افتراضيًا): `$1` الأول، و`$2` الثاني، و`$NF` الأخير:

```bash
awk '{print $1}' access.log                  # عناوين IP فقط
awk '{print $3, $4}' access.log              # المسار والحالة
awk '$4 >= 400' access.log                   # الأسطر التي حالتها 400 فأكثر
awk '$4 >= 400 {n++} END {print n}' access.log   # عددها: 3
awk -F: '{print $1, $7}' /etc/passwd         # فاصل مخصّص: الاسم والـ shell
```

`awk` لغة برمجة صغيرة كاملة، لكن 90% من استخدامها اليومي: "اطبع العمود الفلاني" و"صفِّ حسب قيمة عمود".

## cut و sort و uniq

```bash
cut -d' ' -f3 access.log      # العمود الثالث (فاصل: مسافة)
cut -d, -f2 data.csv          # العمود الثاني من CSV
sort file.txt                 # ترتيب أبجدي
sort -n numbers.txt           # ترتيب رقمي (بدونها: 10 قبل 9)
sort -rn                      # رقمي تنازلي
uniq                          # احذف المكرّر المتجاور
uniq -c                       # عدّ كل مجموعة متجاورة
```

**`uniq` يعمل على الأسطر المتجاورة فقط**، لذلك يسبقه `sort` دائمًا تقريبًا.

## الكل معًا: أكثر الصفحات طلبًا

```bash
awk '{print $3}' access.log | sort | uniq -c | sort -rn | head -3
#       3 /home
#       2 /login
#       1 /admin
```

اقرأ الأنبوب خطوة خطوة: "خذ عمود المسار، رتّبه ليتجاور المتشابه، عدّ كل مجموعة، رتّب العدد تنازليًا، خذ أعلى ثلاثة". هذا النمط (`sort | uniq -c | sort -rn`) يجيب عن أي سؤال "ما الأكثر تكرارًا؟": أكثر العناوين زيارة، أكثر الأخطاء، أكثر المستخدمين نشاطًا.

## أخطاء شائعة

- **`uniq` بلا `sort` قبله:** المكرّر غير المتجاور يبقى.
- **`sort` لأرقام بلا `-n`:** ترتيب نصّي: `10` قبل `9`.
- **`sed -i` بلا تجربة:** يعدّل الملف مباشرة. جرّب بلا `-i`، أو استخدم `-i.bak`.
- **النقطة في الأنماط:** `.` تعني "أي حرف" في grep وsed. للنقطة الحرفية اكتب `\.`.
- **علامات تنصيص مزدوجة مع awk:** `"$1"` يوسّعها الـ Shell قبل awk. استخدم المفردة دائمًا: `'{print $1}'`.
