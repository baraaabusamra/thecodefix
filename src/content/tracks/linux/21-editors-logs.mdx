## nano — الأسهل للمبتدئين

```bash
nano file.txt
```

- `Ctrl+O` حفظ، `Ctrl+X` خروج، `Ctrl+W` بحث.

## vim — قويّ (منحنى تعلّم)

```bash
vim file.txt
```

- `i` للكتابة (وضع الإدراج)، `Esc` للخروج منه.
- `:w` حفظ، `:q` خروج، `:wq` حفظ وخروج، `:q!` خروج دون حفظ.

> 💡 إذا علقت في vim: اضغط `Esc` ثم اكتب `:q!` واضغط Enter.

## السجلّات

```bash
journalctl -u nginx          # سجلّ خدمة معيّنة
journalctl -f                # متابعة حيّة
tail -f /var/log/syslog      # سجلّ النظام العامّ
```

ملفّات السجلّ تقع عادةً في `/var/log/`.
