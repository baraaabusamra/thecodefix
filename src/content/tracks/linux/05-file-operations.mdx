## إنشاء

```bash
touch notes.txt          # ملف فارغ (أو يحدّث تاريخ تعديله إن وُجد)
mkdir projects           # مجلّد
mkdir -p app/src/utils   # مجلّدات متداخلة دفعة واحدة، بلا خطأ إن وُجدت
echo "سطر أول" > a.txt   # ملف بمحتوى (> تكتب، و>> تُلحق)
```

`-p` مفيدة جدًّا في السكربتات: تنشئ كل المسار الناقص ولا تفشل إذا كان المجلّد موجودًا أصلًا.

## النسخ: cp

```bash
cp notes.txt backup.txt        # نسخ ملف
cp notes.txt /tmp/             # نسخ إلى مجلّد (بنفس الاسم)
cp -r app app-backup           # نسخ مجلّد بكل محتواه (r = recursive)
cp -i notes.txt backup.txt     # اسأل قبل الكتابة فوق ملف موجود
cp -a app /backup/             # نسخة "أرشيفية": تحفظ الصلاحيات والتواريخ والروابط
```

بدون `-i`، إذا كان `backup.txt` موجودًا **يُستبدل بصمت**. و`-a` هي الصحيحة للنسخ الاحتياطي: `-r` وحدها قد تُضيع الصلاحيات والتواريخ.

## النقل وإعادة التسمية: mv

```bash
mv notes.txt docs/             # نقل إلى مجلّد
mv old-name.txt new-name.txt   # إعادة تسمية: نفس الأمر
mv -i a.txt b.txt              # اسأل قبل الاستبدال
mv *.jpg photos/               # كل ملفات jpg
```

في Linux لا يوجد أمر منفصل لإعادة التسمية: النقل إلى اسم جديد في نفس المكان **هو** إعادة التسمية. والنقل داخل نفس القرص فوري مهما كان الحجم، لأنه يغيّر الاسم في الفهرس فقط ولا ينسخ البيانات.

## الحذف: rm

```bash
rm notes.txt          # حذف ملف
rm -i *.log           # اسأل عن كل ملف
rm -r old-project/    # حذف مجلّد وكل محتواه
rmdir empty-folder/   # حذف مجلّد فارغ فقط (أأمن)
```

**لا توجد سلّة محذوفات في الطرفية.** `rm` يحذف نهائيًا، و`rm -rf` (`f` = force) يحذف بلا أي سؤال، حتى الملفات المحمية من الكتابة.

### كيف تحذف بأمان؟

النجمة `*` تُوسَّع **قبل** تشغيل الأمر. فقبل أي `rm` بنمط، شاهد ماذا سيُحذف:

```bash
ls *.log              # 1. اعرض ما يطابق النمط
rm *.log              # 2. ثم احذف نفس النمط
```

والفخّ الأخطر في السكربتات: متغيّر فارغ:

```bash
DIR=""                       # تخيّل أنه لم يُضبط بسبب خطأ
# rm -rf "$DIR"/*            # ❌ تصبح rm -rf /* : تحاول حذف النظام كله
rm -rf "${DIR:?DIR فارغ}"/*  # ✅ يتوقّف السكربت برسالة خطأ إذا كان فارغًا
```

`${VAR:?رسالة}` توقف السكربت فورًا إذا كان المتغيّر فارغًا أو غير معرّف. استخدمها مع أي `rm` يعتمد على متغيّر.

## النجوم والأنماط (Globbing)

```bash
ls *.txt          # كل ما ينتهي بـ .txt
ls report-?.pdf   # ? حرف واحد: report-1.pdf و report-a.pdf
ls img[0-9].png   # رقم واحد بين الأقواس
cp {a,b,c}.txt /tmp/   # توسيع الأقواس: a.txt b.txt c.txt
```

الـ Shell يوسّع هذه الأنماط إلى قائمة أسماء **قبل** أن يصل الأمر لـ `cp` أو `rm`. لهذا تعمل مع أي أمر.

## مثال: تنظيم مجلّد تنزيلات

```bash
cd ~/Downloads
mkdir -p images docs archives
mv -i *.jpg *.png images/ 2>/dev/null
mv -i *.pdf *.docx docs/ 2>/dev/null
mv -i *.zip *.tar.gz archives/ 2>/dev/null
ls
```

`2>/dev/null` تخفي رسائل "No such file" إذا لم توجد ملفات من نوع ما ([درس إعادة التوجيه](/learn/linux/10-pipes-redirection)).

## أخطاء شائعة

- **`cp` أو `mv` فوق ملف موجود:** يُستبدل بلا سؤال. أضف `-i`، أو اجعلها افتراضية بـ `alias cp='cp -i'`.
- **`cp` بلا `-r` لمجلّد:** خطأ `omitting directory`.
- **`rm -rf` بمتغيّر قد يكون فارغًا:** استخدم `"${VAR:?}"`.
- **مسافة زائدة:** `rm -rf / tmp/old` (لاحظ المسافة بعد `/`) تعني حذف `/` و`tmp/old`. اقرأ الأمر قبل Enter.
- **الاعتماد على `rm` للتراجع:** لا تراجع. احذف بعد أن تتأكد، أو انقل لمجلّد مؤقت أولًا.
