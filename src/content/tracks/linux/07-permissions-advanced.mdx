## قراءة الصلاحيات

```bash
ls -l
# -rwxr-xr--   المالك: rwx، المجموعة: r-x، الآخرون: r--
```

- `r` قراءة (4)، `w` كتابة (2)، `x` تنفيذ (1).

## chmod بالأرقام

اجمع القيم لكل فئة:

```bash
chmod 755 script.sh    # rwx للمالك، r-x للبقيّة
chmod 644 file.txt     # rw- للمالك، r-- للبقيّة
chmod 600 secret.txt   # rw- للمالك فقط
```

## chmod بالرموز

```bash
chmod +x script.sh     # أضف تنفيذًا للجميع
chmod u+x script.sh    # للمالك فقط
chmod g-w file.txt     # انزع الكتابة عن المجموعة
```

## تغيير الملكية

```bash
sudo chown user file.txt          # المالك
sudo chown user:group file.txt    # المالك والمجموعة
sudo chown -R user folder         # لكل المحتوى
```

> 💡 `755` للمجلّدات والبرامج، `644` للملفّات العاديّة — قاعدة شائعة.

> 🎯 التالي: المستخدمون والمجموعات.
