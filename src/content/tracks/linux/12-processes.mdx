## عرض العمليات

```bash
ps aux               # كل العمليات
ps aux | grep node   # تصفية
top                  # مراقبة حيّة (q للخروج)
htop                 # أجمل (يحتاج تثبيتًا)
```

## إيقاف عملية

```bash
kill 1234            # بالرقم (PID)
kill -9 1234         # إيقاف إجباري
killall node         # كل عمليات node بالاسم
```

## المهامّ في الخلفية

```bash
command &            # تشغيل في الخلفية
jobs                 # المهامّ في هذه الجلسة
fg                   # إعادة آخر مهمّة للمقدّمة
Ctrl+Z               # تعليق المهمّة الحالية
bg                   # متابعتها في الخلفية
```

## تشغيل مستمرّ بعد إغلاق الجلسة

```bash
nohup ./server &     # يستمرّ بعد الخروج
```

> 💡 كل عملية لها رقم PID فريد؛ استخدمه مع `kill` لإيقافها.
