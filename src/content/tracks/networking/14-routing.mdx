## ما هو التوجيه؟

عملية إيجاد المسار الأمثل لنقل الحزم من المصدر إلى الوجهة عبر شبكات متعدّدة.

## الراوتر (Router)

جهاز يربط شبكات مختلفة ويوجّه الحزم بينها بناءً على عنوان IP الوجهة.

## جدول التوجيه (Routing Table)

يحدّد إلى أين تُرسَل الحزم حسب وجهتها:

```
الوجهة          البوّابة التالية
192.168.1.0/24   مباشرة (محلّي)
0.0.0.0/0        مزوّد الخدمة (الافتراضي)
```

## NAT — ترجمة العناوين

يتيح لعدّة أجهزة بعناوين خاصّة مشاركة عنوان عامّ واحد:

```
جهازك (192.168.1.5) → الراوتر (NAT) → الإنترنت (عنوان عامّ)
```

هذا سبب عدم نفاد IPv4 بالكامل بعد.

## البوّابة الافتراضية (Gateway)

الراوتر الذي يخرج منه جهازك للإنترنت (عادةً `192.168.1.1`).

## أداة تتبّع المسار

```bash
traceroute example.com    # يعرض الراوترات في الطريق
```

> 🎯 التالي: التبديل (Switching).
