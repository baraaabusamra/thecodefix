## السويتش (Switch)

جهاز يربط الأجهزة **داخل نفس الشبكة المحلّية** (LAN) ويوجّه الإطارات بناءً على عنوان MAC.

## عنوان MAC

معرّف فيزيائي فريد لكل بطاقة شبكة (مُضمَّن في العتاد):

```
00:1A:2B:3C:4D:5E
```

بخلاف IP (منطقي قابل للتغيير)، MAC ثابت للجهاز.

## ARP — ربط IP بـ MAC

عندما يعرف الجهاز عنوان IP الوجهة لكن يحتاج MAC، يرسل استعلام ARP:
"من يملك 192.168.1.10؟" → يردّ صاحبه بعنوان MAC.

```bash
arp -a      # عرض جدول ARP
```

## السويتش مقابل الراوتر

| | السويتش | الراوتر |
|---|---|---|
| النطاق | داخل LAN | بين الشبكات |
| العنوان | MAC (طبقة 2) | IP (طبقة 3) |
| الوظيفة | يربط الأجهزة | يربط الشبكات |

## الهَب (Hub) — قديم

يبثّ لكل الأجهزة (غير فعّال وغير آمن) — استبدله السويتش.

> 🎯 التالي: أجهزة الشبكة.
