## بروتوكولات شائعة

| البروتوكول | الوظيفة | المنفذ |
|------|------|------|
| **DHCP** | توزيع عناوين IP تلقائيًّا | 67/68 |
| **DNS** | تحويل الأسماء إلى IP | 53 |
| **HTTP/S** | الويب | 80/443 |
| **FTP** | نقل الملفّات | 21 |
| **SSH** | اتصال آمن بالخوادم | 22 |
| **SMTP** | إرسال البريد | 25 |
| **IMAP/POP3** | استقبال البريد | 143/110 |

## DHCP

يمنح جهازك عنوان IP والبوّابة و DNS تلقائيًّا عند الاتصال — لولاه لأعددت كل جهاز يدويًّا.

## SSH

اتصال مشفّر بالخوادم لإدارتها عن بُعد (الأساس لـ DevOps):

```bash
ssh user@server.com
```

## WebSocket

اتصال **ثنائي الاتجاه دائم** بين المتصفّح والخادم — للتطبيقات اللحظية (الدردشة، الإشعارات، الألعاب).

```javascript
const ws = new WebSocket("wss://example.com");
ws.onmessage = (e) => console.log(e.data);
```

بخلاف HTTP (طلب/ردّ)، WebSocket يبقى مفتوحًا للبثّ الفوري.
