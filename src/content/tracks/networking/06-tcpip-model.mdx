## TCP/IP مقابل OSI

TCP/IP هو النموذج **العملي** الذي يعمل به الإنترنت فعليًّا — أبسط من OSI، بأربع طبقات.

| TCP/IP | يقابل OSI |
|------|------|
| التطبيق | 7+6+5 |
| النقل | 4 |
| الإنترنت | 3 |
| الوصول للشبكة | 2+1 |

## الطبقات

- **التطبيق:** البروتوكولات التي يستخدمها المستخدم (HTTP، DNS، SMTP).
- **النقل:** TCP (موثوق) و UDP (سريع).
- **الإنترنت:** IP — العنونة والتوجيه بين الشبكات.
- **الوصول للشبكة:** الإرسال الفعلي عبر الكابلات/اللاسلكي.

## رحلة طلب ويب

1. **التطبيق:** المتصفّح يكوّن طلب HTTP.
2. **النقل:** TCP يقسّمه لحزم ويضمن وصولها.
3. **الإنترنت:** IP يوجّه الحزم للخادم.
4. **الوصول:** تُرسَل كإشارات فيزيائية.

ثم العكس عند الخادم.

> 💡 معظم النقاشات العملية تستخدم TCP/IP، بينما OSI نموذج تعليمي مرجعي.

> 🎯 التالي: عنونة IP.
