## ما هو عنوان IP؟

معرّف رقمي فريد لكل جهاز على الشبكة، يحدّد "أين" يقع.

## IPv4

أربعة أرقام (0-255) مفصولة بنقاط:

```
192.168.1.10
```

~4.3 مليار عنوان — نفدت تقريبًا.

## IPv6

أطول بكثير (128 بت)، لحلّ نفاد IPv4:

```
2001:0db8:85a3::8a2e:0370:7334
```

## عامّ مقابل خاصّ

- **عامّ (Public):** فريد على الإنترنت، يخصّصه مزوّد الخدمة.
- **خاصّ (Private):** داخل الشبكة المحلّية فقط:
  - `10.0.0.0`، `172.16.0.0`، `192.168.0.0`

## ثابت مقابل ديناميكي

- **ثابت:** لا يتغيّر (خوادم).
- **ديناميكي:** يخصّصه DHCP تلقائيًّا (معظم الأجهزة).

## localhost

```
127.0.0.1   ← جهازك نفسه (loopback)
```

> 🎯 التالي: التقسيم الفرعي (Subnetting).
