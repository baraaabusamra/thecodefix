## if / elseif / else

```php
<?php
$score = 85;

if ($score >= 90) {
    echo "ممتاز";
} elseif ($score >= 60) {
    echo "ناجح";
} else {
    echo "راسب";
}
?>
```

## العامل الثلاثي (Ternary)

اختصار لـ if/else بسيط:

```php
<?php
$age = 20;
$status = ($age >= 18) ? "بالغ" : "قاصر";
echo $status;   // بالغ
?>
```

## switch

للمقارنة بقيمة واحدة مع عدّة احتمالات:

```php
<?php
$day = "السبت";

switch ($day) {
    case "الجمعة":
    case "السبت":
        echo "عطلة";
        break;
    default:
        echo "يوم عمل";
}
?>
```

> ⚠️ لا تنسَ `break` في كل `case`، وإلا "تتسرّب" للحالة التالية.

## تعبير match (الحديث)

أُضيف في PHP 8 — أوضح من switch، ويقارن بـ `===`، ويُرجع قيمة:

```php
<?php
$status = 404;

$message = match ($status) {
    200 => "ناجح",
    404 => "غير موجود",
    500 => "خطأ خادم",
    default => "غير معروف",
};

echo $message;   // غير موجود
?>
```

### match مقابل switch

| | switch | match |
|--|--------|-------|
| المقارنة | `==` | `===` |
| `break` | مطلوب | غير مطلوب |
| يُرجع قيمة | لا | نعم |
| عدّة قيم | بـ case متتالية | بفاصلة `1, 2 =>` |

```php
<?php
$result = match ($day) {
    "الجمعة", "السبت" => "عطلة",
    default => "عمل",
};
?>
```

### بدون `default`؟ خطأ صريح لا صمت

إذا لم تطابق أي حالة ولا يوجد `default`، يرمي `match` خطأ `UnhandledMatchError`. هذا مقصود: `switch` في نفس الموقف يمرّ بصمت ولا ينفّذ شيئًا، فيختفي الخطأ.

```php
<?php
$status = 301;

try {
    echo match ($status) {
        200 => "ناجح",
        404 => "غير موجود",
    };
} catch (\UnhandledMatchError $e) {
    echo $e->getMessage();   // Unhandled match case 301
}
?>
```

### نطاقات وشروط: `match (true)`

`match` يقارن بقيم ثابتة، لكن بتمرير `true` تصبح كل حالة شرطًا، والأولى الصحيحة تفوز. بديل مرتّب لسلسلة `if/elseif` تُرجع قيمة:

```php
<?php
$score = 85;

$grade = match (true) {
    $score >= 90 => "ممتاز",
    $score >= 60 => "ناجح",
    default      => "راسب",
};

echo $grade;   // ناجح
?>
```

## أخطاء شائعة

- نسيان `break` في `switch` فتُنفَّذ حالات غير مقصودة.
- حذف `default` من `match` مع قيم غير متوقّعة → `UnhandledMatchError` وقت التشغيل.
- توقّع أن `match` يقبل تحويل النوع — هو يقارن بـ `===` الصارم: `match ("1") { 1 => ... }` لا يطابق، بينما `switch` يطابقه.
