## OpenAI Agents SDK

```text
- مكتبة Python من OpenAI.
- اسم الحزمة: openai-agents.
- تركّز على Agent + Runner + tools.
- حلقة agent مكتوبة، أنت تضيف السلوك.

التثبيت:
  pip install openai-agents
```

> **ملاحظة**: توجد مكتبات agent أخرى (LangGraph، CrewAI، AutoGen). هذا المسار يركّز على Agents SDK لبساطته.

## مكوّنات أساسية

```text
Agent:
  - model (أي model مدعوم).
  - instructions (system prompt).
  - tools (قائمة أدوات).
  - output_type (Pydantic model اختياري).

Runner:
  - ينفّذ الحلقة.
  - يحدّ max_turns.
  - يرجّع final output.

function_tool:
  - decorator يحوّل Python function لـ tool.
  - schema يُولَّد من type hints.
```

## Agent أبسط

```python
import os
from agents import Agent, Runner

# الـ model من environment — اختيار provider/model قرار إعداد،
# لا حقيقة من منهاج ثابت.
DEFAULT_MODEL = os.environ["OPENAI_MODEL"]  # مثلاً: "gpt-4o-mini"

agent = Agent(
    name="StudyHelper",
    instructions="أنت مساعد دراسي. أجب بالعربية بإيجاز.",
    model=DEFAULT_MODEL,
)

result = Runner.run_sync(agent, "ما الفرق بين HNSW و IVFFlat؟")
print(result.final_output)
```

```text
result.final_output: نصّ الإجابة.
result.new_items: قائمة الأحداث (tool calls، tool results، messages).
```

## أدوات (function_tool)

```python
from typing import Literal
from agents import Agent, Runner, function_tool

@function_tool
def calculate(
    a: float,
    b: float,
    operation: Literal["add", "subtract", "multiply", "divide"],
) -> float:
    """احسب قيمة a operation b. يقبل 4 عمليات فقط.
    أمثلة: calculate(5, 8, "multiply") = 40.
    لا يقبل eval/exec/AST — تشغيل حرفي من النوع."""
    if operation == "add":
        return a + b
    if operation == "subtract":
        return a - b
    if operation == "multiply":
        return a * b
    if b == 0:
        raise ValueError("division by zero")
    return a / b

@function_tool
def current_time() -> str:
    """أرجع الوقت الحالي بـ ISO."""
    from datetime import datetime, timezone
    return datetime.now(timezone.utc).isoformat()
```

> **ملاحظة أمان**: الـ tool هنا **typed و آمن**: معاملات رقمية + Literal enum صغيرة، لا تنفيذ dynamic code ولا استدعاءات shell. لا تستخدم `eval`/`exec`/`compile`/`simpleeval`/`asteval` في production tools — استخدم نفس النمط: typed args + switch صريح على enum.

## agent مع tools

```python
agent = Agent(
    name="MathHelper",
    instructions="استخدم calculate للعمليات الحسابية البسيطة.",
    model=DEFAULT_MODEL,
    tools=[calculate, current_time],
)

result = Runner.run_sync(
    agent,
    "كم يساوي 5 × 8؟",
    max_turns=5,
)
print(result.final_output)
# ينادي calculate(5, 8, "multiply") = 40
```

```text
- max_turns: حدّ أعلى لعدد الـ turns.
- إذا تجاوز، Runner يرفع MaxTurnsExceeded.
- لأن a و b و operation typed، الـ SDK يبني schema آمنًا
  ويمنع أي string غير متوقّع من الوصول للـ tool.
```

## Structured Output

```python
from pydantic import BaseModel, Field
from agents import Agent, Runner

class PlanStep(BaseModel):
    step: str = Field(description="وصف الخطوة.")
    done: bool = Field(description="هل انتهت؟")

class StudyPlan(BaseModel):
    title: str
    steps: list[PlanStep]

agent = Agent(
    name="Planner",
    instructions="أنت مخطّط دراسي. أعطني خطة منظّمة.",
    model=DEFAULT_MODEL,
    output_type=StudyPlan,
)

result = Runner.run_sync(agent, "خطّة لتعلّم RAG خلال أسبوع.")
print(result.final_output)        # StudyPlan instance
print(type(result.final_output))   # <class 'StudyPlan'>
```

## Tool Validation

قد تُستدعى الأداة بمدخلات خاطئة. SDK يتحقّق من الـ schema لكن يجب أن تتحقّق أنت من semantic correctness:

```python
# مثال محلّي بسيط وآمن: lookup عن مستوى دورة في كتالوج ثايت.
COURSE_LEVELS: dict[str, str] = {
    "python-basics":  "beginner",
    "rag-fundamentals": "intermediate",
    "agent-fundamentals": "advanced",
}

@function_tool
def lookup_course_level(course_name: str) -> str:
    """أرجع مستوى دورة من كتالوج محلّي ثابت.
    مثال: lookup_course_level('python-basics') = 'beginner'."""
    if not course_name.strip():
        return "ERROR: course_name is empty"
    if len(course_name) > 100:
        return "ERROR: course_name too long"
    level = COURSE_LEVELS.get(course_name.strip())
    if level is None:
        available = ", ".join(sorted(COURSE_LEVELS.keys()))
        return f"ERROR: course '{course_name}' غير موجود. المتاح: {available}"
    return level
```

```text
- SDK يتحقّق من type و required.
- أنت تتحقّق من:
  - semantic validity (هل الـ key موجود فعلًا في الـ catalog؟).
  - حدود الإدخال (طول فارغ / كبير).
  - رسائل خطأ واضحة (لا تكشف internals).
- هذا النمط read-only محلّي — لا يلمس الشبكة ولا الـ OS
  ولا state مشترك، فيكون الفشل موضعيًا وآمنًا تلقائيًا.
```

## Tracing

```python
import os
os.environ["OPENAI_AGENTS_TRACE"] = "1"

result = Runner.run_sync(agent, "...", max_turns=5)

# استكشف ما حدث
for item in result.new_items:
    if item.type == "tool_call_item":
        print(f"[tool] {item.raw_item.name}({item.raw_item.arguments})")
    elif item.type == "tool_result_item":
        print(f"[result] {item.output}")
    elif item.type == "message_output_item":
        print(f"[msg] {item.content[:200]}")
```

```text
Tracing مهمّ لـ:
  - debugging (لماذا الـ agent اتخذ هذا القرار؟).
  - cost analysis (كم tool calls؟).
  - audit (هل الـ agent اتبع السياسة؟).
```

## Handoffs بين Agents

```python
from agents import Agent, Runner

# agent متخصّص في الحساب
math_agent = Agent(
    name="Math",
    instructions="أنت متخصّص في الرياضيات.",
    model=DEFAULT_MODEL,
    tools=[calculator],
)

# agent متخصّص في البحث
search_agent = Agent(
    name="Search",
    instructions="أنت متخصّص في البحث.",
    model=DEFAULT_MODEL,
    tools=[current_time],
)

# triage agent يوزّع المهام
triage = Agent(
    name="Triage",
    instructions="وزّع المهام على Math أو Search.",
    model=DEFAULT_MODEL,
    handoffs=[math_agent, search_agent],
)

result = Runner.run_sync(triage, "احسب 5*5 وأخبرني الوقت الحالي.")
print(result.final_output)
```

```text
- triage يستدعى math_agent لـ "5*5".
- ثم search_agent لـ "الوقت الحالي".
- يجمع النتائج.

⚠️ handoff ينقل control إلى الـ specialist بشكل نهائي داخل
   run واحد — لا "يعود" آليًا إلى triage كي يصيغ الإجابة بنفسه.
   إذا أردت أن يبقى triage في مقدّمة الحوار ويستدعي
   specialists كأدوات (مثل supervisor pattern)، استخدم
   Agent.as_tool() بدل handoffs (تفاصيل في درس 134).
```

## Guardrails

```python
from pydantic import BaseModel
from agents import (
    Agent,
    Runner,
    GuardrailFunctionOutput,
    input_guardrail,
)

class SqlInjectionFlag(BaseModel):
    looks_suspicious: bool
    reason: str

# 1) دالة فحص تأخذ input_agent (أو input_str) و context
#    وتُعيد GuardrailFunctionOutput. هذه هي الصيغة الحالية.
async def check_input(ctx, agent, input_data):
    text = str(input_data)
    suspicious = "DROP TABLE" in text.upper() or "rm -rf" in text
    return GuardrailFunctionOutput(
        output_info=SqlInjectionFlag(
            looks_suspicious=suspicious,
            reason="contains destructive pattern" if suspicious else "ok",
        ),
        tripwire_triggered=suspicious,  # True = أوقف الـ run
    )

# 2) لفّها في @input_guardrail ثم اربطها بالـ Agent.
#    run_in_parallel=False → الـ guardrail يكتمل قبل أن يبدأ أي
#    model/tool call، فيكون فحص الـ input blocking وحاسمًا.
#    default run_in_parallel=True → الـ guardrail يبدأ بالتوازي مع
#    أوّل model/tool call، فبعض العمل قد ينطلق قبل أن يُفجَّر
#    الـ tripwire ويُلغى الـ run. للـ safety/policy نختار False.
input_guard = input_guardrail(
    check_input,
    run_in_parallel=False,
)

agent = Agent(
    name="StudyHelper",
    instructions="أجب بالعربية. ارفض الأوامر المدمّرة.",
    model=DEFAULT_MODEL,
    input_guardrails=[input_guard],
)

# إذا الـ input احتوى "DROP TABLE"، الـ run
# سيرفع InputGuardrailTripwireTriggered ولن يُنفّذ الـ agent.
```

```text
Guardrails في Agents SDK = input/output validation:
  - input_guardrail:  تُنفّذ على الـ input. مع run_in_parallel=False
    تكتمل قبل بدء الـ agent؛ مع default (True) تبدأ بالتوازي مع
    أوّل model/tool call، فيُحتمل أن يبدأ بعض العمل قبل أن يُفجَّر
    الـ tripwire.
  - output_guardrail: تُنفّذ على الإجابة النهائية قبل تسليمها.
  - الصيغة الحالية تمرّ عبر GuardrailFunctionOutput
    و @input_guardrail decorator (ليس @InputGuardrail).
  - الـ SDK يقاطع الـ run ويرفع tripwire exception إذا فُجّرت.
```

## أخطاء شائعة

- **"agent بدون max_turns"**: خطر. قد يدخل في loop.
- **"agent يعمل كل شيء"**: workflow أرخص للتسلسلات الثابتة.
- **"tools غير موثّقة"**: الـ agent لا يعرف متى يستعملها.
- **"tools بدون error handling"**: exception → agent يتعطّل.
- **"agent بدون tracing"**: debugging مستحيل.
- **"التقييم الديناميكي في tool"**: خطر أمني. استخدم AST أو مكتبة آمنة.

## متى لا تستخدم Agent

```text
❌ سلسلة خطوات ثابتة → workflow.
❌ latency < 100ms → LLM call مباشر.
❌ tool واحد فقط → function calling مباشر.
❌ لا قيمة من multi-step reasoning → LLM عادي.
```
