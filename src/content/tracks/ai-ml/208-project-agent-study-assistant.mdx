## الهدف

نبني **agent دراسي** يجيب عن أسئلة ويحسب ويساعد في جدولة الدراسة — باستخدام **OpenAI Agents SDK** مع **max_turns صارم** و**tools آمنة read-only** (لا `eval`، لا `exec`، لا `compile`، لا shelling out، لا filesystem writes).

```text
input:  "كم ساعة أحتاج لتعلّم RAG في 7 أيام؟"
output: agent ينفّذ calculate_study_schedule tool، يجيب بالعربية.
```

## المتطلبات

```text
- Python 3.10+.
- openai-agents (pip install openai-agents).
- OpenAI API key.
- بدون تقييم ديناميكي للـ expressions أو execution مضمّن أو compilation حيّ أو shelling out — tools آمنة فقط.
- بدون file system writes (لا scratchpad، لا sessions JSON، لا journal).
- max_turns صارم.
- SQLiteSession للـ multi-turn memory (يديرها الـ SDK).
```

## ما لا نسمح به في الـ Tools

```text
❌ ممنوع:
  - التقييم الديناميكي للـ expressions — تنفيذ arbitrary Python.
  - exec، compile، __import__ الديناميكي.
  - shelling out (subprocesses / os.system / os.popen).
  - filesystem writes (open(..., 'w')، Path.write_text()، json.dump()).
  - network requests لـ hosts غير مسموحة.
  - أي tool له side-effect على نظام التشغيل.

✅ مسموح (read-only فقط):
  - عمليات حسابية محلّدة (calculator).
  - استرجاع معلومات من corpus ثابت داخل الذاكرة.
  - استدعاء OpenAI API (provider/model من env vars).
```

## المرحلة 1: Tools آمنة (read-only)

```python
# src/tools.py
import re
from agents import function_tool

# ---------- corpus دراسي ثابت داخل الذاكرة ----------
# Read-only: لا filesystem، لا شبكة. مجرد dict في الذاكرة.
COURSE_CATALOG: dict[str, dict] = {
    "python-basics": {
        "title": "أساسيات Python",
        "hours": 12,
        "level": "beginner",
        "topics": ["syntax", "variables", "loops", "functions"],
    },
    "rag-fundamentals": {
        "title": "أساسيات RAG",
        "hours": 18,
        "level": "intermediate",
        "topics": ["embeddings", "vector search", "prompting", "eval"],
    },
    "agent-fundamentals": {
        "title": "أساسيات AI Agents",
        "hours": 22,
        "level": "advanced",
        "topics": ["agent loop", "tools", "memory", "guardrails"],
    },
}

COURSE_NOTES: list[dict] = [
    {"course": "python-basics", "topic": "loops", "note": "for item in iterable: ..."},
    {"course": "python-basics", "topic": "functions", "note": "def name(args): return value"},
    {"course": "rag-fundamentals", "topic": "embeddings",
     "note": "cosine similarity يقيس زاوية بين متّجهَين normalized"},
    {"course": "rag-fundamentals", "topic": "vector search",
     "note": "ANN (HNSW/IVFFlat) أسرع من exact NN على corpus كبير"},
    {"course": "agent-fundamentals", "topic": "agent loop",
     "note": "Agent = LLM + tools + loop مع max_turns صارم"},
    {"course": "agent-fundamentals", "topic": "tools",
     "note": "function_tool يولّد schema تلقائيًا من type hints"},
]


# ---------- calculator ----------
# بدون dynamic code execution: regex + parser محلّي.
# الـ allowed set يطابق ما يفسّره الـ parser (digits، +، -، *، /،
# أقواس، مسافة) — لا comma، لأن الـ parser لا يعالجها.
ALLOWED_TOKENS_PATTERN = r"^[\d+\-*/().\s]+$"

def safe_eval_math(expr: str) -> float:
    """تعبير رياضي بسيط: digits + basic operators فقط."""
    if not re.match(ALLOWED_TOKENS_PATTERN, expr):
        raise ValueError("only digits and basic operators allowed")
    return _parse_expr(expr.replace(" ", ""))

def _parse_expr(s: str) -> float:
    """recursive descent parser للتعبيرات الحسابية."""
    pos = 0

    def peek():
        return s[pos] if pos < len(s) else ""

    def consume():
        nonlocal pos
        c = s[pos]
        pos += 1
        return c

    def parse_number():
        nonlocal pos
        start = pos
        while pos < len(s) and (s[pos].isdigit() or s[pos] == "."):
            pos += 1
        return float(s[start:pos])

    def parse_factor():
        if peek() == "(":
            consume()
            val = parse_expr()
            if peek() != ")":
                raise ValueError("expected )")
            consume()
            return val
        return parse_number()

    def parse_term():
        left = parse_factor()
        while peek() in ("*", "/"):
            op = consume()
            right = parse_factor()
            left = left * right if op == "*" else left / right
        return left

    def parse_expr():
        left = parse_term()
        while peek() in ("+", "-"):
            op = consume()
            right = parse_term()
            left = left + right if op == "+" else left - right
        return left

    return parse_expr()
```

> **لماذا لا التقييم الديناميكي؟** لأن `__import__('os').system('rm -rf /')` عبر الـ interpreter المضمّن كارثي. الـ parser يقبل digits + 4 operators فقط، لا imports، لا calls.

### تعريف Tools لـ Agents SDK

```python
# src/tools.py (تكملة)
from agents import function_tool

@function_tool
def calculator(expression: str) -> str:
    """احسب تعبيرًا رياضيًا. يقبل digits و +، -، *، /، أقواس فقط.
    مثال: '2 + 3 * 4'."""
    try:
        return str(safe_eval_math(expression))
    except (ValueError, ZeroDivisionError) as e:
        return f"ERROR: {e}"

@function_tool
def get_course_info(course_name: str) -> str:
    """أرجع معلومات دورة من كتالوج المقرّرات الثابت.
    أمثلة: 'python-basics'، 'rag-fundamentals'، 'agent-fundamentals'."""
    info = COURSE_CATALOG.get(course_name)
    if not info:
        available = ", ".join(sorted(COURSE_CATALOG.keys()))
        return f"ERROR: course '{course_name}' غير موجود. المتاح: {available}"
    return (
        f"{info['title']}\n"
        f"الساعات المقدّرة: {info['hours']}\n"
        f"المستوى: {info['level']}\n"
        f"المواضيع: {', '.join(info['topics'])}"
    )

@function_tool
def calculate_study_schedule(hours_per_day: float, days: int) -> str:
    """احسب جدول دراسة: كم ساعة إجماليًا؟
    لا يقرأ الـ catalog — يعتمد على المُدخلات فقط."""
    if hours_per_day <= 0 or days <= 0:
        return "ERROR: hours_per_day و days يجب أن تكون أرقامًا موجبة"
    total = hours_per_day * days
    return f"الإجمالي: {total} ساعة على مدى {days} يومًا"

@function_tool
def search_course_notes(query: str) -> str:
    """ابحث في ملاحظات المقرّرات الثابتة عن query.
    match بسيط: case-insensitive substring على topic أو note."""
    q = query.strip().lower()
    if not q:
        return "ERROR: query فارغ"
    hits = []
    for entry in COURSE_NOTES:
        if q in entry["topic"].lower() or q in entry["note"].lower():
            hits.append(f"[{entry['course']}/{entry['topic']}] {entry['note']}")
    if not hits:
        return f"(لا توجد ملاحظات تطابق: {query})"
    return "\n".join(hits[:5])

ALL_TOOLS = [calculator, get_course_info, calculate_study_schedule, search_course_notes]
```

> كل الأدوات read-only: لا `Path.write_text`، لا `json.dump`، لا `open(..., 'w')`. الـ corpus ثابت داخل الذاكرة.

## المرحلة 2: Agent + Runner + Guardrail

```python
# src/agent.py
import os
from pydantic import BaseModel
from agents import (
    Agent,
    Runner,
    SQLiteSession,
    GuardrailFunctionOutput,
    input_guardrail,
)
from tools import ALL_TOOLS

# الـ model من env — اختيار provider/model قرار إعداد.
DEFAULT_MODEL = os.environ["OPENAI_MODEL"]  # مثلاً: "gpt-4o-mini"


# ---------- input guardrail (الصيغة الحالية) ----------
class OffTopicFlag(BaseModel):
    is_off_topic: bool
    reason: str


async def check_input(ctx, agent, input_data):
    """فحص input: رفض المهام المدمّرة. الصيغة الحالية
    تُعيد GuardrailFunctionOutput مع tripwire_triggered.

    هذه policy/UX layer (تطبيق، تجربة) — ليست الـ safety boundary.
    الـ safety boundary الفعلي للـ agent هو:
      - allowlisted read-only tools (لا tools ديناميكية).
      - typed arguments (الـ SDK يبني schema صارم).
      - لا eval/exec/compile/subprocess/shell.
      - لا filesystem writes أو network calls خارج الـ provider API.
      - validation داخل كل tool.
    إن توفّرت هذه الطبقات، فحتى input ضار لا يستطيع فعل شيء خطير
    لأن الـ tools المسموحة محدودة. الـ guardrail يصقل التجربة
    (يمنع المستخدم من الوصول لطريق عديم الجدوى) لكنه لا يحلّ محل
    هذه الطبقات.
    """
    text = str(input_data).lower()
    forbidden = ["rm -rf", "drop table", "delete from", "shutdown", "format c:"]
    is_bad = any(f in text for f in forbidden)
    return GuardrailFunctionOutput(
        output_info=OffTopicFlag(
            is_off_topic=is_bad,
            reason="forbidden destructive pattern" if is_bad else "ok",
        ),
        tripwire_triggered=is_bad,
    )


# run_in_parallel=False: نريد فحص input أولًا قبل أن يصل أي tool
# call أو model call. الـ default في Agents SDK هو True (يُشغَّل
# الـ guardrail موازيًا مع أول model/tool call)؛ نضبطه False هنا
# لأن safety/policy مسار حسّاس ومن الأفضل أن يكون متسلسلًا.
input_guard = input_guardrail(check_input, run_in_parallel=False)


# ---------- agent ----------
study_agent = Agent(
    name="StudyHelper",
    instructions="""أنت مساعد دراسي يجيب بالعربية.
- لديك tools: calculator، get_course_info، calculate_study_schedule، search_course_notes.
- استخدمها عند الحاجة.
- لا تخترع معلومات.
- أجب بإيجاز ما لم يطلب المستخدم تفاصيل.""",
    model=DEFAULT_MODEL,
    tools=ALL_TOOLS,
    input_guardrails=[input_guard],
)


MAX_TURNS = 10  # صارم


def run_agent(user_message: str, session: SQLiteSession) -> str:
    """شغّل الـ agent مع session مستمر. SQLiteSession يحفظ history
    تلقائيًا بين runs (افتراضيًا in-memory، أو persistent مع db_path)."""
    try:
        result = Runner.run_sync(
            study_agent,
            user_message,
            session=session,
            max_turns=MAX_TURNS,
        )
        return result.final_output
    except Exception as e:
        return f"ERROR: {type(e).__name__}: {e}"
```

```text
بديل للـ session:
  - SQLiteSession("student-demo")                → in-memory (يضيع بانتهاء البرنامج).
  - SQLiteSession("student-demo", db_path="...") → persistent على disk (إنتاج).
  - لتطبيق متعدّد المستخدمين: session_id متمايز لكل مستخدم.
  - بدون session: استخدم result.to_input_list() لتمرير history يدويًا.
```

## المرحلة 3: CLI

```python
# src/main.py
import sys
from agents import SQLiteSession
from agent import run_agent


def main():
    # session واحد للطالب — يحفظ history تلقائيًا.
    session = SQLiteSession("student-demo")

    print("Session: student-demo")
    print("Type 'exit' to quit.\n")

    while True:
        try:
            user_input = input("> ").strip()
        except EOFError:
            break

        if not user_input or user_input == "exit":
            break

        answer = run_agent(user_input, session)
        print(f"\n{answer}\n")


if __name__ == "__main__":
    main()
```

## ما يفعله الـ Agent

```text
- يستقبل طلب.
- يقرّر أي tool (أو لا شيء).
- ينفّذ tool read-only.
- يحفظ history عبر SQLiteSession (في الذاكرة افتراضيًا).
- يجيب بالعربية.
```

## ما لا يفعله (عمدًا)

```text
- لا يصل لـ network خارج الـ OpenAI API.
- لا ينفّذ كود (لا eval/exec/compile).
- لا يكتب إلى filesystem (لا scratchpad، لا sessions JSON).
- لا يحذف مستندات.
- لا يستدعي processes خارجية عبر الـ shell.
```

## Acceptance Criteria

```text
□ tools آمنة فقط (لا eval، لا exec، لا compile، لا shelling out).
□ لا filesystem writes من أي tool.
□ max_turns=10 صارم.
□ guardrail يستخدم GuardrailFunctionOutput + @input_guardrail (لا @InputGuardrail).
□ SQLiteSession يحفظ history بين الـ turns.
□ session_id متمايز لكل طالب في تطبيق حقيقي.
□ الكود موثّق بالعربية.
□ API key و model من env vars (لا hardcoded).
```

## Tests يدوية مقترحة

```text
1. "احسب 100 / 4" → الجواب 25.
2. "ما معلومات دورة rag-fundamentals؟" → get_course_info نُفّذ.
3. "ابحث عن embeddings في الملاحظات" → search_course_notes نُفّذ.
4. "rm -rf /" → guardrail رفض (tripwire).
5. "كم اسمي؟" بعد رسالة "اسمي أحمد" (في نفس الـ session) → memory محفوظة.
```

## Risks

```text
- LLM يستدعي tool غير متوقّع:
  → SDK يتحقّق من schema؛ لكن semantic validation أنت مسؤول عنها.

- max_turns منخفض جدًا:
  → ارفعه لمهام أطول، لكن راقب cost.

- session طويل جدًا:
  → أضف compaction (درس 132) — لخّص القديم واحتفظ بآخر N turn.

- in-memory SQLiteSession تضيع بانتهاء البرنامج:
  → استخدم db_path للـ persistence.
```

## الأخطاء الشائعة

- **استخدام التقييم الديناميكي للـ expressions في tool**: كارثة. استخدم parser آمن.
- **filesystem writes في tool**: يخالف سياسة المشروع — كل الأدوات read-only.
- **max_turns غير محدود**: قد يدخل في loop لا نهائي.
- **`@InputGuardrail` decorator مباشرة**: API غير موجود. استخدم `@input_guardrail` مع `GuardrailFunctionOutput`.
- **API key في الكود**: security issue — استخدم env vars.
- **عدم استخدام session**: memory تضيع بين runs.

## ما بعد المشروع

```text
- أضف RAG tool (يستخدم retrieve من مشروع 207) كأداة read-only.
- أضف multi-agent (triage → study_agent) عبر handoffs أو as_tool.
- أضف logging و tracing (OPENAI_AGENTS_TRACE=1) — tracing مكافئ لـ read-only.
- أضف compaction للـ sessions الطويلة.
```
