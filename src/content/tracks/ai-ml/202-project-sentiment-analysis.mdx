## المشكلة

**تصنيف ثنائي** (إيجابي / سلبي) لنصوص قصيرة بطابع تقييم منتجات/خدمات.

## مجموعة البيانات

**اختيار صريح**: بدلًا من استخدام dataset خارجي محميّ بحقوق أو غير موزّع بحرية، نستخدم **مجموعة صغيرة مكتوبة يدويًا في الكود نفسه**. هذا:

- ✅ قابل للتشغيل **بدون تنزيل**.
- ✅ شفّاف: ترى كل عيّنة.
- ✅ لا توجد مشاكل ترخيص.
- ✅ مناسب للهدف التعليمي.
- ⚠️ **صغير جدًا** (100 عيّنة). لا تتوقّع دقّة إنتاج.

> **ملاحظة مهمّة عن العربية**: dataset كاملة بالعربية موثوقة وصغيرة وقابلة لإعادة التوزيع **صعب الحصول عليها**. نُضمّن أمثلة عربية **منفصلة** للتوضيح، لكن خط الأنابيب الرئيسي مُدرَّب على الإنجليزية. في الإنتاج: استخدم AraBERT أو corpus عربي مرخّص.

## خط الأنابيب

```text
[نصّ خام]
    ↓
train_test_split        ← فصل 75/25 قبل أيّ fit
    ↓
Pipeline([
    TfidfVectorizer(),  ← fit على train فقط
    LogisticRegression(),
])
    ↓
fit على train، score على test
```

> **الخطأ الشائع** هو fit الـ vectorizer على كل النصوص قبل split — هذا data leakage. الـ Pipeline يضمن أن TF-IDF learns idf من train فقط.

## التنفيذ الكامل

```python
import numpy as np
from sklearn.feature_extraction.text import TfidfVectorizer
from sklearn.linear_model import LogisticRegression
from sklearn.pipeline import Pipeline
from sklearn.model_selection import train_test_split, cross_val_score
from sklearn.metrics import classification_report, confusion_matrix

np.random.seed(42)

# === البيانات (مختصرة هنا؛ استخدم scripts/_wave5_local_validate.py للقائمة الكاملة) ===
texts = ["amazing product", "terrible quality", "great service", "awful experience"] * 25
labels = [1, 0, 1, 0] * 25

# === فصل train/test قبل أيّ fit ===
X_train, X_test, y_train, y_test = train_test_split(
    texts, labels, test_size=0.25, random_state=42, stratify=labels
)

# === Pipeline ===
pipe = Pipeline([
    ("tfidf", TfidfVectorizer(lowercase=True, ngram_range=(1, 2))),
    ("clf", LogisticRegression(max_iter=1000, random_state=42)),
])

pipe.fit(X_train, y_train)
```

## التقييم

```python
train_acc = pipe.score(X_train, y_train)
test_acc = pipe.score(X_test, y_test)
print(f"Train accuracy: {train_acc:.3f}")
print(f"Test  accuracy: {test_acc:.3f}")

y_pred = pipe.predict(X_test)
print()
print(classification_report(y_test, y_pred, target_names=["neg", "pos"], digits=3))
print("Confusion matrix:")
print(confusion_matrix(y_test, y_pred))
```

## أمثلة عربية (محدودة)

`TfidfVectorizer` المُدرَّب على الإنجليزية **لا يتعرّف** على كلمات عربية. هذه الأمثلة لإظهار **حدود** خط الأنابيب الكلاسيكي مع اللغات المختلفة:

```python
arabic_examples = [
    ("منتج رائع جدا وانصح به", 1),
    ("الجودة ممتازة والشحن سريع", 1),
    ("سيء جدا وخاب املي", 0),
    ("المنتج مكسور وخدمة العملاء سيئة", 0),
]
```

**النتيجة المتوقّعة** (TF-IDF الإنجليزية):

```text
expected=1 pred=1   "منتج رائع جدا وانصح به"              ← أحيانًا يصدف
expected=1 pred=1   "الجودة ممتازة والشحن سريع"           ← أحيانًا يصدف
expected=0 pred=1   "سيء جدا وخاب املي"                   ← غالبًا يخطئ
expected=0 pred=1   "المنتج مكسور وخدمة العملاء سيئة"      ← غالبًا يخطئ
```

> **السبب**: TfidfVectorizer لا يحلل بنية الكلمة، فقط يبحث في vocab. النصّ العربي يصبح OOV بالنسبة للمودل الإنجليزي.

**للتعامل الصحيح مع العربية**: استخدم AraBERT أو XLM-RoBERTa (سيُغطّى في الموجات التالية).

## خطورة data leakage

**الكارثة**:

```python
# ❌ لا تفعل هذا
tfidf = TfidfVectorizer()
X_all = tfidf.fit_transform(texts)            # fit على الكل!
X_train, X_test, y_train, y_test = train_test_split(X_all, labels)
model = LogisticRegression().fit(X_train, y_train)
```

**النتيجة**: TF-IDF idf weights شوهدت بيانات الاختبار → الدقّة مُتفائلة كاذبة.

**الصحيح**:

```python
# ✅ Pipeline يضمن fit على train فقط
pipe = Pipeline([("tfidf", TfidfVectorizer()), ("clf", LogisticRegression())])
X_train, X_test, y_train, y_test = train_test_split(texts, labels)
pipe.fit(X_train, y_train)
pipe.score(X_test, y_test)
```

## تجارب يمكنك تجربتها

1. **`ngram_range=(1, 1)` vs `(1, 2)`**: قارن الأثر. bigrams تلتقط "not good" ككلمة واحدة.
2. **`max_features`** في TfidfVectorizer: حدّ عدد المفردات. جرّب 100، 500، 2000.
3. **`min_df=2`**: تجاهل الكلمات النادرة جدًا.
4. **`stop_words='english'`**: أزل stopwords. لاحظ الفرق (في هذا dataset قد يضعف الأداء).
5. **`class_weight='balanced'`**: إذا كانت الفئات غير متوازنة.
6. **استبدل LogisticRegression بـ SVM**: `LinearSVC` أسرع على بيانات كبيرة.
7. **استخدم GridSearchCV** للبحث في hyperparameters.

## ملاحظات مهمّة

- **Dataset صناعية، 100 عيّنة فقط** — لا تعمّم هذه النتائج على بيانات حقيقية.
- **النتائج العالية متوقّعة** لأن البيانات بسيطة جدًا — كلمات مفتاحية واضحة بدون سخرية أو غموض.
- **TF-IDF + Logistic Regression** خط أساس قوي للبيانات المحدودة. للبيانات الكبيرة، جرّب BERT/AraBERT.
- **أمثلة عربية للتوضيح فقط** — نموذج TF-IDF الإنجليزي لا يحلّل العربية.
- **نتائجك قد تختلف** إذا غيّرت `random_state` أو البيانات. للنتائج المستقرّة استخدم `cross_val_score`.

## أخطاء شائعة

- **fit الـ vectorizer على كامل النصوص قبل split**: data leakage كارثي.
- **تقييم فقط بـ accuracy على بيانات غير متوازنة**: استخدم `classification_report`.
- **عدم استخدام `stratify`** في train_test_split: انحياز في التقسيم.
- **توقّع دقّة عالية على بيانات حقيقية**: dataset هنا بسيط جدًّا.
- **اعتبار نتائج top features "تفسيرًا كاملاً"**: تُظهر أهمّ الكلمات، ليست "سبب القرار" بشكل سببي.
