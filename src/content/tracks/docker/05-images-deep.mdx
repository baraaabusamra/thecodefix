## تنزيل صورة بوسم محدّد

```bash
docker pull node:20        # وسم الإصدار
docker pull node:20-alpine # نسخة أصغر حجمًا
docker pull node           # = node:latest
```

## الطبقات (Layers)

كل صورة مبنية من طبقات متراكمة. الطبقات المشتركة تُخزّن مرّة واحدة فتوفّر مساحة وتسرّع التنزيل.

```bash
docker history node:20    # عرض طبقات الصورة
```

## إدارة الصور

```bash
docker images             # عرض الصور
docker rmi node:20        # حذف صورة
docker image prune        # حذف الصور غير المستخدمة
docker inspect node:20    # تفاصيل دقيقة
```

## اختر صورًا صغيرة

> 💡 نسخ `alpine` أصغر بكثير (~5MB أساس) — مثالية للإنتاج لتقليل الحجم وسطح الهجوم.

> 🎯 التالي: الحاويات بالتفصيل.
