## حلقة for

```c
for (int i = 0; i < 5; i++) {
    printf("%d ", i);   // 0 1 2 3 4
}
```

البنية ثلاثة أجزاء بينها فاصلة منقوطة:

1. **التهيئة** (`int i = 0`): تُنفَّذ مرة واحدة قبل البدء.
2. **الشرط** (`i < 5`): يُفحص **قبل** كل دورة؛ إذا كان خطأ تنتهي الحلقة.
3. **الخطوة** (`i++`): تُنفَّذ في **آخر** كل دورة.

استخدم `for` حين تعرف عدد الدورات أو تمرّ على مدى أرقام.

## حلقة while

تُكرّر طالما الشرط صحيح، وتناسب الحالات التي **لا تعرف** فيها عدد الدورات مسبقًا:

```c
int n = 1234, digits = 0;
while (n > 0) {
    n /= 10;      // احذف آخر رقم
    digits++;
}
printf("%d\n", digits);   // 4
```

## حلقة do...while

تُنفَّذ مرّة واحدة على الأقل قبل فحص الشرط. مثالها الكلاسيكي: اطلب الإدخال حتى يكون صحيحًا (السؤال يجب أن يُطرح مرة على الأقل):

```c
int choice;
do {
    printf("اختر رقمًا من 1 إلى 3: ");
    if (scanf("%d", &choice) != 1) break;   // إدخال غير رقمي
} while (choice < 1 || choice > 3);
```

لاحظ الفاصلة المنقوطة بعد `while (...)` في آخر `do...while`؛ هي مطلوبة هنا فقط.

## break و continue

```c
for (int i = 0; i < 10; i++) {
    if (i == 5) break;       // أوقف الحلقة
    if (i % 2 == 0) continue; // تخطَّ هذه الدورة
    printf("%d ", i);         // 1 3
}
```

`break` تخرج من **الحلقة الداخلية فقط**. للخروج من حلقتين متداخلتين، استخدم متغيّرًا منطقيًا أو انقل الحلقتين لدالة واخرج بـ `return`:

```c
int found = 0;
for (int r = 0; r < 3 && !found; r++) {
    for (int c = 0; c < 3; c++) {
        if (r * c == 2) { found = 1; break; }
    }
}
```

## الحلقة اللانهائية المقصودة

بعض البرامج (الخوادم، الألعاب، الأنظمة المدمجة) تعمل حتى تُوقَف. الصيغة المعتادة `for (;;)` أو `while (1)`، مع `break` أو `return` عند شرط الخروج:

```c
int tries = 0;
for (;;) {
    tries++;
    if (tries == 3) break;
}
printf("%d\n", tries);   // 3
```

## أخطاء شائعة

- **دورة زائدة أو ناقصة (off-by-one):** لمصفوفة من `n` عنصر، الفهارس من `0` إلى `n - 1`، فالشرط الصحيح `i < n` لا `i <= n`. الدورة الزائدة تقرأ خارج المصفوفة بصمت.
- **فاصلة منقوطة بعد رأس الحلقة:** `for (int i = 0; i < 5; i++);` حلقة بجسم فارغ، والكتلة بعدها تُنفَّذ مرة واحدة فقط.
- **العدّ التنازلي بنوع unsigned:** حلقة لا تنتهي، لأن المتغيّر لا يصبح سالبًا أبدًا؛ بعد الصفر يلتفّ لأكبر قيمة:

```c
// ❌ لا تنتهي: i >= 0 صحيح دائمًا مع unsigned
// for (unsigned int i = 4; i >= 0; i--) { ... }

// ✅ الصيغة الآمنة للعدّ التنازلي مع unsigned
for (unsigned int i = 5; i-- > 0; ) {
    printf("%u ", i);   // 4 3 2 1 0
}
```

`-Wextra` في gcc يحذّرك من الشرط الدائم الصحيح.

- **عدّاد عشري:** `for (double x = 0; x != 1.0; x += 0.1)` قد لا تنتهي أبدًا، لأن `0.1` لا تُخزَّن بدقّة فلا يصل `x` إلى `1.0` تمامًا. استخدم عدّادًا صحيحًا واحسب الكسر منه: `x = i / 10.0`.
- **نسيان تغيير المتغيّر داخل `while`:** الشرط لا يتغيّر فلا تنتهي الحلقة.
