## أصغر برنامج C

```c
#include <stdio.h>

int main(void) {
    printf("مرحبًا بالعالم\n");
    return 0;
}
```

اقرأه سطرًا سطرًا:

- `#include <stdio.h>` ليس كود C بالمعنى الدقيق، بل أمر لـ **المعالج المسبق** (preprocessor): "انسخ هنا محتوى ملف الرأس `stdio.h`". هذا الملف يحتوي **تصريحات** دوال الإدخال والإخراج مثل `printf`، فيعرف المترجم شكلها قبل أن تستدعيها.
- `int main(void)` نقطة بداية تنفيذ كل برنامج C. كلمة `int` تعني أن `main` تُرجع عددًا صحيحًا لنظام التشغيل، و`void` تعني أنها لا تأخذ معاملات (سترى لاحقًا نسخة تأخذ معاملات سطر الأوامر).
- `return 0;` تُرجع **رمز الخروج** (exit code) للنظام: `0` يعني "انتهيت بنجاح"، وأي قيمة أخرى تعني فشلًا. السكربتات وأدوات البناء تعتمد على هذا الرقم لتعرف هل نجح برنامجك.

## من ملف نصي إلى برنامج يعمل

C لغة **مترجَمة**: الكود لا يُنفَّذ مباشرة، بل يتحوّل أولًا إلى ملف تنفيذي. احفظ البرنامج في `hello.c` ثم:

```bash
gcc hello.c -o hello    # ترجمة
./hello                  # تشغيل (على Windows: hello.exe)
```

خلف أمر `gcc` الواحد أربع مراحل:

1. **المعالجة المسبقة:** تنفيذ أوامر `#` مثل `#include`.
2. **الترجمة:** تحويل C إلى لغة تجميع (assembly) خاصة بمعالجك.
3. **التجميع:** تحويلها إلى كود آلة في ملف كائن (`.o`).
4. **الربط (linking):** وصل كودك بكود المكتبات (مثل كود `printf` الفعلي) في ملف تنفيذي واحد.

معرفة المراحل تفيدك في قراءة الأخطاء: خطأ "undefined reference" مثلًا يأتي من **الربط**، لا من الترجمة، ومعناه أن المترجم وجد التصريح لكن الرابط لم يجد التعريف.

## الطباعة بـ printf

```c
printf("سطر مع نزول\n");
printf("بلا نزول");
printf("العمر: %d\n", 25);   // %d لإدراج عدد صحيح
```

`printf` لا تضيف سطرًا جديدًا من تلقاء نفسها، فالسطر الثاني يلتصق بما بعده. و`%d` عنصر نائب (placeholder) يُستبدل بالقيمة التي بعد الفاصلة. ستتعرّف على باقي المحدّدات (`%f` و`%c` و`%s`) في درس أنواع البيانات.

### رموز الهروب (Escape Sequences)

بعض الحروف لا تُكتب مباشرة داخل النص، فنكتبها بشرطة مائلة عكسية:

| الرمز | المعنى |
| --- | --- |
| `\n` | سطر جديد |
| `\t` | مسافة جدولة (Tab) |
| `\"` | علامة تنصيص داخل النص |
| `\\` | الشرطة المائلة العكسية نفسها |
| `%%` | علامة `%` حرفية داخل `printf` |

```c
printf("الاسم\tالدرجة\n");
printf("قال: \"مرحبًا\"\n");
printf("نسبة النجاح 90%%\n");
```

## التعليقات

```c
// تعليق سطر واحد

/* تعليق
   متعدّد الأسطر */
```

اكتب في التعليق **لماذا** فعلت شيئًا، لا **ماذا** يفعل السطر؛ الكود نفسه يقول ماذا يفعل.

## القواعد الأساسية

- كل جملة (statement) تنتهي بفاصلة منقوطة `;`.
- الكتل محصورة بين `{ }`.
- C حسّاسة لحالة الأحرف: `Main` ≠ `main`، و`Printf` دالة غير موجودة.
- المسافات والأسطر الفارغة لا تهمّ المترجم، لكنها تهمّ من يقرأ كودك؛ التزم بمسافة بادئة ثابتة.

## أخطاء شائعة

- **نسيان `#include <stdio.h>`:** المترجم الحديث يرفض أو يحذّر من "implicit declaration of function printf". لا تتجاهل هذا التحذير.
- **نسيان الفاصلة المنقوطة:** رسالة الخطأ غالبًا تشير إلى **السطر التالي** لا السطر الناقص، لأن المترجم يكتشف المشكلة حين يصل إلى ما بعده. إذا لم ترَ خطأ في السطر المذكور، انظر للسطر الذي قبله.
- **`printf` بدون `\n` ثم انهيار البرنامج:** المخرجات تُخزَّن مؤقتًا (buffered) وقد لا تظهر أبدًا إذا انهار البرنامج قبل تفريغها، فتظن أن الانهيار حدث قبل الطباعة.
- **كتابة `%` وحدها في `printf`:** تُفسَّر كبداية محدّد تنسيق. استخدم `%%`.
