## التعداد (enum)

حين يكون للمتغيّر مجموعة قيم محدودة (حالة طلب، يوم، لون)، يمكنك تمثيلها بأرقام: 0 = جديد، 1 = مدفوع، 2 = ملغى. لكن `if (status == 2)` لا يقول شيئًا لمن يقرأ. التعداد يعطي هذه الأرقام **أسماء**:

```c
enum Day { SUN, MON, TUE, WED };  // 0, 1, 2, 3

enum Day today = TUE;
printf("%d\n", today);   // 2
```

يمكن تحديد القيم بنفسك، والتالية تكمل العدّ من آخر قيمة:

```c
enum Status { OK = 200, CREATED, NOT_FOUND = 404 };   // CREATED = 201
```

### مثال عملي: حالة طلب

```c
typedef enum { ORDER_NEW, ORDER_PAID, ORDER_CANCELLED, ORDER_COUNT } OrderStatus;

const char *status_names[ORDER_COUNT] = { "جديد", "مدفوع", "ملغى" };

const char *describe(OrderStatus s) {
    switch (s) {
        case ORDER_NEW:       return "بانتظار الدفع";
        case ORDER_PAID:      return "قيد التجهيز";
        case ORDER_CANCELLED: return "لا إجراء";
        default:              return "غير معروف";
    }
}

int main(void) {
    OrderStatus s = ORDER_PAID;
    printf("%s: %s\n", status_names[s], describe(s));   // مدفوع: قيد التجهيز
    return 0;
}
```

حيلتان مفيدتان هنا:

- **`ORDER_COUNT` في الآخر** تساوي عدد القيم تلقائيًا، فتستخدمها حجمًا للمصفوفات وحدًّا للحلقات، وتبقى صحيحة إذا أضفت حالة جديدة قبلها.
- **`switch` على enum:** إذا حذفت `default` ونسيت حالة، فإن `-Wall` يحذّرك (`-Wswitch`) بأن قيمة من التعداد غير مغطّاة. هذا يكشف الأماكن التي تحتاج تحديثًا حين تضيف قيمة.

### enum ليس حماية للأنواع

في C قيم التعداد مجرّد أعداد صحيحة. المترجم يقبل `enum Day d = 42;` أو خلط تعدادين مختلفين بلا خطأ. الاسم يخدم القارئ، لكن التحقّق من أن القيمة ضمن المدى مسؤوليتك (مثلًا قبل استخدامها فهرسًا في `status_names`).

## الاتحاد (union)

يشبه الهيكل في الشكل، لكن كل الحقول تتشارك **نفس** موقع الذاكرة. لذلك حجمه حجم **أكبر** حقل (مع حشو محتمل)، وحقل واحد فقط يحمل قيمة ذات معنى في كل لحظة:

```c
union Value {
    int i;
    double d;
    char c;
};

printf("%zu\n", sizeof(union Value));   // 8: حجم double

union Value v;
v.i = 65;
printf("%d\n", v.i);   // 65
v.d = 2.5;             // كتب فوق نفس البايتات: v.i لم يعد 65
printf("%.1f\n", v.d); // 2.5
```

قراءة حقل غير الذي كتبته آخر مرة تعطيك نفس البايتات مفسَّرة بنوع آخر، وهذا نادرًا ما تريده.

## النمط الحقيقي: Tagged Union

الاتحاد وحده لا يعرف أي حقل هو الفعّال. لذلك يُستخدم عمليًا داخل هيكل مع **وسم** (enum) يقول أي حقل يحمل القيمة. هكذا تبني متغيّرًا "قد يكون رقمًا أو نصًّا"، كما في محلّلات JSON والمفسّرات:

```c
typedef enum { V_INT, V_TEXT } Kind;

typedef struct {
    Kind kind;              // الوسم: أي حقل فعّال
    union {
        int number;
        const char *text;
    } as;
} Value;

void print_value(Value v) {
    switch (v.kind) {
        case V_INT:  printf("رقم: %d\n", v.as.number); break;
        case V_TEXT: printf("نص: %s\n", v.as.text);   break;
    }
}

int main(void) {
    Value a = { .kind = V_INT,  .as.number = 7 };
    Value b = { .kind = V_TEXT, .as.text = "مرحبًا" };
    print_value(a);
    print_value(b);
    return 0;
}
```

القاعدة: كل مكان يكتب في الاتحاد يضبط الوسم، وكل مكان يقرأ يفحص الوسم أولًا.

## struct أم union؟

- **struct:** كل الحقول موجودة معًا. استخدمه حين يملك الشيء **كل** هذه الخصائص (طالب له اسم **و**عمر).
- **union:** حقل واحد فعّال. استخدمه حين يكون الشيء **أحد** هذه الأشكال (قيمة هي رقم **أو** نص)، وغالبًا داخل tagged union.

## أخطاء شائعة

- **افتراض أن enum يمنع القيم الخاطئة:** يقبل أي عدد صحيح؛ افحص المدى قبل استخدامه فهرسًا.
- **طباعة اسم enum مباشرة:** `printf("%s", today)` لا يطبع "TUE". تحتاج مصفوفة أسماء كما في المثال.
- **قراءة حقل اتحاد غير الذي كُتب آخرًا:** احمل الوسم معه دائمًا.
- **`default` في كل switch على enum:** يُسكت تحذير `-Wswitch` المفيد. احذفه حين تريد أن ينبّهك المترجم للحالات الناقصة.
