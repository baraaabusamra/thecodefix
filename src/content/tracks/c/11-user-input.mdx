## قراءة رقم

```c
int age;
printf("كم عمرك؟ ");
scanf("%d", &age);          // لاحظ & قبل المتغيّر
printf("عمرك %d\n", age);
```

### لماذا `&`؟

C تمرّر المعاملات للدوال **بالقيمة** (نسخة). لو كتبت `scanf("%d", age)` لاستلمت `scanf` نسخة من القيمة الحالية ولا تستطيع تغيير `age` الأصلي. `&age` تعطيها **عنوان** المتغيّر في الذاكرة، فتكتب فيه مباشرة. ستفهم هذا بعمق في درس المؤشّرات.

استثناء: المصفوفات (ومنها النصوص) تُمرَّر كعنوان أصلًا، فلا تحتاج `&`.

## افحص ما تُرجعه scanf

إذا كتب المستخدم `abc` بدل رقم، تفشل `scanf` وتترك `age` بقيمته العشوائية، والبرنامج يكمل بها بصمت. `scanf` تُرجع **عدد القيم التي قرأتها بنجاح**، فافحصه:

```c
int age;
if (scanf("%d", &age) != 1) {
    printf("الرجاء إدخال رقم صحيح\n");
    return 1;
}
printf("عمرك %d\n", age);
```

## قراءة عدّة قيم

```c
int a, b;
if (scanf("%d %d", &a, &b) == 2) {
    printf("المجموع %d\n", a + b);
}
```

`%d` يتخطّى المسافات والأسطر الجديدة قبل الرقم تلقائيًا، فيعمل الإدخال `3 4` أو `3` ثم Enter ثم `4`.

## قراءة نص بأمان مع fgets

`scanf("%s")` لها مشكلتان: تتوقّف عند أول مسافة (فـ "محمد علي" تصبح "محمد")، و**لا تعرف حجم المصفوفة** فتكتب خارجها إذا كان الإدخال أطول. إذا اضطررت لها فحدّد العرض: `scanf("%49s", name)` لمصفوفة من 50.

الأفضل `fgets`، التي تقرأ سطرًا كاملًا ولا تتجاوز الحجم المعطى:

```c
char line[100];
if (fgets(line, sizeof(line), stdin) != NULL) {
    line[strcspn(line, "\n")] = '\0';   // احذف سطر Enter من الآخر
    printf("[%s]\n", line);
}
```

`fgets` تحتفظ بحرف `\n` (ضغطة Enter) في آخر النص. `strcspn(line, "\n")` تُرجع موضع أول `\n` (أو طول النص إن لم يوجد)، فنضع الصفر مكانه. بدون هذا السطر ستفشل مقارنات مثل `strcmp(line, "yes")`.

## السطر العالق: خلط scanf و fgets

```c
int age;
char name[50];

scanf("%d", &age);                  // يقرأ الرقم ويترك \n في المخزن
fgets(name, sizeof(name), stdin);   // يقرأ \n المتبقّي فورًا: name فارغ!
```

المستخدم كتب `25` ثم Enter. `scanf` أخذت `25` وتركت Enter، فوجدته `fgets` واعتبرته سطرًا فارغًا. الحلّان:

1. **تخلّص من باقي السطر** بعد `scanf`:

```c
int ch;
while ((ch = getchar()) != '\n' && ch != EOF) { }
```

2. **الأنظف:** اقرأ كل شيء بـ `fgets` ثم حوّل الأرقام من النص بـ `strtol` (درس تحويل النصوص والأرقام). هكذا لا يبقى شيء عالق، وتتحكّم في الأخطاء بالكامل.

ومع قراءة حرف واحد استخدم `scanf(" %c", &c)`: المسافة قبل `%c` تتخطّى أي `\n` متبقٍّ.

## أخطاء شائعة

- **نسيان `&`:** `scanf("%d", age)` تكتب في عنوان عشوائي، والنتيجة غالبًا انهيار. `-Wall` يحذّرك.
- **عدم فحص القيمة المرجعة:** إدخال غير رقمي يترك المتغيّر بقيمة عشوائية.
- **`%s` بلا حد للعرض:** تجاوز ذاكرة مع أي إدخال طويل.
- **نسيان حذف `\n` من `fgets`:** المقارنات تفشل لأن النص `"yes\n"` لا `"yes"`.
- **`%f` لمتغيّر `double` في scanf:** استخدم `%lf`.
