## قراءة رقم

```c
int age;
printf("كم عمرك؟ ");
scanf("%d", &age);          // لاحظ & قبل المتغيّر
printf("عمرك %d\n", age);
```

> ⚠️ `scanf` تحتاج `&` (عنوان المتغيّر) للأنواع البسيطة مثل `int` و`float`.

## قراءة عدّة قيم

```c
int a, b;
scanf("%d %d", &a, &b);
printf("المجموع %d\n", a + b);
```

## قراءة نص بأمان مع fgets

`scanf("%s")` يتوقّف عند أول فراغ؛ لقراءة سطر كامل:

```c
char line[100];
fgets(line, sizeof(line), stdin);
```

`fgets` تحدّ القراءة بحجم المخزن فتمنع تجاوز الذاكرة (أأمن).

## أخطاء شائعة

- نسيان `&` في `scanf` → تعطّل البرنامج.
- خلط `scanf` و`fgets` يترك سطرًا جديدًا عالقًا في المخزن.
