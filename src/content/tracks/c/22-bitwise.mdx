## لماذا البتّات؟

كل عدد صحيح في الذاكرة سلسلة من البتّات (أصفار وآحاد). عوامل البتّات تعمل على كل بت على حدة، وتحتاجها حين تتعامل مع ما هو "ثنائي" بطبيعته:

- **الأعلام (flags):** تخزين عدّة خيارات نعم/لا في عدد واحد (صلاحيات ملف، إعدادات).
- **العتاد والأنظمة المدمجة:** كل بت في سجلّ متحكّم دقيق يشغّل أو يطفئ شيئًا (مصباح، منفذ).
- **البروتوكولات وصيغ الملفات:** قراءة حقول محشورة داخل بايتات.

## عوامل البتّات

| العامل | المعنى | القاعدة |
| --- | --- | --- |
| `&` | AND | 1 إذا كان البتّان 1 |
| `\|` | OR | 1 إذا كان أحدهما 1 |
| `^` | XOR | 1 إذا اختلفا |
| `~` | NOT | قلب كل البتّات |
| `<<` | إزاحة لليسار | تحريك البتّات يسارًا |
| `>>` | إزاحة لليمين | تحريك البتّات يمينًا |

```c
unsigned a = 6;   // 110
unsigned b = 3;   // 011

printf("%u\n", a & b);  // 2  (010)
printf("%u\n", a | b);  // 7  (111)
printf("%u\n", a ^ b);  // 5  (101)
printf("%u\n", a << 1); // 12 (1100): إزاحة بت = ضرب في 2
printf("%u\n", a >> 1); // 3  (011): قسمة على 2
```

## العمليات الأربع على بت واحد

هذه هي الوصفات التي ستكتبها مرارًا. `1u << n` تصنع **قناعًا** (mask) فيه بت واحد فقط في الموضع `n`:

```c
unsigned x = 0;
int n = 3;

x |=  (1u << n);            // تشغيل البت 3:   x = 8
int on = (x >> n) & 1u;     // فحصه:           1
x ^=  (1u << n);            // قلبه:           x = 0
x |=  (1u << n);
x &= ~(1u << n);            // إطفاؤه:         x = 0

printf("%u %d\n", x, on);   // 0 1
```

- **التشغيل** بـ `|`: البت يصبح 1، والباقي لا يتغيّر.
- **الإطفاء** بـ `&` مع قناع مقلوب: كل البتّات 1 ما عدا الهدف، فيُصفَّر وحده.
- **القلب** بـ `^`.
- **الفحص** بالإزاحة ثم `& 1`.

## مثال عملي: صلاحيات بالأعلام

```c
enum {
    PERM_READ  = 1u << 0,   // 001
    PERM_WRITE = 1u << 1,   // 010
    PERM_EXEC  = 1u << 2    // 100
};

int main(void) {
    unsigned perms = PERM_READ | PERM_WRITE;   // قراءة وكتابة

    if (perms & PERM_WRITE) printf("يمكنه الكتابة\n");
    if (!(perms & PERM_EXEC)) printf("لا يمكنه التنفيذ\n");

    perms &= ~PERM_WRITE;                      // سحب صلاحية الكتابة
    printf("%u\n", perms);                     // 1
    return 0;
}
```

عدد واحد يحمل ثلاث صلاحيات، وتمريرها لدالة يصبح معاملًا واحدًا: `open_file("x", PERM_READ | PERM_EXEC)`. هذه الفكرة نفسها وراء صلاحيات الملفات في Linux (`chmod 755`) وخيارات كثير من دوال النظام.

## استخدامات صغيرة شائعة

- **فحص الفردية:** `if (n & 1)` تعني أن آخر بت 1، أي عدد فردي. وتعمل مع السالب أيضًا على الأنظمة الحالية.
- **هل العدد قوة للعدد 2؟** `n != 0 && (n & (n - 1)) == 0`: قوى 2 فيها بت واحد فقط.
- **الضرب والقسمة على 2:** `n << 1` و`n >> 1`. لكن المترجم يحوّل `n * 2` لإزاحة بنفسه؛ اكتب ما هو أوضح للقارئ.

## أخطاء شائعة

- **الأولوية:** `==` تُنفَّذ **قبل** `&`، فـ `x & 1 == 0` تعني `x & (1 == 0)`، أي `x & 0`، وهي صفر دائمًا. ضع الأقواس دائمًا: `(x & 1) == 0`. `-Wall` يحذّرك (`-Wparentheses`).
- **الإزاحة بعدد البتّات أو أكثر:** `1u << 32` مع `unsigned` من 32 بتًا سلوك غير معرّف، لا صفر.
- **الإزاحة مع أعداد سالبة:** إزاحة عدد سالب لليسار سلوك غير معرّف، ولليمين نتيجتها تعتمد على المترجم. استخدم أنواع `unsigned` لكل عمل على البتّات.
- **`1 << 31` بدل `1u << 31`:** الرقم `1` من نوع `int` الموقّع، فإزاحته لموضع الإشارة تجاوز. أضف `u`.
- **الخلط بين `&` و`&&`:** `&&` منطقية (صح/خطأ للتعبير كله)، و`&` تعمل بتًا بتًا. `2 && 1` = 1، أما `2 & 1` = 0.
