## الفكرة: FILE ومخزن مؤقت

`fopen` تفتح ملفًا وتُرجع مؤشّرًا إلى `FILE`، وهو هيكل تديره المكتبة يحفظ موضعك في الملف و**مخزنًا مؤقتًا** (buffer). الكتابة لا تذهب للقرص فورًا، بل تتجمّع في المخزن وتُكتب دفعة واحدة، لأن الوصول للقرص بطيء. `fclose` تفرّغ ما تبقّى وتغلق الملف.

كل ما تعلّمته عن `printf` و`scanf` و`fgets` يعمل مع الملفات بنسخة تبدأ بحرف `f`: `fprintf` و`fscanf` و`fgets`، مع الملف كمعامل.

## فتح وكتابة ملف

```c
FILE *f = fopen("data.txt", "w");   // w = كتابة (يمسح المحتوى القديم)
if (f == NULL) {
    perror("data.txt");             // مثلًا: data.txt: Permission denied
    return 1;
}

fprintf(f, "الاسم,الدرجة\n");
fprintf(f, "%s,%d\n", "سارة", 92);
fclose(f);
```

**افحص `fopen` دائمًا.** الملف قد لا يوجد، أو لا تملك صلاحية، أو المجلّد غير موجود. استخدام `NULL` بعدها انهيار مؤكّد، و`perror` تطبع السبب الحقيقي (درس معالجة الأخطاء).

## أوضاع الفتح

| الوضع | المعنى | إذا لم يوجد الملف |
| --- | --- | --- |
| `"r"` | قراءة فقط | يفشل (NULL) |
| `"w"` | كتابة، **يمسح** المحتوى القديم | يُنشأ |
| `"a"` | إضافة في النهاية | يُنشأ |
| `"r+"` | قراءة وكتابة | يفشل |

احذر `"w"`: فتح ملف مهمّ بها يمسحه **فورًا**، حتى قبل أن تكتب شيئًا. لإضافة سطر لملف سجلّ استخدم `"a"`.

## القراءة سطرًا سطرًا

```c
FILE *f = fopen("data.txt", "r");
if (f == NULL) { perror("data.txt"); return 1; }

char line[256];
int n = 0;
while (fgets(line, sizeof(line), f) != NULL) {
    line[strcspn(line, "\n")] = '\0';
    printf("%d: %s\n", ++n, line);
}
fclose(f);
```

الحلقة تتوقّف حين تُرجع `fgets` القيمة `NULL`، أي عند نهاية الملف أو خطأ قراءة. هذا هو النمط الصحيح.

### الخطأ المشهور: while (!feof(f))

```c
// ❌ يعالج آخر سطر مرّتين
// while (!feof(f)) {
//     fgets(line, sizeof(line), f);
//     printf("%s", line);
// }
```

`feof` لا تتنبّأ بالمستقبل: تصبح صحيحة فقط **بعد** أن تفشل محاولة قراءة. فبعد قراءة آخر سطر تكون ما زالت خطأ، فتدخل الحلقة مرة إضافية، تفشل `fgets` وتترك `line` كما هو، فيُطبع آخر سطر مرّتين. القاعدة: **افحص نتيجة دالة القراءة نفسها**، واستخدم `feof` بعد الحلقة فقط إن أردت التمييز بين "انتهى الملف" و"حدث خطأ".

## ملفات نصية أم ثنائية؟

- **نصية:** تقرؤها بعينك (CSV، سجلّات، إعدادات). تُكتب بـ `fprintf` وتُقرأ بـ `fgets`.
- **ثنائية:** بايتات خام (صور، أو بيانات تحفظها وتسترجعها بسرعة). افتحها بـ `"rb"` و`"wb"`، واستخدم `fwrite` و`fread`:

```c
int scores[3] = {90, 75, 88};

FILE *out = fopen("scores.bin", "wb");
if (out == NULL) return 1;
fwrite(scores, sizeof scores[0], 3, out);   // 3 عناصر بحجم int
fclose(out);

int loaded[3];
FILE *in = fopen("scores.bin", "rb");
if (in == NULL) return 1;
size_t got = fread(loaded, sizeof loaded[0], 3, in);
fclose(in);
printf("%zu: %d %d %d\n", got, loaded[0], loaded[1], loaded[2]);   // 3: 90 75 88
```

`fread` تُرجع **عدد العناصر** المقروءة فعلًا؛ إذا كان أقل مما طلبت فالملف أقصر من المتوقّع. والحرف `b` مهمّ على Windows: في الوضع النصّي يحوّل النظام نهايات الأسطر، فيُفسد البيانات الثنائية. على Linux لا فرق، لكن اكتبه دائمًا ليعمل كودك في كل مكان.

## أخطاء شائعة

- **عدم فحص `fopen`:** انهيار عند أول `fprintf` إذا لم يُفتح الملف.
- **نسيان `fclose`:** آخر جزء من البيانات قد يبقى في المخزن ولا يُكتب، وعدد الملفات المفتوحة معًا محدود.
- **`while (!feof(f))`:** افحص قيمة `fgets` أو `fscanf` أو `fread`.
- **فتح ملف مهمّ بـ `"w"`** بدل `"a"` أو `"r+"`: يُمسح فورًا.
- **مسار نسبي:** `fopen("data.txt", ...)` تبحث في **مجلّد التشغيل الحالي**، لا مجلّد البرنامج أو الكود. إذا "لم يُوجد الملف" وهو أمامك، فهذا السبب غالبًا.
