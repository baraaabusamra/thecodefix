## لماذا تهتمّ C بالنوع؟

في C كل متغيّر يحجز عددًا ثابتًا من **البايتات** في الذاكرة، والنوع هو الذي يحدّد كم بايتًا، وكيف تُفسَّر هذه البايتات: كعدد صحيح، أو كسر، أو حرف. لذلك تكتب النوع عند تعريف المتغيّر ولا يتغيّر بعدها:

```c
int age = 25;
float price = 9.99f;
double pi = 3.14159265358979;
char grade = 'A';

printf("%d - %.2f - %f - %c\n", age, price, pi, grade);
```

## الأنواع الأساسية

| النوع | يخزّن | الحجم الشائع | محدّد printf |
| --- | --- | --- | --- |
| `char` | حرف واحد (رقم صغير فعليًا) | 1 بايت | `%c` |
| `int` | عدد صحيح | 4 بايت | `%d` |
| `long` | عدد صحيح أكبر | 8 على Linux و4 على Windows | `%ld` |
| `long long` | عدد صحيح كبير | 8 بايت | `%lld` |
| `float` | كسر بدقّة نحو 7 خانات | 4 بايت | `%f` |
| `double` | كسر بدقّة نحو 15 خانة | 8 بايت | `%f` |
| `unsigned int` | عدد صحيح غير سالب | 4 بايت | `%u` |

`%.2f` تطبع رقمين بعد الفاصلة العشرية. واستخدم `double` للكسور افتراضيًا؛ `float` للحالات التي تهمّ فيها الذاكرة فعلًا (مثل ملايين القيم في الرسوميات).

## الأحجام ليست ثابتة: sizeof

المعيار يحدّد **حدًّا أدنى** فقط لكل نوع، والحجم الفعلي يعتمد على النظام والمترجم. لا تفترض، بل اسأل:

```c
printf("int: %zu بايت\n", sizeof(int));
printf("long: %zu بايت\n", sizeof(long));
printf("double: %zu بايت\n", sizeof(double));
```

`sizeof` يُرجع قيمة من نوع `size_t`، ومحدّدها `%zu`. إذا احتجت حجمًا مضمونًا (مثلًا في ملف ثنائي أو بروتوكول شبكة)، استخدم أنواع `<stdint.h>` مثل `int32_t` و`uint8_t`.

## signed و unsigned وتجاوز الحدود

كل نوع صحيح له مدى محدود. الثوابت `INT_MAX` و`INT_MIN` في `<limits.h>` تخبرك بحدوده:

```c
#include <limits.h>

printf("%d\n", INT_MAX);          // 2147483647 على معظم الأنظمة

unsigned int u = 0;
u = u - 1;
printf("%u\n", u);                // 4294967295: الأنواع unsigned تلتفّ حول الصفر
```

- النوع **unsigned** إذا تجاوز حدوده **يلتفّ** (wrap around) بشكل معرّف ومضمون.
- النوع **signed** (مثل `int` العادي) إذا تجاوز حدوده فهذا **سلوك غير معرّف** (undefined behavior): لا يوجد ضمان لما سيحدث، والمترجم يحقّ له افتراض أنه لن يحدث أبدًا. احسب بنوع أكبر (`long long`) إذا كانت القيم قد تكبر.

## الكسور ليست دقيقة

الحاسوب يخزّن الكسور بالنظام الثنائي، وبعض الكسور العشرية البسيطة مثل `0.1` لا يمكن تمثيلها بدقّة:

```c
double a = 0.1 + 0.2;
printf("%.17f\n", a);             // 0.30000000000000004
printf("%d\n", a == 0.3);         // 0: ليسا متساويين!
```

لا تقارن الكسور بـ `==`؛ قارن الفرق بهامش صغير، كما في درس مكتبة الرياضيات. ولا تستخدم `float` أو `double` للمبالغ المالية؛ خزّنها كعدد صحيح بأصغر وحدة (القروش أو الفلوس).

## char رقم في الأصل

`char` يخزّن **رمز** الحرف (قيمته في جدول ASCII)، فيمكنك التعامل معه كرقم:

```c
char c = 'A';
printf("%c = %d\n", c, c);        // A = 65
printf("%c\n", c + 1);            // B
```

`char` الواحد يتّسع لحرف إنجليزي واحد فقط. الحروف العربية في ترميز UTF-8 تأخذ بايتين لكل حرف، فلا تتّسع في `char` واحد؛ تحتاج مصفوفة، كما سترى في درس النصوص.

## القيم المنطقية

C القديمة لا تملك نوعًا منطقيًا أصيلًا: الصفر يعني "خطأ" وأي قيمة أخرى تعني "صحيح". منذ C99 تقدر تضمّن `<stdbool.h>`:

```c
#include <stdbool.h>
bool active = true;
```

وفي معيار C23 صارت `bool` و`true` و`false` كلمات مفتاحية بلا حاجة للتضمين.

## الثوابت: `#define` و `const`

القيم التي لا تتغيّر أعطها اسمًا بدل كتابة الرقم مباشرة في الكود:

```c
#define MAX_STUDENTS 30          // يُستبدل نصيًا قبل الترجمة
const double TAX_RATE = 0.16;    // متغيّر حقيقي لا يمكن تعديله

printf("%d طالب، ضريبة %.0f%%\n", MAX_STUDENTS, TAX_RATE * 100);
```

- `#define` يستبدل الاسم بالقيمة **نصيًا** قبل الترجمة، بلا نوع وبلا فاصلة منقوطة في آخره.
- `const` متغيّر له نوع، فيفحصه المترجم ويظهر باسمه في أدوات التصحيح. فضّله ما لم تحتج قيمة تُعرَف وقت الترجمة (مثل حجم مصفوفة عامة).

## أخطاء شائعة

- **محدّد خاطئ:** `printf("%d", 9.99)` يطبع قيمة عشوائية لا 9. المحدّد يجب أن يطابق النوع، و`-Wall` يحذّرك من هذا.
- **قسمة صحيحة بالخطأ:** `double avg = 7 / 2;` تعطي `3.0` لا `3.5`، لأن القسمة تمّت بين عددين صحيحين قبل التحويل. اكتب `7.0 / 2`.
- **`%lf` مع printf و scanf:** في `printf` المحدّد `%f` يكفي لـ `float` و`double` معًا، أما في `scanf` فـ `%f` لـ `float` و`%lf` لـ `double` حصرًا.
- **وضع نص في `char`:** `char c = "A";` خطأ؛ الحرف الواحد بين علامتي `' '` والنص بين `" "`.
- **فاصلة منقوطة بعد `#define`:** `#define MAX 30;` تجعل `MAX` تُستبدل بـ `30;` فتكسر أي تعبير يستخدمها.
