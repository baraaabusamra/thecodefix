## ما هو المؤشّر؟

كل متغيّر يعيش في مكان ما في الذاكرة، ولهذا المكان **عنوان** (رقم). المؤشّر متغيّر عادي، لكن قيمته **عنوان** متغيّر آخر بدل أن تكون رقمًا أو حرفًا.

```c
int age = 25;
int *ptr = &age;          // ptr يخزّن عنوان age

printf("%d\n", *ptr);     // 25: القيمة الموجودة في ذلك العنوان
printf("%p\n", (void *)ptr);   // العنوان نفسه (يختلف في كل تشغيل)

*ptr = 30;                // تعديل age عبر المؤشّر
printf("%d\n", age);      // 30
```

رمزان فقط:

- `&age` تعني "**عنوان** age".
- `*ptr` تعني "**القيمة** في العنوان المخزّن في ptr" (يسمّى dereference).

و`int *ptr` في التعريف تعني "ptr مؤشّر إلى `int`". النوع مهمّ: يخبر المترجم كم بايتًا يقرأ عند `*ptr` وكيف يفسّرها.

## لماذا نحتاج المؤشّرات؟

1. **تعديل متغيّرات المستدعي من داخل دالة.** الدوال تستلم نسخًا، فنمرّر العنوان:

```c
void increment(int *x) {
    (*x)++;              // الأقواس ضرورية: *x++ تعني شيئًا آخر
}

int main(void) {
    int n = 5;
    increment(&n);
    printf("%d\n", n);   // 6
    return 0;
}
```

2. **تمرير بيانات كبيرة بلا نسخ:** تمرير عنوان هيكل كبير (8 بايت) بدل نسخه كاملًا.
3. **الذاكرة الديناميكية:** `malloc` تُرجع عنوانًا، فلا تتعامل معها إلا عبر مؤشّر (الدرس التالي).
4. **البنى المترابطة:** القوائم المترابطة والأشجار عُقد يشير بعضها لبعض.

## المؤشّرات والمصفوفات

اسم المصفوفة **ليس** مؤشّرًا، لكنه **يتحوّل** تلقائيًا لمؤشّر لأول عنصر في معظم التعابير (يسمّى decay). لذلك تتشابه الصيغتان:

```c
int arr[3] = {10, 20, 30};
int *p = arr;                  // = &arr[0]

printf("%d\n", *(p + 1));      // 20
printf("%d\n", p[1]);          // 20: نفس الشيء بالضبط
printf("%zu %zu\n", sizeof(arr), sizeof(p));   // 12 8: هنا يظهر الفرق
```

`arr[i]` هي حرفيًا `*(arr + i)`. والفرق الحقيقي: `sizeof(arr)` حجم المصفوفة كلها، و`sizeof(p)` حجم المؤشّر، ولا يمكنك إسناد شيء جديد لـ `arr`.

### حساب المؤشّرات

`p + 1` لا تتقدّم بايتًا واحدًا، بل **عنصرًا واحدًا** من نوع المؤشّر: مع `int` تتقدّم 4 بايتات، ومع `double` 8. لهذا يمكن المرور على مصفوفة بالمؤشّر:

```c
int data[] = {3, 6, 9};
int *end = data + 3;           // مباشرة بعد آخر عنصر (مسموح كعلامة نهاية)
for (int *q = data; q < end; q++) {
    printf("%d ", *q);         // 3 6 9
}
```

مسموح أن يشير المؤشّر **بعد آخر عنصر مباشرة** للمقارنة، لكن قراءة `*end` سلوك غير معرّف.

## NULL والمؤشّر غير المهيّأ

```c
int *p = NULL;          // "لا يشير لأي شيء"
if (p != NULL) *p = 1;  // افحص قبل الاستخدام
```

مؤشّر **غير مهيّأ** (`int *p;`) يحمل عنوانًا عشوائيًا، والكتابة عبره تُفسد ذاكرة لا تعرفها. هيّئ كل مؤشّر بعنوان حقيقي أو بـ `NULL`. ومنذ C23 يوجد أيضًا `nullptr` (درس الجديد في C23).

## المؤشّر المعلّق (Dangling Pointer)

مؤشّر يشير لذاكرة **لم تعد موجودة**. أشهر صوره إرجاع عنوان متغيّر محلّي:

```c
int *bad(void) {
    int local = 42;
    return &local;      // ❌ local تختفي عند انتهاء الدالة
}
```

gcc يحذّرك هنا (`-Wreturn-local-addr`)، بل يُرجع NULL عمدًا بدل العنوان الفاسد، ومترجمات أخرى قد تُرجع عنوانًا سيُعاد استخدامه فيعمل البرنامج بالصدفة ثم يفسد لاحقًا. الصورة الأخرى استخدام الذاكرة بعد `free`، في الدرس التالي.

## const مع المؤشّرات

موضع `const` يغيّر المعنى. اقرأ التعريف من اليمين لليسار:

```c
int a = 1, b = 2;

const int *p1 = &a;   // مؤشّر إلى int ثابت: لا تغيّر القيمة عبره
// *p1 = 5;           // ❌
p1 = &b;              // ✅ يمكن توجيهه لمكان آخر

int *const p2 = &a;   // مؤشّر ثابت إلى int: القيمة تتغيّر، الاتجاه لا
*p2 = 5;              // ✅
// p2 = &b;           // ❌
```

الأكثر استخدامًا `const int *` في معاملات الدوال: "سأقرأ بياناتك ولن أعدّلها"، مثل `strlen(const char *s)`.

## مؤشّر إلى مؤشّر

```c
int x = 5;
int *p = &x;
int **pp = &p;
printf("%d\n", **pp);   // 5
```

تحتاجه حين تريد دالة تغيّر **المؤشّر نفسه** عند المستدعي (مثلًا دالة تحجز ذاكرة وتضع عنوانها في مؤشّرك)، وفي مصفوفات النصوص مثل `char **argv` ([معاملات سطر الأوامر](/learn/c/25-cli-args)). وللمؤشّر الذي يشير إلى **دالة** درس خاص: [مؤشّرات الدوال](/learn/c/27-function-pointers).

## أخطاء شائعة

- **`*x++` بدل `(*x)++`:** الأولى تزيد **المؤشّر** ثم تقرأ، لا القيمة.
- **`int* a, b;`:** `a` وحدها مؤشّر و`b` عدد صحيح عادي. عرّف كل مؤشّر في سطر، أو اكتب النجمة ملاصقة للاسم: `int *a, *b;`.
- **استخدام مؤشّر غير مهيّأ أو NULL:** انهيار (segmentation fault) أو إفساد ذاكرة صامت.
- **إرجاع عنوان متغيّر محلّي:** أرجع القيمة نفسها، أو احجز بـ `malloc`، أو استلم مكان النتيجة كمعامل من المستدعي.
- **`%d` لطباعة عنوان:** استخدم `%p` مع تحويل إلى `(void *)`.
