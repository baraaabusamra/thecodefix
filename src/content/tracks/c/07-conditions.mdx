## ما هو "الصحيح" في C؟

الشرط في C أي تعبير رقمي: **الصفر خطأ، وأي قيمة أخرى صحيحة**. لذلك `if (count)` تعني "إذا كان `count` لا يساوي صفرًا"، و`if (ptr)` تعني "إذا لم يكن المؤشّر فارغًا". هذا مفيد ومختصر، لكنه أيضًا سبب أشهر أخطاء الشروط كما سترى.

## if / else if / else

```c
int score = 75;

if (score >= 90) {
    printf("ممتاز\n");
} else if (score >= 60) {
    printf("ناجح\n");
} else {
    printf("راسب\n");
}
```

الفحص يتمّ **بالترتيب** ويتوقّف عند أول شرط صحيح. لذلك ضع الشرط الأضيق أولًا: لو بدأت بـ `score >= 60` لطُبع "ناجح" للدرجة 95 أيضًا.

## العامل الثلاثي

اختصار لشرط بسيط **يُنتج قيمة**:

```c
int age = 20;
printf("%s\n", age >= 18 ? "بالغ" : "قاصر");

int a = 7, b = 12;
int max = a > b ? a : b;   // 12
```

استخدمه لاختيار قيمة بين اثنتين فقط. إذا احتجت تداخلًا (`? : ? :`) أو تنفيذ أوامر، فـ `if` أوضح.

## switch

مناسب حين تقارن **قيمة صحيحة واحدة** بعدّة قيم ثابتة:

```c
int day = 3;

switch (day) {
    case 1: printf("الاثنين\n"); break;
    case 2: printf("الثلاثاء\n"); break;
    case 3: printf("الأربعاء\n"); break;
    default: printf("يوم آخر\n");
}
```

- `switch` يعمل مع الأعداد الصحيحة و`char` و`enum` فقط، لا مع النصوص ولا الكسور. لمقارنة النصوص استخدم `if` مع `strcmp`.
- قيمة كل `case` يجب أن تكون ثابتة معروفة وقت الترجمة، لا متغيّرًا.

### السقوط (fall-through)

بدون `break` يستمرّ التنفيذ إلى الحالة التالية. هذا خطأ غالبًا، لكنه مفيد عمدًا حين تشترك عدّة قيم في نفس الكود:

```c
char c = 'e';
switch (c) {
    case 'a': case 'e': case 'i': case 'o': case 'u':
        printf("حرف علّة\n");
        break;
    default:
        printf("حرف ساكن\n");
}
```

## مثال عملي: حاسبة بسيطة

```c
double x = 8, y = 2;
char op = '/';

switch (op) {
    case '+': printf("%.2f\n", x + y); break;
    case '-': printf("%.2f\n", x - y); break;
    case '*': printf("%.2f\n", x * y); break;
    case '/':
        if (y == 0) {
            printf("لا يمكن القسمة على صفر\n");
        } else {
            printf("%.2f\n", x / y);
        }
        break;
    default:
        printf("عملية غير معروفة\n");
}
```

لاحظ أن `switch` يختار العملية، و`if` داخل الحالة يحمي من القسمة على صفر.

## أخطاء شائعة

- **`if (x = 5)` بدل `if (x == 5)`:** الإسناد يُرجع 5، فالشرط صحيح دائمًا ويتغيّر `x` بصمت. بعض المبرمجين يكتبون `if (5 == x)` لأن الخطأ `5 = x` يرفضه المترجم، لكن الأبسط تفعيل `-Wall`.
- **فاصلة منقوطة بعد الشرط:** `if (x > 0);` تجعل الجسم جملة فارغة، والكتلة بعدها تُنفَّذ دائمًا.
- **else المعلّقة بدون أقواس:** `else` ترتبط بأقرب `if`، لا بالتي تقصدها بالمسافة البادئة:

```c
int a = 1, b = 0;
if (a)
    if (b)
        printf("a و b\n");
else
    printf("ليس a؟\n");   // تُطبع! لأن else تتبع if (b)
```

الحل: استخدم الأقواس `{ }` دائمًا، حتى مع سطر واحد. و`-Wall` يحذّرك هنا بـ `-Wdangling-else`.

- **نسيان `break` في `switch`:** تنفيذ الحالات التالية كلها. `-Wextra` في gcc يحذّرك من السقوط غير المقصود (`-Wimplicit-fallthrough`).
