## العوامل الحسابية

| العامل | الوظيفة | مثال | النتيجة |
|--------|---------|------|---------|
| `+` | جمع | `7 + 3` | `10` |
| `-` | طرح | `7 - 3` | `4` |
| `*` | ضرب | `7 * 3` | `21` |
| `/` | قسمة | `7 / 2` | `3.5` |
| `//` | قسمة صحيحة | `7 // 2` | `3` |
| `%` | الباقي | `7 % 2` | `1` |
| `**` | الأُس | `2 ** 3` | `8` |

```python
print(10 // 3)   # 3 (يتجاهل الكسر)
print(10 % 3)    # 1 (الباقي)
print(2 ** 10)   # 1024
```

## عوامل المقارنة

تُرجع دائمًا `True` أو `False`:

```python
print(5 == 5)    # True (يساوي)
print(5 != 3)    # True (لا يساوي)
print(5 > 3)     # True
print(5 <= 4)    # False
```

> ⚠️ **خطأ شائع:** `=` للإسناد، و`==` للمقارنة. لا تخلط بينهما.

## العوامل المنطقية

| العامل | الوصف | مثال |
|--------|-------|------|
| `and` | و — الكل صحيح | `x > 0 and x < 10` |
| `or` | أو — أحدها صحيح | `x < 0 or x > 100` |
| `not` | عكس | `not True` → `False` |

```python
age = 22
if age >= 18 and age <= 60:
    print("ضمن الفئة العاملة")
```

## عوامل الإسناد المختصرة

```python
x = 10
x += 5    # x = x + 5  → 15
x -= 3    # 12
x *= 2    # 24
print(x)  # 24
```
