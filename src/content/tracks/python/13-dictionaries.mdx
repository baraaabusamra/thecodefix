## مفتاح وقيمة

القائمة تصل لعناصرها **بالموضع**: `scores[2]`. لكن ماذا يعني الموضع 2؟ في معظم البيانات الحقيقية تريد الوصول **بالاسم**: سعر "الكتاب"، وعمر "ليلى"، وعاصمة "الأردن". **القاموس `dict`** يربط كل **مفتاح** بـ**قيمة**:

```python
person = {
    "name": "ليلى",
    "age": 28,
    "city": "عمّان",
}
print(person["name"])     # ليلى
print(len(person))        # 3 أزواج
```

هذا شكل البيانات نفسه الذي تصلك به معظم واجهات الويب بصيغة [JSON](/learn/python/18-json)، فستتعامل مع القواميس في كل مشروع تقريبًا.

## القراءة: [] أم get؟

```python
person = {"name": "ليلى", "age": 28}

print(person["name"])                    # مفتاح موجود
print(person.get("email"))               # None: لا خطأ
print(person.get("email", "غير متوفّر"))  # قيمة بديلة
# person["email"]                        ← KeyError: 'email'
```

- **`d[key]`** حين يجب أن يكون المفتاح موجودًا، وغيابه خطأ تريد أن تراه.
- **`d.get(key, default)`** حين يكون المفتاح اختياريًّا.

وللفحص فقط: `"email" in person` تبحث في **المفاتيح** لا القيم.

## الإضافة والتعديل والحذف

```python
product = {"name": "كتاب", "price": 12}

product["price"] = 10            # مفتاح موجود: تعديل
product["stock"] = 50            # مفتاح جديد: إضافة
product.update({"price": 9, "color": "أزرق"})   # عدّة مفاتيح معًا

removed = product.pop("color")   # حذف وإرجاع القيمة
del product["stock"]             # حذف بلا إرجاع
print(product, removed)
```

لا يوجد مفتاح مكرّر: الإسناد لمفتاح موجود **يستبدل** قيمته. و`pop("x", None)` تحذف بلا خطأ إن لم يوجد المفتاح.

## المرور على القاموس

```python
scores = {"رياضيات": 90, "علوم": 85, "لغة": 95}

for subject in scores:                    # المفاتيح افتراضيًّا
    print(subject)

for subject, mark in scores.items():      # المفتاح والقيمة معًا
    print(f"{subject}: {mark}")

print(list(scores.keys()))
print(sum(scores.values()) / len(scores)) # المعدّل: 90.0
print(max(scores, key=scores.get))        # المادة الأعلى: لغة
```

القواميس **تحفظ ترتيب الإضافة** (منذ Python 3.7)، فالطباعة والمرور يتبعان الترتيب الذي أدخلت به المفاتيح.

## نمط العدّ والتجميع

أكثر استخدام عملي للقواميس: عدّ الأشياء.

```python
text = "تفاح موز تفاح برتقال تفاح موز"
counts = {}
for word in text.split():
    counts[word] = counts.get(word, 0) + 1
print(counts)

from collections import Counter
print(Counter(text.split()).most_common(1))   # [('تفاح', 3)]
```

`counts.get(word, 0) + 1`: "القيمة الحالية أو صفر، زائد واحد". وحين تحتاجه كثيرًا، `Counter` من المكتبة القياسية يفعله ومعه `most_common`.

والتجميع في قوائم:

```python
students = [("سارة", "عمّان"), ("أحمد", "إربد"), ("ليلى", "عمّان")]
by_city = {}
for name, city in students:
    by_city.setdefault(city, []).append(name)
print(by_city)     # {'عمّان': ['سارة', 'ليلى'], 'إربد': ['أحمد']}
```

`setdefault(city, [])` تعيد القائمة الموجودة، أو تنشئ قائمة فارغة وتعيدها إن لم يكن المفتاح موجودًا.

## قواميس متداخلة

```python
users = {
    "u1": {"name": "أحمد", "roles": ["admin"]},
    "u2": {"name": "نور", "roles": []},
}
print(users["u1"]["name"])            # أحمد
print(users["u1"]["roles"][0])        # admin

for uid, info in users.items():
    status = "مشرف" if "admin" in info["roles"] else "مستخدم"
    print(uid, info["name"], status)
```

هذا شكل بيانات JSON الحقيقية: قواميس داخلها قوائم داخلها قواميس. اقرأ المسار من اليسار لليمين: "من `users`، المفتاح `u1`، ثم `roles`، ثم العنصر الأول".

## ما الذي يصلح مفتاحًا؟

المفاتيح يجب أن تكون **غير قابلة للتغيير**: نصوص، أرقام، صفوف. القائمة لا تصلح مفتاحًا (`TypeError: unhashable type: 'list'`)، والسبب نفسه كما في [المجموعات](/learn/python/12-sets). أما **القيم** فأي شيء.

```python
distances = {("عمّان", "إربد"): 85, ("عمّان", "العقبة"): 330}
print(distances[("عمّان", "إربد")])    # صفّ كمفتاح مركّب
```

## بناء قاموس بسطر واحد

```python
prices = {"كتاب": 12, "قلم": 1, "دفتر": 3}
with_vat = {item: round(p * 1.16, 2) for item, p in prices.items()}
cheap = {item: p for item, p in prices.items() if p < 5}
print(with_vat)
print(cheap)
```

**Dict Comprehension**، مثل فهم القوائم؛ التفاصيل في [درس Comprehensions](/learn/python/26-comprehensions). ولدمج قاموسين: `merged = a | b` (Python 3.9+)، والقيم في `b` تغلب عند تكرار المفتاح.

## أخطاء شائعة

- **`d["key"]` لمفتاح قد لا يوجد:** `KeyError`. استخدم `get` أو افحص بـ `in`.
- **`"ليلى" in person`** وانتظار البحث في القيم: `in` تبحث في المفاتيح. للقيم: `in person.values()`.
- **تعديل حجم القاموس أثناء المرور عليه** (`del` داخل `for k in d`): `RuntimeError: dictionary changed size during iteration`. مرّ على `list(d)`.
- **قائمة كمفتاح:** حوّلها لصف.
- **`b = a` لنسخ قاموس:** اسمان لقاموس واحد، كالقوائم. استخدم `a.copy()`.
