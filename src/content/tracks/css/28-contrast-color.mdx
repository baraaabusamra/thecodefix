## المشكلة التي تحلّها

خلفية بلون ديناميكي — صورة رمزية بلون عشوائي، أو ثيم يختاره المستخدم، أو لون قادم من نظام إدارة محتوى — تحتاج نص مقروء فوقها: أحيانًا أبيض وأحيانًا أسود، حسب مدى فتوح أو غمق تلك الخلفية بالذات. لعقود كان الحل حساب **سطوع اللون بجافاسكريبت** (صيغة Luminance) واختيار اللون برمجيًا. الآن CSS يفعل ذلك وحده.

## الصياغة

```css
.badge {
  background-color: var(--tag-color);   /* لون ديناميكي أيًا كان */
  color: contrast-color(var(--tag-color));
}
```

`contrast-color()` تأخذ لونًا وتُرجع **إما أبيض أو أسود** — أيّهما يعطي تباينًا أعلى مقابل اللون المُدخَل. عند تساوي التباين تمامًا بين الخيارين، تُرجَع الأبيض.

## مثال عملي: ثيم يتبدّل تلقائيًا

```css
:root {
  --bg: navy;
}

@media (prefers-color-scheme: light) {
  :root { --bg: wheat; }
}

body {
  background-color: var(--bg);
  color: contrast-color(var(--bg));   /* يتكيّف مع كل تغيّر بـ --bg */
}
```

بما أن الدالة تُعاد حسابها تلقائيًا كلما تغيّر `--bg` (بتبديل الثيم أو حتى بحركة/انتقال)، النص يبقى مقروءًا دون أي شرط JavaScript يدوي.

## متى تستخدمها؟

- **شارات وعلامات ديناميكية اللون** (Tags/Labels) قادمة من بيانات أو تصنيفات المستخدم.
- **صور رمزية (Avatars) مولَّدة بلون عشوائي** من الاسم الأول للمستخدم.
- **ثيمات قابلة للتخصيص** يختار فيها المستخدم لون العلامة التجارية بنفسه.

## قيدها المهم: أبيض أو أسود فقط

على عكس ما قد تتوقعه، الدالة **لا** تنتقي من نطاق ألوان علامتك التجارية — نتيجتها ثنائية دائمًا: أبيض أو أسود. إن أردت نصًّا بلون العلامة نفسها (مثلًا بنفسجي فاتح بدل أبيض خام)، فهي ليست الأداة المناسبة؛ تبقى حلول التلوين اليدوي أو خرائط ألوان مُعدَّة مسبقًا هي الخيار هناك.

> 🔑 الدالة تهدف عادة لتحقيق حدّ التباين الأدنى بمعيار WCAG AA، لكنها لا تضمنه بنسبة 100% مع كل لون مُدخَل — اختبر التباين الفعلي في الحالات الحرجة (نصوص أزرار أساسية، تنبيهات) بدل الاعتماد الأعمى عليها.

## دعم المتصفحات لا يزال حديثًا جدًا

هذه دالة وصلت لدعم واسع بالمتصفحات الرئيسية مؤخرًا فقط — لمشروع يحتاج توافقًا مع متصفحات أقدم، وفّر قيمة احتياطية صريحة قبلها (المتصفح يتجاهل قيمة `color` غير المفهومة ويستخدم آخر قيمة صالحة سبقتها):

```css
.badge {
  color: white;                          /* احتياطي لمتصفحات أقدم */
  color: contrast-color(var(--tag-color));
}
```

## الأخطاء الشائعة

- **❌ توقّع لون بمنتصف الطيف** (رمادي متوسط مثلًا) → النتيجة ثنائية دائمًا: أبيض أو أسود فقط.
- **❌ الاعتماد عليها دون قيمة احتياطية** في مشروع يدعم متصفحات أقدم → افقد التباين تمامًا هناك بدل تدهور تدريجي لطيف.
- **❌ افتراض ضمان WCAG AA في كل الحالات** → تظل تحتاج فحصًا يدويًا للألوان الحرجة.

## خلاصة

`contrast-color(<لون>)` تُعيد أبيض أو أسود — أيّهما أوضح تباينًا — مقابل أي لون تمرّره لها، فتحلّ مشكلة قراءة النص فوق خلفيات ديناميكية بسطر CSS واحد بدل حساب سطوع بجافاسكريبت. تذكّر أنها ثنائية النتيجة دومًا، ووفّر قيمة `color` احتياطية لدعم المتصفحات الأقدم.
