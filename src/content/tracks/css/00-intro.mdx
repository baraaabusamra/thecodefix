## ما هي CSS؟

**CSS** اختصار لـ *Cascading Style Sheets* — وهي اللغة التي **نُنسّق** بها
صفحات HTML: الألوان، الخطوط، المسافات، والتخطيط.

> HTML يبني الهيكل، و**CSS تُلبسه الثوب الجميل**.

## شكل قاعدة CSS

```css
h1 {
  color: purple;
  font-size: 32px;
}
```

- `h1` = **المحدِّد** (selector): أي عنصر سنُنسّقه.
- `color` = **الخاصية** (property).
- `purple` = **القيمة** (value).
- كل سطر ينتهي بفاصلة منقوطة `;`.

## ثلاث طرق لإضافة CSS

**1. ملف خارجي (الأفضل):**

```html
<link rel="stylesheet" href="style.css" />
```

**2. داخل `<head>`:**

```html
<style>
  p { color: gray; }
</style>
```

**3. مضمّنة (inline — تجنّبها قدر الإمكان):**

```html
<p style="color: red;">نص أحمر</p>
```

> 🎯 التالي: المحدِّدات — كيف نختار العناصر بدقة.
