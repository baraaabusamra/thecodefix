## المشكلة التي تحلّها

بنيت زر معلومات وأردت أن يظهر بجانبه تلميح (Tooltip)، أو زر قائمة منسدلة وأردت أن تظهر القائمة تحته مباشرة أينما كان الزر على الصفحة. لسنوات، هذا احتاج مكتبة جافاسكربت كاملة (Popper.js أو Floating UI) تحسب موضع الزر بـ `getBoundingClientRect()` عند كل تمرير أو تغيير حجم نافذة، وتحدّث موضع التلميح يدويًا بحلقة `requestAnimationFrame`.

**Anchor Positioning** تحلّ المشكلة من داخل CSS نفسه: تربط عنصرًا (التلميح) بعنصر آخر (الزر) بثلاث خطوات — تسمية، ربط، وتموضع — ومحرّك التخطيط في المتصفح يتولى الباقي، بلا أي حساب جافاسكربت.

## الخطوة الأولى: تسمية عنصر الإرساء

أعطِ العنصر الذي تريد الربط به اسمًا عبر `anchor-name`:

```css
.trigger-button {
  anchor-name: --my-button;
}
```

الاسم يبدأ إلزاميًا بشرطتين `--` (نفس صياغة متغيرات CSS)، ويمكن لعنصر واحد أن يحمل أكثر من اسم مفصولة بفواصل.

## الخطوة الثانية: ربط العنصر الموضَّع بالإرساء

العنصر الذي تريد تموضعه (التلميح) يحتاج `position` من نوع `absolute` أو `fixed`، ثم يربطه بالإرساء عبر `position-anchor`:

```css
.tooltip {
  position: fixed;
  position-anchor: --my-button;
}
```

## الخطوة الثالثة: التموضع بدالة `anchor()`

الآن استخدم دالة `anchor()` داخل خصائص الإزاحة (`top` / `left` / `right` / `bottom` أو النسخ المنطقية) لتموضع التلميح نسبةً لحواف الإرساء:

```css
.tooltip {
  position: fixed;
  position-anchor: --my-button;
  top: anchor(bottom);      /* أسفل الزر مباشرة */
  left: anchor(center);     /* بمحاذاة مركز الزر أفقيًا */
  translate: -50% 8px;      /* تعديل بسيط للمحاذاة والمسافة */
}
```

`anchor()` تقرأ موضع حافة الإرساء المحدَّدة (`top`, `bottom`, `left`, `right`, `center`, أو نسبة مئوية) وتُرجعها كقيمة طول تُستخدم مباشرة في خاصية الإزاحة — تتحدّث تلقائيًا كلما تحرّك الزر أو تغيّر حجم الصفحة، بلا أي كود مراقبة.

> 💡 لا حاجة لتكرار اسم الإرساء داخل كل `anchor()` إن كنت عرّفته مسبقًا بـ `position-anchor` — `anchor(bottom)` وحدها تكفي وتشير إلى الإرساء الافتراضي للعنصر.

## مثال كامل: تلميح يتبع زرًا

```css
.info-button {
  anchor-name: --info-btn;
}

.tooltip {
  position: fixed;
  position-anchor: --info-btn;
  top: anchor(bottom);
  left: anchor(center);
  translate: -50% 6px;
  background: #1e293b;
  color: white;
  padding: 6px 10px;
  border-radius: 6px;
  font-size: 13px;
}
```

```html
<button class="info-button" popovertarget="tip">؟</button>
<div id="tip" class="tooltip" popover>هذا شرح إضافي عن الميزة.</div>
```

لاحظ الدمج مع `popover` (سمة HTML لعرض عناصر فوق باقي الصفحة بلا `z-index` يدوي) — التوليفة الشائعة لبناء تلميحات وقوائم منسدلة بلا أي جافاسكربت إطلاقًا.

## التعامل مع تجاوز حواف الشاشة: `position-try-fallbacks`

ماذا لو كان الزر قرب أسفل الصفحة، فخرج التلميح المتموضع أسفله عن حدود الشاشة؟ خاصية `position-try-fallbacks` تعطي المتصفح بدائل يجرّبها تلقائيًا:

```css
.tooltip {
  position: fixed;
  position-anchor: --info-btn;
  top: anchor(bottom);
  left: anchor(center);
  position-try-fallbacks: flip-block;
}
```

`flip-block` تقلب التموضع عبر المحور الرأسي (فيظهر التلميح فوق الزر بدل أسفله) إن كان التموضع الأصلي سيُخرج العنصر عن حدود الشاشة. من الكلمات المفتاحية الجاهزة أيضًا `flip-inline` (قلب أفقي) و`flip-start` (قلب قطري لكلا المحورين معًا).

## الأخطاء الشائعة

- **❌ نسيان `position: absolute` أو `fixed` على العنصر المُتموضع** → دالة `anchor()` لا تعمل إلا على عنصر positioned؛ بدونها تُهمَل القيمة.
- **❌ افتراض أن اسم الإرساء عادي بلا شرطتين** → يجب أن يبدأ بـ `--` دائمًا، تمامًا كمتغيرات CSS.
- **❌ الاعتماد عليها بلا التحقق من دعم المتصفح المستهدف** → دعمها عبر المتصفحات الرئيسية الثلاثة تحقق بالكامل في يناير 2026 (بعد أن دعمتها Firefox أخيرًا، بينما Chrome يدعمها منذ 2024 وSafari منذ سبتمبر 2025) — لمشروع يحتاج توافقًا مع إصدارات متصفح أقدم من ذلك، لفّها بـ `@supports (anchor-name: --x)` ووفّر تموضعًا بديلًا.

## خلاصة

Anchor Positioning تربط عنصرًا بعنصر آخر بثلاث خطوات — `anchor-name` للتسمية، `position-anchor` للربط، ودالة `anchor()` للتموضع — ليتولى محرّك المتصفح حساب الموضع وتحديثه تلقائيًا بدل مكتبة جافاسكربت كاملة. أضف `position-try-fallbacks` لتفادي خروج العنصر عن حدود الشاشة تلقائيًا أيضًا.
