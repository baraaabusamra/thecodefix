## القالب الأساسي

كل صفحة HTML تتبع نفس الهيكل. احفظ هذا القالب جيدًا:

```html
<!DOCTYPE html>
<html lang="ar" dir="rtl">
  <head>
    <meta charset="UTF-8" />
    <title>عنوان صفحتي</title>
  </head>
  <body>
    <h1>مرحبًا!</h1>
  </body>
</html>
```

## شرح كل جزء

| الجزء | الوظيفة |
|-------|---------|
| `<!DOCTYPE html>` | يخبر المتصفّح أن هذا مستند HTML حديث |
| `<html>` | العنصر الجذر الذي يحتوي كل شيء |
| `lang="ar" dir="rtl"` | لغة الصفحة عربية واتجاهها من اليمين لليسار |
| `<head>` | معلومات عن الصفحة (لا تظهر للزائر) |
| `<meta charset="UTF-8">` | يدعم الحروف العربية بشكل صحيح |
| `<title>` | العنوان الظاهر في تبويب المتصفّح |
| `<body>` | كل المحتوى المرئي للزائر |

## نقطة مهمة للمحتوى العربي

استخدم دائمًا `lang="ar" dir="rtl"` و `charset="UTF-8"` حتى تظهر الحروف
العربية سليمة ومن الاتجاه الصحيح.
