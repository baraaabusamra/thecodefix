## العناوين (Headings)

في HTML ست درجات للعناوين من `<h1>` (الأهم) إلى `<h6>` (الأقل):

```html
<h1>العنوان الرئيسي</h1>
<h2>عنوان فرعي</h2>
<h3>عنوان أصغر</h3>
```

> 💡 استخدم `<h1>` **مرة واحدة** فقط في كل صفحة — فهو الأهم لمحرّكات البحث (SEO).

## الفقرات (Paragraphs)

نكتب النصوص داخل `<p>`:

```html
<p>هذه فقرة كاملة من النص. المتصفّح يضيف مسافة تلقائية بين الفقرات.</p>
<p>وهذه فقرة ثانية منفصلة.</p>
```

## تنسيق النص

```html
<p>هذا نص <strong>مهم جدًا</strong> وهذا نص <em>مائل للتأكيد</em>.</p>
<p>سطر أول<br />سطر ثانٍ بعد كسر السطر.</p>
```

| الوسم | الاستخدام |
|-------|-----------|
| `<strong>` | نص مهم (يظهر **عريضًا**) |
| `<em>` | تأكيد (يظهر *مائلًا*) |
| `<br>` | كسر سطر |
| `<hr>` | خط فاصل أفقي |
