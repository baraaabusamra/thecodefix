## القائمة النقطية (Unordered List)

عندما لا يهمّ الترتيب، نستخدم `<ul>` وكل عنصر داخل `<li>`:

```html
<ul>
  <li>HTML</li>
  <li>CSS</li>
  <li>JavaScript</li>
</ul>
```

النتيجة: قائمة بنقاط •.

## القائمة المرقّمة (Ordered List)

عندما يهمّ الترتيب (خطوات مثلًا)، نستخدم `<ol>`:

```html
<ol>
  <li>افتح المحرّر</li>
  <li>اكتب الكود</li>
  <li>احفظ الملف</li>
</ol>
```

النتيجة: قائمة مرقّمة 1، 2، 3.

## قوائم متداخلة

يمكن وضع قائمة داخل عنصر `<li>`:

```html
<ul>
  <li>
    الواجهة الأمامية
    <ul>
      <li>HTML</li>
      <li>CSS</li>
    </ul>
  </li>
  <li>الواجهة الخلفية</li>
</ul>
```
