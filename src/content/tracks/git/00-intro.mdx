## ما هو Git؟

**Git** نظام **تحكّم بالإصدارات (Version Control)** يحفظ تاريخ كل تغيير في
مشروعك، فتستطيع العودة لأي نقطة سابقة، ومعرفة من غيّر ماذا ومتى.

> تخيّله كزرّ "حفظ" ذكي يتذكّر كل نسخة من مشروعك إلى الأبد.

## لماذا Git؟

- **أمان:** لا تخسر عملك أبدًا، وارجع لأي نسخة قديمة.
- **تعاون:** يعمل فريق كامل على نفس المشروع دون تعارض.
- **معيار الصناعة:** مطلوب في كل وظيفة برمجية تقريبًا.

## Git مقابل GitHub

| | Git | GitHub |
|---|-----|--------|
| ما هو | أداة على جهازك | موقع لاستضافة المشاريع |
| يعمل | محليًا (offline) | على الإنترنت |
| الدور | يتتبّع التغييرات | يشارك ويخزّن المستودعات |

## التثبيت والإعداد

بعد تثبيت Git من [git-scm.com](https://git-scm.com)، عرّف نفسك مرة واحدة:

```bash
git config --global user.name "اسمك"
git config --global user.email "you@example.com"
```

تحقّق من الإصدار:

```bash
git --version
```
