Dart لغة برمجة حديثة من Google، اشتهرت كونها اللغة التي يُبنى بها تطبيقات Flutter، لكنّها لغة عامّة قائمة بذاتها. هذه الصفحة هي المرجع التأسيسي لمسار Dart **كلغة مستقلّة** — بينما يعلّمك [مسار Flutter](/learn/flutter/00-intro) استخدامها في سياق واجهات المستخدم تحديدًا.

## ما هي Dart؟

Dart لغة **مُنمّطة (Typed)، كائنية، ومُحسَّنة لتطبيقات العميل** (واجهات المستخدم)، صمّمتها Google لتكون سريعة ومنتِجة. ما يميّزها تقنيًا قدرتها على الترجمة إلى أهداف متعدّدة:

- **إلى كود أصلي (Native)** لأداء عالٍ على الجوال وسطح المكتب.
- **إلى JavaScript** لتعمل في المتصفّح.

كما تدعم نمطي **JIT** (ترجمة لحظية تسرّع التطوير و«إعادة التحميل السريع») و**AOT** (ترجمة مسبقة لأداء إنتاجي أعلى).

## لماذا تستخدمها Flutter؟

اختارت Flutter لغة Dart لأنها تلائم بناء الواجهات بامتياز: «إعادة التحميل الساخن (Hot Reload)» تجعل تغييرات الواجهة فورية أثناء التطوير، والترجمة إلى كود أصلي تمنح التطبيق أداءً سلسًا. باختصار، Dart تمنح Flutter السرعة في التطوير والأداء في التشغيل معًا.

## Dart خارج Flutter

من المهمّ إدراك أنّ Dart **ليست حكرًا على Flutter**. يمكنك استخدامها لبناء:

- أدوات وسكربتات سطر الأوامر (CLI).
- خوادم وخدمات خلفية.
- تطبيقات ويب (عبر الترجمة إلى JavaScript).

لهذا نعاملها هنا كلغة كاملة تتعلّمها لذاتها، تمامًا كما نعلّم [JavaScript](/learn/javascript/00-intro) مستقلّةً عن أطرها.

## مثال أوّل

```dart
void main() {
  print('مرحبًا من Dart');

  for (var i = 1; i <= 3; i++) {
    print('السطر رقم $i');
  }
}
```

صيغة مألوفة لمن جاء من C أو Java أو JavaScript، مع لمسات حديثة مثل استيفاء النصوص عبر `$`.
