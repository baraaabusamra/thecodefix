## الأنواع الأساسية

| النوع | يخزّن | مثال |
| --- | --- | --- |
| `int` | عدد صحيح (64 بت على الأنظمة الحديثة) | `42` |
| `int8` حتى `int64` و`uint8` حتى `uint64` | أعداد بحجم محدّد | `int32(7)` |
| `float64` | كسر (الافتراضي للأعداد العشرية) | `3.14` |
| `string` | نص UTF-8 غير قابل للتعديل | `"مرحبًا"` |
| `bool` | منطقي | `true` |
| `byte` | اسم آخر لـ `uint8`: بايت واحد | `'A'` |
| `rune` | اسم آخر لـ `int32`: حرف يونيكود واحد | `'ب'` |

```go
var age int = 25
var price float64 = 99.9
var name string = "براء"
var active bool = true
fmt.Printf("%T %T %T %T\n", age, price, name, active)   // int float64 string bool
```

القاعدة العملية: استخدم `int` للأعداد الصحيحة و`float64` للكسور، والأحجام المحدّدة (`int32` و`uint8`...) فقط حين تهمّ فعلًا (صيغة ملف، بروتوكول، توفير ذاكرة في ملايين العناصر).

## القيم الصفرية (Zero Values)

في Go **لا توجد قيم غير مهيّأة**. كل متغيّر يُعرَّف بلا قيمة يأخذ القيمة الصفرية لنوعه:

| النوع | القيمة الصفرية |
| --- | --- |
| الأعداد | `0` |
| `string` | `""` |
| `bool` | `false` |
| المؤشّرات والشرائح والخرائط والقنوات والدوال والواجهات | `nil` |
| البِنى (structs) | كل حقل بقيمته الصفرية |

```go
var count int
var label string
var ready bool
var scores []int
fmt.Println(count, label == "", ready, scores == nil)   // 0 true false true
```

هذا مقصود في تصميم Go: كثير من الأنواع "صالحة للاستخدام فورًا" بقيمتها الصفرية. مثلًا `var sb strings.Builder` أو `var mu sync.Mutex` جاهزان بلا تهيئة، و`append` تعمل على شريحة `nil`.

## لا تحويل ضمني

Go لا تحوّل بين الأنواع تلقائيًا أبدًا، حتى بين `int` و`int64` أو `int` و`float64`:

```go
var i int = 10
var f float64 = 2.5

// fmt.Println(i * f)          // ❌ mismatched types int and float64
fmt.Println(float64(i) * f)    // 25
fmt.Println(i * int(f))        // 20: int(2.5) يقتطع إلى 2
```

قد يبدو هذا ثقيلًا، لكنه يمنع فئة كاملة من الأخطاء الصامتة (فقدان الكسور، أو تجاوز الحدود عند التحويل لنوع أصغر). حين تكتب `int(f)` ترى بعينك أن الكسر سيُحذف.

### التحويل لنوع أصغر قد يلتفّ

```go
big := 300
small := uint8(big)
fmt.Println(small)   // 44: 300 لا تتّسع في 8 بتات (300 - 256)
```

المترجم يقبل التحويل الصريح بلا فحص للمدى أثناء التشغيل. إذا كانت القيمة قد تتجاوز، افحصها قبل التحويل.

## التحويل بين الأرقام والنصوص: strconv

```go
s := strconv.Itoa(42)              // "42"
n, err := strconv.Atoi("42")       // 42, nil
_, err2 := strconv.Atoi("abc")     // 0, خطأ
f, _ := strconv.ParseFloat("3.14", 64)
b, _ := strconv.ParseBool("true")
fmt.Println(s, n, err, err2, f, b)
```

`Atoi` وأخواتها تُرجع **خطأ** إذا لم يكن النص رقمًا صالحًا، فافحصه دائمًا مع إدخال المستخدم.

### الفخّ: string(65)

```go
fmt.Println(string(rune(65)))     // "A": تحويل رمز يونيكود إلى حرف
fmt.Println(strconv.Itoa(65))     // "65": تحويل رقم إلى نصّه
```

`string(n)` لعدد صحيح لا تعطيك "65" بل الحرف الذي رمزه 65. لهذا يحذّرك `go vet` من `string(int)` مباشرة. لتحويل رقم إلى نص استخدم `strconv.Itoa` أو `fmt.Sprint`.

## أخطاء شائعة

- **جمع نص ورقم:** `"العمر: " + 25` خطأ ترجمة. استخدم `fmt.Sprintf("العمر: %d", 25)` أو `strconv.Itoa`.
- **`string(n)` لتحويل رقم:** تعطي حرفًا لا أرقامًا.
- **تجاهل خطأ `strconv.Atoi`:** تُرجع `0` مع الخطأ، فيكمل البرنامج بصفر كأنه قيمة حقيقية.
- **انتظار كسر من قسمة أعداد صحيحة:** `7 / 2` تساوي `3`؛ حوّل أولًا: `float64(7) / 2`.
- **مقارنة `float64` بـ `==`:** `0.1+0.2 == 0.3` خطأ؛ قارن الفرق بهامش صغير.
