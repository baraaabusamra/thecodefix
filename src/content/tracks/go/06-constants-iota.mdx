## الثوابت (const)

قيم تُعرَف **وقت الترجمة** ولا تتغيّر أبدًا:

```go
const Pi = 3.14159
const AppName = "The Code Fix"

const (
    StatusActive   = "active"
    StatusInactive = "inactive"
)
```

لماذا ثابت بدل متغيّر؟ لأنه يمنع التعديل العرضي، ويعطي القيم "السحرية" أسماء تشرح نفسها (`MaxRetries` بدل `3` متناثرة في الكود)، والمترجم يستبدلها مباشرة بلا أي كلفة أثناء التشغيل.

### ما يمكن أن يكون ثابتًا

الثابت يجب أن يُحسب من قيم معروفة وقت الترجمة: أرقام، ونصوص، و`bool`، وتعابير بينها. لا يمكن أن يكون نتيجة دالة تُستدعى أثناء التشغيل، ولا شريحة أو خريطة:

```go
const Timeout = 30 * 60          // ✅ تعبير من ثوابت
// const Now = time.Now()        // ❌ قيمة تُعرف أثناء التشغيل فقط
// const Days = []string{"..."}  // ❌ الشرائح لا تكون ثوابت
```

للقيم الثابتة من هذا النوع استخدم `var` على مستوى الحزمة.

## الثوابت بلا نوع: لماذا لا تحتاج تحويلًا؟

`const Pi = 3.14159` ثابت **بلا نوع** (untyped): يتكيّف مع نوع السياق الذي تستخدمه فيه، وبدقّة عالية جدًّا. لذلك هذا يعمل رغم أن Go لا تحوّل ضمنيًا بين المتغيّرات:

```go
const Big = 1 << 40
var f float64 = Big        // ✅ يصبح float64
var i int64 = Big          // ✅ يصبح int64
// var b int8 = Big        // ❌ constant overflows int8
fmt.Println(f, i)
```

والمترجم يكشف تجاوز الحدود في الثوابت مباشرة، قبل أن يعمل البرنامج.

## iota: مولّد الأرقام المتتالية

داخل كتلة `const`، الكلمة `iota` تساوي رقم السطر في الكتلة بدءًا من 0. وإذا تركت سطرًا بلا قيمة، يكرّر Go التعبير السابق نفسه مع `iota` الجديدة:

```go
const (
    Sunday = iota   // 0
    Monday          // 1
    Tuesday         // 2
    Wednesday       // 3
)
fmt.Println(Sunday, Wednesday)   // 0 3
```

### نوع مخصّص: التعداد الحقيقي في Go

Go لا تملك كلمة `enum`. الاصطلاح: عرّف نوعًا جديدًا ثم ثوابت منه بـ `iota`، وأضف دالة `String()` ليطبع اسمه:

```go
type OrderStatus int

const (
    StatusNew OrderStatus = iota
    StatusPaid
    StatusShipped
)

func (s OrderStatus) String() string {
    switch s {
    case StatusNew:
        return "جديد"
    case StatusPaid:
        return "مدفوع"
    case StatusShipped:
        return "مشحون"
    }
    return fmt.Sprintf("OrderStatus(%d)", int(s))
}

func main() {
    s := StatusPaid
    fmt.Println(s)          // مدفوع: fmt يستدعي String() تلقائيًا
    fmt.Printf("%d\n", s)   // 1
}
```

النوع المخصّص يجعل التواقيع أوضح (`func Ship(s OrderStatus)` بدل `func Ship(s int)`)، والمترجم يمنع تمرير متغيّر `int` عادي بالخطأ. وكتابة `String()` يدويًا لكل تعداد مملّة، لذلك تُولَّد عادة بأداة `stringer` الرسمية (`go generate`).

### بداية من 1 بدل 0

القيمة الصفرية لأي متغيّر من نوعك ستكون `0`، أي أول ثابت. إذا كان "صفر" يعني "لم يُحدَّد بعد" في منطقك، اجعل الثوابت الحقيقية تبدأ من 1:

```go
type Role int

const (
    RoleUnknown Role = iota   // 0: القيمة الصفرية = غير محدّد
    RoleAdmin                 // 1
    RoleEditor                // 2
)
```

هكذا مستخدم نسيت أن تضبط دوره لا يصبح مديرًا صدفة.

### iota مع التعابير

```go
const (
    _  = iota             // تجاهل 0
    KB = 1 << (10 * iota) // 1 << 10 = 1024
    MB                    // 1 << 20
    GB                    // 1 << 30
)
fmt.Println(KB, MB, GB)   // 1024 1048576 1073741824
```

و`iota` مفيدة أيضًا للأعلام (flags): `Read = 1 << iota` ثم `Write` ثم `Exec` تعطي 1 و2 و4.

## أخطاء شائعة

- **أول ثابت يعني شيئًا مهمًّا:** القيمة الصفرية تساويه تلقائيًا. خصّص الصفر لـ "غير معروف".
- **إضافة ثابت في منتصف كتلة iota:** يغيّر أرقام كل ما بعده. إذا كانت الأرقام تُخزَّن في قاعدة بيانات أو ملف، أضف الجديد في **الآخر** فقط، أو اكتب القيم صراحة.
- **محاولة جعل نتيجة دالة أو شريحة ثابتًا:** استخدم `var`.
- **تعداد بلا نوع مخصّص:** ثوابت `int` عادية تقبل أي رقم؛ النوع المخصّص يوضّح القصد ويمنع الخلط.
