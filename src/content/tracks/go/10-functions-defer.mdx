## القيم المرتجعة المتعدّدة

ميزة مميّزة في Go — شائعة لإرجاع نتيجة وخطأ:

```go
func divide(a, b int) (int, error) {
  if b == 0 {
    return 0, fmt.Errorf("القسمة على صفر")
  }
  return a / b, nil
}

result, err := divide(10, 2)
```

## القيم المرتجعة المسمّاة

```go
func split(sum int) (x, y int) {
  x = sum * 4 / 9
  y = sum - x
  return   // يعيد x و y
}
```

## المعاملات المتغيّرة (Variadic)

```go
func sum(nums ...int) int {
  total := 0
  for _, n := range nums {
    total += n
  }
  return total
}
sum(1, 2, 3, 4)   // 10
```

## الدوال كقيم والإغلاقات

```go
// دالة تُمرّر كقيمة
apply := func(x int) int { return x * 2 }
apply(5)   // 10

// إغلاق يحتفظ بالحالة
func counter() func() int {
  count := 0
  return func() int {
    count++
    return count
  }
}
c := counter()
c()  // 1
c()  // 2
```

## defer

يؤجّل استدعاء دالة لينفَّذ لحظة خروج الدالة المحيطة، مهما كان طريق الخروج: `return` عادي، أو `return` مبكر بسبب خطأ، أو `panic`. لذلك هو الأداة القياسية للتنظيف: إغلاق ملف، فكّ قفل، إغلاق اتصال.

```go
func readFile(path string) error {
  file, err := os.Open(path)
  if err != nil {
    return err            // الفتح فشل: لا يوجد ما نغلقه
  }
  defer file.Close()      // مباشرة بعد الفتح الناجح

  // ... استخدام الملف؛ أي return بعد هذا السطر سيغلقه
  return nil
}
```

> 💡 اكتب `defer` مباشرة بعد نجاح الفتح، لا في آخر الدالة، حتى لا يفوتك مسار خروج مبكر.

### الترتيب: آخر defer أولًا (LIFO)

```go
func main() {
  fmt.Println("بداية")
  defer fmt.Println("defer الأول")
  defer fmt.Println("defer الثاني")
  fmt.Println("نهاية")
}
// بداية
// نهاية
// defer الثاني
// defer الأول
```

### الوسائط تُحسب وقت كتابة defer

```go
x := 1
defer fmt.Println("x =", x)   // تُحفظ القيمة 1 الآن
x = 2
// عند الخروج يطبع: x = 1
```

### أخطاء شائعة

- **`defer` داخل حلقة طويلة:** لا يُنفَّذ في نهاية كل دورة، بل يتراكم حتى نهاية الدالة كلها. مع آلاف الملفات قد تنفد الملفات المفتوحة المسموحة. ضع جسم الحلقة في دالة صغيرة يكون الـ `defer` بداخلها.
- **تجاهل خطأ الفتح:** `file, _ := os.Open(...)` ثم `defer file.Close()`. لو فشل الفتح فـ `file` قيمته `nil`، وأي قراءة منه بعدها تفشل. افحص `err` أولًا كما في المثال.
