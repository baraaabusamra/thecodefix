## ما هي Go؟

**Go** (أو **Golang**) لغة برمجة من Google، تجمع بين **بساطة Python وسرعة C**.
صُمّمت للأنظمة الحديثة والخوادم السحابية.

ظهرت Go عام 2009 لتحلّ مشكلات واجهتها Google في المشاريع الضخمة: بطء الترجمة
وتعقيد الصيانة، فجاءت بلغة بسيطة وسريعة وسهلة القراءة.

## أين تُستخدم Go؟

- **الخوادم وواجهات API** عالية الأداء.
- أدوات السحابة الشهيرة (**Docker** و **Kubernetes** مكتوبان بـ Go).
- أدوات سطر الأوامر والأنظمة الموزّعة.

## أول برنامج

```go
package main

import "fmt"

func main() {
    fmt.Println("مرحبًا من Go!")
}
```

- كل برنامج يبدأ بحزمة `main` ودالة `main()`.
- `fmt.Println(...)` للطباعة.

## التشغيل

```bash
go run main.go
go build main.go   # ينتج ملفًا تنفيذيًا
```

## متغيّر ودالة

```go
func add(a int, b int) int {
    return a + b
}

// الاستخدام: add(2, 3) => 5
```

لاحظ أنّ نوع المتغيّر يأتي **بعد** اسمه — عكس كثير من اللغات.

## لماذا Go؟

- **بسيطة:** صياغة نظيفة وقليلة الكلمات المفتاحية.
- **سريعة:** تُترجَم إلى كود آلة.
- **تزامن قوي:** goroutines تجعل البرمجة المتوازية سهلة.

## أسئلة شائعة

**هل Go سهلة للمبتدئين؟**
نعم، من أبسط اللغات المُترجَمة، وصياغتها قليلة القواعد مقارنة بـ C++ أو Java.

**متى أختار Go؟**
عندما تبني خوادم أو أدوات سحابية تحتاج سرعة عالية وتزامنًا فعّالًا.
