## حزمة أم وحدة؟

مصطلحان يختلطان كثيرًا:

- **الحزمة (package):** مجلّد واحد من ملفات `.go` تبدأ كلها بنفس السطر `package x`. هي وحدة **الكود**: الأسماء داخلها يرى بعضها بعضًا.
- **الوحدة (module):** مجموعة حزم لها ملف `go.mod` في جذرها واسم ورقم إصدار. هي وحدة **النشر والتبعيات**: ما تحمّله بـ `go get`.

مشروعك عادة وحدة واحدة فيها عدّة حزم.

## الحزم و package main

```go
package main

import "fmt"

func main() {
    fmt.Println("مرحبًا")
}
```

`package main` حزمة خاصة: هي التي تتحوّل لبرنامج تنفيذي، ويجب أن تحتوي دالة `main`. أي اسم آخر (`package utils`) يجعلها **مكتبة** تستوردها حزم أخرى.

## التصدير: الحرف الكبير

لا توجد كلمات `public` و`private`. **الحرف الأول** للاسم يقرّر:

```go
package shop

func Total(prices []float64) float64 {   // كبير: مُصدَّر، تراه الحزم الأخرى
    sum := 0.0
    for _, p := range prices {
        sum += applyTax(p)
    }
    return sum
}

func applyTax(p float64) float64 {       // صغير: داخل حزمة shop فقط
    return p * 1.16
}
```

القاعدة نفسها للأنواع والثوابت والمتغيّرات وحقول البِنى والـ methods. صدّر الحدّ الأدنى: كل اسم مُصدَّر وعد بأنك لن تكسره، ومن يستخدم حزمتك سيعتمد عليه.

## إنشاء وحدة

```bash
mkdir myapp && cd myapp
go mod init github.com/user/myapp
```

ينشئ `go.mod`:

```text
module github.com/user/myapp

go 1.24
```

- **اسم الوحدة** هو بادئة استيراد كل حزمها. يُكتب عادة كمسار المستودع، حتى يتمكّن الآخرون من تحميلها بـ `go get`، لكن لمشروع محلّي يكفي أي اسم (`myapp`).
- **سطر `go`** أدنى إصدار من Go يحتاجه المشروع، ويتحكّم أيضًا في سلوك بعض الميزات (مثل متغيّر الحلقة الجديد لكل دورة منذ 1.22).

## الاستيراد داخل مشروعك

بنية نموذجية:

```text
myapp/
├── go.mod                 (module github.com/user/myapp)
├── main.go                (package main)
└── internal/
    └── shop/
        └── shop.go        (package shop)
```

```go
package main

import (
    "fmt"

    "github.com/user/myapp/internal/shop"   // اسم الوحدة + المسار
)

func main() {
    fmt.Println(shop.Total([]float64{10, 20}))
}
```

تستدعي الأسماء المُصدَّرة باسم الحزمة: `shop.Total`. وأي حزمة داخل مجلّد اسمه `internal` لا يمكن استيرادها إلا من داخل نفس الوحدة: طريقة Go لإخفاء كود لا تريد أن يعتمد عليه مستخدمو مكتبتك.

## إضافة تبعية خارجية

```bash
go get github.com/google/uuid@latest
```

```go
import "github.com/google/uuid"

id := uuid.NewString()
```

`go get` يضيف سطرًا في `go.mod` بالإصدار، ويسجّل في `go.sum` بصمة تشفيرية لكل ملف محمّل، حتى لا يُستبدل الكود بصمت لاحقًا. **أضف الملفين كليهما إلى Git.**

## أوامر يومية

```bash
go run .            # ترجمة وتشغيل الحزمة في المجلّد الحالي
go build            # بناء ملف تنفيذي
go mod tidy         # أضف الناقص واحذف التبعيات غير المستخدمة
go test ./...       # اختبار كل الحزم في الوحدة
go vet ./...        # فحص أخطاء شائعة
go fmt ./...        # تنسيق الكود بالأسلوب الرسمي
```

`go mod tidy` قبل كل commit عادة جيدة: يُبقي `go.mod` مطابقًا لما يستورده الكود فعلًا.

## أخطاء شائعة

- **دالة بحرف صغير وتستدعيها من حزمة أخرى:** `undefined: shop.total`. كبّر الحرف الأول إن كانت جزءًا من واجهة الحزمة.
- **ملفّان في نفس المجلّد بحزمتين مختلفتين:** خطأ ترجمة. مجلّد واحد = حزمة واحدة (باستثناء `_test`).
- **استيراد دوري:** الحزمة `a` تستورد `b` و`b` تستورد `a`؛ Go ترفضه. انقل المشترك لحزمة ثالثة.
- **عدم إضافة `go.sum` لـ Git:** البناء على أجهزة أخرى أو في CI يفشل أو يتحقّق من جديد.
- **حزمة `utils` أو `common` لكل شيء:** سمِّ الحزمة بما **تفعله** (`shop`، `auth`، `storage`).
