## العوامل الحسابية

```go
a, b := 10, 3
fmt.Println(a+b, a-b, a*b)   // 13 7 30
fmt.Println(a / b)           // 3  (قسمة صحيحة: الكسر يُحذف)
fmt.Println(a % b)           // 1  (الباقي)
fmt.Println(-7 / 2, -7 % 2)  // -3 -1  (القسمة تقتطع نحو الصفر)
```

نوع النتيجة هو نوع الطرفين، لذلك قسمة عددين صحيحين تُعطي عددًا صحيحًا. وبما أن Go لا تحوّل ضمنيًا، لا يمكنك خلط `int` و`float64` في عملية واحدة أصلًا:

```go
total, count := 7, 2
avg := float64(total) / float64(count)
fmt.Println(avg)   // 3.5
```

ولأن باقي القسمة يأخذ إشارة العدد الأول، فحص الفردية بـ `n%2 == 1` يفشل مع السالب (`-3 % 2` تساوي `-1`). اكتب `n%2 != 0`.

### القسمة على صفر

```go
x, zero := 10, 0
// fmt.Println(x / zero)   // panic: runtime error: integer divide by zero
f := 10.0
fmt.Println(f / 0)         // +Inf: مع الكسور لا يحدث panic
_ = x; _ = zero
```

القسمة الصحيحة على صفر تُوقف البرنامج بـ `panic` (وإذا كان الصفر ثابتًا مكتوبًا في الكود يرفضه المترجم أصلًا). افحص المقسوم عليه قبل القسمة حين يأتي من مدخلات.

## الإسناد المختصر والزيادة

```go
n := 5
n += 3    // 8
n *= 2    // 16
n++       // 17
n--       // 16
fmt.Println(n)
```

في Go، `n++` **جملة** لا تعبير: لا تُرجع قيمة، فلا يمكن كتابة `b := n++` أو `f(n++)`، ولا يوجد `++n` إطلاقًا. هذا قرار مقصود يلغي كل ألغاز C مثل `i = i++`.

## المقارنة

`==` و`!=` و`<` و`>` و`<=` و`>=`، والنتيجة `bool`. يمكن مقارنة النصوص مباشرة بـ `==` (المحتوى لا العنوان)، و`<` تقارن أبجديًا بايتًا بايتًا:

```go
fmt.Println("go" == "go", "apple" < "banana")   // true true
```

أما الشرائح والخرائط والدوال فلا تُقارن بـ `==` (إلا مع `nil`). لمقارنة شريحتين استخدم `slices.Equal`.

## المنطقية

```go
a, b := 10, 3
x := a > 5 && b < 5    // و: true
y := a > 50 || b > 5   // أو: false
z := !x                // نفي: false
fmt.Println(x, y, z)
```

`&&` و`||` تختصران التقييم: الطرف الثاني لا يُقيَّم إذا حُسمت النتيجة من الأول. نعتمد على هذا للحماية:

```go
var users []string
if len(users) > 0 && users[0] == "admin" {   // لا panic مع شريحة فارغة
    fmt.Println("مدير")
}
```

## عوامل البِت

```go
a, b := 6, 3       // 110 و 011
fmt.Println(a & b)  // 2  (010)
fmt.Println(a | b)  // 7  (111)
fmt.Println(a ^ b)  // 5  (101)
fmt.Println(a &^ b) // 4  (100): AND NOT، تمسح من a البتّات الموجودة في b
fmt.Println(a << 1) // 12
fmt.Println(a >> 1) // 3
```

`&^` عامل خاص بـ Go لمسح بتّات محدّدة. و`^` وحدها أمام رقم (`^a`) تعني قلب كل البتّات (مثل `~` في C).

## الأولوية

Go لها خمسة مستويات أولوية فقط للعوامل الثنائية: (`*` `/` `%` `<<` `>>` `&` `&^`) ثم (`+` `-` `|` `^`) ثم المقارنات ثم `&&` ثم `||`. لاحظ أن `&` في مستوى الضرب، فـ `x&1 == 0` تُفهم كما تتوقّع `(x&1) == 0`، عكس C. لكن الأقواس تبقى أوضح للقارئ:

```go
result := (2 + 3) * 4
fmt.Println(result)   // 20
```

## أخطاء شائعة

- **`b := a++`:** خطأ ترجمة؛ الزيادة جملة منفصلة.
- **خلط `int` و`float64`:** حوّل أحدهما صراحة.
- **قسمة صحيحة على متغيّر قد يكون صفرًا:** `panic` أثناء التشغيل.
- **`n%2 == 1` للفردية:** يفشل مع الأعداد السالبة.
- **مقارنة شريحتين بـ `==`:** خطأ ترجمة؛ استخدم `slices.Equal`.
