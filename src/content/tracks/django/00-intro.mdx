## ما هو Django؟

**Django** إطار عمل للغة [Python](/learn/python) لبناء تطبيقات ويب احترافية
بسرعة وأمان. شعاره "الإطار للكمالِيِّين ذوي المواعيد النهائية".

> أتقن [أساسيات Python](/learn/python) أولًا — فـ Django مبني عليها.

يتميّز Django بأنه "متكامل": يوفّر لك قاعدة البيانات والمصادقة ولوحة الإدارة
والحماية جاهزة، فتركّز على منطق تطبيقك بدل إعادة اختراع العجلة.

## لماذا Django؟

- **متكامل (Batteries included):** يأتي بكل ما تحتاجه جاهزًا.
- **لوحة إدارة تلقائية** قوية بلا أي كود إضافي.
- **آمن:** حماية مدمجة من أشهر الثغرات.
- يشغّل مواقع ضخمة مثل Instagram.

## أين يُستخدم Django؟

- **المنصّات الكبيرة:** الشبكات الاجتماعية والمواقع عالية الحركة.
- **لوحات الإدارة:** بفضل لوحته التلقائية القوية.
- **واجهات API:** عبر Django REST Framework.

## نمط MVT

Django يتبع نمط **MVT** (نسخة من MVC):

| الجزء | الدور |
|-------|-------|
| **Model** | بنية البيانات (قاعدة البيانات) |
| **View** | المنطق الذي يعالج الطلب |
| **Template** | الواجهة المعروضة (HTML) |

## إنشاء مشروع

```bash
pip install django
django-admin startproject mysite
cd mysite
python manage.py runserver
```

`manage.py` أداة سطر الأوامر التي تدير كل شيء في مشروعك.

## هيكل المشروع

```
mysite/
  manage.py
  mysite/
    settings.py   # الإعدادات
    urls.py       # المسارات الرئيسية
```

## أسئلة شائعة

**Django أم Flask؟**
Django متكامل ومناسب للمشاريع الكبيرة، بينما Flask أخفّ وأنسب للمشاريع الصغيرة
والتعلّم التدريجي.

**هل أحتاج إتقان Python قبل Django؟**
نعم، Django إطار بايثوني بالكامل، فأساسيات اللغة شرط أساسي.
