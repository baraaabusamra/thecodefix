## null safety والثوابت

```dart
final age = 25;          // ثابت وقت التشغيل (يُحسب مرّة واحدة عند التشغيل)
const pi = 3.14;         // ثابت وقت الترجمة (قيمته معروفة قبل التشغيل)
int? maybe = null;       // ? تعني: القيمة قد تكون null
print(maybe ?? 0);       // ?? قيمة بديلة إن كانت null
```

## المعاملات المسمّاة

```dart
void greet(String name, {String greeting = "أهلًا"}) {
  print("$greeting $name");      // معاملات مسمّاة بين {}
}
greet("براء", greeting: "مرحبًا");
```

List<int> nums = [1, 2, 3];
