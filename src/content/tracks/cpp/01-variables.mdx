## تعريف متغيّر

```cpp
int age = 25;
double price = 19.99;
string name = "براء";
bool isActive = true;
char grade = 'A';
```

## الأنواع الأساسية

| النوع | الاستخدام |
|-------|-----------|
| `int` | عدد صحيح |
| `double` | عدد عشري |
| `string` | نص (يحتاج `#include <string>`) |
| `bool` | منطقي |
| `char` | حرف واحد |

## الإخراج (cout)

```cpp
int age = 25;
cout << "العمر: " << age << endl;
```

## الإدخال (cin)

```cpp
int age;
cout << "اكتب عمرك: ";
cin >> age;
cout << "عمرك " << age << endl;
```

## الثوابت

```cpp
const double PI = 3.14159;
```

## العمليات الحسابية

```cpp
int a = 10, b = 3;
cout << a + b;   // 13
cout << a / b;   // 3  (قسمة صحيحة)
cout << a % b;   // 1  (الباقي)
```

> 💡 قسمة عددين صحيحين تعطي نتيجة صحيحة. لنتيجة عشرية اجعل أحدهما `double`.
