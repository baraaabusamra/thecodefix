## الشروط

```csharp
int age = 18;

if (age >= 18) {
    Console.WriteLine("بالغ");
} else {
    Console.WriteLine("قاصر");
}
```

## else if

```csharp
int score = 85;

if (score >= 90) Console.WriteLine("ممتاز");
else if (score >= 75) Console.WriteLine("جيد جدًا");
else Console.WriteLine("مقبول");
```

## switch

```csharp
int day = 3;
switch (day) {
    case 1: Console.WriteLine("الأحد"); break;
    case 2: Console.WriteLine("الاثنين"); break;
    default: Console.WriteLine("يوم آخر"); break;
}
```

## حلقة for

```csharp
for (int i = 1; i <= 5; i++) {
    Console.WriteLine(i);
}
```

## حلقة while

```csharp
int count = 1;
while (count <= 3) {
    Console.WriteLine(count);
    count++;
}
```

## المصفوفات و foreach

```csharp
int[] numbers = {10, 20, 30};

foreach (int n in numbers) {
    Console.WriteLine(n);
}
```

`foreach` تمرّ على كل عنصر بسهولة.

> 🎯 التالي: الأصناف والكائنات (OOP).
