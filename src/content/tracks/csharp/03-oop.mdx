## الصنف والكائن

```csharp
class Car {
    public string Brand;
    public int Speed;

    public void Drive() {
        Console.WriteLine($"{Brand} بسرعة {Speed}");
    }
}

class Program {
    static void Main() {
        Car myCar = new Car();
        myCar.Brand = "Toyota";
        myCar.Speed = 120;
        myCar.Drive();
    }
}
```

## الباني (Constructor)

```csharp
class Car {
    public string Brand;
    public Car(string brand) {
        Brand = brand;
    }
}

Car c = new Car("Honda");
```

## الخصائص (Properties)

ميزة مميّزة في C# للتغليف الأنيق:

```csharp
class Account {
    private double balance;

    public double Balance {
        get { return balance; }
        set { balance = value; }
    }
}
```

أو المختصرة:

```csharp
public string Name { get; set; }
```

## الوراثة

```csharp
class Animal {
    public void Eat() => Console.WriteLine("يأكل");
}

class Dog : Animal {
    public void Bark() => Console.WriteLine("ينبح");
}
```

`Dog` يرث `Eat()` ويضيف `Bark()`.
