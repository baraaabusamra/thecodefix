## ما هي C#؟

**C#** (تُنطق "سي شارب") لغة برمجة حديثة وقوية من مايكروسوفت، كائنية التوجّه،
تعمل على منصّة **.NET**.

صُمّمت لتكون منظّمة وسهلة نسبيًا وقوية في آنٍ واحد، وهي اليوم من أكثر اللغات
استخدامًا في تطوير الألعاب وتطبيقات المؤسسات.

## أين تُستخدم C#؟

- **تطوير الألعاب** عبر محرّك **Unity** (الأشهر للألعاب).
- **تطبيقات الويب** عبر ASP.NET.
- **تطبيقات سطح المكتب** على ويندوز.
- تطبيقات الموبايل عبر .NET MAUI.

## أول برنامج

```csharp
using System;

class Program {
    static void Main() {
        Console.WriteLine("مرحبًا من C#!");
    }
}
```

- `Console.WriteLine(...)` للطباعة.
- البرنامج يبدأ من `Main()`.

## التشغيل

```bash
dotnet run
```

عبر أداة .NET CLI.

## متغيّر وإدخال

```csharp
Console.Write("ما اسمك؟ ");
string name = Console.ReadLine();
Console.WriteLine($"أهلًا {name}");
```

نستخدم `Console.ReadLine()` لقراءة نص من المستخدم، و `$"..."` لدمج المتغيّرات.

## لماذا C#؟

- لغة منظّمة وحديثة وسهلة نسبيًا.
- مدعومة بقوة من مايكروسوفت ومجتمع ضخم.
- الخيار رقم 1 لتطوير الألعاب مع Unity.

## أسئلة شائعة

**هل C# جيدة لتطوير الألعاب؟**
نعم، هي اللغة الأساسية لمحرّك Unity الأشهر عالميًا في صناعة الألعاب.

**ما الفرق بين C# و Java؟**
متشابهتان كثيرًا في الصياغة والفلسفة الكائنية، لكن C# مرتبطة بمنصّة .NET
ومايكروسوفت، بينما Java تعمل على JVM.
