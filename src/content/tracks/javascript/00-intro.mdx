## ما هي جافاسكريبت؟

**جافاسكريبت (JavaScript)** هي لغة البرمجة التي تجعل صفحات الويب تفاعلية.
بينما تبني **HTML** هيكل الصفحة و**CSS** شكلها، فإن **جافاسكريبت** هي التي
تضيف الحركة والمنطق: عند الضغط على زر، أو إرسال نموذج، أو تحديث المحتوى دون
إعادة تحميل الصفحة.

ظهرت جافاسكريبت عام 1995 لتشغيل نصوص بسيطة داخل المتصفّح، لكنها تطوّرت حتى
صارت اليوم من أكثر لغات البرمجة استخدامًا في العالم — تعمل في المتصفّح، وعلى
الخادم، وحتى في تطبيقات الموبايل وسطح المكتب.

## لماذا تتعلّم جافاسكريبت؟

- **تعمل في كل متصفّح** بدون أي إعداد أو تثبيت.
- **لغة واحدة لكل شيء:** الواجهة الأمامية (React) والخلفية (Node.js) معًا.
- **مطلوبة بشدة** في سوق العمل العربي والعالمي، وبرواتب مرتفعة.
- **مجتمع ضخم:** ملايين المطوّرين وآلاف المكتبات الجاهزة.

## أين تُستخدم جافاسكريبت؟

- **مواقع تفاعلية:** القوائم المنسدلة، النوافذ المنبثقة، والتحقّق من النماذج.
- **تطبيقات ويب كاملة:** مثل Gmail و Facebook و YouTube.
- **الخوادم (Back-end):** عبر بيئة Node.js.
- **تطبيقات الجوال:** عبر أدوات مثل React Native.

## أول سطر برمجي

أبسط أمر في جافاسكريبت هو طباعة رسالة في الـ Console (وحدة التحكّم داخل
المتصفّح):

```js
console.log("مرحبًا بك في The Code Fix!");
```

لتجربته: افتح أي متصفّح، اضغط `F12`، ثم اذهب إلى تبويب **Console** والصق
الكود.

## مثال أكبر: بيانات + منطق

```js
let name = "براء";
let hour = 9;

if (hour < 12) {
  console.log("صباح الخير يا " + name);
} else {
  console.log("مساء الخير يا " + name);
}
```

هنا خزّنّا بيانات في **متغيّرات**، ثم اتّخذنا **قرارًا** بناءً عليها — وهذا جوهر
البرمجة: بيانات نُخزّنها، ومنطق نبني عليه.

## أخطاء شائعة للمبتدئين

- الخلط بين `=` (إسناد قيمة) و `==` (مقارنة قيمتين).
- كتابة الكود داخل ملف HTML دون وضعه ضمن وسم `<script>`.
- نسيان أنّ الحروف حسّاسة: `Name` تختلف عن `name`.

## أسئلة شائعة

**هل جافاسكريبت صعبة على المبتدئين؟**
لا، تُعدّ من أسهل اللغات للبدء لأنها تعمل مباشرة في المتصفّح دون إعداد، ونتيجة
كل سطر تظهر أمامك فورًا.

**ما الفرق بين جافاسكريبت وجافا؟**
رغم تشابه الاسم، هما لغتان مختلفتان تمامًا في الاستخدام والصياغة. جافاسكريبت
لغة الويب، وجافا تُستخدم غالبًا في تطبيقات الشركات والأندرويد.

**كم يحتاج تعلّم جافاسكريبت؟**
تتقن الأساسيات خلال أسابيع قليلة بالممارسة اليومية، ثم تتعمّق تدريجيًا مع
المشاريع العملية.

> 🎯 التالي: **المتغيّرات** — الطريقة التي نخزّن بها البيانات ونعيد استخدامها.
