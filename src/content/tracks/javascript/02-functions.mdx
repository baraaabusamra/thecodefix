## ما هي الدالة؟

الدالة هي **مجموعة أوامر** نعطيها اسمًا لنعيد استخدامها وقتما نشاء، بدل تكرار
نفس الكود.

```js
function greet(name) {
  return "أهلًا يا " + name;
}

console.log(greet("سارة")); // أهلًا يا سارة
```

## الدوال السهمية (Arrow Functions)

طريقة أقصر لكتابة الدوال:

```js
const add = (a, b) => a + b;

console.log(add(4, 6)); // 10
```

## لماذا الدوال مهمة؟

- **إعادة الاستخدام:** اكتب الكود مرة، استدعِه مرارًا.
- **التنظيم:** تقسّم البرنامج إلى أجزاء صغيرة مفهومة.
- **الصيانة:** عدّل في مكان واحد بدل عشرات الأماكن.

> 🎯 في الدرس القادم سندخل إلى **الشروط والتحكّم في المسار** (if / else).
