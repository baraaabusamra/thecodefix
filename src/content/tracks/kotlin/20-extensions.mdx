## ما هي دالة التمديد؟

تضيف وظيفة جديدة لنوع موجود (حتى من المكتبة القياسية) دون تعديله أو توريثه:

```kotlin
fun String.shout(): String {
    return this.uppercase() + "!"
}

println("hello".shout())   // HELLO!
```

`this` تشير إلى الكائن الذي استُدعيت عليه الدالة.

ما الذي يحدث فعلًا؟ دالة التمديد **لا تعدّل** الصنف `String`. هي دالة عادية تأخذ النص كأول معامل، والمترجم يسمح لك فقط بكتابة استدعائها بصيغة النقطة. لذلك:

- لا تصل إلى الخصائص الـ `private` في الصنف الأصلي.
- إذا كان للصنف دالة عضو بنفس الاسم والمعاملات، **الدالة العضو تفوز** ويُتجاهل التمديد.

## أمثلة عملية

```kotlin
fun Int.isEven(): Boolean = this % 2 == 0
println(4.isEven())   // true

fun List<Int>.sumOfSquares(): Int = this.sumOf { it * it }
println(listOf(1, 2, 3).sumOfSquares())   // 14
```

## خصائص التمديد

```kotlin
val String.firstChar: Char
    get() = this[0]

println("Kotlin".firstChar)   // K
```

## تمديد نوع nullable

تقدر تعرّف تمديدًا يُستدعى حتى على `null`، وداخله تتعامل مع الحالة:

```kotlin
fun String?.orDash(): String = if (this.isNullOrBlank()) "—" else this

val nick: String? = null
println(nick.orDash())   // — بدون ?. لأن التمديد نفسه يقبل null
```

بهذا الأسلوب كُتبت دوال قياسية مثل `isNullOrEmpty()` و`orEmpty()`.

## يُحسم وقت الترجمة لا وقت التشغيل

اختيار دالة التمديد يعتمد على **النوع المعلن** للمتغيّر، لا على نوع الكائن الحقيقي:

```kotlin
open class Shape
class Circle : Shape()

fun Shape.name() = "شكل"
fun Circle.name() = "دائرة"

val s: Shape = Circle()
println(s.name())   // شكل — لأن s معلن كـ Shape
```

لو كانت `name` دالة عضو `open` مُتجاوَزة، لطبعت "دائرة". لذلك لا تستخدم التمديد حين تحتاج سلوكًا يختلف حسب النوع الفعلي؛ هذا عمل الوراثة والـ `override`.

> 💡 دوال التمديد تجعل الكود أنظف وأقرب للّغة الطبيعية، وتُستخدم بكثرة في مكتبات Android.

## أخطاء شائعة

- **توقّع أن التمديد يتصرّف كـ override:** يُختار حسب النوع المعلن، كما في المثال.
- **تمديد بنفس اسم دالة عضو:** لا يُستدعى أبدًا، والعضو يفوز بصمت.
- **إغراق الأنواع العامة بتمديدات:** عشرات التمديدات على `String` في كل المشروع تجعل من الصعب معرفة مصدر كل دالة. اجعلها `private` في الملف الذي يحتاجها حين تكون محلية.
