## أصغر برنامج

```kotlin
fun main() {
    println("مرحبًا بالعالم")
}
```

- `fun` تعرّف دالة، و`main` نقطة البداية.
- لا حاجة للفاصلة المنقوطة في نهاية السطر.

لماذا `main` بالذات؟ لأن هذا هو الاسم الذي يبحث عنه نظام التشغيل (عبر JVM) حين تشغّل البرنامج: يبدأ التنفيذ من أول سطر داخل `main` وينتهي بنهايتها. ملف بلا `main` يُترجَم عادي، لكنه لا يُشغَّل وحده، وهذا طبيعي لملفات الأصناف التي يستخدمها ملف آخر.

وعلى عكس Java، لا تحتاج `main` أن تكون داخل صنف: تكتبها مباشرة في الملف (top-level function).

## قوالب النصوص (String Templates)

```kotlin
val name = "براء"
println("أهلًا $name")
println("الناتج: ${2 + 3}")
```

القاعدة: `$name` لمتغيّر وحده، و`${...}` لأي **تعبير** (عملية حسابية، استدعاء دالة، خاصية):

```kotlin
val items = listOf("قلم", "دفتر")
println("العدد: ${items.size}")      // العدد: 2
println("العدد: $items.size")        // العدد: [قلم, دفتر].size  ← خطأ شائع
```

في السطر الأخير يأخذ Kotlin `$items` فقط، ويطبع `.size` كنص عادي.

## قراءة إدخال المستخدم

```kotlin
fun main() {
    print("ما اسمك؟ ")
    val name = readln()               // يقرأ سطرًا كاملًا كنص
    println("أهلًا $name")

    print("كم عمرك؟ ")
    val age = readln().toIntOrNull()  // null إن كتب المستخدم شيئًا ليس رقمًا
    println(if (age != null) "بعد سنة: ${age + 1}" else "هذا ليس رقمًا")
}
```

`readln()` تُرجع دائمًا نصًّا (`String`)، فإذا أردت رقمًا حوّله. `toIntOrNull()` أأمن من `toInt()` لأنها لا تُنهي البرنامج بخطأ إذا كان الإدخال غير رقمي (التفاصيل في الدرس القادم).

## أخطاء شائعة

- **`$list.size` بدل `${list.size}`:** أي شيء بعد اسم المتغيّر (نقطة، قوس، عملية) يحتاج الأقواس المعقوفة.
- **نسيان أن `readln()` نص:** `readln() + 1` يعطي `"51"` إذا كتب المستخدم `5`، لأن `+` هنا دمج نصوص لا جمع.
- **كتابة `main` بحرف كبير أو اسم آخر:** `Main` أو `start` لن تُشغَّل كنقطة بداية.

> 💡 Kotlin موجزة جدًّا: لا تحتاج فواصل منقوطة ولا كلاسًا حاويًا مثل Java لبرنامج بسيط.
