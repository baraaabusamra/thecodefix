## الحسابية

```kotlin
println(10 + 3)   // 13
println(10 - 3)   // 7
println(10 * 3)   // 30
println(10 / 3)   // 3 (قسمة صحيحة)
println(10 % 3)   // 1
```

### القسمة الصحيحة: أشهر مفاجأة

إذا كان الطرفان عددين صحيحين (`Int`)، تكون النتيجة عددًا صحيحًا ويُحذف الجزء العشري، حتى لو خزّنتها في `Double`:

```kotlin
val avg: Double = (7 / 2).toDouble()   // 3.0 لا 3.5 — القسمة حدثت قبل التحويل
val avg2 = 7 / 2.0                     // 3.5 ✅ يكفي أن يكون طرف واحد Double
val avg3 = 7.toDouble() / 2            // 3.5 ✅
```

### باقي القسمة مع الأعداد السالبة

`%` تأخذ إشارة الطرف الأيسر، فقد تعطي نتيجة سالبة. إذا أردت باقيًا موجبًا دائمًا (مثلًا للف دائري على قائمة)، استخدم `mod`:

```kotlin
println(-7 % 3)       // -1
println((-7).mod(3))  // 2
```

## المقارنة

`==`، `!=`، `>`، `<`، `>=`، `<=`.

> 💡 في Kotlin `==` يقارن **القيم** (يستدعي equals)، و`===` يقارن **المرجع** (نفس الكائن).

```kotlin
val a = "hi"
val b = "hi"
println(a == b)    // true (نفس القيمة)
```

مثال يوضّح الفرق بينهما:

```kotlin
data class Point(val x: Int, val y: Int)

val p1 = Point(1, 2)
val p2 = Point(1, 2)
val p3 = p1

println(p1 == p2)    // true  — نفس القيم
println(p1 === p2)   // false — كائنان مختلفان في الذاكرة
println(p1 === p3)   // true  — نفس الكائن
```

في الاستخدام اليومي تحتاج `==` دائمًا تقريبًا. وهذا عكس Java، حيث `==` على الكائنات تقارن المرجع، ولذلك يقع مبرمجو Java الجدد على Kotlin في هذا الفرق.

## المنطقية

```kotlin
val x = 5
println(x > 0 && x < 10)   // و
println(x < 0 || x > 3)    // أو
println(!(x == 5))         // نفي
```

`&&` و`||` "قصيرة الدارة": إذا عُرفت النتيجة من الطرف الأول لا يُحسب الثاني. لذلك هذا آمن:

```kotlin
val name: String? = null
if (name != null && name.length > 3) { /* ... */ }   // الطرف الثاني لا يُنفَّذ إن كان null
```

## الانتماء: in و !in

```kotlin
val age = 25
println(age in 18..60)        // true — داخل النطاق
println("قلم" in listOf("قلم", "دفتر"))   // true
println(age !in 0..17)        // true — ليس قاصرًا
```

## الإسناد المختصر

```kotlin
var n = 5
n += 3    // 8
n++       // 9
```

## أخطاء شائعة

- **`7 / 2` وتوقّع `3.5`:** القسمة بين عددين صحيحين تُسقط الكسر. اجعل أحد الطرفين `Double`.
- **`===` لمقارنة النصوص أو القيم:** استخدم `==`. `===` لحالات نادرة تحتاج فيها التأكد أنه نفس الكائن.
- **`%` لحساب فهرس دائري بأرقام سالبة:** قد يعطي فهرسًا سالبًا؛ استخدم `mod`.
