## ما هي Kotlin؟

**Kotlin** لغة حديثة من JetBrains، تعمل على JVM مثل [Java](/learn/java) لكنها
**أوجز وأكثر أمانًا**. اعتمدتها جوجل **رسميًا** كاللغة المفضّلة لتطوير الأندرويد.

صُمّمت لتصحّح عيوب Java مع الحفاظ على توافق كامل معها، فتستطيع خلط اللغتين في
نفس المشروع بسلاسة.

## لماذا Kotlin؟

- **اللغة الرسمية للأندرويد**.
- **أوجز من Java** بكثير (كود أقل لنفس النتيجة).
- **آمنة من القيم الفارغة (null safety)**.
- متوافقة 100% مع Java.

## أين تُستخدم Kotlin؟

- **تطبيقات الأندرويد:** الخيار الرسمي الأول.
- **الخوادم:** عبر أُطُر مثل Ktor و Spring.
- **متعدّد المنصّات:** مشاركة الكود بين Android و iOS.

## أول برنامج

```kotlin
fun main() {
    println("مرحبًا من Kotlin!")
}
```

أبسط بكثير من Java — لا حاجة لصنف يلفّ كل شيء.

## التشغيل

```bash
kotlinc main.kt -include-runtime -d main.jar
java -jar main.jar
```

أو مباشرة في Android Studio لتطبيقات الأندرويد.

## Kotlin مقابل Java

```kotlin
// Kotlin — سطر واحد
val name = "براء"

// Java — أطول
// String name = "براء";
```

> 💡 إن كنت تعرف Java فستتعلّم Kotlin بسرعة كبيرة — وستحبّ إيجازها.

## أسئلة شائعة

**هل أتعلّم Java قبل Kotlin؟**
ليس شرطًا، لكن معرفة Java تساعد لأنهما تعملان على نفس المنصّة (JVM).

**هل Kotlin مستقبل الأندرويد؟**
نعم، جوجل تدفع نحوها بقوة وتوصي بها رسميًا للتطبيقات الجديدة.
