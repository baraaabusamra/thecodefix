## حلقة for

```kotlin
for (i in 1..5) {
    println(i)          // 1..5
}

for (i in 0 until 5) {  // 0..4 (لا يشمل 5)
    println(i)
}

for (i in 10 downTo 1 step 2) {
    println(i)
}
```

`for` في Kotlin تمرّ دائمًا على **شيء**: نطاق أو قائمة أو نص. لا توجد صيغة `for (int i = 0; i < n; i++)` الموجودة في Java وC.

### `..` أم `until`؟ أشهر خطأ في الحلقات

`1..5` **تشمل** الرقم الأخير، و`until` **لا تشمله**. عند المرور على فهارس قائمة، آخر فهرس هو `size - 1`، فاستخدام `..` يتجاوز القائمة:

```kotlin
val names = listOf("أ", "ب", "ج")

for (i in 0..names.size) println(names[i])      // ❌ IndexOutOfBoundsException عند i = 3
for (i in 0 until names.size) println(names[i]) // ✅ 0, 1, 2
for (i in names.indices) println(names[i])      // ✅ الأوضح: indices = 0 until size
```

ومنذ Kotlin 1.9 تقدر تكتب `0..<names.size` بنفس معنى `until`.

## المرور على مجموعة

```kotlin
val fruits = listOf("تفاح", "موز", "برتقال")
for (fruit in fruits) {
    println(fruit)
}

for ((index, value) in fruits.withIndex()) {
    println("$index: $value")
}
```

إذا لم تحتج الفهرس، مرّ على العناصر مباشرة كما في أول مثال. هذا أوضح وأقل عرضة للخطأ من المرور بالفهارس.

## تكرار عدد محدّد: repeat

حين لا تحتاج رقم الدورة أصلًا:

```kotlin
repeat(3) {
    println("مرحبًا")
}
```

## while و do...while

```kotlin
var n = 3
while (n > 0) {
    println(n)
    n--
}

do {
    println("مرّة على الأقل")
} while (false)
```

استخدم `while` حين لا تعرف عدد الدورات مسبقًا (مثلًا: حتى يكتب المستخدم إدخالًا صحيحًا). و`do...while` تضمن تنفيذ الجسم مرة واحدة على الأقل قبل فحص الشرط.

## break و continue

```kotlin
for (i in 1..10) {
    if (i == 5) break
    if (i % 2 == 0) continue
    println(i)
}
```

### الخروج من حلقتين معًا: التسميات (labels)

`break` العادية تخرج من الحلقة الداخلية فقط. لتخرج من الخارجية، سمِّها بـ `@`:

```kotlin
outer@ for (row in 1..3) {
    for (col in 1..3) {
        if (row * col == 4) break@outer   // يخرج من الحلقتين
        println("$row × $col")
    }
}
```

## for أم forEach؟

```kotlin
fruits.forEach { println(it) }
```

النتيجة نفسها، لكن داخل `forEach` لا تعمل `break` ولا `continue`، لأن الجسم دالة (lambda) لا حلقة. إذا احتجت إيقاف المرور أو تخطّي عنصر، استخدم `for` العادية.

## أخطاء شائعة

- **`0..list.size`:** يتجاوز آخر فهرس. استخدم `until` أو `indices`.
- **`break` داخل `forEach`:** خطأ ترجمة. استخدم `for`.
- **حلقة `while` لا تغيّر شرطها:** نسيان `n--` يجعلها لا تنتهي أبدًا.
