## لماذا Generics؟

تتيح كتابة كود يعمل مع **أي نوع** مع الحفاظ على أمان النوع (يكشف الأخطاء وقت الترجمة).

رأيتها بالفعل: `ArrayList<String>` و `HashMap<String, Integer>`.

## صنف عام

```java
public class Box<T> {
  private T value;

  public void set(T value) { this.value = value; }
  public T get() { return value; }
}
```

الاستخدام:

```java
Box<String> b1 = new Box<>();
b1.set("مرحبًا");
String s = b1.get();    // بلا تحويل، آمن

Box<Integer> b2 = new Box<>();
b2.set(42);
int n = b2.get();       // Integer يتحوّل لـ int تلقائيًّا (unboxing)

// b2.set("نص");        // خطأ ترجمة: incompatible types
```

`<>` الفارغة (diamond، منذ Java 7) تعني "استنتج النوع من التعريف"، فلا تكرّر `Box<Integer>` مرتين.

## أسماء معاملات النوع

الحرف مجرّد اسم، لكن هذا العرف المتّبع في Java ومكتباتها:

| الاسم | المعنى | مثال |
|-------|--------|------|
| `T` | Type: نوع عام | `Box<T>` |
| `E` | Element: عنصر في مجموعة | `List<E>` |
| `K`, `V` | Key, Value | `Map<K, V>` |
| `R` | Return: نوع الإرجاع | `Function<T, R>` |

## دالة عامّة

```java
public static <T> void printArray(T[] arr) {
  for (T item : arr) {
    System.out.println(item);
  }
}
```

## الحدود (Bounded)

تقييد النوع:

```java
public static <T extends Number> double sum(T a, T b) {
  return a.doubleValue() + b.doubleValue();
}
```

## الفائدة

- **أمان النوع:** خطأ النوع يُكشف وقت الترجمة لا التشغيل.
- **إعادة الاستخدام:** كود واحد لكل الأنواع.
- **بلا تحويل (casting):** المترجم يعرف النوع.

## أخطاء شائعة

- **الأنواع البدائية:** `Box<int>` خطأ ترجمة، لأن معامل النوع لازم يكون صنفًا. استخدم `Box<Integer>`، والتحويل بين `int` و`Integer` يصير تلقائيًّا.
- **النوع الخام (raw type):** كتابة `Box` بدون `<...>` تترجَم مع تحذير فقط، وتُرجعك لعالم `Object`، فيرجع الخطأ لوقت التشغيل:

```java
Box raw = new Box();             // بدون نوع
raw.set("نص");                   // مقبول — المترجم لا يعرف النوع
Integer x = (Integer) raw.get(); // ClassCastException وقت التشغيل
```

- **`List<?>` بدون حاجة:** علامة `?` (wildcard) تعني "نوع مجهول"، فلا تقدر تضيف عناصر للقائمة. إذا كنت تعرف النوع اكتبه: `List<String>`.
