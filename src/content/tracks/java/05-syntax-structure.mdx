## أصغر برنامج

كل برنامج Java يبدأ من صنف ودالة `main`:

```java
public class Main {
  public static void main(String[] args) {
    System.out.println("مرحبًا بالعالم");
  }
}
```

- اسم الملف يجب أن يطابق اسم الصنف العام: `Main.java`.
- التنفيذ يبدأ من `main`.

## الطباعة

```java
System.out.println("سطر مع نزول");  // ينهي بسطر جديد
System.out.print("بلا نزول سطر");
System.out.printf("العمر: %d%n", 25); // مُنسّق
```

## التعليقات

```java
// تعليق سطر واحد

/* تعليق
   متعدّد الأسطر */
```

## الفاصلة المنقوطة والأقواس

- كل جملة تنتهي بـ `;`.
- الكتل تُحاط بـ `{ }`.
- Java حسّاسة لحالة الأحرف: `Main` ≠ `main`.

## أخطاء شائعة

- نسيان `;` في نهاية الجملة.
- عدم تطابق اسم الملف مع اسم الصنف العام.
