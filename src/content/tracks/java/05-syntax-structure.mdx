## أصغر برنامج كامل

في [المقدمة](/learn/java/00-intro) رأيت هذا البرنامج. هنا نفكّكه كلمة كلمة، لأنك ستكتبه في بداية كل ملف:

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("مرحبًا بالعالم");
    }
}
```

| الجزء | معناه الآن |
| --- | --- |
| `public class Main` | صنف اسمه `Main`. كل كود Java يعيش داخل صنف |
| `public static void main(String[] args)` | نقطة البداية: JVM تبحث عن هذا التوقيع بالضبط وتبدأ التنفيذ منه |
| `System.out.println(...)` | اطبع ما بين القوسين ثم انزل سطرًا |
| `{ }` | تحدّد بداية ونهاية الصنف والدالة |

لا تحتاج أن تفهم `public` و`static` و`String[] args` بعمق الآن؛ ستعود إليها في [درس الدوال](/learn/java/03-methods) و[درس الأصناف](/learn/java/13-classes-objects). المهم أن تعرف أن تغيير اسم الدالة (مثل `Main` بحرف كبير) أو نوع معاملها يجعل البرنامج يُترجَم ثم يرفض التشغيل، لأن JVM لا تجد نقطة البداية.

## الترجمة والتشغيل

احفظ الكود في ملف اسمه **`Main.java`**، بنفس اسم الصنف العام وبنفس حالة الأحرف:

```bash
javac Main.java    # يترجم إلى Main.class (bytecode)
java Main          # يشغّل الصنف (بلا .class)
```

ومنذ Java 11 تستطيع تشغيل ملف واحد مباشرة بلا خطوة ترجمة منفصلة، وهو أسرع للتجربة:

```bash
java Main.java
```

## الطباعة: println و print و printf

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("سطر كامل");      // يطبع ثم ينزل سطرًا
        System.out.print("بلا نزول، ");      // يبقى على نفس السطر
        System.out.print("ثم يكمل هنا");
        System.out.println();                // سطر فارغ = نزول فقط

        String name = "سارة";
        int age = 22;
        System.out.println("الاسم: " + name + "، العمر: " + age);
        System.out.printf("العمر: %d، المعدّل: %.2f%n", age, 91.456);
    }
}
```

الناتج:

```text
سطر كامل
بلا نزول، ثم يكمل هنا
الاسم: سارة، العمر: 22
العمر: 22، المعدّل: 91.46
```

`+` تلصق النصوص بالقيم. أما `printf` فتكتب "قالبًا" فيه مواضع تُملأ بالترتيب:

| الرمز | يُملأ بـ | مثال |
| --- | --- | --- |
| `%d` | عدد صحيح | `%d` ← `22` |
| `%.2f` | عدد عشري بمنزلتين (مع تقريب) | `91.456` ← `91.46` |
| `%s` | نص أو أي قيمة | `%s` ← `سارة` |
| `%n` | سطر جديد | |

`String.format(...)` تقبل نفس القالب لكنها **تعيد** النص بدل طباعته، فتحفظه في متغيّر.

### رموز الهروب

بعض الأحرف لا تُكتب مباشرة داخل `"..."`:

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("سطر أول\nسطر ثانٍ");
        System.out.println("الاسم:\tبراء");
        System.out.println("قال: \"مرحبًا\"");
        System.out.println("C:\\Users\\Baraa");
    }
}
```

`\n` سطر جديد، و`\t` مسافة جدولة، و`\"` علامة اقتباس داخل النص، و`\\` شرطة مائلة واحدة (مهمّة في مسارات Windows).

> 💡 إذا ظهرت الحروف العربية علامات `???` في الطرفية، فالمشكلة في ترميز الطرفية لا في كودك. مع Java 19 وما بعدها جرّب: `java -Dstdout.encoding=UTF-8 Main.java`.

## التعليقات

```java
public class Main {
    public static void main(String[] args) {
        // تعليق سطر واحد: يتجاهله المترجم

        /* تعليق
           متعدّد الأسطر */

        System.out.println("يعمل"); // تعليق بعد الكود
    }
}
```

وهناك نوع ثالث يبدأ بـ `/**` يُكتب فوق الأصناف والدوال، وتولّد منه أداة `javadoc` صفحات توثيق. اكتب التعليق ليشرح **لماذا** فعلت شيئًا، لا ليعيد ما يقوله الكود.

## قواعد الكتابة

- **كل جملة تنتهي بـ `;`**، أما سطور مثل `public class Main {` فهي بداية كتلة لا جملة.
- **Java حسّاسة لحالة الأحرف:** `System` ليست `system`، و`Main` ليست `main`.
- **المسافات والأسطر الفارغة لا تهم المترجم**، لكنها تهمّك وتهم من يقرأ كودك. أزح كل كتلة داخلية بأربع مسافات.
- **صنف عام واحد لكل ملف**، واسم الملف يطابقه.

### أعراف التسمية

لا يفرضها المترجم، لكن كل كود Java في العالم يلتزم بها، فالتزم بها من البداية:

| النوع | العُرف | مثال |
| --- | --- | --- |
| صنف | PascalCase | `BankAccount` |
| دالة ومتغيّر | camelCase | `getBalance`، `totalPrice` |
| ثابت | UPPER_SNAKE_CASE | `MAX_SIZE` |
| حزمة | أحرف صغيرة | `com.thecodefix.app` |

## قراءة رسالة الخطأ

انسَ الفاصلة المنقوطة بعد `println("hi")`، وسيقول `javac`:

```text
Main.java:3: error: ';' expected
        System.out.println("hi")
                                ^
1 error
```

الرسالة تعطيك ثلاثة أشياء: **الملف ورقم السطر** (`Main.java:3`)، و**المشكلة** (`';' expected`)، و**الموضع** بعلامة `^`. ابدأ دائمًا بأول خطأ في القائمة: خطأ واحد في الأعلى قد يولّد أخطاء وهمية تحته تختفي حين تصلحه.

## أخطاء شائعة

- **اسم ملف لا يطابق الصنف العام:** `class Main` في `main.java` يعطي خطأ ترجمة.
- **اسم `main` خاطئ** (`Main` أو `mian`): يُترجَم البرنامج، ثم يقول `java`: `can't find main(String[]) method in class: Main`.
- **`system.out.println`** بحرف صغير: `package system does not exist`.
- **علامات اقتباس "ذكية"** (`“...”`) منسوخة من مستند Word بدل `"..."`: الخطأ `illegal character: '\u201c'`.
- **قوس `}` ناقص:** الخطأ يظهر غالبًا في آخر الملف (`reached end of file while parsing`) لا في مكان النسيان الحقيقي.
