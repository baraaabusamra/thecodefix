## العوامل الحسابية

```java
int a = 10, b = 3;
a + b;  // 13
a - b;  // 7
a * b;  // 30
a / b;  // 3 (قسمة صحيحة!)
a % b;  // 1 (الباقي)
```

> ⚠️ قسمة عددين صحيحين تعطي صحيحًا: `10 / 3 = 3`. لنتيجة عشرية اجعل أحدهما `double`.

## الإسناد المختصر

```java
a += 5;   // a = a + 5
a *= 2;   // a = a * 2
a++;      // زيادة 1
a--;      // إنقاص 1
```

## عوامل المقارنة

```java
a == b;   // يساوي
a != b;   // لا يساوي
a > b;    a < b;   a >= b;   a <= b;
```

## العوامل المنطقية

```java
boolean x = (a > 5) && (b < 5);  // و
boolean y = (a > 5) || (b > 5);  // أو
boolean z = !x;                   // نفي
```

## == مقابل equals

- `==` تقارن **المراجع** للكائنات.
- `.equals()` تقارن **المحتوى**.

```java
String s1 = new String("hi");
String s2 = new String("hi");
s1 == s2;        // false (مرجعان مختلفان)
s1.equals(s2);   // true (نفس المحتوى)
```

> 💡 قارن النصوص دائمًا بـ `.equals()` لا `==`.

> 🎯 التالي: النصوص String ودوالها.
