## ArrayList — قائمة ديناميكية

تكبر وتصغر تلقائيًّا، عكس المصفوفة:

```java
import java.util.ArrayList;

ArrayList<String> names = new ArrayList<>();
names.add("براء");
names.add("سارة");
names.get(0);          // "براء"
names.set(1, "علي");   // تعديل
names.remove(0);        // حذف
names.size();           // العدد
```

المرور:

```java
for (String name : names) {
  System.out.println(name);
}
```

أهمّ الدوال:

| الدالة | الوظيفة |
|--------|---------|
| `add(item)` | إضافة في النهاية |
| `add(index, item)` | إضافة في موضع محدّد، والباقي يُزاح لليمين |
| `get(index)` / `set(index, item)` | قراءة / استبدال عنصر |
| `remove(index)` / `remove(item)` | حذف بالفهرس / حذف أول ظهور للقيمة |
| `size()` / `isEmpty()` | العدد / فارغة؟ |
| `contains(item)` / `indexOf(item)` | موجود؟ / موضعه أو `-1` |

> 💡 عرّف المتغيّر بنوع الواجهة: `List<String> names = new ArrayList<>();`. كودك يعتمد على "قائمة" لا على تنفيذ معيّن، فتقدر تغيّره لاحقًا (مثلًا إلى `LinkedList`) بتعديل سطر واحد.

### أخطاء شائعة مع ArrayList

- **الأنواع البدائية:** `ArrayList<int>` خطأ ترجمة. استخدم الصنف المغلِّف `ArrayList<Integer>`.
- **`remove` مع أرقام:** مع `ArrayList<Integer>`، الرقم يُفهم كفهرس لا كقيمة:

```java
import java.util.List;

ArrayList<Integer> nums = new ArrayList<>(List.of(10, 20, 30));
nums.remove(1);                     // → [10, 30]  حُذف الفهرس 1، أي القيمة 20
nums.remove(Integer.valueOf(10));   // → [30]  حُذفت القيمة 10
```

- **الحذف أثناء المرور بـ for-each:** يرمي `ConcurrentModificationException`. استخدم `removeIf`:

```java
names.removeIf(name -> name.startsWith("س"));
```

- **فهرس خارج القائمة:** `names.get(names.size())` يرمي `IndexOutOfBoundsException`، لأن آخر فهرس هو `size() - 1`.

## HashMap — مفتاح وقيمة

```java
import java.util.HashMap;

HashMap<String, Integer> ages = new HashMap<>();
ages.put("براء", 25);
ages.put("سارة", 22);
ages.get("براء");          // 25
ages.containsKey("علي");   // false
ages.remove("سارة");
```

المرور:

```java
for (String key : ages.keySet()) {
  System.out.println(key + " = " + ages.get(key));
}
```

## HashSet — قيم فريدة

```java
import java.util.HashSet;

HashSet<String> cities = new HashSet<>();
cities.add("الرياض");
cities.add("الرياض");   // يُتجاهل التكرار
cities.size();           // 1
```

## أيّها أختار؟

| الحاجة | الصنف |
|--------|-------|
| قائمة مرتّبة بفهارس | `ArrayList` |
| ربط مفتاح بقيمة | `HashMap` |
| قيم فريدة بلا تكرار | `HashSet` |
