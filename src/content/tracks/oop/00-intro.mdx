## ما هي OOP؟

**البرمجة كائنية التوجّه (OOP)** أسلوب لتنظيم الكود حول **كائنات (Objects)**
تجمع البيانات والسلوك معًا، بدل دوال منفصلة عن البيانات.

> هذه المفاهيم مشتركة بين Java و Python و C++ و C# و JavaScript وغيرها —
> تعلّمها مرة، طبّقها في أي لغة.

## الصنف والكائن (Class & Object)

- **الصنف (Class):** قالب أو مخطّط (مثل مخطّط منزل).
- **الكائن (Object):** نسخة فعلية من القالب (المنزل المبني).

```python
class Car:
    def __init__(self, brand):
        self.brand = brand

    def drive(self):
        print(f"{self.brand} تسير")

my_car = Car("Toyota")   # كائن
my_car.drive()
```

## لماذا OOP؟

- **تنظيم:** كود مرتّب يعكس الواقع.
- **إعادة استخدام:** عبر الوراثة.
- **صيانة أسهل:** تعديل في مكان واحد.
- **قابلية التوسّع:** مناسبة للمشاريع الكبيرة.

## الركائز الأربع (لمحة سريعة)

- **التغليف (Encapsulation):** إخفاء التفاصيل الداخلية.
- **الوراثة (Inheritance):** اشتقاق صنف من آخر.
- **تعدّد الأشكال (Polymorphism):** سلوك مختلف لنفس الاستدعاء.
- **التجريد (Abstraction):** التركيز على "ماذا" بدل "كيف".

سنفصّل كلًّا منها في الدروس القادمة.

## البرمجة الإجرائية مقابل الكائنية

| | إجرائية | كائنية |
|---|---------|--------|
| التنظيم | حول الدوال | حول الكائنات |
| البيانات | منفصلة | مدمجة مع السلوك |
| المشاريع الكبيرة | تصبح فوضوية | منظّمة |

## أسئلة شائعة

**هل OOP مرتبطة بلغة معيّنة؟**
لا، هي **أسلوب تفكير** تدعمه معظم اللغات الحديثة، فتتعلّمه مرة وتطبّقه في أيّها.

**متى أستخدم OOP؟**
خاصة في المشاريع المتوسّطة والكبيرة، حيث يساعد التنظيم الكائني على الصيانة
والتوسّع.
