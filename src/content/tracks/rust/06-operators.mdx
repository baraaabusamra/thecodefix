## الحسابية

```rust
let sum = 10 + 3;     // 13
let diff = 10 - 3;    // 7
let prod = 10 * 3;    // 30
let quot = 10 / 3;    // 3 (قسمة صحيحة)
let rem = 10 % 3;     // 1
```

## المقارنة

`==`، `!=`، `>`، `<`، `>=`، `<=` — تعيد `bool`.

## المنطقية

```rust
let a = true;
let b = false;
println!("{}", a && b);   // و
println!("{}", a || b);   // أو
println!("{}", !a);       // نفي
```

## تحويل الأنواع بـ as

Rust لا يحوّل الأنواع ضمنيًّا — استخدم `as`:

```rust
let x: i32 = 10;
let y: f64 = x as f64;
let z: u8 = 300 as u8;    // انتبه: قد يقتطع القيمة
```

> ⚠️ Rust لا يسمح بخلط الأنواع في العمليات (لا `i32 + f64` مباشرة) — حوّل أوّلًا.
