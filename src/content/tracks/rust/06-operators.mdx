## الحسابية

```rust
let sum = 10 + 3;     // 13
let diff = 10 - 3;    // 7
let prod = 10 * 3;    // 30
let quot = 10 / 3;    // 3 (قسمة صحيحة: الكسر يُحذف)
let rem = 10 % 3;     // 1
let real = 10.0 / 3.0;
println!("{sum} {diff} {prod} {quot} {rem} {real:.3}");   // ... 3.333
println!("{} {}", -7 / 2, -7 % 2);                        // -3 -1
```

القسمة الصحيحة تقتطع نحو الصفر، فالباقي يأخذ إشارة العدد الأول. وإذا أردت باقيًا موجبًا دائمًا (مثلًا لحساب يوم الأسبوع من رقم سالب) استخدم `rem_euclid`:

```rust
println!("{}", (-7_i32).rem_euclid(3));   // 2 لا -1
```

### الطرفان من نفس النوع

Rust لا تخلط الأنواع في عملية واحدة، ولا حتى `i32` مع `i64`:

```rust
let a: i32 = 5;
let b: f64 = 2.5;
// let c = a * b;          // ❌ cannot multiply `i32` by `f64`
let c = a as f64 * b;      // ✅ 12.5
println!("{c}");
```

### القسمة على صفر

القسمة الصحيحة على صفر توقف البرنامج (`panic: attempt to divide by zero`)، أما مع الكسور فالنتيجة `inf` أو `NaN` بلا توقّف. إذا كان المقسوم عليه يأتي من مدخلات، استخدم `checked_div` التي تُرجع `None`:

```rust
let total: i32 = 100;
let count: i32 = 0;
match total.checked_div(count) {
    Some(avg) => println!("المعدّل {avg}"),
    None => println!("لا يوجد عناصر"),
}
```

## الإسناد المركّب

```rust
let mut n = 5;
n += 3;   // 8
n *= 2;   // 16
n -= 1;   // 15
println!("{n}");
```

لا يوجد `++` ولا `--` في Rust. اكتب `n += 1`. قرار مقصود: يلغي ألغاز "قبل أم بعد" وتعابير مثل `i = i++`.

## المقارنة

`==` و`!=` و`<` و`>` و`<=` و`>=` تُرجع `bool`، والطرفان يجب أن يكونا من **نفس النوع**:

```rust
let x: i32 = 5;
let y: i64 = 5;
// x == y               // ❌ mismatched types
println!("{}", x as i64 == y);          // true
println!("{}", "apple" < "banana");     // true: أبجديًا
```

مقارنة النصوص بـ `==` تقارن المحتوى (لا العناوين كما في C)، وتعمل بين `String` و`&str` مباشرة.

## المنطقية

```rust
let a = true;
let b = false;
println!("{}", a && b);   // false: و
println!("{}", a || b);   // true: أو
println!("{}", !a);       // false: نفي
```

`&&` و`||` تختصران التقييم: لا يُقيَّم الطرف الثاني إذا حُسمت النتيجة. والشرط في `if` يجب أن يكون `bool` حقيقيًا؛ `if count` لعدد خطأ ترجمة.

## عوامل البت

`&` و`|` و`^` و`!` (قلب البتّات للأعداد) و`<<` و`>>`. مثال سريع لفحص الزوجية: `n & 1 == 0`. انتبه هنا: في Rust أولوية `&` أعلى من `==`، فهذا يعمل كما تتوقّع، عكس C.

## تحويل الأنواع: as و From/TryFrom

```rust
let x: i32 = 10;
let y: f64 = x as f64;     // 10.0
let z = 300_i32 as u8;     // 44: يقتطع البتّات العليا بصمت!
let w = 3.99_f64 as i32;   // 3: يحذف الكسر (لا تقريب)
let n = -1_i32 as u32;     // 4294967295
println!("{y} {z} {w} {n}");
```

`as` لا تفشل أبدًا، وهذا بالضبط خطرها: التحويل لنوع أصغر يعطي نتيجة "خاطئة" بلا أي تحذير. للتحويلات الآمنة استخدم:

```rust
let small: u8 = 200;
let big: i32 = small.into();                 // ✅ From: آمن دائمًا (من أصغر لأكبر)

let value: i32 = 300;
let r: Result<u8, _> = u8::try_from(value);  // ✅ TryFrom: يفشل بوضوح
println!("{big} {:?}", r);                   // 200 Err(TryFromIntError(PosOverflow))
```

القاعدة: `into()` حين يكون التحويل مضمونًا، و`try_from` حين قد لا تتّسع القيمة، و`as` للحالات التي تعرف فيها السلوك بالضبط (مثل `f64` إلى `i32` مع حذف الكسر عمدًا).

## أخطاء شائعة

- **`i++`:** غير موجود؛ اكتب `i += 1`.
- **خلط `i32` و`f64` أو `i32` و`usize`:** حوّل صراحة.
- **`as u8` لقيمة قد تكون كبيرة:** تقتطع بصمت؛ استخدم `u8::try_from`.
- **القسمة على متغيّر قد يكون صفرًا:** `panic`؛ استخدم `checked_div`.
- **`%` لإيجاد الدورة مع الأعداد السالبة:** استخدم `rem_euclid`.
