## ما هي Rust؟

**Rust** لغة برمجة حديثة تجمع بين **سرعة C++ وأمان الذاكرة** دون كانس مهملات
(garbage collector). تُصنَّف سنويًا كأكثر لغة محبوبة بين المطوّرين.

سرّ تميّزها هو نظام **الملكية (Ownership)** الذي يتحقّق من صحّة التعامل مع
الذاكرة **وقت الترجمة**، فيمنع فئة كاملة من الأخطاء قبل أن يعمل البرنامج أصلًا.

## لماذا Rust؟

- **آمنة للذاكرة:** تمنع أخطاء الذاكرة الشائعة وقت الترجمة.
- **سريعة:** أداء يضاهي C/C++.
- تُستخدم في الأنظمة، الويب (WebAssembly)، والأدوات عالية الأداء.

## أين تُستخدم Rust؟

- **أنظمة التشغيل والمتصفّحات:** أجزاء من Firefox و Windows.
- **أدوات المطوّرين:** أدوات بناء وحزم عالية الأداء.
- **WebAssembly:** تشغيل كود سريع داخل المتصفّح.

## أول برنامج

```rust
fn main() {
    println!("مرحبًا من Rust!");
}
```

- `fn main()` نقطة البداية.
- `println!` ماكرو للطباعة (لاحظ علامة `!`).

## التشغيل

```bash
cargo run        # عبر مدير الحزم cargo
```

`cargo` أداة Rust لإدارة المشاريع والحزم والبناء.

## متغيّر ثابت افتراضيًا

```rust
let name = "براء";       // ثابت افتراضيًا
let mut age = 25;        // متغيّر (mutable)
age = 26;
```

في Rust القيم **ثابتة افتراضيًا**، وتضيف `mut` صراحةً عندما تريد تغييرها.

## فلسفة Rust

> "إن تُرجم البرنامج، فغالبًا سيعمل بشكل صحيح." — مترجم Rust صارم لكنه يحميك
> من فئة كاملة من الأخطاء قبل التشغيل.

## أسئلة شائعة

**هل Rust صعبة؟**
منحنى تعلّمها أحدّ بسبب مفهوم الملكية، لكن هذا الصرامة نفسها تمنحك برامج آمنة
وموثوقة.

**متى أختار Rust؟**
عندما تحتاج أداء C++ مع ضمانات أمان أعلى، خاصة في الأنظمة والأدوات الحسّاسة.

> 🎯 التالي: المتغيّرات والملكية (Ownership).
