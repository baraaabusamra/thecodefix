## ما هي Rust؟

**Rust** لغة برمجة حديثة تجمع بين **سرعة C++ وأمان الذاكرة** دون كانس مهملات
(garbage collector). تُصنَّف سنويًا كأكثر لغة محبوبة بين المطوّرين.

## لماذا Rust؟

- **آمنة للذاكرة:** تمنع أخطاء الذاكرة الشائعة وقت الترجمة.
- **سريعة:** أداء يضاهي C/C++.
- تُستخدم في الأنظمة، الويب (WebAssembly)، والأدوات عالية الأداء.

## أول برنامج

```rust
fn main() {
    println!("مرحبًا من Rust!");
}
```

- `fn main()` نقطة البداية.
- `println!` ماكرو للطباعة (لاحظ علامة `!`).

## التشغيل

```bash
cargo run        # عبر مدير الحزم cargo
```

`cargo` أداة Rust لإدارة المشاريع والحزم والبناء.

## فلسفة Rust

> "إن تُرجم البرنامج، فغالبًا سيعمل بشكل صحيح." — مترجم Rust صارم لكنه يحميك
> من فئة كاملة من الأخطاء قبل التشغيل.
