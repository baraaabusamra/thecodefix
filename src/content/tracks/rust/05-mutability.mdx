## المتغيّرات ثابتة افتراضيًا

```rust
let x = 5;
// x = 6;        // ❌ cannot assign twice to immutable variable `x`
let mut y = 5;
y = 6;           // ✅ بفضل mut
println!("{x} {y}");
```

في معظم اللغات المتغيّر قابل للتغيير ما لم تقل غير ذلك. Rust تعكس القاعدة: `let` وحدها تعني "لن تتغيّر"، و`mut` تقول صراحة "هذه ستتغيّر". الفائدة عملية جدًّا:

- حين تقرأ كودًا وترى `let`، تعرف أن القيمة لن تتغيّر في أي سطر لاحق، فتتتبّع منطقًا أقل.
- المترجم يحذّرك إذا كتبت `mut` ولم تعدّل المتغيّر فعلًا (`variable does not need to be mutable`).
- قواعد الاستعارة لاحقًا تعتمد على هذا التمييز: لا يمكن أخذ مرجع للتعديل (`&mut`) إلا من متغيّر `mut`.

## التعريف بلا قيمة ابتدائية

```rust
let status;            // بلا قيمة الآن
let score = 75;
if score >= 60 {
    status = "ناجح";   // يُسند مرة واحدة فقط
} else {
    status = "راسب";
}
println!("{status}");
```

متغيّر بلا `mut` يمكن إسناده **مرة واحدة** لاحقًا، والمترجم يتأكّد أنه أُسند في كل المسارات قبل قراءته. لا قيم عشوائية كما في C، ولا `null`.

## الثوابت: const

```rust
const MAX_POINTS: u32 = 100_000;
const SECONDS_PER_DAY: u64 = 24 * 60 * 60;

fn main() {
    println!("{MAX_POINTS} {SECONDS_PER_DAY}");
}
```

الفرق بين `const` و`let`:

| | `let` | `const` |
| --- | --- | --- |
| النوع | يُستنتج غالبًا | **إلزامي** |
| القيمة | أي قيمة، حتى نتيجة تُحسب أثناء التشغيل | تُحسب وقت الترجمة فقط |
| المكان | داخل الدوال | أي مكان، حتى على مستوى الملف |
| التسمية | `snake_case` | `SCREAMING_SNAKE_CASE` |

استخدم `const` للقيم المعروفة مسبقًا والمشتركة في البرنامج (حدود، ونسب، وأحجام).

## التظليل (Shadowing)

تعريف متغيّر **جديد** بنفس اسم متغيّر سابق، بكلمة `let` مرة أخرى:

```rust
let input = "  42  ";
let input = input.trim();                  // &str بلا مسافات
let input: i32 = input.parse().unwrap();   // الآن رقم
println!("{}", input + 1);                 // 43
```

بدل ثلاثة أسماء (`input_raw` و`input_trimmed` و`input_number`)، اسم واحد يمرّ بمراحل تحويل. كل `let` تُنشئ متغيّرًا جديدًا تمامًا، بنوع جديد إن أردت، والقديم لم يعد يمكن الوصول إليه.

### التظليل داخل كتلة مؤقت

```rust
let x = 5;
{
    let x = x * 2;
    println!("داخل الكتلة: {x}");   // 10
}
println!("خارجها: {x}");            // 5
```

## mut أم التظليل؟

```rust
let mut count = 0;
count += 1;            // ✅ mut: نفس المتغيّر، نفس النوع

let spaces = "   ";
let spaces = spaces.len();   // ✅ تظليل: نوع جديد (من &str إلى usize)

let mut text = "   ";
// text = text.len();  // ❌ mismatched types: mut لا يغيّر النوع
```

- **`mut`:** المتغيّر نفسه يتغيّر عبر الزمن، ونوعه ثابت. للعدّادات والمجمِّعات والحالة.
- **التظليل:** سلسلة تحويلات، كل خطوة قيمة جديدة قد تكون بنوع مختلف، والنتيجة النهائية غير قابلة للتغيير.

## أخطاء شائعة

- **نسيان `mut`** ثم تعديل المتغيّر: الرسالة تقترح الحل (`help: consider making this binding mutable`).
- **إضافة `mut` لكل متغيّر "احتياطًا":** تخسر الضمان، والمترجم يحذّرك من غير الضروري منها.
- **`const` بلا نوع:** `const MAX = 10;` خطأ؛ النوع إلزامي.
- **محاولة تغيير النوع بـ `mut`:** استخدم التظليل.
- **التظليل غير المقصود في كتلة:** `let x = ...` داخل `if` تنشئ متغيّرًا جديدًا يختفي بنهاية الكتلة؛ إذا أردت تعديل الخارجي اجعله `mut` واكتب `x = ...`.
