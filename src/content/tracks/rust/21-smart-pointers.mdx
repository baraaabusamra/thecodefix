## ما هو المؤشّر "الذكي"؟

المرجع `&T` يستعير فقط. المؤشّر الذكي **يملك** البيانات التي يشير إليها، ويضيف سلوكًا: مكان تخزين مختلف، أو عدّ مالكين، أو فحص قواعد أثناء التشغيل. وحين ينتهي يحرّر ما يملكه تلقائيًا. `String` و`Vec` نفسيهما مؤشّران ذكيان.

## `Box<T>`: قيمة على الكومة

```rust
let b = Box::new(5);
println!("{}", *b + 1);    // 6: استخدمه كأنه القيمة نفسها
```

`Box` يضع القيمة على الكومة ويبقي على المكدّس مؤشّرًا فقط. لن تحتاجه لعدد صغير، بل في ثلاث حالات:

### 1. الأنواع التعاودية

نوع يحتوي نفسه يكون حجمه لا نهائيًا، فلا يستطيع المترجم حسابه:

```rust
#[derive(Debug)]
enum List {
    Cons(i32, Box<List>),   // Box حجمه ثابت (مؤشّر) مهما كان ما بداخله
    Nil,
}

use List::{Cons, Nil};

fn sum(l: &List) -> i32 {
    match l {
        Cons(v, rest) => v + sum(rest),
        Nil => 0,
    }
}

fn main() {
    let list = Cons(1, Box::new(Cons(2, Box::new(Cons(3, Box::new(Nil))))));
    println!("{}", sum(&list));   // 6
}
```

بدون `Box` يرفض المترجم: `recursive type List has infinite size`. وهكذا تُبنى الأشجار والقوائم المترابطة.

### 2. أنواع مختلفة خلف سمة واحدة

`Vec<Box<dyn Shape>>` قائمة تخلط دوائر ومربّعات معًا ([درس الكائنات السمة](/learn/rust/24-trait-objects)).

### 3. نقل بيانات كبيرة بلا نسخ

نقل `Box` ينسخ المؤشّر فقط (8 بايتات)، لا البيانات.

## `Rc<T>`: عدّة مالكين

قاعدة الملكية تقول مالك واحد. لكن أحيانًا تحتاج عدّة أجزاء من البرنامج أن تملك **نفس** البيانات، ولا تعرف أيّها ينتهي آخرًا (عقدة في رسم بياني يشير إليها كثيرون مثلًا). `Rc` (Reference Counted) يعدّ المالكين ويحرّر البيانات حين يصل العدد للصفر:

```rust
use std::rc::Rc;

let config = Rc::new(String::from("prod"));
let service_a = Rc::clone(&config);       // لا ينسخ النص: يزيد العدّاد
let service_b = Rc::clone(&config);
println!("{}", Rc::strong_count(&config)); // 3
drop(service_a);
println!("{}", Rc::strong_count(&config)); // 2
println!("{service_b}");
```

`Rc::clone` رخيصة جدًّا: تزيد عدّادًا فقط. والاصطلاح كتابتها `Rc::clone(&x)` لا `x.clone()`، لتوضح للقارئ أنها ليست نسخًا عميقًا.

قيدان: `Rc` يعطي **قراءة فقط**، ويعمل في **خيط واحد**. لعدّة خيوط استخدم `Arc` (درس التزامن).

## `RefCell<T>`: التعديل عبر مرجع للقراءة

المستعير يفحص "كاتب واحد أو قرّاء كثيرون" **وقت الترجمة**. أحيانًا يكون الكود صحيحًا لكن المترجم لا يستطيع إثباته. `RefCell` ينقل الفحص إلى **وقت التشغيل**:

```rust
use std::cell::RefCell;

let data = RefCell::new(vec![1, 2]);
data.borrow_mut().push(3);               // استعارة للتعديل، تنتهي فورًا
println!("{:?}", data.borrow());         // [1, 2, 3]

let r1 = data.borrow();
// let w = data.borrow_mut();            // ❌ panic: RefCell already borrowed
println!("{}", r1.len());
```

القاعدة نفسها، لكن كسرها يسبّب `panic` بدل خطأ ترجمة. لذلك استخدمه فقط حين تحتاجه فعلًا، وأبقِ الاستعارات قصيرة.

## التركيبة الشائعة: `Rc<RefCell<T>>`

عدّة مالكين **وكلّهم** يعدّلون:

```rust
use std::cell::RefCell;
use std::rc::Rc;

#[derive(Debug)]
struct Account {
    balance: i32,
}

fn main() {
    let shared = Rc::new(RefCell::new(Account { balance: 100 }));
    let atm = Rc::clone(&shared);
    let app = Rc::clone(&shared);

    atm.borrow_mut().balance -= 30;
    app.borrow_mut().balance += 50;
    println!("{:?}", shared.borrow());   // Account { balance: 120 }
}
```

## أيّها أختار؟

| تحتاج | استخدم |
| --- | --- |
| مالك واحد، البيانات على الكومة | `Box<T>` |
| عدّة مالكين للقراءة، خيط واحد | `Rc<T>` |
| تعديل داخلي يفحصه وقت التشغيل | `RefCell<T>` |
| عدّة مالكين يعدّلون، خيط واحد | `Rc<RefCell<T>>` |
| عدّة مالكين عبر خيوط | `Arc<Mutex<T>>` |

ابدأ دائمًا بالملكية العادية والمراجع. إذا وجدت نفسك تضع `Rc<RefCell<...>>` في كل مكان، فالتصميم غالبًا يحتاج إعادة تفكير.

## أخطاء شائعة

- **دورة مراجع بـ `Rc`:** عقدتان يملك كلٌّ منهما الأخرى لا تصلان للصفر أبدًا: تسرّب. استخدم `Weak` لأحد الاتجاهين (مثلًا من الابن للأب).
- **استعارة `RefCell` طويلة ثم استعارة أخرى:** `panic: RefCell already borrowed`. أنهِ الاستعارة قبل التالية.
- **`Rc` مع الخيوط:** خطأ ترجمة (`Rc cannot be sent between threads safely`)؛ استخدم `Arc`.
- **`Box` لكل شيء:** القيم العادية على المكدّس أسرع؛ `Box` للحالات الثلاث أعلاه.
- **`x.clone()` على `Rc` في كود يقرؤه غيرك:** اكتب `Rc::clone(&x)` ليتضح أنها رخيصة.

> 🎯 التالي: التزامن (Concurrency).
