## ما هي قاعدة البيانات؟

**قاعدة البيانات (Database)** مكان منظّم لتخزين البيانات واسترجاعها بكفاءة.
بدلًا من ملفات نصّية فوضوية، نخزّن البيانات في **جداول** مرتّبة.

## ما هي SQL؟

**SQL** (Structured Query Language) هي اللغة التي **نتحدّث بها مع قواعد
البيانات**: نضيف، نقرأ، نعدّل، ونحذف البيانات.

> SQL مهارة أساسية لأي مطوّر — واجهة أمامية أو خلفية أو تحليل بيانات.

## الجداول والصفوف والأعمدة

تخيّل جدول `users`:

| id | name | email | age |
|----|------|-------|-----|
| 1 | براء | baraa@mail.com | 25 |
| 2 | سارة | sara@mail.com | 22 |

- **العمود (Column):** حقل مثل `name`.
- **الصف (Row):** سجلّ واحد (مستخدم كامل).

## أشهر قواعد البيانات

| القاعدة | ملاحظة |
|---------|--------|
| MySQL | الأشهر، مفتوح المصدر |
| PostgreSQL | قوي ومتقدّم |
| SQLite | خفيف، ملف واحد |
| SQL Server | من مايكروسوفت |

كلها تستخدم لغة SQL بنفس الأساسيات.

## أول استعلام

```sql
SELECT * FROM users;
```

هذا يجلب **كل** الصفوف من جدول `users`. النجمة `*` تعني "كل الأعمدة".

> 🎯 التالي: استرجاع البيانات بـ SELECT.
