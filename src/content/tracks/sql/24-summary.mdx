## أحسنت! أكملت مسار SQL كاملًا

من أول `SELECT` إلى تصميم قواعد بيانات آمنة وسريعة — إليك خريطة ما أتقنته.

## ما تعلّمته

- **الأساسيات:** SELECT و WHERE و ORDER BY و LIMIT و DISTINCT.
- **تعديل البيانات:** INSERT و UPDATE و DELETE.
- **التعامل مع NULL** ودوال النصوص والأعداد والتاريخ.
- **الجداول:** CREATE و ALTER و DROP وأنواع البيانات والقيود.
- **المفاتيح والعلاقات:** PRIMARY و FOREIGN KEY والعلاقات 1:N و N:M.
- **الربط:** INNER و LEFT و RIGHT و FULL و SELF و CROSS JOIN و UNION.
- **الاستعلامات المتقدّمة:** Subqueries و CASE و GROUP BY و HAVING.
- **الاحتراف:** Views و Indexes و Transactions و Procedures و Triggers.
- **التصميم والأمان:** التطبيع، حقن SQL والوقاية منه، الصلاحيات، الأداء.
- **تحسين الأداء (جديد):** فهرسة B-Tree، الفهارس الجزئية والغلافية، تحسين الاستعلامات، تحليل EXPLAIN و Slow Query Log.
- **استعلامات متقدّمة (جديد):** جداول مؤقتة بـ WITH وWITH RECURSIVE، دوال النافذة Window Functions، وUPSERT لإدراج أو تحديث ذرّي.

## خطوتك القادمة

- **طبّق:** صمّم قاعدة بيانات لمشروع حقيقي (متجر، مدوّنة).
- **اربطها ببرنامجك:** تعلّم استخدام SQL من **Node.js** أو **PHP** أو **Python**.
- **تعمّق:** اطّلع على حزمة تحسين أداء SQL والاستعلامات المتقدّمة (الدروس 25-31) لضبط استعلاماتك في الإنتاج.
- **وسّع آفاقك:** اكتشف قواعد البيانات غير العلائقية مثل **MongoDB**.
