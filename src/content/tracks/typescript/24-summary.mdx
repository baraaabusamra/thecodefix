## مبروك! 🎉

أتممت مسار **TypeScript من الصفر إلى الاحتراف** — المهارة التي تفصل
المطوّر الهاوي عن المحترف في عالم JavaScript الحديث.

## ما تعلّمته

- **الأساسيات:** الأنواع البسيطة، الاستنتاج مقابل التحديد، الأنواع
  الخاصّة، null.
- **هياكل البيانات:** المصفوفات، الصفوف، أنواع الكائنات، التعدادات،
  الأنواع الحرفية.
- **التنظيم:** type مقابل interface، التحويل، الأصناف ومُعدِّلات الوصول.
- **القوّة:** الأنواع العامّة (Generics)، الأنواع المساعدة، keyof.
- **الاحتراف:** حُرّاس الأنواع، الأنواع المتقدّمة (الشرطية والمُعيَّنة)،
  async، المُزخرِفات.
- **العملي:** TypeScript مع Node.js، معالجة الأخطاء، الترحيل وأفضل
  الممارسات.

## القاعدة التي تلخّص TypeScript

> **TypeScript هو JavaScript بأمان.** يكتشف الأخطاء وأنت تكتب لا وقت
> التشغيل. أتقن `strict` والأنواع العامّة وتنميط حدود النظام، فتلك 80% من
> فائدته اليومية.

## نصائح ذهبية

- **فعّل `strict` وتجنّب `any`** — هذه هي اللعبة كلّها.
- **اقرأ أنواع المكتبات** — مهارة لا تقدّر بثمن لفهم أي أداة بسرعة.
- **نمّط حدود نظامك** (API، النماذج، التخزين) أولًا — أكبر عائد على الجهد.
- **استخدم TypeScript في مشروع حقيقي** — مع React أو Node لترى قيمته فعلًا.

## خطوتك التالية

```text
JavaScript → TypeScript → React + TS / Node + TS → مطوّر محترف
```

- **React مع TypeScript** — تنميط الـ props والحالة والأحداث.
- **Node.js مع TypeScript** — خوادم وواجهات API آمنة.
- **Next.js** — يدعم TypeScript جاهزًا (مثل هذا الموقع!).
- **NestJS** — إطار خلفي مبني على TypeScript بالكامل.
