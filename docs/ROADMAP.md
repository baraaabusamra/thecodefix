# 🚀 The Code Fix — الخطة الكبرى (Master Roadmap)

> إلى أين يتّجه المشروع: المراحل، الميزات القادمة، اللغات والمواضيع الجديدة،
> البنية التحتية، الربح، والسياق العالمي. مرتّبة بالأولوية — لا تنفّذ مرحلتين معًا.
> آخر تحديث: **2026-07-03**. (توثيق ما هو مبنيّ في [PROJECT.md](PROJECT.md))

---

## 🧭 البوصلة

**الرؤية:** أن يكون The Code Fix **الوجهة الأولى** لكل متعلّم برمجة عربي —
كما W3Schools للعالم، لكن أحدث وأجمل وتفاعلي وبالعربي.

**الوضع الآن:** المنتج الهندسي **مكتمل** (768 درسًا، محرّر، شهادات، إدارة).
عنق الزجاجة = **الزوّار**، وليس الميزات. لذلك الترتيب أدناه يقدّم النموّ على البناء.

**قاعدة ذهبية:** لا نبني ميزة جديدة كبيرة إلا إذا خدمت أحد ثلاثة:
(1) زوّار أكثر، (2) بقاء أطول للزائر، (3) دخل. أي شيء آخر = تأجيل.

## المرحلة 1 — يوليو/أغسطس: محرّك النمو العضوي (SEO) 📈

**الهدف: من ~0 إلى مئات الزيارات العضوية يوميًا.** أفضل استثمار للجهد حاليًا.

1. **دفعة E-E-A-T** (أضعف نقطة = أقوى عامل):
   - تواريخ ظاهرة "نُشر/آخر تحديث" على الدروس والمقالات + `dateModified` في schema.
   - صناديق "باختصار" (TLDR) أعلى مقالات المقارنة والأخطاء.
   - جدول المحتويات "على هذه الصفحة" للجوال (حاليًا شاشات xl فقط).
   - صور أصلية (سكرين-شوت مخرجات + دياغرامات) للصفحات المحورية.
2. **توسعة عنقود الأخطاء** — أفضل رهان مكتوب/منخفض المنافسة. المقالات القادمة:
   `IndexError/KeyError بايثون` · `NullPointerException جافا` · `fatal: not a git repository` ·
   `Merge conflict حلّه` · `Hydration error React` · `useEffect حلقة لانهائية` ·
   `Permission denied لينكس` · `MySQL Access denied` · `Docker port already allocated` ·
   `pip install يفشل` · `SyntaxError بايثون` · `undefined vs null`.
3. **صفحات محورية (Pillars):** إغناء صفحة كل مسار `/learn/<tech>` لتجمع دروسه
   + مقالاته + خريطته + اختباره بروابط وصفية (لا "التالي" فقط).
4. **تحسين مبني على البيانات:** كل أسبوعين من GSC — الصفحات في مركز 5–20 تُحسَّن
   (عنوان/إغناء/روابط) قبل كتابة أي محتوى جديد.
5. **باك-لينكس أولية:** إجابات مفيدة في مجموعات المطورين العرب + عرض المنصّة على
   صفحات موارد الجامعات والبوتكامبات العربية.

**مقياس النجاح:** >60% من الصفحات مفهرسة، >100 نقرة عضوية/يوم بنهاية أغسطس.

## المرحلة 2 — سبتمبر/أكتوبر: البقاء والرجوع (Retention) 🔁

**الهدف: الزائر يعود.** الآن فقط تستحق الميزات الجديدة البناء:

1. **تمارين تفاعلية لكل درس** ⭐ (الفجوة الأكبر مقارنة بـ W3Schools):
   "جرّب بنفسك" + تمرين بمُدقّق تلقائي (للبايثون والجافاسكريبت عبر المحرّر
   الموجود — تحقّق من المخرجات). يبدأ بالمسارات الخمسة الكبرى.
2. **نظام نقاط وإنجازات (Gamification):** نقاط لكل درس/اختبار، شارات
   (أنهيت HTML 🏅، 7 أيام متتالية 🔥)، سلسلة أيام (streak) — كلها فوق
   `user_progress` الموجود.
3. **نشرة بريدية أسبوعية** ("درس الأسبوع + مقال + وظيفة"): جمع الإيميلات من
   الموقع + إرسال عبر Resend — أصل توزيع تملكه لا تتحكم فيه خوارزمية.
4. **مشاركة الشهادة على LinkedIn** بضغطة (صفحة شهادة علنية بـ OG جميلة) —
   تسويق مجاني ذاتي التوليد.
5. **مجتمع** (الأسهل أولًا): قناة Telegram/Discord مرتبطة من الموقع؛
   أسئلة/تعليقات على الدروس لاحقًا (عبء إشراف — لا تستعجل).

## المرحلة 3 — نوفمبر/ديسمبر: التوسّع الذكي 🤖

1. **مساعد ذكاء اصطناعي للمتعلّم** ⭐ (ميزة العصر):
   - "اشرح هذا الخطأ" — زر في المحرّر يرسل الكود + الخطأ لنموذج AI ويشرح بالعربي.
   - "لماذا لا يعمل كودي؟" داخل دروس بايثون/JS.
   - البنية: Vercel AI Gateway (مزوّدون متعددون، حدود إنفاق) + حدود استخدام
     للمجاني — وهذه أول ميزة **Pro** منطقية.
2. **صفحات مرجعية (Reference) — SEO برمجي:** مرجع وسوم HTML، دوال Python/JS،
   خصائص CSS، أوامر Git/Linux/SQL… آلاف الصفحات long-tail (تخطّيناها عمدًا
   سابقًا — الآن وقتها). قالب واحد + بيانات JSON.
3. **قسم مشاريع تطبيقية:** "ابنِ معك خطوة بخطوة" (موقع شخصي، To-Do بـ React،
   API بـ Node، بوت تيليجرام بايثون…) — أعلى طلب من المتعلّمين العرب بعد الأساسيات.
4. **ترقية البحث:** بحث فوري أفضل (المحتوى نما عن قدرة البحث الحالي).

## 🌍 السياق العالمي والسوق

- **المنافسون العرب:** أكاديمية حسوب (مقالات قوية)، الزيرو Elzero (يوتيوب ضخم)،
  إدراك/سطر (مؤسسي)، برمج (تفاعلي). **تمايزنا:** الوحيد الذي يجمع
  "شامل + تفاعلي في المتصفّح + شهادات تحقّق + مجاني + حديث البنية" في مكان واحد.
- **الاتجاه العالمي 2026:** التعلّم بمساعدة AI أصبح متوقّعًا (مرحلة 3 ليست رفاهية)؛
  الطلب يتحوّل نحو مهارات AI + Cloud — لذلك هي أول المسارات الجديدة.
- **الفرصة الديموغرافية:** المحتوى التعليمي العربي الجادّ أقل بكثير من حجم
  الجمهور (400+ مليون ناطق، متوسط أعمار صغير، إقبال متسارع على التقنية).
- **المخاطر:** (1) دقة المحتوى المولَّد — عيّن مراجعات عشوائية دورية؛
  (2) تحديثات Google ضد المحتوى الآلي — الحل E-E-A-T + أصالة؛
  (3) طاقة مؤسس واحد — الالتزام بمرحلة واحدة في كل مرة؛
  (4) نسخ المنافسين — سرعة التنفيذ هي الخندق.
