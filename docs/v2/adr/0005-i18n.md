# ADR 0005 — اللغات

- **الحالة:** مقترح — المرحلة 1 منفّذة
- **التاريخ:** 2026-10-16

## السياق

كل روابط الموقع الحالية عربية وبدون بادئة (`/learn/python/01-variables`) ومفهرسة بجوجل. أي لغة جديدة لازم ما تمس هاي الروابط.

## القرار

- **العربية افتراضية وبدون بادئة للأبد.** أي لغة ثانية ببادئتها: `/en/learn/…`.
- جدول اللغات بمكان واحد: `@tcf/content/i18n` (`LOCALES`: الاسم، الاتجاه rtl/ltr، `htmlLang`، البادئة، `enabled`).

| المرحلة | شو بتشمل | الحالة |
|---|---|---|
| 1. المحتوى | `content/<locale>/…`، `contentDir(collection, locale)`، جدول اللغات | ✅ منفّذة |
| 2. المسارات | `apps/web/src/app/en/…` (أو `[locale]` مع Proxy يعيد كتابة الروابط العربية داخليًا)، `hreflang` بين النسختين، sitemap لكل لغة | ⏳ |
| 3. نصوص الواجهة | استخراج النصوص المكتوبة بالكود لقواميس (`packages/i18n` بـ `npm run new-module i18n … --foundation`) | ⏳ |

- المرحلة 2 بتبدأ بلغة وحدة ومسار واحد كتجربة، مع فحص إنه ولا رابط عربي تغيّر (نفس مقارنة قائمة الـ 3,967 صفحة اللي استخدمناها بـ V2).
- محتوى اللغة الثانية بيخضع لنفس دليل المحتوى (لا ترجمة آلية حرفية — content-guidelines §14 بنسخته للغة الهدف).
