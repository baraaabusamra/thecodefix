## 2. الاشتراكات الشهرية (3 أسابيع) — ADR 0008

خطط + استحقاقات + webhook بمعاملات + `hasEntitlement()` + اختبار بيمنع ميزة مدفوعة بدون فحص.

## 3. الفيديو (أسبوعين) — ADR 0007

جداول `video_asset` و`watch_progress`، روابط موقّعة للمدفوع، أول دورة مصورة.

## 4. الموبايل (4–6 أسابيع) — ADR 0006

هوية بتوكنات، `POST /api/v1/progress`، `apps/mobile` (Expo) بيستهلك `@tcf/contracts`.

## 5. اللغة الإنجليزية (تدريجي) — ADR 0005

المرحلة 2 (مسارات `/en/…` + hreflang) بمسار واحد تجريبي، ثم المرحلة 3 (قواميس الواجهة).

## 6. الجامعات — ADR 0009

مؤسسات بنوع `university`، أدوار مؤسسية، مقاعد كاستحقاقات، لوحة جامعة.
