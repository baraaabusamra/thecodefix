## نقاط لازم تنحسم قبل الإطلاق الكبير

1. **CSP بوضع Report-Only** (`apps/web/next.config.ts`): بيسجّل المخالفات بدون منعها، و`script-src` فيه `'unsafe-inline'` و`'unsafe-eval'`. الخطة: مراجعة تقارير `/api/csp-report`، ثم nonce للسكربتات الـ inline، و`'wasm-unsafe-eval'` بس لملعب Python، ثم تفعيل `Content-Security-Policy`.
2. **Rate limit بالذاكرة** (`@tcf/core/rate-limit`): لكل instance وبينمسح مع كل cold start. كافي هلأ؛ مع الـ API العام للموبايل والاشتراكات: Upstash Redis خلف نفس الدالة `rateLimit()` (ما بتتغير واجهتها).
3. **الكتابات غير الذرّية** (ADR 0004): `withTransaction` جاهز؛ التبنّي يبدأ بالاشتراكات.
4. **هوية الموبايل** (ADR 0006): توكنات قصيرة العمر قبل أي endpoint بيكتب.
