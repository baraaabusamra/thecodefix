# حوكمة البيانات الوقائعية — الجامعات والوظائف والمناهج

> **هذا الملف يُقرأ فقط عند العمل على**: قسم الجامعات
> (`src/content/academic-universities/`, `src/content/academic-study-plans/`)،
> نظام استخراج المناهج (`src/lib/curriculum/`)، أو قسم الوظائف (`/jobs`).
> **ما يُحمَّل تلقائيًا بكل جلسة** — على عكس
> [content-guidelines.md](content-guidelines.md) (يحكم المحتوى التحريري:
> دروس/مقالات/مرجع) و[seo-technical-policy.md](seo-technical-policy.md).

**ليش ملف منفصل؟** المحتوى التحريري (درس، مقال) سؤاله "هل يستاهل يُنشر؟".
البيانات الوقائعية (جامعة X بتطلب كم ساعة معتمدة؟) سؤالها مختلف جذريًا:
**"هل هذا صحيح، ومن مين مصدره؟"** — هذا الملف يجاوب على السؤال التاني.

معظم القواعد هون **موصوفة أصلًا بالـschema الفعلي** (`src/db/schema.ts`،
جداول `pipeline_*`) — مو اقتراح نظري، توثيق لبنية موجودة.

---

## 1) هرم أولوية المصادر

عند وجود تعارض أو غموض، الأولوية:

1. الموقع الرسمي للجامعة/الجهة
2. الموقع الرسمي للكلية/القسم
3. الكتالوج الأكاديمي الرسمي
4. مستند خطة الدراسة/المنهج الرسمي (PDF)
5. مصدر حكومي/جهة اعتماد
6. مصدر ثانوي موثوق

**لا تستبدل مصدرًا رسميًا بمصدر أضعف** بدون تبرير موثّق بحقل `notes`
(`pipelineCurriculumCourses.notes`).

## 2) الـProvenance إلزامي — وموجود أصلًا بالـschema

كل حقيقة مستخرجة (رقم ساعات معتمدة، متطلّب قبول...) **لازم تُربط بدليلها**:

| المطلوب | الجدول الفعلي |
|---|---|
| رابط المصدر + نوعه + درجة مصداقيته | `pipelineSources` (`url`, `sourceType`, `credibilityScore`) |
| المستند نفسه (PDF/HTML) | `pipelineDocuments` (`storagePath`, `contentHash`) |
| النص الدقيق المُستخرَج منه + رقم الصفحة | `pipelineExtractionEvidence` (`text`, `pageNumber`, `section`) |
| طريقة الاستخراج (أي نموذج AI ونسخة الـprompt) | `pipelineExtractionRuns` (`model`, `promptVersion`) |
| مستوى الثقة بالحقيقة المحدّدة | `pipelineCurriculumCourses.confidence` (HIGH/MEDIUM/LOW) |
| ربط كل مساق بدليله الدقيق | `pipelineCurriculumCourses.evidenceId` |

**لا تُدخل بيانة أكاديمية بدون `evidenceId`** — لو ما في دليل مستخرَج،
الحقل يبقى فارغًا (`null`)، لا تُخمَّن قيمة.

## 3) ممنوع التلفيق — بلا استثناء

ممنوع توليد أو تخمين: أسماء جامعات/برامج/مساقات غير موجودة فعليًا، أرقام
ساعات معتمدة، رسوم دراسية، متطلّبات قبول، مواعيد نهائية، إعلانات وظائف،
رواتب، تقييمات أو آراء مستخدمين. **لو المعلومة غير متوفرة: اتركها فارغة
أو اكتب "غير محدّد بالمصدر الرسمي" — لا تخترع قيمة معقولة الشكل.**

هذا القيد **أعلى من أي درجة جودة أو اكتمال** — صفحة "مكتملة" بمعلومة
ملفّقة واحدة مرفوضة، بغض النظر عن باقي محتواها.

## 4) تعارض المصادر

لو مصدرين رسميين تعارضوا على نفس الحقيقة (مثلًا 120 مقابل 132 ساعة
معتمدة):

- **لا تختر تلقائيًا** أحدهما بدون قاعدة واضحة.
- الأولوية: المصدر الأحدث (`pipelineSources.lastCheckedAt`) + الأعلى
  `credibilityScore`.
- لو التعارض غير قابل للحسم آليًا: `pipelineCurriculumVersions.status`
  يبقى `draft`، ويُحوَّل لمراجعة بشرية عبر `pipelineReviewQueue` — **لا
  يُنشر كحقيقة مؤكّدة**.

## 5) الإصدار الزمني (Versioning) — موجود أصلًا

`pipelineCurriculumVersions` مصمّم أصلًا لهذا:
`academicYear` + `version` + `status` (`draft` → `approved` → `deprecated`).
**لا تستبدل نسخة منهج قديمة بالجديدة بالحذف** — النسخة القديمة تنتقل
لـ`deprecated`، تبقى بالقاعدة. المستخدم يجب يقدر يميّز أي نسخة هو شايف.

## 6) الحدّ الأدنى لكل نوع كيان قبل النشر

| الكيان | الحدّ الأدنى المطلوب |
|---|---|
| جامعة | الاسم الرسمي، الدولة، الموقع الرسمي |
| برنامج/تخصّص | الجامعة، اسم البرنامج، الدرجة العلمية |
| مساق ضمن منهج | الاسم، البرنامج المرتبط، `evidenceId` أو تصنيف `confidence: LOW` صريح |
| وظيفة (`/jobs`) | المسمّى، الجهة، الموقع/عن بُعد، رابط التقديم، تاريخ النشر |

لو الحد الأدنى غير مكتمل: **لا يُعامَل كمحتوى نهائي منشور** — يبقى
بحالة مسودة (`pipelineReviewQueue` أو `pipelineCollectionJobs.status`).

## 7) حياة الوظائف (Jooble) — الحداثة إلزامية

وظائف منتهية الصلاحية **يجب ألا تظهر كأنها فعّالة**. عند عرض بيانات
Jooble، تحقّق من تاريخ النشر ولا تعرض قوائم قديمة بدون إشارة واضحة لعمرها.
هذا مختلف عن "صدق حقول الحداثة" بـ`seo-technical-policy.md` §13 (ذاك عن
عدم تزوير `updated`؛ هذا عن دورة حياة محتوى فعليًا مؤقّت الطبيعة).

## 8) بنية "مصدر الحقيقة" (Source of Truth)

```
pipelineSources (المصدر)
  → pipelineDocuments (المستند المحمَّل)
    → pipelineExtractionRuns (عملية الاستخراج بالذكاء الاصطناعي)
      → pipelineExtractionEvidence (الدليل النصّي الدقيق)
        → pipelineCurriculumCourses (الحقيقة النهائية + مستوى الثقة)
          → pipelineReviewQueue (بوابة المراجعة البشرية قبل النشر)
```

**الذكاء الاصطناعي لا يصبح أبدًا "مصدر الحقيقة" بنفسه** — هو أداة تحويل
من مستند مصدره معروف إلى بيانة مهيكلة، مش مصدر مستقل. أي بيانة بدون
سلسلة كاملة لهاي البنية = غير موثوقة للنشر.

## 9) لا سلطة أو خبرة مزيّفة

لا تكتب "خبير معتمد"، "معلومة موثّقة رسميًا" أو ما شابه إلا لو فعليًا
مدعومة بمصدر بالـprovenance. لا تدّعي تجربة مباشرة ("زرنا الجامعة...")
غير حقيقية.
