# دليل الكلمات المفتاحية — The Code Fix

> بحث كلمات مفتاحية شامل: كيف يبحث المجتمع العربي عن البرمجة على Google، وكيف نتصدّر النتائج.
> آخر تحديث: 2026-06-30. مصدر البيانات: Google search/autocomplete + تحليل المنافسين.

---

## 1) كيف يبحث المبرمج العربي فعليًا؟ (سلوك البحث)

افهم السلوك أولًا، ثم استهدف الكلمات:

1. **العربية هي لغة البحث الأساسية** لكن المصطلحات التقنية تُكتب إنجليزي داخل الجملة:
   مثل `شرح JavaScript`, `الفرق بين let و const`, `flexbox بالعربي`.
2. **كلمة "بالعربي" مؤهِّل ذهبي** — المستخدم يضيفها ليستبعد المحتوى الإنجليزي:
   `تعلم بايثون بالعربي`, `كورس React بالعربي`.
3. **البحث بصيغة سؤال** سائد جدًا: `ما هو`, `كيف`, `لماذا`, `هل`, `ما الفرق بين`, `من أين أبدأ`.
4. **اختلاف اللهجات** في نية البحث نفسها:
   - خليجي: `من وين أبدأ البرمجة`
   - مصري: `إزاي أتعلم برمجة`
   - مغاربي: `كيفاش نتعلم البرمجة`
   - فصحى: `كيف أتعلم البرمجة من الصفر`
5. **الترجمة الصوتية (Franco/Arabizi)** أقل في Google وأكثر في يوتيوب/تيك توك، لكنها موجودة: `ta3alom programming`.
6. **النية غالبًا تعليمية مجانية**: كلمات `مجانًا`, `من الصفر`, `للمبتدئين`, `بدون شهادة` عالية الحجم.
7. **الجوال + يوتيوب** هما المنصتان الأساسيتان → العناوين القصيرة والمحتوى المنظّم يفوز.

**المنافسون الرئيسيون (لتحليل الفجوات):** أكاديمية حسوب، أكاديمية الزيرو (Elzero)، إدراك، منصة المدرسة (Almdrasa)، برمج (Barmej)، مهارة تك، Gammal Tech، Devrabic، DevArabi.

## 10) كلمات حل الأخطاء (Debugging — فرص مدوّنة ممتازة)

نية عالية جدًا وتكرار يومي من المطورين:

- حل مشكلة {رسالة الخطأ}
- معنى خطأ `Cannot read properties of undefined`
- `CORS error` حل
- `npm install` لا يعمل
- `404` كيف أصلحه
- لماذا لا يظهر css في الصفحة؟
- الكود لا يعمل في جافاسكريبت

> الصيغة: `[رسالة الخطأ بالإنجليزية] + بالعربي/حل/معنى`. هذه كلمات long-tail ذهبية لأن المطور يلصق الخطأ حرفيًا.

## 11) صيغة الـ Long-tail البرمجية (Programmatic SEO)

ولّد آلاف الصفحات بدمج قوالب × مواضيع:

```
[ما هو | شرح | تعلم | أمثلة | تمارين | الفرق بين] + [المفهوم] + [بالعربي | من الصفر | للمبتدئين]
```

أمثلة ناتجة: `شرح الحلقات في بايثون للمبتدئين`, `أمثلة على flexbox بالعربي`,
`الفرق بين map و forEach في جافاسكريبت`, `تمارين على الدوال من الصفر`.

كل **عنوان درس** عندنا = كلمة long-tail مستقلة. الموقع فيه ~770 درسًا → ~770 صفحة long-tail جاهزة. اربط كل درس بعنوان واضح يحتوي الكلمة + `بالعربي`.

## 13) خطة التصدّر على Google (Action plan)

**جاهز ومنجز ✅**
- بنية URL واضحة، canonical لكل صفحة، sitemap (858 رابط)، robots.
- بيانات منظّمة JSON-LD: Organization، WebSite + SearchAction، BreadcrumbList، Course/LearningResource، FAQPage.
- بطاقات OG/Twitter ديناميكية لكل درس، `lang="ar" dir="rtl"`.

**التالي (الأولويات) ⏭️**
1. **عناوين الدروس** = كلمة مفتاحية + "بالعربي" (مراجعة الـ `<title>` لكل درس).
2. **مقالات المقارنة** (`الفرق بين …`) — منافسة منخفضة وحجم عالٍ.
3. **سلسلة حل الأخطاء** في المدوّنة — تجلب مطورين في لحظة الحاجة.
4. **الربط الداخلي**: كل درس يربط للمقدمة + الدرس التالي + الاختبار + خارطة الطريق.
5. **FAQ في كل مسار** بأسئلة `ما هو/كيف/هل` (Schema جاهز).
6. **سرعة النشر**: درس/مقال جديد بانتظام (Google يكافئ المحتوى الطازج).
7. **استهداف "أفضل لغة 2026" و"من أين أبدأ"** بمقال محوري (pillar) يربط كل المسارات.

- **People Also Ask** — منجم لأسئلة الـ FAQ.
- **AnswerThePublic / Keyword Tool** (يدعمان العربية).
- **Google Search Console** — أهم أداة: يكشف الكلمات التي يصلك منها زوّار فعليًا (راقبه أسبوعيًا).
