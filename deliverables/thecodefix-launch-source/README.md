# The Code Fix — launch film source

A 30-second, 1920×1080, 60 fps launch film built as a **HyperFrames** composition
(HTML + GSAP, rendered by the HyperFrames CLI 0.8.164). Everything in the film —
picture, music and sound effects — is generated from this folder.

## Layout

| Path | What it is |
|---|---|
| `index.html` | The composition: camera rig, scene DOM (incl. the lesson page rebuilt in code), styles, bundled fonts |
| `js/film.js` | Builds the single paused GSAP timeline (`window.TCF_BUILD`) — camera, thread, all six scenes |
| `timing/build-timeline.mjs` | **Shared timeline.** Defines every sound-bearing event in frames and reads real product data from `../../src/content` |
| `timing/timeline.json`, `js/timeline.generated.js`, `js/data.generated.js` | Generated by the script above (do not edit) |
| `audio/build_audio.py` | Procedural score + SFX (numpy/scipy, no samples). Writes `audio/score.wav`, stems and a cue sheet |
| `scripts/motion-blur.py` | Temporal supersampling: 240 fps sub-frames → 60 fps with a linear-light 180° tent shutter |
| `scripts/render-final.mjs` | Alternative motion-blur path through HyperFrames' engine `motionBlur` option (slower; see production report) |
| `scripts/verify.py` | Verifies a render from the media itself: frame count, duration, codecs, loudness, A/V offset, cue onsets, keystroke picture sync, frames every 0.5 s |
| `assets/` | Fonts (Cairo, JetBrains Mono, Noto Color Emoji subsets — OFL), GSAP, the official logo files |
| `BRIEF.md` | Intent and constraints |

## Rebuild

Requirements: Node ≥ 22, FFmpeg, Python 3 with numpy + scipy + pillow, and a Chrome/Chromium
(`HYPERFRAMES_BROWSER_PATH`). HyperFrames is pinned to 0.8.164.

```bash
# 1. shared timeline + real product data (reads ../../src/content)
node timing/build-timeline.mjs

# 2. soundtrack (same frame timeline -> sample = frame * 800)
python3 audio/build_audio.py

# 3. checks
npx hyperframes@0.8.164 lint .

# 4. draft (60 fps, no motion blur, ~4 min on 2 cores)
npx hyperframes@0.8.164 render . -f 60 -q looks -o ../renders/draft.mp4

# 5. final: true sub-frames — two 240 fps passes, the second shifted by 1/480 s
#    (= 480 real re-renders per second), then a 5-sample 180° tent shutter in linear light
#    (~15 min per pass on 2 cores + ~10 min for the blend)
npx hyperframes@0.8.164 render . -f 240 --crf 8 -o ../renders/sub240.mp4
npx hyperframes@0.8.164 render . -f 240 --crf 8 --strict-variables \
  --variables '{"subframeOffset":0.0020833333333333333}' -o ../renders/sub240b.mp4
python3 scripts/motion-blur.py ../renders/sub240.mp4 ../renders/sub240b.mp4 ../thecodefix-launch.mp4 14

# 6. verify from the rendered media
python3 scripts/verify.py ../thecodefix-launch.mp4 ../renders/final-review
```

## Editing notes

- Change *when* something happens in `timing/build-timeline.mjs`, re-run steps 1–2; picture and
  sound move together.
- Lesson titles, track names, counts and roadmap links come from the app's content at build time,
  so the film stays truthful if the curriculum changes.
- The in-film logo is an SVG reconstruction of `assets/brand/icon.png`, diff-verified against it
  (≈1 % mean alpha error, ≈3/255 colour error).
