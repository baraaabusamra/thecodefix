الإعداد الذي كتبناه في [الدرس السابق](/learn/terraform/06-install-first-config) بقيم ثابتة. المتغيّرات والمخرجات تجعله مرنًا وقابلًا لإعادة الاستخدام. درس عملي.

> ⚠️ الإعداد تمثيليّ؛ شغّله في بيئة حقيقية للتأكّد.

## المتغيّرات (Variables): مدخلات قابلة للتخصيص

بدل تضمين قيمة ثابتة كالمنطقة، عرّفها كمتغيّر:

```hcl
variable "region" {
  type    = string
  default = "us-east-1"
}

provider "aws" {
  region = var.region
}
```

الآن يمكن تغيير المنطقة دون تعديل منطق الإعداد — تشير إليها بـ `var.region`.

## تمرير قيم المتغيّرات

هناك عدّة طرق لتمرير قيمة (تتجاوز الافتراضية):

- **سطر الأوامر**: `terraform apply -var="region=eu-west-1"`.
- **ملفّ `terraform.tfvars`**: تضع فيه القيم فيقرأها Terraform تلقائيًا.
- **متغيّرات بيئة**: بادئة `TF_VAR_` (مثل `TF_VAR_region`).

هذا يتيح إعدادًا واحدًا يعمل عبر بيئات مختلفة (تطوير/إنتاج) بقيم مختلفة.

## المخرجات (Outputs): إظهار النتائج

بعد التطبيق، قد تحتاج قيمًا أنشأها Terraform (اسم حاوية، عنوان خادم). المخرجات تظهرها:

```hcl
output "bucket_name" {
  value = aws_s3_bucket.example.bucket
}
```

بعد `apply`، يطبع Terraform قيمة `bucket_name`. المخرجات مفيدة أيضًا لتمرير قيم بين [الوحدات](/learn/terraform/04-modules).

## لماذا هذا مهمّ؟

- **إعادة الاستخدام**: إعداد واحد يخدم عدّة بيئات بتغيير القيم فقط.
- **الوضوح**: المدخلات والمخرجات تجعل واجهة إعدادك مفهومة.
- **التكامل**: المخرجات تربط أجزاء بنيتك بعضها ببعض.
