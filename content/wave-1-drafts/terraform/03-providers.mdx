المزوّد (Provider) هو ما يمنح Terraform قدرته على إدارة منصّات متعدّدة. تبني هذه الصفحة على [ما هو Terraform؟](/learn/terraform/01-what-is-terraform).

## ما هو المزوّد؟

المزوّد إضافة (Plugin) تتيح لـ Terraform التخاطب مع منصّة معيّنة عبر واجهتها البرمجية (API). مزوّد `aws` يديره موارد AWS، ومزوّد `azurerm` يدير Azure، وهكذا. المزوّد هو **الجسر** بين كود Terraform والمنصّة الفعليّة.

هذا ما يجعل Terraform متعدّد المنصّات: المنطق واللغة نفسها، ويتغيّر المزوّد فقط.

## إعداد المزوّد

تعرّف المزوّد وتضبطه (المنطقة، بيانات الاعتماد) في كودك:

```hcl
provider "aws" {
  region = "us-east-1"
}
```

> ⚠️ لا تضع بيانات الاعتماد مباشرةً في الكود؛ استخدم متغيّرات بيئة أو آليات اعتماد آمنة.

## الموارد ومصادر البيانات

يقدّم كل مزوّد نوعين ممّا يمكنك استخدامه:

- **الموارد (Resources)**: أشياء **ينشئها ويديرها** Terraform (خادم، حاوية، قاعدة بيانات).
- **مصادر البيانات (Data Sources)**: أشياء **يقرأها** Terraform من المنصّة دون إنشائها (مثل جلب معرّف صورة موجودة لاستخدامه).

## إدارة الإصدارات

المزوّدون يتطوّرون، لذا يُفضّل **تثبيت إصدار المزوّد** لضمان سلوك متوقّع وقابل لإعادة الإنتاج:

```hcl
terraform {
  required_providers {
    aws = {
      source  = "hashicorp/aws"
      version = "~> 5.0"
    }
  }
}
```

> ℹ️ رقم الإصدار (`~> 5.0`) توضيحيّ؛ تحقّق من أحدث إصدار مستقرّ للمزوّد في السجلّ الرسمي قبل الاعتماد عليه.

يُنزّل Terraform المزوّدين المطلوبين عند تشغيل `terraform init`.
