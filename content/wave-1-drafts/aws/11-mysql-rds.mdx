بعد أن فهمت [ما هو Amazon RDS؟](/learn/aws/06-rds)، سننشئ قاعدة بيانات MySQL مُدارة ونتّصل بها. يفترض الدرس إلمامًا بأساسيات [SQL](/learn/sql/00-intro).

> ⚠️ الأوامر تمثيلية؛ لا تضع كلمة المرور مباشرةً في الأمر في بيئة حقيقية (تظهر في السجلّات)، واستخدم إدارة أسرار مناسبة. شغّلها في حساب حقيقي للتأكّد.

## الخطوة 1: أنشئ الـ DB Instance

```bash
aws rds create-db-instance \
  --db-instance-identifier mydb \
  --engine mysql \
  --db-instance-class db.t3.micro \
  --master-username admin \
  --master-user-password <كلمة-مرور-قويّة> \
  --allocated-storage 20
```

يبدأ AWS بإنشاء القاعدة وتهيئتها؛ قد يستغرق ذلك بضع دقائق.

## الخطوة 2: انتظر حتى تصبح جاهزة واحصل على نقطة الاتّصال

تحقّق من الحالة واحصل على **نقطة الاتّصال (Endpoint)** — العنوان الذي تتّصل به:

```bash
aws rds describe-db-instances \
  --db-instance-identifier mydb \
  --query 'DBInstances[0].[DBInstanceStatus,Endpoint.Address]'
```

انتظر حتى تصير الحالة `available`.

## الخطوة 3: اتّصل بقاعدة البيانات

باستخدام عميل MySQL ونقطة الاتّصال التي حصلت عليها:

```bash
mysql -h <نقطة-الاتّصال> -u admin -p
```

أدخل كلمة المرور، وستكون داخل قاعدة بياناتك المُدارة، جاهزًا لإنشاء الجداول وتشغيل الاستعلامات كما تعلّمت في [مسار SQL](/learn/sql/00-intro).

## اعتبارات أمان مهمّة

- **لا تجعلها عامّة**: الأفضل وضع قاعدة البيانات في [شبكة فرعية خاصّة](/learn/aws/09-vpc-subnets) لا يصلها الإنترنت مباشرةً.
- **قيّد الوصول**: اسمح بالاتّصال من مصادر موثوقة فقط عبر مجموعة الأمان.
- **أسرار لا نصوص صريحة**: أدِر كلمة المرور بأداة أسرار، لا في الكود أو الأوامر.

## التنظيف

**مهمّ:** قاعدة البيانات تكلّف ما دامت قائمة. عند الانتهاء:

```bash
aws rds delete-db-instance \
  --db-instance-identifier mydb --skip-final-snapshot
```

> ℹ️ `--skip-final-snapshot` مناسب للتجارب فقط؛ في الإنتاج خذ لقطة نهائية قبل الحذف.
