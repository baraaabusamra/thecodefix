**C** و **C++** لغتان قويّتان مرتبطتان ارتباطًا وثيقًا، لكن بينهما فروق مهمّة.

## C — الأساس 🇨

[لغة C](/learn/c) هي **أمّ اللغات** وأساس أنظمة التشغيل. بسيطة في مفاهيمها،
تعطيك تحكّمًا مباشرًا في الذاكرة.

- ✅ أساس فهم كيف يعمل الحاسوب
- ✅ تُستخدم في الأنظمة والأجهزة المدمجة
- ❌ لا تدعم البرمجة كائنية التوجّه

## C++ — التوسعة الحديثة ➕

[C++](/learn/cpp) بُنيت على C وأضافت **البرمجة كائنية التوجّه** (راجع
[OOP](/learn/oop)) وميزات قويّة، مع الحفاظ على السرعة.

- ✅ كل قوّة C + الكلاسات والقوالب
- ✅ الخيار الأول للألعاب والمحرّكات والتطبيقات عالية الأداء

## مثال عملي: إدارة نفس المورد

**C** — عليك حجز الذاكرة وتحريرها يدويًّا بنفسك، بلا أي مساعدة من اللغة:

```c
int *numbers = malloc(5 * sizeof(int));
if (numbers == NULL) return 1; // يجب التحقّق يدويًّا من الفشل
numbers[0] = 10;
free(numbers); // نسيان هذا السطر = تسريب ذاكرة، لا تحذير من المترجم
```

**C++** — نفس الفكرة، لكن عبر أدوات تُحرَّر تلقائيًّا (RAII):

```cpp
#include <vector>
std::vector<int> numbers(5);
numbers[0] = 10;
// لا حاجة لـ free() — الذاكرة تُحرَّر تلقائيًّا عند خروج numbers من النطاق
```

هذا هو جوهر الفرق: C تعطيك أدوات خام (malloc/free) دون أي شبكة أمان — كل
خطأ إدارة ذاكرة مسؤوليتك الكاملة. C++ تبني فوقها تجريدات (مثل std::vector)
تحقّق نفس الأداء لكن بأمان أعلى بكثير، دون التضحية بالسرعة.

## جدول المقارنة

| الجانب | C | C++ |
|--------|---|-----|
| النموذج | إجرائي | إجرائي + كائني |
| كائنية التوجّه | ❌ | ✅ |
| التعقيد | أبسط | أوسع |
| الاستخدام | الأنظمة والأجهزة | الألعاب والتطبيقات الكبيرة |
| إدارة الذاكرة | يدوية بالكامل (malloc/free) | يدوية أو تلقائية عبر RAII |
| المكتبة القياسية | صغيرة جدًّا وخام | ضخمة (STL: حاويات، خوارزميات) |

## خطأ شائع عند الاختيار

الظنّ بأن "تعلّم C أولًا إلزامي" قبل C++ — غير دقيق فعليًّا. كثير من مبرمجي
C++ المحترفين لم يكتبوا C خالصة يومًا؛ تعلّم C++ مباشرةً باستخدام أدواتها
الحديثة (std::vector بدل المصفوفات الخام، Smart Pointers بدل new/delete)
أسرع وأأمن للمبتدئ من إتقان C أولًا ثم "الترقية".
