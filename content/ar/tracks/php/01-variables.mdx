## تعريف متغيّر

في PHP كل متغيّر يبدأ بعلامة `$`:

```php
<?php
$name = "براء";
$age = 25;
$price = 19.99;
$isActive = true;
?>
```

## أنواع البيانات

| النوع | مثال |
|-------|------|
| String (نص) | `"مرحبا"` |
| Integer (صحيح) | `42` |
| Float (عشري) | `3.14` |
| Boolean (منطقي) | `true` / `false` |
| Array (مصفوفة) | `[1, 2, 3]` |

## الطباعة

```php
<?php
$name = "سارة";
echo "مرحبًا";
echo $name;
?>
```

## دمج النصوص

نستخدم النقطة `.` للدمج، أو ندرج المتغيّر داخل نص بعلامتي تنصيص مزدوجتين:

```php
<?php
$name = "علي";

echo "مرحبًا " . $name;   // الدمج بالنقطة
echo "مرحبًا $name";       // الإدراج المباشر
?>
```

> 💡 الإدراج المباشر يعمل فقط مع علامتي التنصيص المزدوجتين `"..."`، وليس المفردتين.

## الثوابت (Constants)

```php
<?php
define("SITE_NAME", "The Code Fix");
echo SITE_NAME;
?>
```
