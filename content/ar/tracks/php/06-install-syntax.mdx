## تشغيل PHP

PHP لغة خادم — تحتاج خادمًا لتشغيلها. أسهل طريقة محليًّا هي حزمة **XAMPP**
أو **Laragon** (تجمع PHP + MySQL + Apache)، أو خادم PHP المدمج:

```bash
php -S localhost:8000      # خادم تطوير سريع
php file.php               # تشغيل ملف مباشرة
```

## وسوم PHP

يُكتب كود PHP داخل وسمَي `<?php` و`?>`، ويمكن دمجه مع HTML:

```php
<!DOCTYPE html>
<html>
<body>
  <h1><?php echo "مرحبًا من PHP"; ?></h1>
</body>
</html>
```

> كل أمر ينتهي بفاصلة منقوطة `;` — على عكس بايثون.

## الطباعة: echo و print

```php
<?php
echo "مرحبًا بالعالم";
echo "أ", "ب", "ج";        // echo يقبل عدّة قيم

print "نصّ آخر";            // print يقبل قيمة واحدة فقط
?>
```

الفرق العملي ضئيل — `echo` أسرع قليلًا وأكثر استخدامًا.

## الدمج مع المتغيّرات

```php
<?php
$name = "سارة";
echo "أهلًا $name";              // أهلًا سارة (تفسير داخل "")
echo 'أهلًا $name';             // أهلًا $name (بلا تفسير في '')
echo "أهلًا " . $name;          // الدمج بنقطة .
?>
```

> 💡 علامتا الاقتباس المزدوجتان `"` تفسّران المتغيّرات، والمفردتان `'` لا.

## التعليقات

```php

// تعليق سطر واحد
# تعليق سطر واحد (بديل)

/*
تعليق
```

## أخطاء شائعة

- نسيان الفاصلة المنقوطة `;` في نهاية الأمر.
- توقّع تفسير المتغيّرات داخل `' '` — استخدم `" "` للتفسير.
