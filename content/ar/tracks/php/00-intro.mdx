## ما هي PHP؟

**PHP** لغة برمجة تعمل على **الخادم (Server)** لبناء مواقع ديناميكية. تشغّل
مواقع ضخمة مثل ووردبريس وفيسبوك في بداياته، وأكثر من نصف مواقع الإنترنت.

## لماذا PHP؟

- **سهلة التعلّم** ومنتشرة بشدة.
- **استضافة رخيصة** ومتوفّرة في كل مكان.
- أساس أنظمة شهيرة مثل **WordPress** و**[Laravel](/learn/laravel)**.

## أين تُستخدم PHP؟

- **أنظمة إدارة المحتوى:** ووردبريس يشغّل نحو 40% من مواقع الويب.
- **المتاجر الإلكترونية:** مثل ووكومرس وماجنتو.
- **تطبيقات الويب المخصّصة:** عبر إطار Laravel الحديث.

## كيف تعمل PHP؟

تُنفَّذ على الخادم وتُرسل **HTML جاهزًا** للمتصفّح. نكتب كود PHP بين وسمين خاصين:

```php
<?php
  echo "مرحبًا من PHP!";
?>
```

## دمج PHP مع HTML

ميزة PHP أنها تندمج مباشرةً داخل HTML:

```php
<h1>الصفحة الرئيسية</h1>
<p>اليوم: <?php echo date("Y-m-d"); ?></p>
```

- `echo` تطبع النص أو القيمة.
- ملفات PHP تأخذ الامتداد `.php`.

## متغيّر بسيط

```php
<?php
  $name = "براء";
  echo "مرحبًا $name";
?>
```

لاحظ أنّ كل متغيّر في PHP يبدأ بعلامة `$`.

## كيف تشغّلها؟

تحتاج خادمًا يدعم PHP (مثل XAMPP محليًا)، ثم:

```bash
php -v          # عرض الإصدار
php file.php     # تشغيل ملف من الطرفية
```

## أسئلة شائعة

**هل PHP لغة ميّتة؟**
لا، ما زالت تشغّل أكثر من نصف الويب، وإطار Laravel أعطاها دفعة حديثة قوية.

**هل PHP سهلة للمبتدئين؟**
نعم، من أسهل لغات الخادم للبدء، خاصة مع توفّر الاستضافة والموارد العربية.
