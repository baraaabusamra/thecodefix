## الشروط (if / else)

```php
<?php
$age = 18;

if ($age >= 18) {
  echo "بالغ";
} elseif ($age >= 13) {
  echo "مراهق";
} else {
  echo "طفل";
}
?>
```

## عوامل المقارنة والمنطق

| العامل | المعنى |
|--------|--------|
| `==` | يساوي (قيمة) |
| `===` | يساوي (قيمة ونوع) |
| `!=` | لا يساوي |
| `&&` | و |
| `\|\|` | أو |

> 💡 يُفضّل `===` على `==` لأنه يقارن النوع أيضًا ويتجنّب أخطاء خفية.

## switch

```php
<?php
$day = "السبت";

switch ($day) {
  case "الجمعة":
  case "السبت":
    echo "عطلة";
    break;
  default:
    echo "يوم عمل";
}
?>
```

## حلقة for

```php
<?php
for ($i = 1; $i <= 5; $i++) {
  echo $i . " ";
}
?>
```

## حلقة while

```php
<?php
$count = 1;
while ($count <= 3) {
  echo $count;
  $count++;
}
?>
```
