## الدالة range

`range()` تولّد سلسلة أرقام، تُستخدم كثيرًا مع حلقات `for`:

```python
for i in range(5):
    print(i)          # 0 1 2 3 4

for i in range(1, 6):
    print(i)          # 1 2 3 4 5

for i in range(0, 10, 2):
    print(i)          # 0 2 4 6 8 (بخطوة 2)
```

## دوال lambda (المختصرة)

دالة قصيرة بلا اسم، تُكتب في سطر واحد بكلمة `lambda`:

```python
square = lambda x: x ** 2
print(square(5))      # 25

add = lambda a, b: a + b
print(add(3, 4))      # 7
```

تتألّق مع `map` و`filter` و`sorted`:

```python
nums = [1, 2, 3, 4, 5]
squares = list(map(lambda x: x ** 2, nums))
print(squares)        # [1, 4, 9, 16, 25]

evens = list(filter(lambda x: x % 2 == 0, nums))
print(evens)          # [2, 4]
```

وأكثر استخدام لها عمليًا: معامل `key` في `sorted` و`max` و`min`، لتحديد **على أي أساس** تتمّ المقارنة:

```python
students = [("سارة", 88), ("خالد", 95), ("نور", 79)]

print(sorted(students, key=lambda s: s[1]))
# [('نور', 79), ('سارة', 88), ('خالد', 95)]

print(max(students, key=lambda s: s[1]))   # ('خالد', 95)
print(sorted([5, 2, 8, 1], key=lambda x: -x))   # [8, 5, 2, 1]
```

### lambda = تعبير واحد فقط

جسم lambda تعبير واحد تُعاد قيمته تلقائيًا، بلا `return`. لا تقبل جُملًا مثل `if` العادية أو الحلقات أو الإسناد، لكن تقبل التعبير الشرطي المختصر:

```python
sign = lambda n: "موجب" if n > 0 else "سالب أو صفر"
print(sign(5))    # موجب

# bad = lambda x: return x + 1    # SyntaxError
```

## الوسائط المرنة *args

لاستقبال عدد غير محدّد من القيم:

```python
def total(*numbers):
    return sum(numbers)

print(total(1, 2, 3))        # 6
print(total(10, 20, 30, 40)) # 100
```

## الوسائط المسمّاة **kwargs

لاستقبال عدد غير محدّد من الأزواج مفتاح=قيمة:

```python
def show_profile(**info):
    for key, value in info.items():
        print(f"{key}: {value}")

show_profile(name="سامي", age=30, city="دبي")
```
