## الشرط الأساسي

نستخدم `if` لتنفيذ كود فقط عند تحقّق شرط. **المسافة البادئة (indentation)
إلزامية** في بايثون:

```python
age = 18

if age >= 18:
    print("بالغ")
else:
    print("قاصر")
```

> ⚠️ لاحظ النقطتين `:` والمسافة البادئة (4 مسافات) — هكذا تعرف بايثون
> ما ينتمي للشرط.

## عدة شروط (elif)

```python
score = 85

if score >= 90:
    print("ممتاز")
elif score >= 75:
    print("جيد جدًا")
elif score >= 50:
    print("مقبول")
else:
    print("راسب")
```

## عوامل المقارنة

| العامل | المعنى |
|--------|--------|
| `==` | يساوي |
| `!=` | لا يساوي |
| `>` `<` | أكبر / أصغر |
| `>=` `<=` | أكبر أو يساوي / أصغر أو يساوي |

## العوامل المنطقية

```python
age = 25
has_id = True

if age >= 18 and has_id:
    print("مسموح بالدخول")

if age < 12 or age > 65:
    print("خصم خاص")
```
