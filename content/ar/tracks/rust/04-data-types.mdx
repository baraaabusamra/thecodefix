## الأنواع العددية

```rust
let age: i32 = 25;       // عدد صحيح موقّع 32 بت (الافتراضي)
let big: u64 = 1_000_000; // غير موقّع؛ _ للفصل البصري فقط
let price: f64 = 9.99;   // عشري 64 بت (الافتراضي للكسور)
let index: usize = 3;    // بحجم مؤشّر النظام: للفهارس والأطوال
```

| الأنواع | المدى |
| --- | --- |
| `i8` `i16` `i32` `i64` `i128` | موقّعة: سالبة وموجبة |
| `u8` `u16` `u32` `u64` `u128` | غير موقّعة: صفر فأعلى |
| `isize` و`usize` | بحجم معمارية الجهاز (64 بت عادة) |
| `f32` و`f64` | كسور |

إذا لم تحدّد النوع، Rust تختار `i32` للأعداد الصحيحة و`f64` للكسور. و`usize` إلزامي للفهرسة: `v[i]` تطلب `i` من نوع `usize`، لذلك ترى أطوال المجموعات (`len()`) من هذا النوع.

### تجاوز الحدود: لا صمت

```rust
let x: u8 = 255;
// let y = x + 1;   // في debug: panic "attempt to add with overflow"
let (y, overflowed) = x.overflowing_add(1);
println!("{y} {overflowed}");           // 0 true
println!("{:?}", x.checked_add(1));     // None: آمنة
println!("{}", x.saturating_add(10));   // 255: تقف عند الحد
println!("{}", x.wrapping_add(1));      // 0: التفاف صريح
```

في نسخة debug يتوقّف البرنامج عند التجاوز بدل نتيجة خاطئة صامتة، وفي release يلتفّ. لا تعتمد على أيّهما؛ إذا كان التجاوز ممكنًا، اختر السلوك صراحة: `checked_` تُرجع `None`، و`saturating_` تقف عند الحد، و`wrapping_` تلتفّ عمدًا.

## المنطقي والحرف

```rust
let active: bool = true;
let letter: char = 'ع';
println!("{}", std::mem::size_of::<char>());   // 4
```

`char` في Rust حرف يونيكود كامل بحجم **4 بايت**، فيتّسع لأي حرف عربي أو رمز تعبيري، بعكس `char` في C الذي يتّسع لبايت واحد. يُكتب بين علامتي `' '`، والنص بين `" "`.

## النصوص: نوعان

```rust
let s: &str = "ثابت";                       // شريحة نصية: مرجع لنص موجود
let mut owned: String = String::from("قابل");
owned.push_str(" للتعديل");                  // String يملك بياناته ويكبر
println!("{s} / {owned}");
println!("{}", "عربي".len());                // 8: بايتات UTF-8 لا حروف
println!("{}", "عربي".chars().count());      // 4: الحروف الفعلية
```

`&str` للقراءة (النصوص الحرفية في الكود من هذا النوع)، و`String` حين تحتاج ملكية النص أو تعديله. الفرق مرتبط بالملكية، ومشروح في [درس الشرائح](/learn/rust/10-slices). وكما في معظم اللغات الحديثة، `len()` تعدّ **البايتات**، والحرف العربي بايتان في UTF-8.

## الصفوف (Tuples)

مجموعة **ثابتة** من قيم قد تختلف أنواعها:

```rust
let person: (&str, u32) = ("براء", 25);
println!("{} {}", person.0, person.1);
let (name, age) = person;          // تفكيك
println!("{name} عمره {age}");
```

مفيدة لإرجاع عدّة قيم من دالة. وإذا كثرت الحقول أو احتاجت أسماء، استخدم struct.

## المصفوفات

```rust
let nums: [i32; 5] = [1, 2, 3, 4, 5];   // النوع: 5 عناصر i32
let zeros = [0; 3];                      // [0, 0, 0]
println!("{} {}", nums[0], nums.len());  // 1 5
```

الطول **جزء من النوع** ويُعرف وقت الترجمة، والمصفوفة تعيش على المكدّس. للمجموعات التي يتغيّر حجمها استخدم `Vec` ([درس المجموعات](/learn/rust/15-collections)).

### الفهرسة خارج الحدود: panic لا فساد ذاكرة

```rust
let nums = [1, 2, 3];
let i = 7;
// println!("{}", nums[i]);   // panic: index out of bounds: the len is 3 but the index is 7
println!("{:?}", nums.get(i)); // None: الطريقة الآمنة
```

عكس C، Rust **تفحص الحدود** عند كل فهرسة وتوقف البرنامج بدل قراءة ذاكرة عشوائية. وإذا كان الفهرس قد يكون خارج المدى، `get` تُرجع `Option`.

## أخطاء شائعة

- **خلط الأنواع العددية:** `let x: i32 = 5; let y: i64 = x;` خطأ؛ Rust لا تحوّل ضمنيًا. حوّل بـ `as` أو `into()` ([درس العوامل](/learn/rust/06-operators)).
- **فهرسة بـ `i32`:** `v[i]` تحتاج `usize`.
- **الاعتماد على التفاف الأعداد:** يتوقّف في debug ويلتفّ في release؛ استخدم `checked_` أو `wrapping_` صراحة.
- **`len()` لعدد الحروف العربية:** يعدّ البايتات؛ استخدم `chars().count()`.
- **`'نص'` بعلامتين مفردتين:** `char` لحرف واحد فقط.
