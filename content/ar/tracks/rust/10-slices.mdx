## ما هي الشريحة؟

الشريحة **مرجع لجزء متجاور** من مجموعة: مصفوفة، أو Vec، أو نص. لا تملك البيانات ولا تنسخها؛ هي نافذة عليها، تتكوّن من مؤشّر لبداية الجزء وطوله. ولأنها مرجع، تخضع لكل قواعد [الاستعارة](/learn/rust/09-borrowing).

## شرائح المصفوفات والمتجهات

```rust
let arr = [1, 2, 3, 4, 5];
let part = &arr[1..4];       // [2, 3, 4]: من الفهرس 1 حتى 4 (غير شامل)
println!("{:?} {}", part, part.len());

let v = vec![10, 20, 30, 40];
let head = &v[..2];          // [10, 20]
let tail = &v[2..];          // [30, 40]
println!("{:?} {:?}", head, tail);
```

نوع الشريحة `&[i32]`. وأهمّ فائدة عملية لها: دالة تأخذ `&[T]` تقبل مصفوفة، أو Vec، أو جزءًا من أيٍّ منهما:

```rust
fn sum(nums: &[i32]) -> i32 {
    nums.iter().sum()
}

fn main() {
    let arr = [1, 2, 3];
    let v = vec![4, 5, 6, 7];
    println!("{} {} {}", sum(&arr), sum(&v), sum(&v[1..3]));   // 6 22 11
}
```

`&v` لـ `Vec` تتحوّل إلى `&[i32]` تلقائيًا. لذلك اكتب معاملات الدوال كشرائح لا كـ `&Vec<i32>`.

## شرائح النصوص: &str

النص الحرفي في الكود `"مرحبًا"` من نوع `&str`: شريحة نصية تشير إلى نص مخزّن داخل البرنامج نفسه. و`String` نص **مملوك** على الكومة يمكن تعديله وتكبيره. وأي `String` يمكن استعارته كـ `&str`:

```rust
fn first_word(s: &str) -> &str {
    s.split(' ').next().unwrap_or("")
}

fn main() {
    let owned = String::from("مرحبًا بالعالم");
    println!("{}", first_word(&owned));       // يعمل مع String
    println!("{}", first_word("أهلًا يا صديق")); // ومع &str مباشرة
}
```

القاعدة نفسها: معامل نصي للقراءة يكون `&str` لا `&String`.

| | `&str` | `String` |
| --- | --- | --- |
| الملكية | مرجع (مستعار) | مملوك |
| التعديل | لا | نعم (`push_str` وغيرها) |
| الاستخدام | معاملات الدوال، النصوص الحرفية | حقول البِنى، نصوص تُبنى أثناء التشغيل |

## الفخّ مع النصوص العربية: الحدود بالبايت

فهرسة الشرائح النصية `&s[a..b]` تكون **بالبايت** لا بالحرف. والحرف العربي في UTF-8 بايتان:

```rust
let s = String::from("مرحبًا بالعالم");
// let bad = &s[0..5];   // ❌ panic: byte index 5 is not a char boundary; it is inside 'ح'
let ok = &s[0..6];       // ✅ أول 3 حروف (6 بايتات): مرح
println!("{ok}");
```

إذا وقع حدّ الشريحة في منتصف حرف، يتوقّف البرنامج. هذا تصميم آمن: بدل نص مكسور، تعرف فورًا أن هناك خطأ. لكن لا تحسب البايتات يدويًا مع نص عربي، بل استخدم الدوال التي تعرف حدود الحروف:

```rust
let s = "مرحبًا بالعالم";

let first: String = s.chars().take(3).collect();   // أول 3 حروف بأمان
println!("{first}");                               // مرح

if let Some((word, rest)) = s.split_once(' ') {    // القصّ عند فاصل
    println!("[{word}] [{rest}]");
}

for (i, ch) in s.char_indices().take(3) {          // موضع كل حرف بالبايت
    println!("{i}: {ch}");                         // 0: م ثم 2: ر ثم 4: ح
}
```

و`s.get(0..5)` تُرجع `None` بدل التوقّف إذا كان الحدّ غير صالح.

## الشرائح والملكية معًا

```rust
let mut s = String::from("hello world");
let word = first_word(&s);   // word شريحة من s
// s.clear();                // ❌ لا يمكن تعديل s وword ما زالت تشير إليها
println!("{word}");
s.clear();                   // ✅ بعد آخر استخدام لـ word

fn first_word(s: &str) -> &str {
    s.split(' ').next().unwrap_or("")
}
```

المستعير يمنع تعديل النص الأصلي ما دامت شريحة منه مستخدمة، فلا تشير شريحة أبدًا إلى نص تغيّر أو حُذف.

## أخطاء شائعة

- **`&s[0..n]` بأرقام بايتات على نص عربي:** `panic` إذا وقعت في منتصف حرف. استخدم `chars()` أو `split_once` أو `get`.
- **`s[0]` لقراءة حرف:** غير مسموح أصلًا في Rust (`the type str cannot be indexed by integer`)، لأن الحرف قد يكون أكثر من بايت. استخدم `s.chars().nth(0)`.
- **`&Vec<T>` أو `&String` كمعامل:** اكتب `&[T]` و`&str`، فتقبل الدالة أنواعًا أكثر.
- **إرجاع شريحة من `String` محلّي:** الشريحة لا تعيش أطول من النص؛ أرجِع `String`.
- **`v[2..10]` على Vec أقصر:** `panic`؛ استخدم `v.get(2..10)` إن لم تكن متأكدًا من الطول.
