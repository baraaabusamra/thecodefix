## if

```rust
let n = 7;
if n > 10 {
    println!("كبير");
} else if n > 5 {
    println!("متوسط");
} else {
    println!("صغير");
}
```

لا أقواس حول الشرط، والأقواس المعقوفة إلزامية، والشرط يجب أن يكون `bool`: `if n` لعدد خطأ ترجمة (`expected bool, found integer`).

### if تعبير يُرجع قيمة

```rust
let n = 7;
let size = if n > 5 { "كبير" } else { "صغير" };
println!("{size}");
```

لا حاجة لعامل ثلاثي `? :`؛ `if` نفسها هي العامل. الشرط الوحيد: كل الفروع تُرجع **نفس النوع**. `if x { 5 } else { "خمسة" }` خطأ ترجمة.

## loop: حلقة لا نهائية حتى break

```rust
let mut attempts = 0;
let result = loop {
    attempts += 1;
    if attempts == 3 {
        break attempts * 10;   // break تُرجع قيمة من الحلقة
    }
};
println!("{result}");          // 30
```

`loop` للحلقات التي تتوقّف من داخلها (إعادة المحاولة حتى تنجح، قراءة حتى نهاية المدخلات). وميزتها أن `break` تُرجع قيمة، فتكتب `let result = loop { ... }` بلا متغيّر خارجي.

## while

```rust
let mut n = 3;
while n > 0 {
    println!("{n}");
    n -= 1;
}
println!("انطلق!");
```

## for: الأكثر استخدامًا

```rust
for i in 0..5 {            // 0 إلى 4 (الحد الأعلى غير مشمول)
    print!("{i} ");
}
println!();
for i in 1..=5 {           // 1 إلى 5 (=: شامل)
    print!("{i} ");
}
println!();
for i in (1..=3).rev() {   // عكسي: 3 2 1
    print!("{i} ");
}
println!();
```

### المرور على مجموعة

```rust
let names = vec!["براء", "سارة", "علي"];

for name in &names {                        // استعارة: names تبقى صالحة
    println!("{name}");
}
for (i, name) in names.iter().enumerate() { // مع الفهرس
    println!("{i}: {name}");
}
println!("{}", names.len());                // ✅
```

لاحظ `&names`: المرور على `names` مباشرة (`for name in names`) **يستهلك** المتجه وينقل ملكيته للحلقة، فلا تستطيع استخدامه بعدها. هذا من أول المواقف التي ستلتقي فيها بالملكية ([درس الملكية](/learn/rust/08-ownership)). القاعدة: `&v` للقراءة، و`&mut v` للتعديل، و`v` حين لا تحتاجه بعد الحلقة.

```rust
let mut prices = vec![10, 20, 30];
for p in &mut prices {
    *p += 5;        // تعديل كل عنصر في مكانه
}
println!("{:?}", prices);   // [15, 25, 35]
```

لماذا `for` أفضل من `while i < v.len()`؟ لأنها لا تخطئ في الحدود أبدًا، والمترجم يحذف فحص الحدود منها، فتكون أسرع وأأمن من الفهرسة اليدوية.

## الخروج من حلقات متداخلة: التسميات

```rust
'outer: for r in 0..3 {
    for c in 0..3 {
        if r * c == 2 {
            break 'outer;      // يخرج من الحلقتين
        }
        println!("{r},{c}");
    }
}
```

التسمية تبدأ بعلامة `'`. وتعمل مع `continue 'outer` أيضًا.

## أخطاء شائعة

- **`0..n` وتوقّع أن يشمل n:** النطاق `..` لا يشمل الحد الأعلى؛ استخدم `..=`.
- **`for x in v` ثم استخدام `v`:** خطأ "borrow of moved value". استخدم `&v`.
- **فروع `if` بأنواع مختلفة** حين تُستخدم كقيمة: كل الفروع يجب أن تُرجع نفس النوع.
- **`if` بلا `else` كقيمة:** `let x = if c { 5 };` خطأ، لأن الفرع الغائب يُرجع `()`.
- **العدّ التنازلي بـ `(5..0)`:** نطاق فارغ لا يدور أبدًا؛ اكتب `(0..5).rev()`.
