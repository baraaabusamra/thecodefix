## أصغر برنامج

```rust
fn main() {
    println!("مرحبًا بالعالم");
}
```

`main` نقطة البداية، و`println!` ماكرو طباعة (لاحظ `!`).

## Cargo — مدير المشاريع

```bash
cargo new my_app      # مشروع جديد
cd my_app
cargo run             # ترجمة وتشغيل
cargo build           # ترجمة فقط
cargo build --release # نسخة محسّنة للإنتاج
```

## الطباعة مع قيم

```rust
let name = "براء";
println!("أهلًا {name}");          // إدراج مباشر
println!("الناتج: {}", 2 + 3);     // عنصر نائب
```
