## أصغر برنامج

```rust
fn main() {
    println!("مرحبًا بالعالم");
}
```

`main` نقطة بداية كل برنامج تنفيذي. و`println!` ليست دالة بل **ماكرو** (لاحظ `!`): الماكرو يولّد كودًا وقت الترجمة، ولهذا يستطيع `println!` قبول عدد متغيّر من القيم وفحص نص التنسيق قبل التشغيل. خطأ مثل `println!("{} {}", x)` (قيمة ناقصة) يكتشفه المترجم لا المستخدم.

## Cargo: الأداة التي ستستخدمها يوميًا

يمكنك ترجمة ملف واحد بـ `rustc main.rs`، لكن في الواقع كل مشروع Rust يُدار بـ **Cargo**: أداة البناء، ومدير الحزم، ومشغّل الاختبارات، كلها في أمر واحد. تأتي مع Rust تلقائيًا عند التثبيت بـ `rustup`.

```bash
cargo new my_app      # مشروع جديد
cd my_app
cargo run             # ترجمة وتشغيل
cargo build           # ترجمة فقط (إلى target/debug)
cargo build --release # نسخة محسّنة للإنتاج (إلى target/release)
cargo check           # فحص الأخطاء بلا توليد ملف تنفيذي: أسرع بكثير
```

`cargo new` تنشئ:

```text
my_app/
├── Cargo.toml        إعدادات المشروع والتبعيات
├── .gitignore
└── src/
    └── main.rs       نقطة البداية
```

و`Cargo.toml`:

```toml
[package]
name = "my_app"
version = "0.1.0"
edition = "2024"

[dependencies]
```

**الإصدار (edition)** يحدّد مجموعة قواعد اللغة التي يُترجم بها مشروعك (2015 و2018 و2021 و2024). الإصدارات متوافقة: مكتبة مكتوبة بإصدار 2018 تعمل في مشروعك بـ 2024 بلا مشاكل.

### debug أم release؟

النسخة العادية (debug) تُترجم بسرعة وتحتوي فحوصات إضافية، مثل إيقاف البرنامج عند تجاوز حدود عدد صحيح. أما `--release` فتُطبّق تحسينات قويّة، فتكون أبطأ في الترجمة وأسرع بكثير في التشغيل، أحيانًا عشرة أضعاف أو أكثر. **لا تقس الأداء أبدًا بنسخة debug.**

## الطباعة والتنسيق

```rust
let name = "براء";
let score = 92.456;

println!("أهلًا {name}");               // إدراج المتغيّر باسمه مباشرة
println!("الناتج: {}", 2 + 3);          // {} عنصر نائب لتعبير
println!("{:.1}", score);               // 92.5: خانة عشرية واحدة
println!("[{:>6}]", 42);                // [    42]: محاذاة لليمين بعرض 6
println!("{:?}", vec![1, 2, 3]);        // [1, 2, 3]: صيغة التصحيح (Debug)
eprintln!("رسالة خطأ");                 // إلى stderr بدل stdout
```

- `{}` تستخدم صيغة **العرض** (`Display`) المخصّصة للمستخدم.
- `{:?}` تستخدم صيغة **التصحيح** (`Debug`) للمبرمج، وتعمل مع معظم الأنواع المركّبة. و`{:#?}` تطبعها مقسّمة على أسطر.
- `format!` تعمل مثل `println!` لكنها تُرجع `String` بدل الطباعة.

## التعليقات والتوثيق

```rust
// تعليق سطر
/* تعليق متعدّد الأسطر */

/// تعليق توثيق: يظهر في صفحة التوثيق المولّدة بـ cargo doc
fn area(w: f64, h: f64) -> f64 {
    w * h
}
```

تعليقات `///` تُكتب بـ Markdown فوق الدوال والأنواع، و`cargo doc --open` تحوّلها لموقع توثيق كامل لمشروعك وتبعياته.

## أدوات تأتي مع Rust

```bash
cargo fmt      # تنسيق الكود بالأسلوب الرسمي
cargo clippy   # مئات الفحوصات للأخطاء والأنماط غير الاصطلاحية
cargo test     # تشغيل الاختبارات
```

`clippy` معلّم ممتاز للمبتدئين: يشرح لماذا الكود يمكن أن يكون أبسط، مع رابط للتفاصيل.

## أخطاء شائعة

- **نسيان `!`:** `println("...")` خطأ؛ هو ماكرو `println!`.
- **عدد عناصر نائبة لا يطابق القيم:** المترجم يرفضه، اقرأ الرسالة.
- **`{}` لـ Vec أو struct:** خطأ "doesn't implement Display". استخدم `{:?}`.
- **قياس السرعة بـ `cargo run` العادية:** استخدم `cargo run --release`.
- **إضافة مجلّد `target` إلى Git:** ضخم ويُعاد توليده؛ `cargo new` تضيفه لـ `.gitignore` تلقائيًا.
