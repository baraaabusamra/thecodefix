## العوامل الحسابية

```cpp
int a = 7, b = 3;
cout << a + b;   // 10
cout << a - b;   // 4
cout << a * b;   // 21
cout << a / b;   // 2 (قسمة صحيحة!)
cout << a % b;   // 1 (الباقي)
```

> ⚠️ `7 / 3` يساوي `2` لأن كليهما `int`. للحصول على `2.33` اجعل أحدهما
> `double`.

## الزيادة والنقصان

```cpp
int x = 5;
x++;        // x = 6
x--;        // x = 5
cout << ++x;   // 6 (يزيد ثم يطبع)
cout << x++;   // 6 (يطبع ثم يزيد)
```

## عوامل المقارنة

تُرجع `true` (1) أو `false` (0):

```cpp
cout << (5 == 5);   // 1 (يساوي)
cout << (5 != 3);   // 1 (لا يساوي)
cout << (5 > 3);    // 1
cout << (5 <= 4);   // 0
```

## العوامل المنطقية

| العامل | المعنى | مثال |
|--------|--------|------|
| `&&` | و | `x > 0 && x < 10` |
| `\|\|` | أو | `x < 0 \|\| x > 100` |
| `!` | نفي | `!isActive` |

```cpp
int age = 22;
if (age >= 18 && age <= 60) {
    cout << "ضمن الفئة العاملة";
}
```

## عوامل الإسناد المختصرة

```cpp
int x = 10;
x += 5;    // x = 15
x -= 3;    // 12
x *= 2;    // 24
x /= 4;    // 6
```

## أخطاء شائعة

- استخدام `=` (إسناد) بدل `==` (مقارنة) في الشروط.
- الخلط بين `++x` (قبل) و`x++` (بعد) في التعابير المركّبة.
