## ما هي C++؟

**C++** لغة برمجة قوية وسريعة، امتداد للغة [C](/learn/c) مع إضافة البرمجة كائنية
التوجّه. تُستخدم حيث يهمّ الأداء قبل أي شيء آخر.

طوّرها **Bjarne Stroustrup** في الثمانينيات، وما زالت حتى اليوم العمود الفقري
لمحرّكات الألعاب والتطبيقات التي تتطلّب سرعة قصوى وتحكّمًا دقيقًا في الموارد.

## أين تُستخدم C++؟

- **الألعاب** ومحرّكاتها (Unreal Engine).
- **أنظمة التشغيل** والبرامج عالية الأداء.
- **البرمجة التنافسية** (Competitive Programming).
- أنظمة مدمجة وتطبيقات الزمن الحقيقي.

## أول برنامج

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "مرحبًا من C++!" << endl;
    return 0;
}
```

- `#include <iostream>` لإدخال أدوات الإدخال/الإخراج.
- `cout <<` للطباعة.
- `main()` نقطة بداية البرنامج.

## التشغيل

```bash
g++ main.cpp -o main
./main
```

`g++` يترجم الكود إلى ملف تنفيذي.

## قراءة مُدخَل من المستخدم

```cpp
int age;
cout << "كم عمرك؟ ";
cin >> age;
cout << "عمرك " << age;
```

نستخدم `cin >>` لقراءة قيمة من لوحة المفاتيح.

## لماذا C++ قوية؟

- **سرعة قريبة من العتاد** (hardware).
- **تحكّم دقيق في الذاكرة**.
- مرونة بين البرمجة الإجرائية والكائنية.

## أسئلة شائعة

**ما الفرق بين C و C++؟**
C++ امتداد لـ C يضيف البرمجة الكائنية ومكتبة قياسية أوسع، مع الحفاظ على سرعة C.

**هل C++ صعبة للمبتدئين؟**
أكثر تعقيدًا من بايثون، لكنها تعلّمك مفاهيم عميقة وتفتح أبواب الألعاب والأنظمة.
