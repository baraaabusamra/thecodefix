## العائلات

| المدى | المعنى |
|------|------|
| `2xx` | نجاح |
| `3xx` | إعادة توجيه |
| `4xx` | خطأ من العميل |
| `5xx` | خطأ من الخادم |

## الأكثر استخدامًا

```
200 OK              نجاح عامّ
201 Created         أُنشئ المورد (بعد POST)
204 No Content      نجاح بلا محتوى (بعد DELETE)

301 Moved Permanently  انتقل الرابط نهائيًّا

400 Bad Request     طلب غير صالح
401 Unauthorized    غير مصادَق (سجّل الدخول)
403 Forbidden       ممنوع (لا صلاحية)
404 Not Found       غير موجود
409 Conflict        تعارض (مثل بريد مكرّر)
422 Unprocessable   بيانات فشلت التحقّق

500 Internal Error  خطأ في الخادم
503 Service Unavailable  الخدمة غير متاحة
```

## الاستخدام الصحيح

```js
res.status(201).json(newUser);          // بعد الإنشاء
res.status(404).json({ error: "غير موجود" });
res.status(401).json({ error: "سجّل الدخول" });
```

> 💡 إرجاع الرمز الصحيح يجعل واجهتك مفهومة وسهلة التصحيح.
