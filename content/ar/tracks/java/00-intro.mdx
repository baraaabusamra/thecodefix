## ما هي Java؟

**Java** لغة برمجة قوية متعدّدة الاستخدامات، شعارها **"اكتب مرة، شغّل في أي
مكان"** بفضل آلة Java الافتراضية (JVM).

> ملاحظة: Java و JavaScript **لغتان مختلفتان تمامًا** رغم تشابه الاسم!

ظهرت Java عام 1995، وما زالت حتى اليوم من أكثر اللغات استخدامًا في الأنظمة
الكبيرة، بفضل استقرارها وأدائها القوي ونظامها البيئي الضخم.

## لماذا Java؟

- **مطلوبة بشدة** في الشركات والأنظمة الكبيرة (البنوك، المؤسسات).
- لغة تطبيقات **الأندرويد** الأساسية (مع Kotlin).
- قوية ومنظّمة وكائنية التوجّه (OOP).

## أين تُستخدم Java؟

- **أنظمة المؤسسات:** البنوك وشركات التأمين والأنظمة الحرجة.
- **تطبيقات الأندرويد:** بجانب [Kotlin](/learn/kotlin).
- **الخوادم الكبيرة:** عبر أُطُر مثل Spring.

## أول برنامج

في Java كل شيء داخل **صنف (class)**، والبرنامج يبدأ من دالة `main`:

```java
public class Main {
    public static void main(String[] args) {
        System.out.println("مرحبًا من Java!");
    }
}
```

- `System.out.println(...)` تطبع سطرًا.
- لاحظ الفاصلة المنقوطة `;` في نهاية كل أمر.

## صيغة أبسط للمبتدئين (منذ Java 25)

كل الدروس هنا تستخدم الصيغة الكاملة أعلاه — وهي الشكل القياسي في أي مشروع Java حقيقي، فتعلّمها ضروري. لكن منذ Java 25، صارت هناك صيغة مختصرة مخصصة للتعلّم والبرامج الصغيرة، بدون `class` أو `public static` أو `String[] args`:

```java
void main() {
    IO.println("مرحبًا من Java!");
}
```

المترجم يضيف الصنف والتفاصيل المطلوبة تلقائيًا خلف الكواليس. هذه الصيغة مفيدة للتجربة السريعة، لكن الصيغة الكاملة تبقى المعيار في الشركات ومعظم الأكواد الموجودة — لهذا نبدأ بها.

## كيف تعمل Java؟

```
كود .java  →  (تُترجَم)  →  bytecode  →  (تعمل على)  JVM
```

هذا ما يجعلها تعمل على أي نظام فيه JVM.

## التشغيل

```bash
javac Main.java   # ترجمة
java Main         # تشغيل
```

## أخطاء شائعة للمبتدئين

- نسيان أنّ اسم الملف يجب أن يطابق اسم الصنف العام (`Main.java` لصنف `Main`).
- إهمال الفاصلة المنقوطة `;` في نهاية الأوامر.
- الخلط بين Java و JavaScript.

## أسئلة شائعة

**هل Java صعبة للمبتدئين؟**
أكثر تفصيلًا من بايثون، لكنها منظّمة وتعلّمك مفاهيم البرمجة الكائنية بعمق.

**هل Java ما زالت مطلوبة؟**
نعم، بقوة — خاصة في الشركات الكبيرة وتطبيقات الأندرويد.
