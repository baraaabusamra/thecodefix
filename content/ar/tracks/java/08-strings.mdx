## إنشاء النصوص

```java
String name = "براء";
int len = name.length();   // الطول
```

## أهمّ الدوال

| الدالة | الوظيفة |
|--------|---------|
| `length()` | الطول |
| `charAt(i)` | الحرف في موضع |
| `substring(a, b)` | جزء من النص |
| `indexOf("x")` | موضع نص |
| `toUpperCase()` / `toLowerCase()` | الحالة |
| `trim()` | إزالة المسافات الطرفية |
| `replace("a","b")` | الاستبدال |
| `split(",")` | التقسيم لمصفوفة |
| `contains("x")` | يحتوي؟ |
| `equals(s)` / `equalsIgnoreCase(s)` | مقارنة المحتوى (مع حالة الأحرف أو بدونها) |
| `isEmpty()` / `isBlank()` | فارغ تمامًا؟ / فارغ أو مسافات فقط؟ (Java 11+) |

```java
String s = "  Hello World  ";
s.trim().toUpperCase();      // "HELLO WORLD"
s.contains("World");          // true
"Java".substring(1, 3);       // "av" — النهاية غير مشمولة
"".isEmpty();                 // true
"   ".isEmpty();              // false — فيه مسافات
"   ".isBlank();              // true
```

## مقارنة النصوص: `equals` وليس `==`

`==` تقارن **المرجع** (هل المتغيّران يشيران لنفس الكائن في الذاكرة؟)، أما `equals` فتقارن **المحتوى** حرفًا حرفًا:

```java
String a = "Java";
String b = new String("Java");

a == b;                       // false — كائنان مختلفان
a.equals(b);                  // true  — نفس الأحرف
a.equalsIgnoreCase("JAVA");   // true  — بتجاهل حالة الأحرف
```

> ⚠️ أحيانًا تبدو `==` صحيحة مع النصوص المكتوبة مباشرة في الكود، لأن Java تعيد استخدام نفس الكائن لها (String pool). ثم تفشل فجأة مع نص جاء من مدخلات المستخدم أو من `new String`. قارن النصوص بـ `equals` دائمًا.

## النصوص متعددة الأسطر (Text Blocks)

منذ Java 15، `"""` تفتح نصًّا متعدد الأسطر بدون الحاجة لـ `\n` أو تهريب علامات الاقتباس:

```java
String html = """
    <html>
        <body>مرحبًا</body>
    </html>
    """;
```

Java تحذف تلقائيًا أي مسافة بادئة مشتركة بين كل الأسطر (بناءً على أقل سطر تباعدًا) — فتقدر تكتب النص بنفس تنسيق كودك دون كسر المحاذاة.

```java
// بالطريقة القديمة:
String old = "السطر الأول\n" +
             "السطر الثاني\n" +
             "نص بين \"علامتي اقتباس\" هنا";

// بـ text block:
String modern = """
    السطر الأول
    السطر الثاني
    نص بين "علامتي اقتباس" هنا
    """;
```

- شرطة مائلة `\` في نهاية السطر تُلغي السطر الجديد (تكمل بدون فاصل).
- `\s` تحافظ على مسافة بيضاء زائدة في نهاية السطر كانت ستُحذف تلقائيًا.

> 💡 مثالية لـ SQL أو JSON أو HTML مضمّنة داخل الكود — بدون تهريب مزعج لعلامات الاقتباس.

## النصوص غير قابلة للتغيير (Immutable)

كل تعديل على String ينشئ نصًّا جديدًا. للتعديل المتكرّر استخدم `StringBuilder`:

```java
StringBuilder sb = new StringBuilder();
sb.append("ا");
sb.append("ب");
String result = sb.toString();   // "اب"
```

> 💡 `StringBuilder` أسرع بكثير عند بناء نص داخل حلقة.

## أخطاء شائعة

- **استدعاء دالة بدون حفظ نتيجتها:** `name.toUpperCase();` وحدها لا تغيّر `name` لأن النص غير قابل للتغيير. الصحيح: `name = name.toUpperCase();`.
- **مقارنة النصوص بـ `==`:** تقارن المرجع لا المحتوى، كما في القسم أعلاه. استخدم `equals`.
- **الدمج بـ `+` داخل حلقة طويلة:** كل دورة تنشئ نصًّا جديدًا وتنسخ كل ما قبله. استخدم `StringBuilder`.
- **فهرس خارج النص:** `"Java".charAt(4)` يرمي `StringIndexOutOfBoundsException`، لأن آخر فهرس هو `length() - 1`.
