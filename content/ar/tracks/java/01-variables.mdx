## تعريف متغيّر

في Java نحدّد **نوع** المتغيّر صراحةً قبل اسمه:

```java
int age = 25;
double price = 19.99;
String name = "براء";
boolean isActive = true;
char grade = 'A';
```

## الأنواع الأساسية

| النوع | الاستخدام | مثال |
|-------|-----------|------|
| `int` | عدد صحيح | `42` |
| `double` | عدد عشري | `3.14` |
| `String` | نص | `"مرحبا"` |
| `boolean` | منطقي | `true` |
| `char` | حرف واحد | `'A'` |

## الطباعة والدمج

```java
String name = "سارة";
int age = 22;
System.out.println("الاسم: " + name + "، العمر: " + age);
```

نستخدم `+` لدمج النصوص مع القيم.

## الثوابت (final)

قيمة لا يمكن تغييرها:

```java
final double PI = 3.14159;
```

## الاستقبال من المستخدم

```java
import java.util.Scanner;

Scanner input = new Scanner(System.in);
System.out.print("اكتب اسمك: ");
String name = input.nextLine();
System.out.println("أهلًا " + name);
```
