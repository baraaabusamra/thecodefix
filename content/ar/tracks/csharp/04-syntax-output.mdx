## أصغر برنامج

```csharp
using System;

class Program
{
    static void Main()
    {
        Console.WriteLine("مرحبًا بالعالم");
    }
}
```

في C# الحديثة (.NET 6+) يمكن الاختصار بـ **top-level statements**:

```csharp
Console.WriteLine("مرحبًا بالعالم");
```

## الطباعة

```csharp
Console.WriteLine("سطر مع نزول");
Console.Write("بلا نزول");
Console.WriteLine($"العمر: {25}");   // قالب نصّي
```

## التعليقات

// تعليق سطر

/* تعليق

## القواعد الأساسية

- كل جملة تنتهي بـ `;`.
- الكتل بين `{ }`.
- C# حسّاسة لحالة الأحرف.
- الاصطلاح: أسماء الأصناف والدوال بـ PascalCase.

## أخطاء شائعة

- نسيان `using System;` (في غير top-level).
- نسيان الفاصلة المنقوطة.
