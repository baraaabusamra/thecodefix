## ما هي Node.js؟

**Node.js** بيئة تشغيل تتيح لك تشغيل **JavaScript خارج المتصفّح** — على
الخادم (Server). قبلها كانت JavaScript حبيسة المتصفّح فقط.

> بفضل Node.js يمكنك بناء الواجهة الأمامية والخلفية بلغة واحدة: JavaScript.

بُنيت Node.js على محرّك **V8** (نفس محرّك جافاسكريبت في متصفّح Chrome)، ما
يمنحها سرعة عالية وكفاءة في التعامل مع آلاف الطلبات المتزامنة.

## ماذا نبني بـ Node.js؟

- **خوادم الويب** وواجهات برمجية (APIs).
- **أدوات سطر الأوامر** (CLI).
- **التعامل مع الملفات** وقواعد البيانات.
- أدوات البناء التي تستخدمها يوميًا (مثل npm نفسها).

## لماذا Node.js؟

- **لغة واحدة** للواجهة والخادم توفّر وقت التعلّم.
- **نظام حزم ضخم:** npm أكبر مستودع مكتبات في العالم.
- **مجتمع نشط** ووفرة وظائف في السوق العربي والعالمي.

## أول برنامج

أنشئ ملف `app.js`:

```js
console.log("مرحبًا من Node.js!");
```

ثم شغّله من الطرفية:

```bash
node app.js
```

لاحظ: نفس `console.log` التي تعرفها — لكنها تعمل الآن على الخادم.

## خادم ويب بسيط

```js
import http from "node:http";

http.createServer((req, res) => {
  res.end("مرحبًا من خادم Node.js");
}).listen(3000);
```

بهذه الأسطر القليلة أنشأت خادمًا يستمع على المنفذ 3000 — دون أي برامج إضافية.

## التحقّق من التثبيت

```bash
node --version    # يعرض إصدار Node
npm --version     # يعرض إصدار مدير الحزم
```

## أسئلة شائعة

**هل أتعلّم JavaScript قبل Node.js؟**
نعم، Node.js تشغّل جافاسكريبت، فلا بدّ من إتقان أساسياتها أولًا.

**هل Node.js لغة برمجة؟**
لا، هي **بيئة تشغيل** لجافاسكريبت على الخادم، وليست لغة مستقلّة.

> 🎯 التالي: الوحدات (Modules) و npm.
