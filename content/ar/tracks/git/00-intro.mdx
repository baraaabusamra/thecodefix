## ما هو Git؟

**Git** نظام **تحكّم بالإصدارات (Version Control)** يحفظ تاريخ كل تغيير في
مشروعك, فتستطيع العودة لأي نقطة سابقة، ومعرفة من غيّر ماذا ومتى.

> تخيّله كزرّ "حفظ" ذكي يتذكّر كل نسخة من مشروعك إلى الأبد.

## لماذا Git؟

- **أمان:** لا تخسر عملك أبدًا، وارجع لأي نسخة قديمة.
- **تعاون:** يعمل فريق كامل على نفس المشروع دون تعارض.
- **معيار الصناعة:** مطلوب في كل وظيفة برمجية تقريبًا.

## أين يُستخدم Git؟

- **كل مشاريع البرمجة تقريبًا:** فردية كانت أو ضمن فريق.
- **المصادر المفتوحة:** التعاون على منصّات مثل GitHub و GitLab.
- **النشر (Deployment):** كثير من المنصّات تنشر مباشرة من مستودع Git.

## Git مقابل GitHub

| | Git | GitHub |
|---|-----|--------|
| ما هو | أداة على جهازك | موقع لاستضافة المشاريع |
| يعمل | محليًا (offline) | على الإنترنت |
| الدور | يتتبّع التغييرات | يشارك ويخزّن المستودعات |

## التثبيت والإعداد

بعد تثبيت Git من [git-scm.com](https://git-scm.com)، عرّف نفسك مرة واحدة:

```bash
git config --global user.name "اسمك"
git config --global user.email "you@example.com"
```

تحقّق من الإصدار:

```bash
git --version
```

## دورة العمل الأساسية

```bash
git init            # ابدأ مستودعًا جديدًا
git add .           # جهّز التغييرات
git commit -m "أول حفظة"   # احفظها في التاريخ
```

هذه الأوامر الثلاثة هي قلب استخدامك اليومي لـ Git.

## أسئلة شائعة

**هل أحتاج GitHub لأستخدم Git؟**
لا، Git يعمل محليًا على جهازك دون إنترنت. GitHub مجرّد مكان لاستضافة مشاريعك
ومشاركتها.

**هل Git صعب؟**
الأوامر الأساسية سهلة، والتعقيد يأتي لاحقًا مع الفروع والدمج — وكلها تُتقن
بالممارسة.

> 🎯 التالي: الأوامر الأساسية — كيف نحفظ التغييرات.
