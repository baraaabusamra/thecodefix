## مستودع جديد: git init

```bash
cd my-project
git init          # ينشئ مجلّد .git المخفي
```

أصبح المجلّد الآن مستودعًا يتتبّع التغييرات.

## نسخ مستودع موجود: git clone

```bash
git clone https://github.com/user/repo.git
cd repo
```

هذا ينسخ كامل المشروع وتاريخه ويربطه تلقائيًا بالمستودع البعيد باسم `origin`.

## فحص الحالة

```bash
git status
```

`git status` صديقك الدائم — يخبرك بالملفات المعدّلة وغير المتتبّعة وحالة الفرع.

## مجلّد .git

يحتوي كل تاريخ المشروع. حذفه يحوّل المجلّد إلى مجلّد عادي بلا تتبّع.

> 🎯 التالي: منطقة التجهيز والـ commit.
