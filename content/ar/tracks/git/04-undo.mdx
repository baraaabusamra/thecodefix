## التراجع عن تعديلات لم تُحفظ

لإلغاء تغييرات ملف قبل `add`:

```bash
git restore file.txt        # أرجع الملف لآخر نسخة محفوظة
```

## إخراج ملف من منطقة التجهيز

```bash
git restore --staged file.txt   # تراجع عن git add
```

## تعديل آخر commit

نسيت ملفًا أو أخطأت في الرسالة؟

```bash
git add forgotten.txt
git commit --amend -m "رسالة محدّثة"
```

## تراجعت عن commit كامل؟

لتصحيح أخطاء أعمق من ملف واحد — إلغاء آخر commit بالكامل أو أكثر — يوجد أمران:

- **`git reset`**: يحذف commits محليًا (قبل الرفع/push فقط).
- **`git revert`**: ينشئ commit جديدًا يلغي تغييرًا سابقًا (آمن حتى بعد الرفع).

```bash
git reset --soft HEAD~1    # مثال سريع: تراجع عن آخر commit (يبقي التغييرات)
```

> ⚠️ لـ `reset` أنماط أخرى (`--mixed`، `--hard`) وفروقات مهمة عن `revert` —
> راجع درس [التراجع: reset و revert و restore](/learn/git/18-reset-revert-restore) للتعمّق الكامل.

## القاعدة الذهبية

- **محليًا (لم ترفع بعد):** `reset` مقبول.
- **بعد الرفع للفريق:** استخدم `revert` دائمًا حتى لا تُفسد تاريخ الآخرين.
