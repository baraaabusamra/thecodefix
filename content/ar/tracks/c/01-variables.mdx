## تعريف المتغيّرات

```c
int age = 25;
float price = 19.99;
char grade = 'A';
```

## الأنواع الأساسية

| النوع | الاستخدام |
|-------|-----------|
| `int` | عدد صحيح |
| `float` / `double` | عدد عشري |
| `char` | حرف واحد |

> ملاحظة: لا يوجد نوع `string` مدمج في C — النصوص مصفوفات من `char`.

## الإخراج (printf) ومحدّدات التنسيق

```c
int age = 25;
float price = 19.99;
printf("العمر: %d\n", age);
printf("السعر: %.2f\n", price);
```

| المحدّد | للنوع |
|---------|-------|
| `%d` | int |
| `%f` | float |
| `%c` | char |
| `%s` | نص |

## الإدخال (scanf)

```c
int age;
printf("اكتب عمرك: ");
scanf("%d", &age);
printf("عمرك %d\n", age);
```

> ⚠️ لاحظ `&` قبل المتغيّر في `scanf` — نمرّر عنوانه ليُخزَّن فيه الإدخال.
