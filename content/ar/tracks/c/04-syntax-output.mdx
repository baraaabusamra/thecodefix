## أصغر برنامج C

```c
#include <stdio.h>

int main() {
    printf("مرحبًا بالعالم\n");
    return 0;
}
```

- `#include <stdio.h>` يستورد دوال الإدخال/الإخراج مثل `printf`.
- `int main()` نقطة بداية تنفيذ كل برنامج C.
- `return 0;` تعني أن البرنامج انتهى بنجاح.

## الطباعة بـ printf

```c
printf("سطر مع نزول\n");
printf("بلا نزول");
printf("العمر: %d\n", 25);   // %d لإدراج عدد صحيح
```

`\n` تعني سطرًا جديدًا، و`%d` عنصر نائب (placeholder) يُستبدل بالقيمة بعد الفاصلة.

## التعليقات

```c
// تعليق سطر واحد

/* تعليق
   متعدّد الأسطر */
```

## القواعد الأساسية

- كل جملة تنتهي بفاصلة منقوطة `;`.
- الكتل محصورة بين `{ }`.
- C حسّاسة لحالة الأحرف: `Main` ≠ `main`.

## أخطاء شائعة

- نسيان `#include <stdio.h>` قبل استخدام `printf`.
- نسيان `\n` فيلتصق المخرج بالسطر التالي.
