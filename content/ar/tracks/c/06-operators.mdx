## العوامل الحسابية

```c
int a = 10, b = 3;
printf("%d\n", a + b);  // 13
printf("%d\n", a - b);  // 7
printf("%d\n", a * b);  // 30
printf("%d\n", a / b);  // 3  (قسمة صحيحة)
printf("%d\n", a % b);  // 1  (الباقي)
```

### القسمة الصحيحة

إذا كان طرفا القسمة عددين صحيحين، فالنتيجة عدد صحيح ويُحذف الكسر (لا تقريب). للحصول على الكسر اجعل أحد الطرفين عشريًا **قبل** القسمة:

```c
int total = 7, count = 2;
double wrong = total / count;            // 3.0: القسمة تمّت صحيحة أولًا
double right = (double)total / count;    // 3.5
printf("%.1f %.1f\n", wrong, right);
```

`(double)total` اسمه **تحويل صريح** (cast): تحوّل القيمة لنوع آخر في هذا التعبير فقط.

### باقي القسمة مع الأعداد السالبة

`%` تعمل على الأعداد الصحيحة فقط، والقسمة في C **تقتطع نحو الصفر**، فالباقي يأخذ إشارة العدد الأول:

```c
printf("%d %d\n", -7 / 2, -7 % 2);   // -3 -1
```

لذلك فحص الفردية بـ `n % 2 == 1` يفشل مع الأعداد السالبة الفردية (الباقي `-1`). استخدم `n % 2 != 0`.

## عوامل المقارنة

`==` و`!=` و`>` و`<` و`>=` و`<=` تُرجع `1` (صحيح) أو `0` (خطأ)، كعدد صحيح عادي.

## العوامل المنطقية

```c
int x = 5;
if (x > 0 && x < 10) printf("بين 0 و 10\n");   // و
if (x < 0 || x > 100) printf("خارج النطاق\n"); // أو
if (!(x == 5)) printf("ليس 5\n");              // نفي
```

### التقييم المختصر (Short-circuit)

`&&` لا تقيّم الطرف الثاني إذا كان الأول خطأ، و`||` لا تقيّمه إذا كان الأول صحيحًا. هذا ليس تفصيلًا: نعتمد عليه لحماية العمليات الخطرة:

```c
int count = 0, sum = 10;
if (count != 0 && sum / count > 2) {   // لا قسمة على صفر: الطرف الثاني لا يُقيَّم
    printf("المعدّل أكبر من 2\n");
}
```

لو عكست الترتيب لحدثت القسمة على صفر قبل الفحص.

## الإسناد المختصر والزيادة

```c
int n = 5;
n += 3;   // n = 8
n++;      // n = 9
n--;      // n = 8
```

### `i++` أم `++i`؟

كلاهما يزيد `i` بواحد. الفرق في **قيمة التعبير** حين تستخدمه داخل تعبير آخر:

```c
int i = 5;
int a = i++;   // a = 5 ثم تصبح i = 6  (استخدم ثم زِد)
int j = 5;
int b = ++j;   // تصبح j = 6 ثم b = 6  (زِد ثم استخدم)
printf("%d %d\n", a, b);   // 5 6
```

في سطر مستقل مثل `i++;` لا فرق. القاعدة العملية: لا تخلط الزيادة مع تعبير آخر يقرأ نفس المتغيّر، لأن `i = i++` و`printf("%d %d", i, i++)` **سلوك غير معرّف**: المعيار لا يحدّد ترتيب التنفيذ، فيعطي كل مترجم نتيجة مختلفة.

## الأولوية (Precedence)

الضرب والقسمة قبل الجمع والطرح، والمقارنة قبل `&&`، و`&&` قبل `||`. لكن لا تحفظ الجدول كاملًا؛ **ضع أقواسًا** حين يكون الترتيب غير بديهي:

```c
int r = 2 + 3 * 4;       // 14 لا 20
int s = (2 + 3) * 4;     // 20
printf("%d %d\n", r, s);
```

## أخطاء شائعة

- **`=` بدل `==` في الشرط:** `if (x = 5)` تُسند 5 إلى `x` ثم تعتبر الشرط صحيحًا دائمًا. `-Wall` يحذّرك منها.
- **`&` بدل `&&`:** `&` عامل بتّات (درس العمليات على البتّات) ولا يختصر التقييم، فيعمل أحيانًا بالصدفة ويفشل في حالات أخرى.
- **انتظار كسر من قسمة صحيحة:** `1 / 2` تساوي `0`.
- **`%` مع الكسور:** `5.5 % 2` خطأ ترجمة؛ استخدم `fmod` من `math.h`.
