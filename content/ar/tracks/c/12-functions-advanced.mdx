## لماذا الدوال؟

الدالة تعطي اسمًا لمجموعة خطوات، فتكتبها مرة وتستدعيها من أي مكان. هذا يقلّل التكرار، ويجعل كل جزء صغيرًا بما يكفي لتفهمه وتختبره وحده. القاعدة العملية: إذا نسخت نفس الأسطر مرّتين، أو احتجت تعليقًا لتشرح ماذا يفعل مقطع طويل، فهذا مكان دالة.

```c
int add(int a, int b) {   // نوع الإرجاع، الاسم، المعاملات
    return a + b;
}

void greet(void) {        // void: لا تُرجع شيئًا ولا تأخذ معاملات
    printf("أهلًا\n");
}
```

## التصريح المسبق (Prototype)

المترجم يقرأ الملف من الأعلى للأسفل، فيجب أن يعرف شكل الدالة **قبل** أن تستدعيها. إذا أردت كتابة `main` أولًا، ضع **نموذج** الدالة في الأعلى:

```c
int add(int a, int b);   // النموذج: الشكل فقط بلا جسم

int main(void) {
    printf("%d\n", add(2, 3));
    return 0;
}

int add(int a, int b) {  // التعريف
    return a + b;
}
```

في المشاريع الكبيرة تُجمَع النماذج في ملفات `.h`، كما في درس تنظيم البرنامج عبر ملفات متعددة.

## التمرير بالقيمة: لماذا لا يعمل swap؟

C تمرّر **نسخة** من كل معامل. الدالة تعمل على النسخة، والأصل لا يتأثّر:

```c
void swap_wrong(int a, int b) {
    int t = a; a = b; b = t;     // تبدّل النسختين فقط
}

void swap(int *a, int *b) {
    int t = *a; *a = *b; *b = t; // تبدّل القيمتين في العنوانين الأصليين
}

int main(void) {
    int x = 1, y = 2;
    swap_wrong(x, y);
    printf("%d %d\n", x, y);     // 1 2: لم يتغيّر شيء
    swap(&x, &y);
    printf("%d %d\n", x, y);     // 2 1
    return 0;
}
```

لتعديل متغيّر المستدعي، مرّر **عنوانه** (`&x`) واستلمه **كمؤشّر** (`int *a`). هذا نفس سبب `&` في `scanf`. المؤشّرات مشروحة بالتفصيل في الدرس التالي.

## النطاق (Scope)

- **متغيّر محلّي:** يُعرَّف داخل دالة أو كتلة `{ }`، ويوجد فقط داخلها ويختفي عند الخروج منها.
- **متغيّر عام (global):** يُعرَّف خارج كل الدوال، وتراه كل الدوال في الملف.

```c
int calls = 0;            // عام

void work(void) {
    int temp = 5;         // محلّي: يُنشأ من جديد في كل استدعاء
    calls++;
    printf("%d\n", temp);
}
```

المتغيّرات العامة مريحة لكنها تجعل أي دالة قادرة على تغيير الحالة، فيصعب تتبّع من غيّر ماذا. فضّل تمرير القيم كمعاملات وإرجاع النتائج.

### static داخل الدالة

إذا أردت متغيّرًا يحتفظ بقيمته بين الاستدعاءات **دون** أن يكون عامًا، استخدم `static`. يُهيّأ مرة واحدة فقط ويبقى حتى نهاية البرنامج، لكنه لا يُرى إلا داخل دالته:

```c
int next_id(void) {
    static int id = 0;    // يُهيّأ مرة واحدة
    return ++id;
}

int main(void) {
    int a = next_id(), b = next_id(), c = next_id();
    printf("%d %d %d\n", a, b, c);   // 1 2 3
    return 0;
}
```

تفاصيل `static` و`extern` في درس أصناف التخزين.

## الاستدعاء الذاتي (Recursion)

دالة تستدعي نفسها على مشكلة **أصغر**، حتى تصل لحالة بسيطة تعرف جوابها مباشرة (حالة التوقّف):

```c
long long factorial(int n) {
    if (n <= 1) return 1;            // حالة التوقّف
    return n * factorial(n - 1);     // مشكلة أصغر
}

int main(void) {
    printf("%lld\n", factorial(10)); // 3628800
    return 0;
}
```

كل استدعاء يحجز مكانًا في **المكدّس** (stack) حتى يُرجع. بلا حالة توقّف، أو مع عمق كبير جدًّا (ملايين الاستدعاءات)، يمتلئ المكدّس وينهار البرنامج (stack overflow). لذلك الحلقة العادية أفضل لما يمكن كتابته بحلقة بسهولة مثل المضروب، والاستدعاء الذاتي يتألّق مع البنى المتفرّعة: الأشجار، والمجلّدات داخل المجلّدات، وخوارزميات "فرّق تسد".

## أخطاء شائعة

- **استدعاء دالة قبل تعريفها بلا نموذج:** المترجم الحديث يرفض أو يحذّر من "implicit declaration". ضع النموذج في الأعلى.
- **نسيان `return` في دالة غير `void`:** المستدعي يستلم قيمة عشوائية. `-Wall` يحذّرك (`-Wreturn-type`).
- **توقّع أن تعديل المعامل يغيّر الأصل:** مرّر مؤشّرًا.
- **إرجاع عنوان متغيّر محلّي:** `return &temp;` يُرجع عنوانًا يختفي فور انتهاء الدالة.
- **`int f()` بدل `int f(void)`:** قبل C23، الأقواس الفارغة تعني "معاملات غير محدّدة" لا "بلا معاملات"، فلا يفحص المترجم الاستدعاءات. اكتب `void` صراحة.
