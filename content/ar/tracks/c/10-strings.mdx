## النص = مصفوفة char تنتهي بصفر

C لا تملك نوع `string`. النص مصفوفة حروف تنتهي بالحرف الخاص `\0` (null terminator)، وكل دوال النصوص تعرف نهاية النص بالبحث عن هذا الصفر:

```c
char name[] = "Baraa";   // {'B','a','r','a','a','\0'}: 6 بايتات لا 5
printf("%s\n", name);    // %s لطباعة نص
printf("%zu\n", sizeof(name));   // 6
```

لذلك **احجز دائمًا مكانًا إضافيًا للصفر**: نص من 10 حروف يحتاج مصفوفة من 11 على الأقل.

## الحروف العربية والبايتات

النصوص العربية تُخزَّن عادة بترميز UTF-8، وفيه الحرف العربي **بايتان**. و`strlen` تعدّ البايتات لا الحروف:

```c
#include <string.h>

printf("%zu\n", strlen("Baraa"));   // 5
printf("%zu\n", strlen("براء"));    // 8: أربعة حروف × بايتين
```

انتبه لهذا عند حساب أحجام المصفوفات أو قصّ النصوص: قصّ نص عربي عند بايت فردي يكسر الحرف الأخير.

## دوال مكتبة string.h

```c
#include <string.h>

char a[20] = "Hello";
char b[20] = "World";

printf("%zu\n", strlen(a));   // الطول: 5
strcpy(a, b);                 // نسخ b إلى a
strcat(a, "!");               // إلحاق
printf("%s\n", a);            // World!
printf("%d\n", strcmp(a, b)); // قيمة موجبة: a أكبر أبجديًا
```

`strcmp` تُرجع **صفرًا** إذا تساوى النصّان، وقيمة سالبة أو موجبة حسب الترتيب الأبجدي. لا تفترض أنها `-1` أو `1` بالضبط؛ افحص الإشارة فقط.

## المقارنة بـ == لا تعمل

```c
char x[] = "abc";
char y[] = "abc";

if (x == y)              printf("== : متساويان\n");    // لا تُطبع: عنوانان مختلفان
if (strcmp(x, y) == 0)   printf("strcmp : متساويان\n"); // ✅
```

`x == y` تقارن **عنواني** المصفوفتين في الذاكرة، وهما مكانان مختلفان رغم تطابق المحتوى. gcc الحديث يحذّرك من هذا بـ `-Warray-compare`.

## النسخ الآمن: snprintf

`strcpy` و`strcat` لا تعرفان حجم المصفوفة الهدف، فإذا كان المصدر أطول **تكتبان خارجها** (buffer overflow). هذا من أشهر أسباب الثغرات في برامج C:

```c
char small[8];
// strcpy(small, "نص طويل جدًّا");   // ❌ تجاوز الذاكرة

snprintf(small, sizeof(small), "%s", "Hello, World");   // ✅ تقصّ وتضيف \0
printf("%s\n", small);   // Hello, 
```

`snprintf` تكتب على الأكثر `sizeof(small) - 1` حرفًا ثم الصفر، فلا تتجاوز أبدًا. وهي تفيد أيضًا لبناء نص من عدّة قيم: `snprintf(buf, sizeof(buf), "%s: %d", name, age)`.

أما `strncpy` فاسمها يوحي بالأمان لكنها **لا تضيف `\0`** إذا امتلأت المصفوفة، فتترك نصًا بلا نهاية.

## المصفوفة مقابل المؤشّر إلى نص ثابت

```c
char arr[] = "hello";       // نسخة قابلة للتعديل في مصفوفتك
const char *ptr = "hello";  // يشير إلى نص ثابت في ذاكرة للقراءة فقط

arr[0] = 'H';               // ✅
// ptr[0] = 'H';            // ❌ سلوك غير معرّف: غالبًا انهيار (segmentation fault)
printf("%s %s\n", arr, ptr);
```

النص الحرفي `"hello"` المكتوب في الكود ثابت. اكتب `const char *` حين تشير إليه، فيمنعك المترجم من محاولة تعديله.

## القراءة من المستخدم

قراءة النصوص بأمان (`fgets` بدل `scanf("%s")`) مشروحة بالتفصيل في الدرس التالي.

## أخطاء شائعة

- **نسيان مكان `\0`:** `char code[4] = "ABCD";` لا تترك مكانًا للصفر، فتقرأ `printf` ما بعدها في الذاكرة.
- **`==` لمقارنة النصوص:** استخدم `strcmp(a, b) == 0`.
- **`strcpy` إلى مصفوفة أصغر:** استخدم `snprintf`.
- **تعديل نص حرفي عبر مؤشّر:** انسخه لمصفوفة أولًا.
- **إسناد نص لمصفوفة بعد تعريفها:** `name = "Ali";` خطأ ترجمة؛ استخدم `snprintf` أو `strcpy` مع مصدر مضمون الحجم.
