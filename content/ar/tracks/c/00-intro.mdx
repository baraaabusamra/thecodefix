## ما هي لغة C؟

**C** لغة برمجة أساسية ومنخفضة المستوى نسبيًا، طُوّرت في السبعينيات. تُسمّى
**"أمّ لغات البرمجة"** لأن كثيرًا من اللغات الحديثة (C++, Java, Python)
استلهمت منها.

رغم قدمها، ما زالت C حاضرة بقوة اليوم في كل ما يحتاج أداءً عاليًا وتحكّمًا
دقيقًا في العتاد، من أنظمة التشغيل إلى الأجهزة المدمجة.

## لماذا تتعلّم C؟

- **تفهم كيف يعمل الحاسوب فعلًا** (الذاكرة، المؤشّرات).
- أساس **أنظمة التشغيل** (Linux مكتوب بـ C).
- تجعل تعلّم أي لغة أخرى أسهل.

## أين تُستخدم C؟

- **أنظمة التشغيل:** نواة Linux و Windows.
- **الأنظمة المدمجة:** المعالجات الدقيقة والأجهزة.
- **البرامج عالية الأداء:** حيث كل جزء من الثانية مهمّ.

## أول برنامج

```c
#include <stdio.h>

int main() {
    printf("مرحبًا من لغة C!\n");
    return 0;
}
```

- `#include <stdio.h>` لإدخال دوال الإدخال/الإخراج.
- `printf(...)` للطباعة، و `\n` لسطر جديد.
- `main()` نقطة البداية.

## التشغيل

```bash
gcc main.c -o main
./main
```

`gcc` يترجم الكود إلى ملف تنفيذي يعمل مباشرة على نظامك.

## C مقابل اللغات الحديثة

| | C | لغات حديثة |
|---|---|------------|
| المستوى | منخفض | عالٍ |
| إدارة الذاكرة | يدوية | تلقائية غالبًا |
| السرعة | فائقة | متفاوتة |
| التحكّم | كامل | مجرّد |

## أخطاء شائعة للمبتدئين

- نسيان `\n` فيلتصق الإخراج في سطر واحد.
- إهمال تحرير الذاكرة المحجوزة يدويًا (تسرّب ذاكرة).
- نسيان `return 0;` في نهاية `main`.

## أسئلة شائعة

**هل تعلّم C صعب؟**
أصعب قليلًا من اللغات الحديثة بسبب إدارة الذاكرة اليدوية، لكنها تبني أساسًا
قويًا يسهّل كل ما بعدها.

**هل C ما زالت مطلوبة؟**
نعم، خاصة في أنظمة التشغيل والأنظمة المدمجة والبرمجيات عالية الأداء.
