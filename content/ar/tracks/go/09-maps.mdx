## ما هي الخريطة؟

بنية تربط **مفتاحًا** بـ **قيمة**، مثل القاموس: تبحث بالكلمة فتجد معناها. البحث والإضافة والحذف سريعة جدًّا مهما كبرت الخريطة، لأنها تعتمد على جدول تجزئة (hash table) لا على المرور عنصرًا عنصرًا كالشريحة.

```go
ages := map[string]int{
    "براء": 25,
    "سارة": 22,
}
fmt.Println(ages["براء"])   // 25
```

النوع `map[string]int` يعني: مفاتيح نصية وقيم أعداد صحيحة. المفتاح يجب أن يكون نوعًا **قابلًا للمقارنة** بـ `==` (أرقام، نصوص، `bool`، بِنى من هذه الأنواع)، لذلك لا تصلح الشرائح مفاتيح.

## الإضافة والتعديل والحذف

```go
ages := map[string]int{"براء": 25}
ages["علي"] = 30       // إضافة
ages["براء"] = 26      // تعديل: نفس الصيغة
delete(ages, "علي")    // حذف (لا خطأ إن لم يوجد المفتاح)
fmt.Println(ages, len(ages))
```

## فحص الوجود: صيغة comma ok

الوصول لمفتاح **غير موجود** لا يسبّب خطأ، بل يُرجع **القيمة الصفرية**:

```go
ages := map[string]int{"براء": 25, "رضيع": 0}

fmt.Println(ages["خالد"])     // 0: غير موجود
fmt.Println(ages["رضيع"])     // 0: موجود وقيمته 0!

if age, ok := ages["خالد"]; ok {
    fmt.Println("موجود:", age)
} else {
    fmt.Println("غير موجود")
}
```

القيمة وحدها لا تميّز "غير موجود" من "موجود وقيمته صفر". المتغيّر الثاني `ok` يحسم هذا. استخدم الصيغة الكاملة كلما كان الفرق مهمًّا.

## مثال عملي: عدّ الكلمات

القيمة الصفرية هنا ميزة لا مشكلة: `counts[w]++` تعمل حتى مع كلمة جديدة لأنها تبدأ من 0:

```go
text := "go is fun and go is fast"
counts := make(map[string]int)
for _, w := range strings.Fields(text) {
    counts[w]++
}
fmt.Println(counts["go"], counts["is"], counts["fun"])   // 2 2 1
```

## الخريطة nil: قراءة نعم، كتابة لا

```go
var m map[string]int       // nil: لم تُنشأ بعد
fmt.Println(m["x"], len(m)) // 0 0: القراءة آمنة

// m["x"] = 1              // ❌ panic: assignment to entry in nil map

m = make(map[string]int)   // أنشئها أولًا
m["x"] = 1
fmt.Println(m)
```

عكس الشرائح التي تعمل `append` على `nil` منها، الخريطة يجب أن تُنشأ بـ `make` أو بقيمة حرفية `{}` قبل الكتابة فيها. هذا من أشهر أسباب الـ `panic` عند المبتدئين، خصوصًا مع حقل خريطة داخل struct لم يُهيّأ.

## المرور وترتيبه

```go
ages := map[string]int{"براء": 25, "سارة": 22, "علي": 30}
for name, age := range ages {
    fmt.Printf("%s = %d\n", name, age)   // الترتيب يختلف بين تشغيل وآخر!
}
```

ترتيب المرور على الخريطة **عشوائي عمدًا**، وGo تغيّره بين التشغيلات حتى لا يعتمد أحد عليه. إذا احتجت ترتيبًا ثابتًا (للطباعة أو الاختبار)، رتّب المفاتيح أولًا:

```go
ages := map[string]int{"براء": 25, "سارة": 22, "علي": 30}
keys := slices.Sorted(maps.Keys(ages))   // Go 1.23+
for _, k := range keys {
    fmt.Println(k, ages[k])
}
```

`maps.Keys` تُرجع مكرِّرًا على المفاتيح و`slices.Sorted` تجمعه في شريحة مرتّبة (التفاصيل في [درس التكرارات المخصّصة](/learn/go/29-iterators)).

## الخرائط مراجع

الخريطة تُمرَّر لدالة كمرجع: الدالة تعدّل **نفس** الخريطة، بلا حاجة لمؤشّر:

```go
func addBonus(scores map[string]int) {
    for k := range scores {
        scores[k] += 5
    }
}

func main() {
    s := map[string]int{"a": 90}
    addBonus(s)
    fmt.Println(s["a"])   // 95
}
```

## أخطاء شائعة

- **الكتابة في خريطة nil:** `panic`. أنشئها بـ `make` أولًا.
- **الاعتماد على ترتيب المرور:** عشوائي؛ رتّب المفاتيح.
- **التمييز بين "غير موجود" والصفر بالقيمة وحدها:** استخدم `v, ok := m[k]`.
- **الكتابة في خريطة من عدّة goroutines معًا:** الخرائط غير آمنة للتزامن، وGo توقف البرنامج بـ `fatal error: concurrent map writes`. احمِها بـ `sync.Mutex` ([درس المزامنة](/learn/go/18-sync)).
- **أخذ عنوان قيمة داخل خريطة:** `&m["a"]` خطأ ترجمة، لأن الخريطة قد تنقل قيمها داخليًا. خزّن مؤشّرات كقيم إن احتجت.

> 🎯 التالي: الدوال المتقدّمة و defer.
