## المصفوفة (Array): ثابتة الحجم

```go
var nums [3]int = [3]int{1, 2, 3}
nums[0] = 10
fmt.Println(nums, len(nums))   // [10 2 3] 3
```

الحجم **جزء من النوع**: `[3]int` و`[4]int` نوعان مختلفان، ولا يمكن تمرير أحدهما مكان الآخر. والمصفوفة **قيمة**: الإسناد والتمرير لدالة ينسخانها كاملة. لهذا نادرًا ما تُستخدم مباشرة؛ ستتعامل مع الشرائح في 95% من الوقت.

## الشريحة (Slice): نافذة على مصفوفة

```go
fruits := []string{"تفاح", "موز"}   // بلا رقم بين الأقواس = شريحة
fruits = append(fruits, "برتقال")
fmt.Println(fruits, len(fruits))     // [تفاح موز برتقال] 3
```

الشريحة لا تخزّن البيانات بنفسها. هي هيكل صغير من ثلاثة أجزاء:

1. **مؤشّر** إلى مصفوفة أساسية مخفيّة تحمل البيانات فعلًا.
2. **الطول** (`len`): عدد العناصر المتاحة الآن.
3. **السعة** (`cap`): عدد العناصر التي تتّسع لها المصفوفة الأساسية من نقطة البداية.

فهم هذه الأجزاء الثلاثة يشرح كل سلوك "غريب" للشرائح.

## append والسعة

```go
var s []int   // nil: طول 0 وسعة 0، وappend تعمل عليها مباشرة
for i := 0; i < 5; i++ {
    s = append(s, i)
    fmt.Println(len(s), cap(s))
}
```

حين تمتلئ السعة، `append` تحجز مصفوفة أساسية **جديدة أكبر** (عادة الضعف للشرائح الصغيرة)، وتنسخ العناصر إليها، وتُرجع شريحة تشير إلى الجديدة. لهذا **يجب** دائمًا إسناد النتيجة: `s = append(s, x)`. `append` وحدها لا تغيّر `s`.

## make: حجز مسبق

```go
a := make([]int, 3)       // [0 0 0]: طول 3
b := make([]int, 0, 100)  // طول 0 وسعة 100
fmt.Println(a, len(b), cap(b))
```

إذا عرفت مسبقًا كم عنصرًا ستضيف تقريبًا، `make([]T, 0, n)` تحجز مرة واحدة وتوفّر إعادة الحجز والنسخ المتكرّرة.

## التقطيع (Slicing) ومشاركة الذاكرة

```go
nums := []int{10, 20, 30, 40, 50}
fmt.Println(nums[1:3])   // [20 30]: من 1 حتى 3 (غير شامل)
fmt.Println(nums[:2])    // [10 20]
fmt.Println(nums[2:])    // [30 40 50]
```

التقطيع **لا ينسخ** البيانات: الشريحة الجديدة تشير إلى نفس المصفوفة الأساسية. تعديل إحداهما يظهر في الأخرى:

```go
nums := []int{10, 20, 30, 40, 50}
part := nums[1:3]
part[0] = 99
fmt.Println(nums)   // [10 99 30 40 50]: الأصل تغيّر!
```

### الفخّ الأشهر: append على شريحة مقطوعة

```go
base := []int{1, 2, 3, 4}
head := base[:2]            // [1 2] لكن السعة 4
head = append(head, 100)    // في السعة مكان، فتكتب فوق base[2]
fmt.Println(base)           // [1 2 100 4]
```

`head` طولها 2 لكن سعتها 4، فـ `append` لم تحجز مصفوفة جديدة بل كتبت في المكان التالي، وهو عنصر في `base`. إذا كنت ستعدّل شريحة مقطوعة أو تضيف إليها، **انسخها أولًا**:

```go
base := []int{1, 2, 3, 4}
head := slices.Clone(base[:2])   // نسخة مستقلّة
head = append(head, 100)
fmt.Println(base, head)          // [1 2 3 4] [1 2 100]
```

## المرور والحذف والنسخ

```go
fruits := []string{"تفاح", "موز", "برتقال"}
for i, v := range fruits {
    fmt.Println(i, v)
}

dst := make([]string, len(fruits))
n := copy(dst, fruits)            // تنسخ min(len(dst), len(src)) عنصرًا
fmt.Println(n, dst)

fruits = slices.Delete(fruits, 1, 2)   // حذف العنصر رقم 1
fmt.Println(fruits)                    // [تفاح برتقال]
```

حزمة `slices` (منذ Go 1.21) فيها معظم ما تحتاجه: `slices.Contains` و`slices.Index` و`slices.Sort` و`slices.Delete` و`slices.Clone` و`slices.Equal`. فضّلها على كتابة الحلقات يدويًا.

## أخطاء شائعة

- **`append(s, x)` بلا إسناد:** النتيجة تضيع؛ اكتب `s = append(s, x)`.
- **تعديل شريحة مقطوعة وتوقّع أن الأصل لا يتأثّر:** التقطيع يشارك الذاكرة؛ استخدم `slices.Clone`.
- **`make([]int, n)` ثم `append`:** تحصل على `n` أصفار **ثم** عناصرك. أردت غالبًا `make([]int, 0, n)`.
- **الفهرسة خارج الطول:** `s[len(s)]` تسبّب `panic: index out of range`، عكس C التي تقرأ بصمت.
- **إرجاع شريحة صغيرة من مصفوفة ضخمة:** تُبقي المصفوفة كلها في الذاكرة. انسخ الجزء الذي تحتاجه.
