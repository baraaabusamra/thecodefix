## النص في Go: بايتات UTF-8

النص (`string`) في Go سلسلة **بايتات** غير قابلة للتعديل، مكتوبة عادة بترميز UTF-8. في UTF-8 الحرف الإنجليزي بايت واحد، والحرف العربي **بايتان**. وهذا أهمّ ما تعرفه عن النصوص في Go، خصوصًا كمطوّر عربي:

```go
s := "مرحبا"
fmt.Println(len(s))                      // 10: عدد البايتات لا الحروف!
fmt.Println(utf8.RuneCountInString(s))   // 5: عدد الحروف الفعلي
```

`len` تعدّ البايتات دائمًا. لعدد الحروف استخدم `utf8.RuneCountInString` من حزمة `unicode/utf8`.

## rune: الحرف الحقيقي

`rune` اسم آخر لـ `int32`، ويمثّل **نقطة يونيكود** واحدة، أي حرفًا واحدًا مهما كان عدد بايتاته:

```go
s := "أهلا"

fmt.Println(s[0])                // 216: بايت، ونصف حرف "أ" فقط
for i, r := range s {
    fmt.Printf("%d: %c\n", i, r) // 0: أ ثم 2: ه ثم 4: ل ثم 6: ا
}
```

- **الفهرسة** `s[i]` تُرجع **بايتًا**، وليس حرفًا.
- **`range` على نص** يفكّ UTF-8 ويُرجع حروفًا (`rune`)، والفهرس `i` هو موضع البايت الذي يبدأ عنده الحرف، لذلك يقفز 0 ثم 2 ثم 4.

### قصّ النصوص العربية بأمان

```go
s := "مرحبا بالعالم"
// fmt.Println(s[:3])     // ❌ يقصّ في منتصف حرف: يطبع رمزًا مكسورًا
r := []rune(s)
fmt.Println(string(r[:5]))   // ✅ مرحبا
```

التحويل إلى `[]rune` يعطيك شريحة حروف تقدر تفهرسها وتقصّها بأمان، ثم `string(...)` تعيدها نصًّا. لها كلفة (نسخ النص كله)، فاستخدمها حين تحتاج فعلًا العمل بالحروف.

## حزمة strings

```go
fmt.Println(strings.ToUpper("go"))                // GO
fmt.Println(strings.Contains("golang", "go"))     // true
fmt.Println(strings.ReplaceAll("a-b-c", "-", "_"))// a_b_c
fmt.Println(strings.Split("a,b,c", ","))          // [a b c]
fmt.Println(strings.Join([]string{"x", "y"}, "+"))// x+y
fmt.Println(strings.TrimSpace("  hi  "))          // hi
fmt.Println(strings.HasPrefix("golang", "go"))    // true
fmt.Println(strings.Index("golang", "lang"))      // 2
fmt.Println(strings.Fields("  a  b   c "))        // [a b c]
```

كل هذه الدوال تعمل صحيحًا مع العربية لأنها تتعامل مع UTF-8. لاحظ أن `Index` تُرجع موضع **بايت** لا حرف، وتُرجع `-1` إذا لم تجد النص.

### مثال: تحليل سطر إعدادات

```go
line := "  port = 8080  "
key, value, found := strings.Cut(line, "=")
if found {
    fmt.Printf("[%s] = [%s]\n", strings.TrimSpace(key), strings.TrimSpace(value))
}
// [port] = [8080]
```

`strings.Cut` تقسم النص عند أول ظهور للفاصل وتُرجع الجزأين، وهي أبسط من `Split` حين تتوقّع جزأين بالضبط.

## النصوص غير قابلة للتعديل

```go
s := "hello"
// s[0] = 'H'          // ❌ cannot assign to s[0]
b := []byte(s)
b[0] = 'H'
s = string(b)
fmt.Println(s)         // Hello
```

كل "تعديل" على نص يُنشئ نصًّا جديدًا. لهذا بناء نص كبير بـ `+=` داخل حلقة بطيء: كل دورة تنسخ كل ما سبق.

## بناء النصوص بكفاءة: strings.Builder

```go
var sb strings.Builder
for i := 1; i <= 3; i++ {
    fmt.Fprintf(&sb, "سطر %d\n", i)
}
sb.WriteString("النهاية")
fmt.Println(sb.String())
```

`strings.Builder` يجمّع الأجزاء في مخزن واحد يكبر تدريجيًا، ثم `String()` تعطيك النتيجة مرة واحدة. استخدمه حين تبني نصًّا في حلقة.

## التنسيق

```go
name := "براء"
msg := fmt.Sprintf("مرحبًا %s، عمرك %d", name, 25)
fmt.Println(msg)
fmt.Printf("%q\n", "سطر\tمع tab")   // يطبع النص بين علامات تنصيص مع رموز الهروب
```

`%q` مفيدة جدًّا للتصحيح: تُظهر المسافات والرموز المخفية في النص.

## أخطاء شائعة

- **`len(s)` لعدد الحروف:** يعدّ البايتات. استخدم `utf8.RuneCountInString`.
- **`s[i]` لقراءة حرف عربي:** يُرجع بايتًا من منتصف الحرف. استخدم `range` أو `[]rune`.
- **القصّ `s[:n]` على نص عربي:** قد يكسر الحرف الأخير.
- **`+=` في حلقة كبيرة:** بطيء؛ استخدم `strings.Builder`.
- **`strings.Replace` بدون `-1`:** المعامل الأخير عدد مرّات الاستبدال؛ لاستبدال الكل استخدم `strings.ReplaceAll`.
