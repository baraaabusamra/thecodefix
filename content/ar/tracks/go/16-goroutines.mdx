## ما هي الـ Goroutine؟

دالة تعمل **في نفس الوقت** مع باقي البرنامج. تكتب `go` قبل أي استدعاء، فيبدأ في الخلفية ويكمل البرنامج فورًا بلا انتظار:

```go
func sayHello(name string) {
    fmt.Println("مرحبًا", name)
}

func main() {
    go sayHello("سارة")   // تبدأ في الخلفية
    sayHello("براء")      // تعمل الآن في main
    time.Sleep(100 * time.Millisecond)   // للتوضيح فقط: انظر الأسفل
}
```

الـ goroutine ليست خيط نظام تشغيل (thread). هي أخفّ بكثير: تبدأ بمكدّس صغير جدًّا (بضعة كيلوبايتات) يكبر عند الحاجة، و**بيئة تشغيل Go** (runtime) توزّعها على عدد قليل من الخيوط الحقيقية. لهذا تقدر تشغّل **مئات الآلاف** منها، بينما الخيوط الحقيقية تكلّف ميغابايتات لكل واحد.

## دالة مجهولة كـ goroutine

```go
go func() {
    fmt.Println("مهمّة في الخلفية")
}()   // لاحظ () في الآخر: نستدعي الدالة
```

## المشكلة الأولى: البرنامج لا ينتظر

```go
func main() {
    go fmt.Println("قد لا تظهر أبدًا!")
}
```

حين تنتهي `main` ينتهي البرنامج كله فورًا، ومعه كل الـ goroutines التي لم تكمل. `time.Sleep` في المثال الأول "تعمل" بالصدفة: لا أحد يضمن أن 100 ملّي ثانية تكفي. الطريقة الصحيحة هي **المزامنة**: انتظار صريح حتى تنتهي.

## الانتظار الصحيح: sync.WaitGroup

```go
func main() {
    var wg sync.WaitGroup
    urls := []string{"a.com", "b.com", "c.com"}

    for _, u := range urls {
        wg.Add(1)              // سجّل مهمة قبل تشغيلها
        go func() {
            defer wg.Done()    // أعلن انتهاءها مهما حدث
            fmt.Println("جلب", u)
        }()
    }

    wg.Wait()                  // انتظر حتى ينتهي الكل
    fmt.Println("انتهى الكل")
}
```

ترتيب أسطر "جلب" سيختلف بين تشغيل وآخر: هذا طبيعي، فالـ goroutines تعمل بلا ترتيب مضمون. ومنذ Go 1.25 يوجد اختصار `wg.Go(func() { ... })` يجمع `Add` و`go` و`Done` في سطر واحد. التفاصيل في [درس المزامنة](/learn/go/18-sync).

### متغيّر الحلقة: تغيّر في Go 1.22

استخدمنا `u` مباشرة داخل الـ goroutine. منذ **Go 1.22** كل دورة لها نسخة جديدة من متغيّر الحلقة، فهذا آمن. في الإصدارات الأقدم كانت كل الدورات تشترك في متغيّر واحد، فتطبع الـ goroutines غالبًا آخر قيمة ثلاث مرات، وكان الحل تمريره كمعامل: `go func(u string) { ... }(u)`. ستراه كثيرًا في كود قديم، وهو يعمل في الإصدارات الحديثة أيضًا.

## مثال عملي: معالجة متوازية مع جمع النتائج

```go
func square(n int) int {
    time.Sleep(50 * time.Millisecond)   // نتظاهر بعمل بطيء (طلب شبكة مثلًا)
    return n * n
}

func main() {
    nums := []int{1, 2, 3, 4, 5}
    results := make([]int, len(nums))
    var wg sync.WaitGroup

    start := time.Now()
    for i, n := range nums {
        wg.Add(1)
        go func() {
            defer wg.Done()
            results[i] = square(n)   // كل goroutine تكتب في خانتها فقط: آمن
        }()
    }
    wg.Wait()

    fmt.Println(results)                                 // [1 4 9 16 25]
    fmt.Println(time.Since(start) < 200*time.Millisecond) // true: ~50ms لا 250ms
}
```

خمس مهام بطيئة اكتملت في وقت مهمّة واحدة تقريبًا. وكتابة كل goroutine في **فهرس مختلف** من الشريحة آمنة؛ أما كتابة عدّة goroutines في **نفس** المتغيّر فهي سباق بيانات يحتاج قفلًا أو قناة.

## التزامن ليس التوازي

- **التزامن (Concurrency):** تنظيم عدّة مهام **تتقدّم معًا**، مثل نادل يخدم عدّة طاولات.
- **التوازي (Parallelism):** تنفيذ عدّة مهام **في نفس اللحظة** على أنوية مختلفة.

Go تعطيك التزامن بالـ goroutines، والـ runtime يحوّله لتوازٍ حقيقي حين تتوفّر أنوية. والفائدة الأكبر في الخوادم ليست الحساب بل **الانتظار**: آلاف الطلبات تنتظر قاعدة البيانات أو الشبكة، وكل واحدة في goroutine لا تكلّف شيئًا وهي تنتظر. هكذا يخدم `net/http` كل طلب في goroutine خاصة به تلقائيًا.

## أخطاء شائعة

- **الاعتماد على `time.Sleep` للانتظار:** يعمل على جهازك ويفشل تحت الضغط. استخدم `WaitGroup` أو القنوات.
- **`wg.Add(1)` داخل الـ goroutine:** قد يصل `Wait` قبلها فلا ينتظر شيئًا. استدعِ `Add` **قبل** `go`.
- **عدّة goroutines تكتب نفس المتغيّر:** سباق بيانات (data race). شغّل `go run -race` لاكتشافه.
- **goroutine لا تنتهي أبدًا (goroutine leak):** تنتظر قناة لن يُرسَل عليها شيء، فتبقى في الذاكرة طوال عمر البرنامج. لكل goroutine طريق خروج واضح ([درس context](/learn/go/26-context)).
- **إطلاق goroutine لكل شيء:** للعمل الصغير جدًّا، كلفة التنسيق أكبر من الفائدة.
