## العوامل الحسابية

```go
a, b := 10, 3
a + b   // 13
a - b   // 7
a * b   // 30
a / b   // 3 (قسمة صحيحة)
a % b   // 1 (الباقي)
```

## الإسناد

```go
a += 5    // a = a + 5
a -= 2
a *= 3
a++       // زيادة (جملة، ليست تعبيرًا)
a--
```

> ⚠️ في Go، `a++` جملة مستقلّة — لا يمكن `b := a++`.

## المقارنة

```go
a == b    a != b
a > b     a < b
a >= b    a <= b
```

تعيد `bool`.

## المنطقية

```go
x := (a > 5) && (b < 5)   // و
y := (a > 5) || (b > 5)   // أو
z := !x                    // نفي
```

## عوامل البِت

```go
a & b    // AND
a | b    // OR
a ^ b    // XOR
a << 1   // إزاحة يسار
a >> 1   // إزاحة يمين
```

## الأولوية

استخدم الأقواس للوضوح:

```go
result := (a + b) * 2
```
