## الخاصّية المميّزة

في كل عقدة: كل القيم في الفرع **الأيسر أصغر**، وكل القيم في **الأيمن أكبر**.

```
        8
       / \
      3   10
     / \    \
    1   6    14
```

## البحث

```python
def search(node, target):
    if not node or node.value == target:
        return node
    if target < node.value:
        return search(node.left, target)
    return search(node.right, target)
```

نتجاهل نصف الشجرة في كل خطوة → `O(log n)` للشجرة المتوازنة.

## التعقيد

| العملية | متوازنة | غير متوازنة |
|------|------|------|
| البحث/الإدراج/الحذف | `O(log n)` | `O(n)` |

## الأشجار المتوازنة

شجرة منحرفة (كقائمة) تفقد الكفاءة. أشجار مثل **AVL** و**Red-Black** تحافظ على التوازن تلقائيًا.

> 🎯 التالي: الأكوام (Heaps).
