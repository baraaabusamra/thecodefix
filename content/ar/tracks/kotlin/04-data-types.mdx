## val مقابل var

```kotlin
val name = "براء"   // ثابت (لا يتغيّر) — مفضّل
var age = 25        // متغيّر (يمكن تغييره)
age = 26
// name = "سارة"    // خطأ ترجمة: val لا يُعاد إسناده
```

> 💡 فضّل `val` دائمًا واستخدم `var` فقط عند الحاجة للتغيير. كلما قلّت المتغيّرات التي تتغيّر، سهل تتبّع الكود.

### `val` يعني "المرجع ثابت"، لا "الكائن ثابت"

`val` يمنع إعادة الإسناد فقط. إذا كان الكائن نفسه قابلًا للتعديل، تقدر تعدّله:

```kotlin
val cart = mutableListOf("قلم")
cart.add("دفتر")          // ✅ مسموح: عدّلنا محتوى القائمة
// cart = mutableListOf() // ❌ ممنوع: إسناد قائمة جديدة
```

## الأنواع الأساسية

```kotlin
val i: Int = 42
val l: Long = 9999999999
val d: Double = 3.14
val f: Float = 3.14f        // Float يحتاج اللاحقة f
val b: Boolean = true
val c: Char = 'أ'
val s: String = "نص"
```

| النوع | يخزّن | ملاحظة |
| --- | --- | --- |
| `Int` | عدد صحيح | من -2,147,483,648 إلى 2,147,483,647 |
| `Long` | عدد صحيح كبير | للأرقام الأكبر (أوقات بالمللي ثانية، معرّفات) |
| `Double` | عدد عشري | الافتراضي لأي رقم بفاصلة |
| `Float` | عدد عشري أقل دقة | يحتاج `f`: `3.14f` |
| `Boolean` | `true` أو `false` | |
| `Char` | حرف واحد | بعلامة مفردة `'أ'` |
| `String` | نص | بعلامة مزدوجة `"نص"` |

### تجاوز حدود Int

إذا تجاوزت النتيجة أكبر قيمة لـ `Int`، لا يحدث خطأ: الرقم "يلتفّ" بصمت إلى السالب.

```kotlin
val max = Int.MAX_VALUE      // 2147483647
println(max + 1)             // -2147483648
println(max.toLong() + 1)    // 2147483648 ✅
```

لذلك استخدم `Long` لأي قيمة قد تكبر (مجاميع مالية، أوقات بالمللي ثانية).

## استنتاج النوع

Kotlin تستنتج النوع غالبًا:

```kotlin
val count = 10        // Int
val big = 3_000_000_000  // Long تلقائيًا، لأنه أكبر من حد Int
val price = 9.99      // Double
val active = true     // Boolean
```

النوع يُحدَّد **مرة واحدة** عند التعريف ولا يتغيّر: `var count = 10` ثم `count = "عشرة"` خطأ ترجمة.

## التحويل بين الأنواع

Kotlin لا تحوّل بين الأنواع الرقمية تلقائيًا، حتى من الأصغر للأكبر. التحويل دائمًا صريح:

```kotlin
val x = 10
val y: Double = x.toDouble()
// val z: Double = x       // خطأ ترجمة: Int ليس Double
```

### من نص إلى رقم: `toInt()` أم `toIntOrNull()`؟

```kotlin
"42".toInt()           // 42
"abc".toInt()          // ❌ NumberFormatException ويتوقّف البرنامج
"abc".toIntOrNull()    // null — بدون انهيار

val age = "abc".toIntOrNull() ?: 0   // 0 كقيمة بديلة
```

استخدم `toInt()` فقط إذا كنت متأكدًا أن النص رقم، و`toIntOrNull()` لأي نص جاء من المستخدم أو من ملف أو شبكة. علامة `?:` تعطي قيمة بديلة عند `null`، وتفاصيلها في الدرس القادم.

## أخطاء شائعة

- **`val price: Float = 9.99`:** خطأ ترجمة، لأن `9.99` من نوع `Double`. اكتب `9.99f`.
- **`Int` لأرقام كبيرة:** تلتفّ بصمت إلى قيمة سالبة بدل أن تعطي خطأ.
- **`toInt()` على إدخال المستخدم:** أول حرف غير رقمي ينهي البرنامج.
