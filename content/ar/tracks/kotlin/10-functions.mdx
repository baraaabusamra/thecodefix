## دالة أساسية

```kotlin
fun add(a: Int, b: Int): Int {
    return a + b
}
```

كل جزء له معنى: `fun` كلمة التعريف، ثم الاسم، ثم المعاملات وكل واحد بنوعه، ثم نوع القيمة المُرجعة بعد `:`. أنواع المعاملات **إجبارية** دائمًا، لأن Kotlin لا تستنتجها من طريقة الاستدعاء.

## دالة تعبير واحد

```kotlin
fun add(a: Int, b: Int) = a + b   // النوع يُستنتج
```

إذا كان جسم الدالة تعبيرًا واحدًا، تحذف الأقواس و`return` وتكتب `=`. مناسبة للدوال القصيرة الواضحة؛ أمّا إذا احتاجت الدالة عدّة خطوات أو شروطًا، فالجسم العادي أوضح.

## دوال لا تُرجع شيئًا: Unit

```kotlin
fun log(message: String) {
    println("[LOG] $message")
}
```

لم نكتب نوع إرجاع، فهو `Unit` تلقائيًا: معناه "لا قيمة مفيدة"، مثل `void` في Java. كتابة `: Unit` صراحةً جائزة لكنها غير ضرورية.

## المعاملات الافتراضية

```kotlin
fun greet(name: String, greeting: String = "أهلًا") {
    println("$greeting $name")
}

greet("براء")              // أهلًا براء
greet("سارة", "مرحبًا")    // مرحبًا سارة
```

## المعاملات المسمّاة

```kotlin
fun createUser(name: String, age: Int, active: Boolean = true) {}

createUser(name = "براء", age = 25)   // وضوح وترتيب حرّ
```

قيمتها الحقيقية تظهر مع القيم المنطقية والأرقام، حيث الاستدعاء بدون أسماء غامض:

```kotlin
sendEmail("a@b.com", true, false)                          // ما معنى true و false؟
sendEmail("a@b.com", urgent = true, copyToSender = false)  // واضح بدون فتح تعريف الدالة
```

ومع القيم الافتراضية، تقدر تتخطّى معاملًا في الوسط وتحدّد ما بعده بالاسم:

```kotlin
fun book(room: String, nights: Int = 1, breakfast: Boolean = false) {}

book("101", breakfast = true)   // nights تأخذ قيمتها الافتراضية 1
```

## عدد متغيّر من المعاملات (vararg)

```kotlin
fun sum(vararg nums: Int): Int {
    return nums.sum()
}
sum(1, 2, 3, 4)   // 10
```

داخل الدالة يكون `nums` مصفوفة. وإذا كانت عندك مصفوفة جاهزة، مرّرها بعامل النشر `*`:

```kotlin
val values = intArrayOf(5, 10)
sum(*values)          // 15
sum(1, *values, 2)    // 18
```

## دوال داخل دوال

تقدر تعرّف دالة داخل دالة أخرى، فتكون مرئية هناك فقط. مفيد لخطوة مساعدة لا يحتاجها أحد غير هذه الدالة:

```kotlin
fun register(name: String, email: String) {
    fun requireNotBlank(value: String, field: String) {
        require(value.isNotBlank()) { "$field مطلوب" }
    }

    requireNotBlank(name, "الاسم")
    requireNotBlank(email, "البريد")
    // ... حفظ المستخدم
}
```

> 💡 المعاملات الافتراضية والمسمّاة تغني عن كتابة دوال متعدّدة (overloads) كما في Java.

## أخطاء شائعة

- **دالة تعبير واحد بنوع إرجاع غير متوقّع:** `fun total() = items.size > 0` تُرجع `Boolean` لا `Int`. حين يكون النوع مهمًّا، اكتبه صراحة.
- **خلط المعاملات المسمّاة وغير المسمّاة بترتيب خاطئ:** بعد أول معامل بالاسم، الأسلم أن تسمّي كل ما بعده.
- **تمرير مصفوفة لـ vararg بدون `*`:** `sum(values)` خطأ ترجمة؛ اكتب `sum(*values)`.
