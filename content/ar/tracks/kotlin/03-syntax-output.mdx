## أصغر برنامج

```kotlin
fun main() {
    println("مرحبًا بالعالم")
}
```

- `fun` تعرّف دالة، و`main` نقطة البداية.
- لا حاجة للفاصلة المنقوطة في نهاية السطر.

## الطباعة

```kotlin
println("سطر مع نزول")
print("بلا نزول")
```

## قوالب النصوص (String Templates)

```kotlin
val name = "براء"
println("أهلًا $name")
println("الناتج: ${2 + 3}")
```

## التعليقات

```kotlin
// تعليق سطر
/* تعليق
   متعدّد الأسطر */
```

> 💡 Kotlin موجزة جدًّا: لا تحتاج فواصل منقوطة ولا كلاسًا حاويًا مثل Java لبرنامج بسيط.
