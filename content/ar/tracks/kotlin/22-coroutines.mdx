## ما هي الكوروتينات؟

طريقة Kotlin للبرمجة غير المتزامنة بكفاءة وبكود يبدو متسلسلًا — أخفّ بكثير من الخيوط.

المشكلة التي تحلّها: طلب شبكة يأخذ ثانية. إذا انتظرته على الخيط الرئيسي تتجمّد الواجهة. الحل التقليدي خيوط إضافية أو دوال callback متداخلة يصعب قراءتها. الكوروتين **يتوقّف مؤقتًا** عند الانتظار ويحرّر الخيط لعمل آخر، ثم يكمل من نفس السطر حين تصل النتيجة. والكود يُكتب سطرًا بعد سطر كأنه عادي.

> 📦 الكوروتينات ليست جزءًا من اللغة الأساسية: تحتاج مكتبة `kotlinx-coroutines-core` في مشروعك (في أندرويد تأتي مع مكتبات Jetpack عادة).

## دالة suspend

```kotlin
import kotlinx.coroutines.*

suspend fun fetchData(): String {
    delay(1000)              // انتظار غير محظور
    return "البيانات جاهزة"
}
```

`delay` لا يحظر الخيط (بخلاف Thread.sleep).

`suspend` تعني "هذه الدالة قد تتوقّف مؤقتًا". لذلك تُستدعى فقط من داخل كوروتين أو من دالة `suspend` أخرى؛ استدعاؤها من دالة عادية خطأ ترجمة.

## launch — تشغيل في الخلفية

```kotlin
fun main() = runBlocking {
    launch {
        println(fetchData())
    }
    println("يعمل بالتوازي")
}
```

`runBlocking` يحظر الخيط الحالي حتى ينتهي كل ما بداخله. مناسب لـ `main` في الأمثلة وفي الاختبارات فقط، **لا** داخل تطبيق أندرويد أو خادم.

## async — نتيجة متوازية

```kotlin
runBlocking {
    val a = async { fetchData() }
    val b = async { fetchData() }
    println(a.await() + b.await())   // معًا
}
```

مع `async` تبدأ العمليتان معًا، فيأخذ المجموع حوالي ثانية واحدة لا ثانيتين. `launch` لا تُرجع نتيجة (تُرجع `Job` للتحكّم فقط)، و`async` تُرجع `Deferred` تأخذ قيمتها بـ `await()`.

| تريد | استخدم |
| --- | --- |
| تشغيل عمل لا تحتاج نتيجته (حفظ، إرسال) | `launch` |
| نتيجة ستستخدمها لاحقًا، خاصة عدّة نتائج معًا | `async` + `await` |

## على أي خيط؟ Dispatchers

```kotlin
withContext(Dispatchers.IO) {
    // قراءة ملف أو طلب شبكة
}
```

- `Dispatchers.Main`: خيط الواجهة في أندرويد، لتحديث العناصر.
- `Dispatchers.IO`: للانتظار على شبكة أو ملفات أو قاعدة بيانات.
- `Dispatchers.Default`: لحسابات ثقيلة على المعالج.

## التزامن المنظَّم (Structured Concurrency)

كل كوروتين يعيش داخل **نطاق** (scope). إذا أُلغي النطاق، تُلغى كل الكوروتينات بداخله تلقائيًّا، وإذا فشل أحد الأبناء يصل الخطأ للأب. هذا يمنع العمل "اليتيم" الذي يستمر بعد أن يغلق المستخدم الشاشة.

## في أندرويد

الكوروتينات أساس العمليات غير المتزامنة في أندرويد (شبكة، قاعدة بيانات) دون تجميد الواجهة. والنطاقات الجاهزة مثل `viewModelScope` تُلغي العمل تلقائيًّا حين تُغلق الشاشة:

```kotlin
viewModelScope.launch {
    val user = repository.loadUser()   // دالة suspend
    _state.value = user
}
```

## أخطاء شائعة

- **`GlobalScope.launch`:** كوروتين لا يرتبط بأي شاشة أو طلب، فيستمر حتى بعد أن تنتهي الحاجة إليه، وأخطاؤه لا تصل لأحد. استخدم نطاقًا مرتبطًا بدورة الحياة.
- **`Thread.sleep` داخل كوروتين:** يحظر الخيط كله. استخدم `delay`.
- **`runBlocking` داخل التطبيق:** يجمّد الخيط الذي يعمل عليه، وعلى الخيط الرئيسي يجمّد الواجهة.
- **طلب شبكة على `Dispatchers.Main`:** يجمّد الواجهة؛ انقله إلى `Dispatchers.IO`.
