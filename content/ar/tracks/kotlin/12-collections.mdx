## أي مجموعة أختار؟

| تحتاج | استخدم | مثال |
| --- | --- | --- |
| عناصر مرتّبة، يُسمح بالتكرار، وصول بالفهرس | `List` | قائمة مهام، نتائج بحث |
| قيم فريدة بلا تكرار | `Set` | وسوم مقال، معرّفات زُوّار |
| ربط مفتاح بقيمة | `Map` | اسم ← عمر، كود دولة ← اسمها |

## القوائم (List)

```kotlin
val fruits = listOf("تفاح", "موز")     // غير قابلة للتعديل
println(fruits[0])                      // تفاح
println(fruits.size)

val mutable = mutableListOf(1, 2, 3)
mutable.add(4)
mutable.remove(1)
```

## المجموعات (Set) — قيم فريدة

```kotlin
val unique = setOf(1, 2, 2, 3)   // {1, 2, 3}
val ms = mutableSetOf<Int>()
ms.add(5)
```

أسرع طريقة لحذف التكرار من قائمة: `listOf(3, 1, 3, 2).toSet()` أو `.distinct()` إذا أردت قائمة.

## الخرائط (Map)

```kotlin
val ages = mapOf("براء" to 25, "سارة" to 22)
println(ages["براء"])            // 25

val mm = mutableMapOf<String, Int>()
mm["علي"] = 30
```

### `ages["x"]` تُرجع قيمة قد تكون null

المفتاح قد لا يكون موجودًا، لذلك نوع `ages["براء"]` هو `Int?` لا `Int`:

```kotlin
val a = ages["خالد"]                       // null — المفتاح غير موجود
val b = ages["خالد"] ?: 0                  // 0 كقيمة بديلة
val c = ages.getOrDefault("خالد", 0)       // نفس الشيء
val d = ages.getValue("براء")              // 25 — ويرمي NoSuchElementException إن لم يوجد
```

المرور على الخريطة:

```kotlin
for ((name, age) in ages) {
    println("$name: $age")
}
```

## الثابت مقابل القابل للتعديل

- `listOf` / `setOf` / `mapOf` → للقراءة فقط (مفضّلة).
- `mutableListOf` / ... → قابلة للتعديل.

> 💡 فضّل المجموعات غير القابلة للتعديل ما لم تحتج التغيير — أأمن.

### "للقراءة فقط" ≠ "ثابتة"

نوع `List` يمنعك **أنت** من التعديل عبر هذا المتغيّر، لكنه لا يضمن أن القائمة لن تتغيّر. إذا كانت في الأصل `MutableList` وعدّلها أحد عبر مرجع آخر، يرى الكل التغيير:

```kotlin
val source = mutableListOf(1, 2)
val view: List<Int> = source   // نفس القائمة، بنوع للقراءة فقط
source.add(3)
println(view)                   // [1, 2, 3]
```

إذا أردت نسخة مستقلة لا تتأثر، انسخها: `val snapshot = source.toList()`.

### `val` و`var` شيء، و`mutable` شيء آخر

```kotlin
val a = mutableListOf(1)   // المتغيّر ثابت، المحتوى يتغيّر: a.add(2) ✅
var b = listOf(1)          // المتغيّر يتغيّر، المحتوى لا: b = b + 2 ✅  b.add(2) ❌
```

الأوضح غالبًا: `val` مع `listOf`، وتغيّر المجموعة فقط حين تحتاج فعلًا.

## أخطاء شائعة

- **`list[5]` على قائمة من 3 عناصر:** `IndexOutOfBoundsException`. استخدم `getOrNull(5)` إن لم تكن متأكدًا.
- **التعامل مع `map[key]` كأنها `Int`:** نوعها `Int?`؛ أعطِ قيمة بديلة بـ `?:`.
- **ظن أن `List` ثابتة تمامًا:** هي للقراءة فقط عبر هذا المرجع؛ انسخ بـ `toList()` إن احتجت لقطة ثابتة.
