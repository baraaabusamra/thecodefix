## if تعبير (يُرجع قيمة)

```kotlin
val n = 7
if (n > 5) {
    println("كبير")
} else {
    println("صغير")
}

val max = if (n > 5) n else 0   // if كقيمة
```

في Kotlin، `if` ليست جملة فقط بل **تعبير** يُرجع قيمة، لذلك لا يوجد فيها العامل الثلاثي `? :` الموجود في Java وC. وإذا استخدمت `if` كقيمة فـ `else` **إجبارية**، لأن المتغيّر يحتاج قيمة في كل الحالات:

```kotlin
// val label = if (n > 5) "كبير"        // خطأ ترجمة: ماذا لو لم يتحقّق الشرط؟
val label = if (n > 5) "كبير" else "صغير"
```

ومع الكتل، آخر سطر في الكتلة هو القيمة:

```kotlin
val fee = if (n > 5) {
    println("رسوم عالية")
    100          // هذه القيمة
} else {
    50
}
```

## when (بديل switch الأقوى)

```kotlin
val day = 3
when (day) {
    1 -> println("الاثنين")
    2, 3 -> println("الثلاثاء أو الأربعاء")
    in 4..5 -> println("نهاية الأسبوع")
    else -> println("يوم آخر")
}
```

ميزات تجعلها أقوى من `switch`:
- لا حاجة لـ `break`: يُنفَّذ الفرع المطابق الأول فقط، ولا "تسقط" للفرع التالي.
- عدّة قيم في فرع واحد بالفاصلة (`2, 3`)، ونطاقات (`in 4..5`)، وأنواع (`is String`).

`when` أيضًا تعبير يُرجع قيمة:

```kotlin
val grade = when {
    n >= 90 -> "ممتاز"
    n >= 60 -> "ناجح"
    else -> "راسب"
}
```

### when بدون وسيط

لاحظ أن المثال الأخير لا يحتوي `when (x)`. بدون وسيط، كل فرع شرط منطقي كامل، والأول الصحيح يفوز. هذا بديل أوضح من سلسلة طويلة من `if / else if`.

### when الشاملة

حين تُستخدم `when` كقيمة، يجب أن تغطي **كل** الحالات. مع الأرقام والنصوص هذا مستحيل بدون `else`. أمّا مع `Boolean` أو `enum` أو أصناف `sealed`، فيعرف المترجم كل القيم الممكنة، فلا تحتاج `else`:

```kotlin
enum class Light { RED, YELLOW, GREEN }

fun action(l: Light) = when (l) {
    Light.RED -> "قف"
    Light.YELLOW -> "استعد"
    Light.GREEN -> "انطلق"
}   // بدون else — وإذا أضفت لونًا جديدًا للتعداد، ينبّهك المترجم هنا
```

هذه ميزة حقيقية: إضافة قيمة جديدة تكشف لك فورًا كل مكان نسيت أن تعالجها فيه. (تفاصيل enum وsealed في درس لاحق.)

## النطاقات (Ranges)

```kotlin
val r = 1..10        // 1 إلى 10
println(5 in r)      // true
val down = 10 downTo 1
val step = 1..10 step 2
```

## أخطاء شائعة

- **`if` كقيمة بدون `else`:** خطأ ترجمة.
- **إضافة `else` في `when` على enum:** تعمل، لكنها تُسكت تنبيه المترجم عند إضافة قيمة جديدة. اتركها بدون `else` إن كنت تغطي كل القيم.
- **ترتيب الفروع:** في `when` بدون وسيط، الأول الصحيح يفوز. `n >= 60` قبل `n >= 90` يجعل الـ 95 "ناجح".
