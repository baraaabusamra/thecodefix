## الحسابية

```kotlin
println(10 + 3)   // 13
println(10 - 3)   // 7
println(10 * 3)   // 30
println(10 / 3)   // 3 (قسمة صحيحة)
println(10 % 3)   // 1
```

## المقارنة

`==`، `!=`، `>`، `<`، `>=`، `<=`.

> 💡 في Kotlin `==` يقارن **القيم** (يستدعي equals)، و`===` يقارن **المرجع** (نفس الكائن).

```kotlin
val a = "hi"
val b = "hi"
println(a == b)    // true (نفس القيمة)
```

## المنطقية

```kotlin
val x = 5
println(x > 0 && x < 10)   // و
println(x < 0 || x > 3)    // أو
println(!(x == 5))         // نفي
```

## الإسناد المختصر

```kotlin
var n = 5
n += 3    // 8
n++       // 9
```
