## أوّل برنامج

```swift
print("مرحبًا بالعالم")
```

Swift لا تحتاج دالة `main` صريحة في ملف بسيط، ولا فاصلة منقوطة في نهاية السطر.

## الطباعة وقوالب النصوص

```swift
let name = "براء"
let age = 25
print("أهلًا \(name)")
print("بعد سنة: \(age + 1)")
```

الإدراج في Swift يكون بـ `\(expression)`.

## التعليقات

```swift
// تعليق سطر
/* تعليق
   متعدّد الأسطر */
```

## القواعد الأساسية

- حسّاسة لحالة الأحرف.
- الاصطلاح: camelCase للمتغيّرات والدوال، PascalCase للأنواع.

> 💡 Swift لغة آمنة وحديثة من Apple، تجمع بين الأداء وسهولة القراءة.
