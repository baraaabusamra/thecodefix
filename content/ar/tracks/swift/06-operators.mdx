## الحسابية

```swift
print(10 + 3)   // 13
print(10 - 3)   // 7
print(10 * 3)   // 30
print(10 / 3)   // 3 (قسمة صحيحة بين Int)
print(10 % 3)   // 1
```

## المقارنة

`==`، `!=`، `>`، `<`، `>=`، `<=`.

## المنطقية

```swift
let x = 5
print(x > 0 && x < 10)   // و
print(x < 0 || x > 3)    // أو
print(!(x == 5))         // نفي
```

## النطاقات (Ranges)

```swift
let closed = 1...5      // 1 إلى 5 (شامل)
let half = 1..<5        // 1 إلى 4
for i in 1...3 { print(i) }
```

## الإسناد المختصر

```swift
var n = 5
n += 3    // 8
```

> ⚠️ Swift صارمة في الأنواع: لا يمكن جمع Int و Double مباشرة — حوّل أوّلًا.
