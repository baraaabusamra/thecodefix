> 💡 هذا الدرس يبني على أساسيات `docker run` و`docker ps` من درس
> [الصور والحاويات](/learn/docker/01-images-containers) — هنا نتعمّق في دورة حياة الحاوية والمراقبة والتشخيص.

## تشغيل حاوية

```bash
docker run -d --name web nginx     # -d في الخلفية، --name اسم
docker run -it ubuntu bash         # -it جلسة تفاعلية
```

## إدارة دورة الحياة

```bash
docker ps                 # العاملة
docker stop web           # إيقاف
docker start web          # تشغيل من جديد
docker restart web        # إعادة تشغيل
docker rm web             # حذف (بعد الإيقاف)
docker rm -f web          # حذف إجباري
```

## الدخول والمراقبة

```bash
docker exec -it web bash  # تنفيذ أمر داخل الحاوية
docker logs web           # سجلّات الحاوية
docker logs -f web        # متابعة حيّة
docker stats              # استهلاك المعالج/الذاكرة
```
