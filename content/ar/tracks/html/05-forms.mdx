## ما هو النموذج؟

النموذج `<form>` هو الطريقة التي نجمع بها بيانات المستخدم: تسجيل دخول،
تواصل، بحث... إلخ.

```html
<form>
  <label for="name">الاسم:</label>
  <input type="text" id="name" placeholder="اكتب اسمك" />

  <label for="email">البريد:</label>
  <input type="email" id="email" />

  <button type="submit">إرسال</button>
</form>
```

## أنواع حقول الإدخال

الخاصية `type` تغيّر سلوك `<input>`:

| النوع | الاستخدام |
|-------|-----------|
| `text` | نص عادي |
| `email` | بريد إلكتروني (تحقّق تلقائي) |
| `password` | كلمة مرور (مخفية) |
| `number` | أرقام فقط |
| `checkbox` | خانة اختيار |
| `radio` | اختيار واحد من عدة |

## لماذا `<label>` مهم؟

ربط `<label>` بالحقل عبر `for` و `id` يجعل النموذج:

- **أسهل** (النقر على النص يفعّل الحقل).
- **أفضل للوصول** (قارئات الشاشة).
