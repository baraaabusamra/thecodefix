## الروابط (Links)

نستخدم العنصر `<a>` (anchor) لإنشاء رابط، والخاصية `href` تحدّد الوجهة:

```html
<a href="https://thecodefix.com">زر موقعنا</a>
<a href="/learn">صفحة المسارات</a>
<a href="https://thecodefix.com" target="_blank">افتح في تبويب جديد</a>
```

- `href` = عنوان الوجهة (رابط خارجي أو مسار داخلي).
- `target="_blank"` = يفتح الرابط في تبويب جديد.

## الصور (Images)

نعرض الصور بالعنصر `<img>`، وهو عنصر **مغلق ذاتيًا** (بلا وسم نهاية):

```html
<img src="logo.png" alt="شعار The Code Fix" width="200" />
```

| الخاصية | الوظيفة |
|---------|---------|
| `src` | مسار الصورة |
| `alt` | وصف نصّي بديل (مهم للـ SEO وذوي الاحتياجات) |
| `width` / `height` | الأبعاد |

> ⚠️ لا تنسَ `alt` أبدًا — يصف الصورة لمحرّكات البحث وقارئات الشاشة، ويظهر
> إن فشل تحميل الصورة.

## رابط داخل صورة

يمكن جعل صورة قابلة للنقر بوضعها داخل رابط:

```html
<a href="/">
  <img src="logo.png" alt="العودة للرئيسية" />
</a>
```

> 🎯 التالي: القوائم لتنظيم المحتوى.
