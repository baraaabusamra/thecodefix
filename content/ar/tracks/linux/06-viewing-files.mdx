## أي أداة لأي ملف؟

| الحالة | الأداة |
| --- | --- |
| ملف قصير، تريد رؤيته كله | `cat` |
| ملف طويل، تريد التصفّح والبحث | `less` |
| بداية الملف فقط (عناوين أعمدة CSV مثلًا) | `head` |
| نهاية الملف (آخر الأحداث في سجلّ) | `tail` |
| سجلّ يُكتب الآن، تريد متابعته حيًّا | `tail -f` |

## cat: الطباعة الكاملة

```bash
cat config.yml          # كل المحتوى
cat -n script.sh        # مع أرقام الأسطر
cat header.txt body.txt > page.txt   # الاسم الحقيقي: concatenate، أي دمج ملفات
```

`cat` على ملف من مئة ألف سطر يُغرق الشاشة. ولا تستخدمها مع الملفات الثنائية (صور أو برامج): تطبع رموزًا عشوائية قد تخرّب عرض الطرفية. إذا حدث ذلك اكتب `reset`.

## less: التصفّح المريح

```bash
less /var/log/syslog
```

داخل `less`:

| المفتاح | يفعل |
| --- | --- |
| `Space` و`b` | صفحة للأمام وللخلف |
| `g` و`G` | بداية الملف ونهايته |
| `/كلمة` ثم `n` و`N` | بحث، ثم النتيجة التالية والسابقة |
| `F` | متابعة حيّة مثل `tail -f` (و`Ctrl+C` للعودة) |
| `q` | خروج |

`less` لا تحمّل الملف كله في الذاكرة، فتفتح ملفات بالجيجابايتات فورًا. وهي البرنامج نفسه الذي يعرض صفحات `man`.

## head و tail

```bash
head data.csv           # أول 10 أسطر
head -n 1 data.csv      # سطر العناوين فقط
tail -n 20 app.log      # آخر 20 سطرًا
tail -n +2 data.csv     # من السطر الثاني للنهاية: تخطّي العناوين
```

`tail -n +2` حيلة شائعة لمعالجة CSV بدون سطر العناوين.

## tail -f: مراقبة السجلّات حيًّا

```bash
tail -f /var/log/nginx/access.log
tail -F app.log                       # يستمرّ حتى لو أُعيد إنشاء الملف
tail -f app.log | grep --line-buffered ERROR   # الأخطاء فقط، لحظة حدوثها
```

`tail -f` تُبقي الملف مفتوحًا وتطبع كل سطر جديد فور كتابته. أشغّلها في نافذة، ثم أعيد طلب الصفحة في المتصفّح في نافذة أخرى، فأرى الطلب يظهر مباشرة. و`-F` الكبيرة أفضل للسجلّات التي "تُدوَّر" (rotated): يُنقل الملف القديم ويُنشأ جديد بنفس الاسم، فتتابع `-F` الجديد بينما تبقى `-f` عالقة على القديم.

## wc: العدّ

```bash
wc -l access.log        # عدد الأسطر: كم طلبًا وصل؟
wc -w essay.txt         # عدد الكلمات
grep -c ERROR app.log   # عدد الأسطر التي فيها ERROR
```

```bash
printf 'a\nb\nc\n' > three.txt
wc -l three.txt         # 3 three.txt
wc -l < three.txt       # 3 : بلا اسم الملف، أنسب للسكربتات
```

## مثال: فحص سريع لسجلّ خادم

```bash
wc -l /var/log/nginx/access.log                 # كم طلبًا اليوم؟
tail -n 5 /var/log/nginx/error.log              # آخر الأخطاء
grep -c " 500 " /var/log/nginx/access.log       # كم خطأ 500؟
```

ولتحليل أعمق (أكثر الصفحات طلبًا، أكثر العناوين زيارة) ستجمع هذه الأدوات مع `sort` و`uniq` في [درس معالجة النصوص](/learn/linux/09-text-processing).

## أخطاء شائعة

- **`cat` لملف ضخم:** تجمّد الطرفية دقائق. استخدم `less` أو `tail`.
- **`cat` لملف ثنائي:** شاشة مليئة بالرموز. اكتب `reset`، واستخدم `file` لمعرفة نوع الملف أولًا (`file image.png`).
- **`tail -f` على سجلّ يُدوَّر:** تتوقّف عن رؤية الجديد بصمت. استخدم `tail -F`.
- **`less` و"عالق":** اضغط `q`.
- **`cat file | grep`:** يعمل، لكن `grep pattern file` مباشرة أبسط.
