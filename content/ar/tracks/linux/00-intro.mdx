## ما هو Linux؟

**Linux** نظام تشغيل مفتوح المصدر، مجاني وقوي، يشغّل معظم **الخوادم** في
العالم، والهواتف (أندرويد مبني عليه)، والأنظمة المدمجة.

يأتي Linux في **توزيعات (Distributions)** متعدّدة مثل Ubuntu و Debian و
Fedora، تشترك كلها في النواة نفسها وتختلف في الأدوات والواجهة.

## لماذا يتعلّمه المطوّر؟

- معظم الخوادم تعمل بـ Linux — ستتعامل معه عند النشر.
- سطر الأوامر أسرع وأقوى من الواجهة الرسومية.
- أساسي لـ DevOps و [Docker](/learn/docker) والسحابة.

## ما هو سطر الأوامر (Terminal)؟

واجهة نصّية تكتب فيها **أوامر** للتحكّم بالنظام، بدل النقر بالفأرة. أسرع
وأكثر دقّة للمطوّرين.

## أول الأوامر

```bash
pwd        # أين أنا؟ (المجلد الحالي)
whoami     # من أنا؟ (اسم المستخدم)
date       # التاريخ والوقت
clear      # تنظيف الشاشة
```

## بنية الأمر

```bash
command -options arguments
```

مثال:

```bash
ls -l /home    # ls = الأمر، -l = خيار، /home = وسيط
```

## التنقّل بين المجلدات

```bash
ls          # عرض محتويات المجلد
cd /var     # الانتقال إلى مجلد
cd ..       # الرجوع للمجلد الأعلى
```

هذه الأوامر ستستخدمها في كل جلسة عمل على Linux.

## الحصول على مساعدة

```bash
man ls       # دليل الأمر الكامل
ls --help    # ملخّص سريع
```

## أسئلة شائعة

**هل أحتاج تثبيت Linux على جهازي؟**
يمكنك تجربته عبر آلة افتراضية أو WSL على ويندوز أو خادم سحابي — دون استبدال
نظامك الأساسي.

**هل سطر الأوامر صعب؟**
يبدو مخيفًا في البداية، لكن بضعة أوامر أساسية تغطّي معظم احتياجاتك اليومية.
