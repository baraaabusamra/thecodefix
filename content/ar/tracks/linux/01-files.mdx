## التنقّل بين المجلدات

```bash
ls            # عرض محتويات المجلد
ls -la        # عرض تفصيلي مع الملفات المخفية
cd /home      # الانتقال لمجلد
cd ..         # المجلد الأعلى
cd ~          # المجلد الرئيسي (home)
```

## إنشاء الملفات والمجلدات

```bash
mkdir projects        # إنشاء مجلد
mkdir -p a/b/c        # إنشاء مجلدات متداخلة
touch file.txt        # إنشاء ملف فارغ
```

## النسخ والنقل والحذف

```bash
cp file.txt copy.txt      # نسخ
cp -r folder1 folder2     # نسخ مجلد
mv file.txt /home/        # نقل
mv old.txt new.txt        # إعادة تسمية
rm file.txt               # حذف ملف
rm -r folder              # حذف مجلد
```

> ⚠️ **حذر شديد:** لا يوجد "سلّة محذوفات" في سطر الأوامر — `rm` يحذف نهائيًا!
> تجنّب `rm -rf /` تمامًا.

## عرض محتوى الملفات

```bash
cat file.txt       # عرض الملف كاملًا
head file.txt      # أول 10 أسطر
tail file.txt      # آخر 10 أسطر
less file.txt      # تصفّح تفاعلي
```

## البحث

```bash
find . -name "*.txt"      # البحث عن ملفات
grep "كلمة" file.txt       # البحث داخل ملف
```
