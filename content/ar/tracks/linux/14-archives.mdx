## tar (الأشهر)

```bash
tar -czf archive.tar.gz folder/    # إنشاء أرشيف مضغوط
tar -xzf archive.tar.gz            # فكّ الأرشيف
tar -tzf archive.tar.gz            # عرض المحتوى دون فكّ
```

شرح الأعلام: `c` إنشاء، `x` استخراج، `z` ضغط gzip، `f` اسم الملف، `t` عرض.

## gzip

```bash
gzip file.txt        # → file.txt.gz (يحذف الأصل)
gunzip file.txt.gz   # فكّ الضغط
```

## zip / unzip

```bash
zip -r archive.zip folder/    # ضغط
unzip archive.zip             # فكّ
```

## مثال عملي: نسخة احتياطية

```bash
tar -czf backup-$(date +%F).tar.gz /home/user/data
```

> 💡 `.tar.gz` هو الصيغة الأكثر شيوعًا لنقل المشاريع والنسخ الاحتياطية في Linux.
