## الطرفية والـ Shell: شيئان مختلفان

- **الطرفية (Terminal):** النافذة التي تكتب فيها وتقرأ النتائج. مجرّد واجهة: GNOME Terminal وWindows Terminal وiTerm2 كلها طرفيات.
- **الـ Shell:** البرنامج **داخل** الطرفية الذي يقرأ ما تكتبه، ويفسّره، ويشغّل البرامج. الأشهر **Bash** (الافتراضي في معظم توزيعات Linux) و**Zsh** (الافتراضي في macOS).

حين تتصل بخادم عبر SSH، طرفيتك على جهازك لكن الـ Shell يعمل على الخادم. ولمعرفة أي Shell تستخدم:

```bash
echo $SHELL     # مثلًا /bin/bash
```

## المحثّ (Prompt)

```text
baraa@server:~/projects$
```

المستخدم `baraa`، على الجهاز `server`، في المجلّد `~/projects` (و`~` اختصار لمجلّدك الرئيسي). و`$` في الآخر تعني مستخدمًا عاديًا، و`#` تعني `root`: إذا رأيت `#` فكل أمر تكتبه يملك صلاحيات كاملة على النظام.

## بنية الأمر

```bash
ls -l -a /home     # أمر، خياران، معامل
ls -la /home       # الخيارات القصيرة تُدمج
ls --all /home     # الخيارات الطويلة بشرطتين
```

```text
command  [options]  [arguments]
   ls      -la        /home
```

- **الأمر:** البرنامج الذي يُشغَّل.
- **الخيارات (options):** تغيّر سلوكه، وتبدأ بـ `-` (قصيرة) أو `--` (طويلة).
- **المعاملات (arguments):** ما يعمل عليه: ملف أو مجلّد أو نص.

والمسافة هي الفاصل بين الأجزاء. لذلك اسم ملف فيه مسافة يحتاج علامات تنصيص: `cat "my notes.txt"`، وإلا فهم الـ Shell أنهما ملفّان `my` و`notes.txt`.

## أوامر أولى

```bash
whoami          # اسم المستخدم الحالي
hostname        # اسم الجهاز
date            # التاريخ والوقت
echo "مرحبًا"   # طباعة نص
clear           # تنظيف الشاشة (أو Ctrl+L)
```

## اختصارات توفّر عليك ساعات

| الاختصار | يفعل |
| --- | --- |
| `Tab` | إكمال اسم الأمر أو الملف تلقائيًا (اضغطه مرّتين لعرض الاحتمالات) |
| `↑` و`↓` | تصفّح الأوامر السابقة |
| `Ctrl+C` | إيقاف الأمر الجاري |
| `Ctrl+R` | بحث في الأوامر السابقة |
| `Ctrl+A` و`Ctrl+E` | بداية السطر ونهايته |
| `Ctrl+D` | إنهاء الإدخال أو الخروج من الجلسة |

`Tab` وحده يمنع معظم الأخطاء الإملائية في المسارات: إذا لم يُكمل، فالمسار غالبًا غير موجود.

## الحصول على المساعدة

```bash
man ls          # الدليل الكامل (q للخروج، / للبحث)
ls --help       # ملخّص سريع للخيارات
type cd         # هل هو برنامج أم أمر مدمج في الـ Shell؟
```

`man` تعمل بلا إنترنت، وهي المرجع الرسمي. وأغلب الأوامر تقبل `--help` لملخّص أسرع.

### أمر مدمج أم برنامج؟

```bash
type cd         # cd is a shell builtin
type ls         # ls is aliased to `ls --color=auto' (أو /usr/bin/ls)
```

`cd` جزء من الـ Shell نفسه (لا يمكن أن يكون برنامجًا منفصلًا، لأن البرنامج لا يستطيع تغيير مجلّد الـ Shell الذي شغّله). أما `ls` فبرنامج في `/usr/bin`. ولهذا `man cd` قد لا تجد شيئًا، بينما `help cd` تعمل.

## أخطاء شائعة

- **`command not found`:** خطأ إملائي، أو البرنامج غير مثبّت، أو مجلّده ليس في `PATH` ([درس متغيّرات البيئة](/learn/linux/15-environment-variables)).
- **أسماء ملفات بمسافات بلا تنصيص:** الأمر يرى عدّة معاملات.
- **حالة الأحرف:** `LS` ليس `ls`، و`File.txt` ليس `file.txt`. Linux حسّاس لحالة الأحرف.
- **العمل كـ `root` دائمًا:** خطأ واحد بلا رجعة. اعمل كمستخدم عادي واستخدم `sudo` عند الحاجة.
- **لصق أوامر من الإنترنت دون فهمها:** خاصة ما يبدأ بـ `sudo` أو يحتوي `| bash`. اقرأ الأمر أولًا.
