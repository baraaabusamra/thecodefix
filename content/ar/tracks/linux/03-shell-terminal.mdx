## الطرفية والـ Shell

- **الطرفية (Terminal):** النافذة التي تكتب فيها الأوامر.
- **الـ Shell:** البرنامج الذي يفسّر أوامرك. الأشهر **Bash** (و**Zsh**).

## بنية الأمر

```bash
command [options] [arguments]
ls -l /home          # الأمر ls، الخيار l-، المعامل المسار
```

## أوامر أولى

```bash
whoami      # اسم المستخدم الحالي
date        # التاريخ والوقت
clear       # تنظيف الشاشة
echo "مرحبًا"  # طباعة نص
```

## المساعدة

```bash
man ls       # دليل الأمر الكامل
ls --help    # ملخّص سريع
```

> 💡 الرمز `$` في بداية السطر يعني أنك مستخدم عادي، و`#` يعني المستخدم الجذر (root).
