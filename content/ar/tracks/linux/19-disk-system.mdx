## مساحة القرص

```bash
df -h                # المساحة الكلّية لكل قسم (مقروءة)
du -sh folder/       # حجم مجلّد محدّد
du -sh *             # حجم كل عنصر في المجلّد الحالي
```

## الذاكرة

```bash
free -h              # الذاكرة المستخدمة والمتاحة
```

## معلومات النظام

```bash
uname -a             # معلومات النواة والنظام
uptime               # مدّة التشغيل والحِمل
lscpu                # معلومات المعالج
```

## الأقراص والتجزئة

```bash
lsblk                # الأقراص والأقسام
mount /dev/sdb1 /mnt # ربط قرص
umount /mnt          # فكّ الربط
```

> 💡 `df -h` و`du -sh` أوّل ما تستخدمه عند امتلاء القرص لمعرفة من يستهلك المساحة.
