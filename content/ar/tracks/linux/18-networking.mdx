## الاختبار

```bash
ping google.com       # اختبر الاتصال (Ctrl+C للإيقاف)
```

## تنزيل وطلب

```bash
curl https://api.example.com           # طلب HTTP
curl -O https://site.com/file.zip      # تنزيل بنفس الاسم
wget https://site.com/file.zip         # تنزيل
```

## الاتصال بخادم بعيد: ssh

```bash
ssh user@192.168.1.10        # دخول
ssh user@host -p 2222        # منفذ مخصّص
```

## نقل الملفّات: scp

```bash
scp file.txt user@host:/path/      # رفع
scp user@host:/path/file.txt .     # تنزيل
scp -r folder user@host:/path/     # مجلّد
```

## معلومات الشبكة

```bash
ip addr               # عناوين IP
netstat -tulpn        # المنافذ المفتوحة (أو ss -tulpn)
```

> 💡 `ssh` و`scp` أساس إدارة الخوادم البعيدة — استخدم مفاتيح SSH بدل كلمات المرور للأمان.
