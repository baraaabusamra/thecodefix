## الجدار الناري (Firewall)

يفلتر حركة المرور بناءً على قواعد، فيسمح بالمسموح ويمنع غيره.

- **حسب المنفذ:** اسمح بـ 443 (HTTPS)، امنع غيره.
- **حسب العنوان:** اسمح/امنع عناوين IP محدّدة.
- **حسب الاتجاه:** وارد (inbound) وصادر (outbound).

```bash
# مثال ufw على Linux
sudo ufw allow 443
sudo ufw deny 23
```

## VPN — الشبكة الخاصّة الافتراضية

ينشئ نفقًا مشفّرًا بين جهازك وخادم VPN، فيحمي بياناتك ويخفي عنوانك الحقيقي.

**الاستخدامات:**
- اتصال آمن عبر شبكات Wi-Fi عامّة.
- الوصول لشبكة الشركة عن بُعد.
- الخصوصية.

## كيف يعمل VPN؟

```
جهازك → [نفق مشفّر] → خادم VPN → الإنترنت
```

المواقع ترى عنوان خادم VPN بدل عنوانك.

## ملاحظة أمنية

VPN يحمي **النقل**، لكنه لا يغني عن HTTPS والمصادقة وتحديث الأنظمة.
