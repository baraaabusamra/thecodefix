## ما هو عنوان IP؟

**عنوان IP** رقم فريد يميّز كل جهاز على الشبكة، مثل عنوان منزلك.

```
IPv4:  192.168.1.10      (الأشهر)
IPv6:  2001:0db8:85a3::8a2e:0370:7334   (أحدث، أكبر)
```

## IP عام مقابل خاص

| النوع | الاستخدام |
|-------|-----------|
| **عام (Public)** | يميّزك على الإنترنت |
| **خاص (Private)** | داخل شبكتك المحلية (192.168.x.x) |

## ما هو DNS؟

البشر يتذكّرون الأسماء لا الأرقام. **DNS** (Domain Name System) هو "دليل
هاتف الإنترنت" الذي يترجم الأسماء إلى عناوين IP:

```
thecodefix.com  ──(DNS)──→  76.76.21.21
```

## كيف يعمل DNS؟ (مبسّط)

1. تكتب `thecodefix.com`.
2. يسأل جهازك خادم DNS: "ما عنوان IP لهذا الاسم؟"
3. يردّ خادم DNS بالعنوان.
4. يتّصل المتصفّح بذلك العنوان.

## أنواع سجلّات DNS الشائعة

| السجلّ | الوظيفة |
|--------|---------|
| `A` | يربط اسمًا بعنوان IPv4 |
| `AAAA` | يربط اسمًا بعنوان IPv6 |
| `CNAME` | اسم بديل لاسم آخر |
| `MX` | خوادم البريد |

> 💡 عند ربط نطاق بموقعك (كما في Vercel)، تضيف سجلّ `A` أو `CNAME` عند مزوّد
> النطاق — هذا تطبيق عملي مباشر لما تعلّمته!
