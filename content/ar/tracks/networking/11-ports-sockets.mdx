## ما هو المنفذ (Port)؟

رقم يميّز خدمة/تطبيقًا على نفس الجهاز. العنوان يحدّد **الجهاز**، والمنفذ يحدّد **الخدمة**.

```
192.168.1.10:443
└─── الجهاز ───┘ └منفذ┘
```

## المنافذ الشهيرة

| المنفذ | الخدمة |
|------|------|
| 80 | HTTP |
| 443 | HTTPS |
| 22 | SSH |
| 21 | FTP |
| 25 | SMTP (بريد) |
| 53 | DNS |
| 3306 | MySQL |
| 5432 | PostgreSQL |
| 27017 | MongoDB |

## نطاقات المنافذ

- 0–1023: معروفة (well-known).
- 1024–49151: مسجّلة.
- 49152–65535: ديناميكية/مؤقّتة.

## المقبس (Socket)

دمج عنوان IP + منفذ = نقطة اتصال فريدة:

```
93.184.216.34:443
```

## أداة فحص

```bash
netstat -tulpn      # المنافذ المفتوحة (Linux)
```

> 💡 عند تشغيل خادم محلّي على `localhost:3000`، 3000 هو المنفذ الذي يستمع عليه تطبيقك.

> 🎯 التالي: HTTP و HTTPS.
