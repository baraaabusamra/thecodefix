## الأجهزة الرئيسية

| الجهاز | الوظيفة |
|------|------|
| **المودم (Modem)** | يربط بيتك بمزوّد الإنترنت |
| **الراوتر (Router)** | يوجّه بين الشبكات + يوزّع الإنترنت |
| **السويتش (Switch)** | يربط أجهزة LAN |
| **نقطة الوصول (Access Point)** | تتيح الاتصال اللاسلكي (Wi-Fi) |
| **الجدار الناري (Firewall)** | يفلتر حركة المرور للحماية |

## في المنزل

غالبًا يدمج جهاز واحد عدّة وظائف:

```
الإنترنت → مودم/راوتر (+ سويتش + Wi-Fi مدمج) → أجهزتك
```

## في الشركات

أجهزة منفصلة ومتخصّصة:

```
الإنترنت → جدار ناري → راوتر → سويتشات → الأجهزة + نقاط وصول
```

## أجهزة أخرى

- **Load Balancer:** يوزّع الحمل على عدّة خوادم.
- **Proxy:** وسيط بين العميل والخادم.
- **Repeater:** يقوّي الإشارة لمسافة أبعد.

> 🎯 التالي: الشبكات اللاسلكية.
