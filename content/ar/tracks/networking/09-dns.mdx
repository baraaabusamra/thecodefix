## ما هو DNS؟

"دليل هاتف الإنترنت": يحوّل الأسماء المقروءة (`example.com`) إلى عناوين IP (`93.184.216.34`).

## عملية الاستعلام

1. تكتب `example.com` في المتصفّح.
2. يسأل جهازك خادم DNS.
3. يبحث عبر التسلسل: الجذر → نطاق `.com` → خادم النطاق.
4. يعيد عنوان IP، فيتّصل المتصفّح بالخادم.

## أنواع السجلّات

| السجلّ | الوظيفة |
|------|------|
| `A` | اسم → IPv4 |
| `AAAA` | اسم → IPv6 |
| `CNAME` | اسم بديل (alias) |
| `MX` | خادم البريد |
| `TXT` | نصّ (تحقّق، SPF) |
| `NS` | خوادم الأسماء |

## التخزين المؤقّت (Caching)

تُخزَّن النتائج مؤقّتًا (TTL) لتسريع الزيارات التالية وتقليل الحمل.

## أدوات

```bash
nslookup example.com
dig example.com
```

> 💡 تغيير DNS قد يستغرق وقتًا للانتشار (propagation) حسب TTL.

> 🎯 التالي: TCP و UDP.
