## HTTP — بروتوكول الويب

يحكم تواصل المتصفّح مع الخادم: طلب (Request) → استجابة (Response).

```
GET /index.html HTTP/1.1
Host: example.com
```

## HTTPS — النسخة الآمنة

HTTP فوق طبقة تشفير (TLS). يحمي البيانات من التنصّت والتلاعب.

```
https://example.com   ← القفل في المتصفّح
```

## الفرق

| | HTTP | HTTPS |
|---|---|---|
| التشفير | لا | نعم (TLS) |
| المنفذ | 80 | 443 |
| الأمان | بيانات مكشوفة | بيانات مشفّرة |

## لماذا HTTPS إلزامي اليوم؟

- يحمي كلمات المرور والمعلومات الحسّاسة.
- المتصفّحات تحذّر من مواقع HTTP.
- مطلوب لميزات حديثة و SEO.

## إصدارات HTTP

- **HTTP/1.1:** الكلاسيكي.
- **HTTP/2:** أسرع (تعدّد الإرسال).
- **HTTP/3:** فوق UDP (QUIC) لزمن وصول أقلّ.

> 💡 احصل على شهادة SSL مجّانية من Let's Encrypt لتفعيل HTTPS.
